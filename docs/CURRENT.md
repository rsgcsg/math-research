## 2. 重审后的唯一主攻与两条备线

主攻是**任意支持的完整联合分离**，而不是把m机械改成4、5、6。
对所有proper完整划分c，列D_c记录15域的源/像完整模式差。精确目标仍是二择：

```
正：同一个λ≥0，Σλ=1，Dλ=0；
负：有理势y与δ>0，使每个合法完整c都有 y·D_c≥δ。
```

负证据一旦真实取得，T105已有有限实际NON5编译；当前缺的仍是这个全词严格间隙。
S已正解决，故势必须使用其外八个完整域的信息。
E111关闭的u全域加12二点事件、E105固定词池的cut都不能升级为全词负证据。
E115已继续检查新S极点加入旧种子：三轮候选势均被合法零值完整词击破，每轮增加30模式行。
最终11词/235行仅有池内分离，仍UNKNOWN；停止把换种子和机械加轮次当主攻。
补充负阈值探针又给第一份势的价格−1合法词，故它甚至不能作全词非负的支持缩小切面。
下一候选必须提供超出E111旧族的跨运动事件关系，并先接受合法零值词的证伪。
这里“跨运动”指多个合法运动差势的组合，不允许未经证明的同步乘积。

几何备线：域外、异中心的实际有限图及其**自由**五色端口关系；不等待无限接触全部穷尽才找有限下界。
上界备线：全有限实代数单位配置的统一≤6，或严格零坏边极限；尚无共尾构造。
因此χ=6仍有两项独立终局义务：真实NON5下界、全配置六色上界。没有可诚实汇报的完成百分比。
