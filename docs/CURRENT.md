## 4. 剩下的不是“漏跑一个结尾”，而是完整颜色关系的缺口

固定Ω₅(Y)为Y的全部合法至多五块划分。固定各完整域D_j的点顺序，并由g_j传送到像。
令a_j(c)、b_j(c)分别为源、像的完整划分，定义

```text
D[(j,p),c] = 1[a_j(c)=p] - 1[b_j(c)=p].
```

问题是是否存在 `λ≥0, Σλ=1, Dλ=0`。列是全部Ω₅(Y)，所有运动必须用同一个λ。
支持、正权、颜色命名及匹配可以改变，不额外要求局部匹配满足全局几何群关系。

## 5. 三个真实难点，以及哪个“复杂”只是表示现象

**A. 全自由五染色，而不是指定背景。** 六点单位星K₁,₅可二染；五叶分别预染五色时，
中心却无法延拓。这说明“边界状态无解”只是否定那份预染色。
从旧算子、支持群或参考配色得到的强迫，必须证明对所有合法自由重染仍成立。
T133–134使等式层可以分离，但没有消掉恰一色与边排斥的联合约束。

**B. 组合强迫必须在二维同时实现。** 抽象CSP强不等于单位图可实现；几何真的逃域也
不等于颜色关系收缩。T123九点图兼有真实CM逃逸和原端口关系不变，说明两者可完全分离。
共用对象是 `G→U(R²)` 的几何承诺与 `Hom(G,K_k)` 的完整关系；缺一侧都不能证明新界。

**C. 某宿主可染与全域覆盖不同。** 单个数域、单个无限轨道或任意多已算窗口可染，
没有证明所有有限实代数配置可染。难染有限投影H亦不能由`G→H`反推G难染。
上界需要真正的共尾/兼容延拓或严格零坏边极限，不是分母、精度或样本数量增长。

134个T编号、模型状态数、非交换群阶数和累计SAT冲突，不是离原答案的距离量。
本项目没有经过校准的成功概率、剩余步数或规模估计，不能据此说“已经接近六色”。
