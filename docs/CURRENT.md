## 3. 研究顺序修正：有限下界不必等待无限例外穷尽

此前将“T139有限例外有效找全”写成几何下界搜索的前置关口，要求过强。
给定有限精确点集V，只要所列E₀中的每条边确实长1且(V,E₀)不可五染，
那么实际单位图(V,E_unit)因E₀⊆E_unit也不可五染。遗漏真边不损害负结论；伪边会。
反方向，给所列子图一个五染色不证明诱导图或无限宿主可染。

因此可以立即从有限旋转片段与非零平移副本构造候选，逐条精确认证单位边，
再允许全部顶点自由重染。**T139有效穷尽服务于完整无限接触描述/正延拓，不是有限NON5证据的必要前提。**
完整证明、双接触平移公式和便宜排除条件在[构造入口](proofs/next_attack_gate.md)。

初等排除条件：两个不相交的可k染块若总共最多k−1条跨边，总能通过重命名一块的颜色一起k染。
对k=5，只发现2–4条跨边的无交点拼合不值得宣称五色压力；交点存在时必须另处理其同色识别。
五条跨边只是越过这条排除线，不是不可五染的充分条件。
本次双接触公式检查121个有理中心差、92个精确根，并穷举16024种小调色板禁配矩阵；
一个双接触菱形仍恰三色。它们只校准构造接口，不是Y上的新大型搜索或新的T/E结果。

## 4. 收敛到一个主攻、一个几何备线、一个独立上界问题

**主攻：跨运动联合事件与配套完整词。** 从其他运动的实际联合划分信息提出共享势，

负候选用精确整数目标和独立RUP通道检查；CNF中score≤0不可满足才给整数正间隙≥1。
score≤−1不可满足仅给≥0。受限模型UNSAT、预算耗尽、非支持证明步骤不改变全词状态。

**几何备线：有限异中心接触核。** 选两对跨副本端点，从双接触方程直接求代数平移，
而不是先扫大量任意小数。保留交点和跨边端点，在自由颜色关系上检验是否产生新限制；

构造公式不保证会产生强迫；找到一个非零距离的无条件五色等色对已足以经T014编译NON5。
