## 3. 原始问题、固定实例与受限模型三层量词

令Ω₅(Y)是整个实际图Y的全部合法五色划分，各运动最大域给源/像划分a_j(c)、b_j(c)，
`D[(j,p),c]=1[a_j(c)=p]−1[b_j(c)=p]`。当前有限目标仍是

```
存在 λ≥0，Σλ=1，Dλ=0；所有15个运动共享同一λ，列来自全部Ω₅(Y)。
```

不能固定五个词、旧颜色作用、支持群或词池来替代全部列。
正证书须检查整个Y的所有实际边及每个完整域的完整分布；各运动分别有解不足。
负证书须给有理y和δ>0，独立证明 `yᵀD_c≥δ` 对每一合法c成立，然后才能用T105编译NON5。
E105的一般大规模定价UNSAT独立认证后端仍未实现；程序诚实保存UNSAT_UNCERTIFIED。
本次30个已记录价格查询均有SAT反例，不存在一个现成全词UNSAT结果只等“补盖章”。

固定15域实例可能可行；正解只退休该实例，不证明全平面五染色。

## 4. 主要真实难点与建议主攻

**全自由颜色关系。** 固定预染色、支持群或等式类的失败，都可能被重新选择色词/权重修复。
T133–134已经显示仅拆等式变量不是升色机制；必须同时保留恰一色、所有单位边排斥和共同分布。

**二维实现和组合强迫须同时成立。** 抽象高色图可能不可单位实现；新数域、新方向或高密度
又可能不增加颜色限制。T123的九点CM逃逸仍χ4且不改旧端口关系，是明确反例。

**局部正解不能替代全配置上界。** 指定数域、单u无限轨道和有限精度样本都不能覆盖全部
有限实代数配置；源图映向难染目标也不能反推源图难染。

主攻保持一个有限实例的全词共同律/严格分离，但不再机械延长同一列生成：

- **配套列而非孤立列：** 同时设计多个合法词，使新增模式行能在所有运动间闭合；支持和权重可变。
  输出必须是完整Y上的词和精确权重，不能只给边界模式的假想循环。
- **共享事件势而非只标记已见完整模式：** 尝试用相等关系等小事件的共同规则给所有模式赋势，
  避免新词两侧全部落入零系数区。它只是一条研究方向；不声称小事件对任意支持正律完备。
  负式仍须在整个proper空间验证；正律仍须完整域验收。
- **把负认证后端做实：** 精确绑定几何、事件编码、整数目标与CNF/PB证明，独立检查UNSAT；
  此工程缺口与“是否存在分离式”的数学缺口分开，完成前者不保证后者。

几何备线只保留能收缩自由五色端口关系的实际接触核；不同点被所有五染色强迫同色是T014的
充分突破目标，不是可免费使用的元件。上界备线须提出覆盖所有有限实代数配置的统一≤5/≤6
存在论证或严格零坏边极限。停止同Y只加u幂、纯群复杂度升级和固定精度样本循环作为独立主攻。

这些优先级来自已有证据，不是成功概率或剩余步数估计。研究编号、状态数和SAT成本都不是
离原问题答案的距离。可直接完成的归并/验收/归档已经处理；开放的数学量词不因清理而消失。
