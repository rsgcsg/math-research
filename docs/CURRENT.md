# 当前研究状态：外部无五染已核验，研究转向有限见证与6/7终局

2026-10-07。OpenAI Family158在普通任意染色意义下证明平面不可五染；本轮已在固定原源码、Lean4.34.1及固定Mathlib上实际编译该目标，显式核对命题及三项标准基础公理。**普通范围现在为6≤χ(R²)≤7，这是外部结果，不是本项目原Y搜索得出的新下界。**

## 本轮得到的结构结果

设F⊂R为代数子域，对正平方根闭合，且F(i)的范数一群可除。对于其中任意正距离集Δ、每个有限k，F²的距离-Δ图可k染，当且仅当R²相应图可k染。最大可解代数扩张的实部F_sol满足这些条件。

因此 χ(U(F_sol²))=χ(U(R²))∈{6,7}；某个正规闭包可解的有限实数域已经达到全平面的色数。还存在根式坐标的有限恰六色单位图，但没有输出坐标、顶点数或有效搜索界。

这不是所有有限图的重新实现：X⁵−X−1的正根不在F_sol，结合有限Beckman–Quarles强迫，存在不能单位同态到F_sol²的有限平面单位图。T122排除的同态普适性与本轮得到的色数极值共尾性不同。

新结果使用分支限定R158-H/T/S/N，不覆盖并行T170等编号；状态是依赖固定Family158分析引理的书面证明。新子域推广尚未Lean形式化、未外部同行复核。有限算术程序的PASS不等同于这个无限定理的机器证明。

## 追加闭合：有限二点模板与旋转群不足性

[R158-C](proofs/radical_finite_template_transfer.md)把同色禁配推广到任意有限标签集、
按正距离给定的对称允许关系。F_sol²与R²对每一个这样的模板具有相同存在性答案。
关键新步骤是利用旋转−1与极化，证明连续因子投影保留所有不同颜色的非零位移交叉相关，
再以正坐标选标签保留零禁配。特别地，每个有限(a,b)多重染色与有理循环模板答案相同。
未给任何新分数/循环色数的数值，未把任意高阶CSP归入该结论。

[R158-F](proofs/finitely_generated_rotation_rigidity_obstruction.md)独立证明：

这个谱反例不是proper染色，不决定full15，也不否定有限图证据的存在。

## 原问题的准确剩余义务

**6还是7：** 统一证明F_sol²可六染就足够得到全平面恰六色；或者在F_sol²找到有限不可六染图，就得到恰七色。本轮均未完成。

**显式下界：** 外部证明及本轮推广保证有限不可五染根式图存在，但没有给出实用规模。本项目的几何/CSP/全词分离工具仍可用于输出真正可重放的显式见证。固定Y的full15仍可能可行；外部无五染不能代替它的判定。

**已停止的捷径：** 不继续把5→6作为公开未知界；不把“可解根式”缩成“尺规平方根”；不把支持群可解性与坐标域Galois可解性混同；不直接将五色palette证明中的5替成6。
