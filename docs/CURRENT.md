## 3. 本轮新数学：非零平移并不需要无分类地扫描

[T139](proofs/translated_rotation_contacts.md)：对任意有限秩单位旋转群H、a,b,t非零，
`|a x-(t+b y)|=1, x,y∈H`，除下列三族外只有有限多解：

```
a x=t, |b|=1；   b y=-t, |a|=1；   a x=b y, |t|=1。
```

前两类是副本中心星，第三类是单位平移匹配。任意有限轨道宿主S与t+S之间，
除副本已有边和可能的平移匹配外，只有有限新增边。
完整证明把六/七项Laurent式按最小零和块分解，用ESS Theorem1.1控制比值；
指数差格秩二给有限纤维，秩一只有上述三类。有限秩足够，不要求H本身有限生成或系数代数。

这比T138的“交点有限”更强：现在分类了单位接触。但它仍**不是有效穷举器，也不是五色延拓**。
数量界 `4·877·exp(3·36^18·(2r+1))` 不给最大指数。
固定v=(3+4i)/5，取t_N=v^N−2，已能让真正例外出现在任意大指数N；
不能从“例外数量有限”直接拿一个固定扫描窗口充当完整证明。
