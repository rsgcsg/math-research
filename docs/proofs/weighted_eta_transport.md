# T144：固定点正规形的加权版本：不用复制原子，也不要求确定性匹配

2026-09-28。接续已发布 a885b67c。以下是自足的结构证明；它不是原15域无解或HN新界的断言。
当前搜索和负认证的结果另行保存，不能从本正规形推断它们已经成功。

## 1. 任意兼容边图上的平凡调色板

设 X 是有限点集，g 是环境上 r 阶置换，D=X∩g^{-1}X。假定 X 含固定点 o，
含 g-封闭的 R 且 χ(G[R])≥k−1，并且 gcd(r,(k−1)!)=1。
取任意有限族合法 k 色词 c_i。允许在索引间选任意有向边 i→j；每条边只要求
c_j(gx)=π_ij(c_i(x)) 对所有 x∈D 成立，π_ij 是颜色置换。
这里不要求边形成置换，不要求每个顶点只有一个入边或出边。

**命题。** 存在各词的颜色重命名 q_i，使每一条选定边都成为
f_j(gx)=f_i(x)，其中 f_i=q_i∘c_i。各完整颜色划分不变。

证明：在边图中允许沿反向边行走，其作用分别为 g^{-1} 和 π_ij^{-1}。
任意闭合游走从状态 i 返回 i。设几何指数的有向和为 n，调色板乘积为 P。
对每个 x∈R，游走所有中间几何点均在R，因而
c_i(g^n x)=P(c_i(x))。重复整个游走 r 次给 P^r(c_i(x))=c_i(x)。
在固定点处同一游走又给 P(c_i(o))=c_i(o)，所以 P 的阶整除 (k−1)!。
与 r 互素保证 Fix(P^r)=Fix(P)。R上至少使用k−1色，故P固定至少k−1色，P=id。
这对每个闭合游走都成立，而不只是某个状态置换的循环。

在边图每个无向连通分量选根及一棵树，固定根的q；沿边递推 q_j=q_iπ_ij^{-1}。
所有闭路乘积平凡保证定义与路径无关，并给 q_jπ_ijq_i^{-1}=id。证毕。

其他运动仍可把调色板共轭为 q_jρq_i^{-1}；更直接地，所有完整划分都没改变，
所以任意其他划分概率条件同时保留。不能同时未经证明消除其他运动的调色板。

## 2. 对任意实权重共同律的应用

设 μ=Σ_i λ_i δ_[c_i]，λ_i>0，Σλ_i=1，源、像的完整D划分分布相等。
记源模式为 A_i，像模式为 B_j。对每个模式p，公共总质量为
w_p=Σ_{A_i=p}λ_i=Σ_{B_j=p}λ_j。令

T_ij = λ_i λ_j / w_p  （A_i=B_j=p时），否则为0。

则T的行和与列和都等于λ。对每条T_ij>0的边，模式相等可提升为某个颜色置换π_ij。
应用第1节，得到同样的原子数、同样的原权重和同样的完整划分，但现在

Σ_i λ_i δ_(f_i|D) = Σ_i λ_i δ_((f_i∘g)|D)

作为有颜色名称的整个元组分布也相等。

因此正规形并不需要权重有理，不需要放大分母，不需要将m个不同划分复制成更多等权状态。
它不声称每份词分别g不变，也不把加权运输T强行改为保持原子权重的置换。

甚至可一次对Ω_k(X)中每个完整划分选一个代表，并加入全部兼容的g边。
该有限图的所有闭路仍平凡，所以可得到一套与具体概率律无关的统一颜色命名。
这是存在性正规形；不声称枚举Ω_k(X)在计算上可行。

原Y完整η域的固定点、36点闭合四色子图和gcd(5,24)=1，均由
[已有正规形及独立检查](anchored_eta_normalization.md)给出，故本加权版本直接适用。

## 3. 权重(2,1,1)的匹配只需三类，但必须包含拆分

令A_0,A_1,A_2是三个源模式，B_0,B_1,B_2是三个像模式。
加权多重集相等

2δ_A0+δ_A1+δ_A2 = 2δ_B0+δ_B1+δ_B2

当且仅当以下三类至少一类成立：

1. A0=B0，A1=B1，A2=B2；
2. A0=B0，A1=B2，A2=B1；
3. A0=B1=B2，B0=A1=A2。

证明：A0=B0时消去两单位质量，余下是二元素多重集相等。
A0≠B0时，右侧唯一能提供A0的两单位质量的是B1、B2同时等于A0；
同理A1、A2同时等于B0。反方向逐式代入即可。

对η，第1节使每条相等关系直接成为逐字母相等；三类的有向运输边分别为
[(0,0),(1,1),(2,2)]、[(0,0),(1,2),(2,1)]、[(0,1),(0,2),(1,0),(2,0)]。
在其他运动上仍须允许每条关系各自的颜色置换，不能偷用η的正规形。

结合已有三原子权重分类，这给原15域三原子查询的六个完备情形：
等权的η支持循环型1+1+1、2+1、3；以及(2,1,1)的以上三类。
六个情形须分别具有正确的存在编码及独立负证据，才可声称没有三原子律。
任何未认证UNSAT、UNKNOWN或未执行的情形都不能跳过；即使六类全被排除，也不否定任意支持。

## 4. 最小机制校准：保持权重的置换并不完备

取真实四点X={0,a,ga,z}，a=(10,0)，g为绕原点120度旋转，z=(0,20)。
其诱导单位图无边，完整g域只有{0,a}，固定集合R={0}。
取k=2，则χ(R)=1=k−1且gcd(3,1)=1。按上述四点顺序的三个色词为
0010、0100、0101，权重分别为1/2、1/4、1/4。
源模式为同色、异色、异色，像模式为异色、同色、同色，故加权完整律成立。
三个完整划分彼此不同。唯一半质量原子若被保持权重的状态置换匹配，必须匹配自身，
但它的源像模式不同。因此没有这样的确定性权重保持置换，必须允许第三类拆分运输。
这里故意使用无边图隔离概率表示机制，不把它当成任何色数下界证据。

## 5. 意义与边界

这是对任意实权重和全部有限支持都成立的精确表示简化，比固定m等权的循环正规化更强。
它为先前遗漏的非等权分支提供不增加原子数的直接编码；但原始任务仍是同一个律同时满足
全部15个完整域，或全合法色词上的严格分离。表示定理不是该任务的答案。
