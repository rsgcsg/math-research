# R2026-K23-COLLISION：近单位 K₂,₃ 的最优碰撞尺度 Θ(√ε)

2026-11-06。接续[近单位图稳定性和碰撞同态](near_unit_graph_stability_and_collisions_20261106.md)。数学问题：在ε>0的近单位平面点图中，经典精确单位距离禁止的K₂,₃可以出现，但五个点必须以多快的尺度趋近碰撞？本页给出**全配置统一的定量上界6√ε和具有同阶下界的显式五点构造**，不依赖Voronov或OpenAI下界，不证明 χ(ℝ²)=7，不宣称已有几何估计的文献优先权。精确有理数校准程序为 research/verify_quantitative_k23_collision.py。

## 1. 定理及几何意义

**定理K。** 对0<ε≤1/16，若平面中五个不同点 A,B,C,D,E 满足
\[
1-\varepsilon\le\|U-V\|\le1+\varepsilon
\quad\text{对所有 } U\in\{A,B\},\ V\in\{C,D,E\},
\]
则五点中存在两个点P≠Q使
\[
\boxed{\|P-Q\|\le6\sqrt{\varepsilon}.}\tag{1}
\]
这个结论允许左侧两点互不相邻、右侧三点互不相邻；它是**抽象K₂,₃作为边子图出现时**的几何限制，不要求恰为诱导K₂,₃。

指数1/2不可改进成任何更大的幂：对每个0<ε≤1/16取
\[
A=(-1,0),\ B=(1,0),\ C=(0,0),\
D=(0,\sqrt\varepsilon),\ E=(0,-\sqrt\varepsilon).
\]
A、B至C的边长为1，至D、E的边长为√(1+ε)∈(1,1+ε)。五点全部不同，五点的最小两两距离**恰为√ε**。故在任何统一的碰撞距离估计中，√ε的幂次是最优的；数值常数6未声称最优。

推论：如果五点之间的最小距离至少σ>0，ε≤1/16，则含全部六条近单位边的K₂,₃要求
\[
\boxed{\varepsilon>\frac{\sigma^2}{36}.}\tag{2}
\]
对一张有限点集最小间距为σ的区间距离图，ε<min(1/16,σ²/36)时必K₂,₃-free；若等号处需要区分严格性，可改为≤并依定理严格不等号处理。这个估计量化了上一轮的“非邻点碰撞”同态边界。

## 2. 无任何光滑性假设的初等证明

令d=||A−B||>0，作刚体变换把A移到(0,0)、B移到(d,0)。对任意右侧顶点U=(x_U,y_U)，记r_A(U)=||U−A||、r_B(U)=||U−B||。

因为r_A,r_B∈[1−ε,1+ε]，
\[
r_A(U)^2-r_B(U)^2=2dx_U-d^2
\quad\Rightarrow\quad
\left|x_U-\frac d2\right|\le\frac{2\varepsilon}{d}.
\]
任意右端U,V因此满足
\[
|x_U-x_V|\le\frac{4\varepsilon}{d},\qquad
|x_U^2-x_V^2|\le\frac{10\varepsilon}{d}
\]
（第二式用|x_U|,|x_V|≤1+ε≤5/4）。同时 |r_A(U)^2−r_A(V)^2|≤4ε，故
\[
\boxed{|y_U^2-y_V^2|\le4\varepsilon+\frac{10\varepsilon}{d}.}\tag{3}
\]

在C,D,E中必有两个U,V的y坐标同号（把零分配到任意一侧）；同号时
\[
|y_U-y_V|^2\le|y_U^2-y_V^2|.
\]

分三种情况：

1. **d≤6√ε。** A、B本身即满足(1)，包含等号。
2. **d≥1。** 从(3)及横坐标差得
   \[
   \|U-V\|^2\le16\varepsilon^2+14\varepsilon\le15\varepsilon<36\varepsilon,
   \]
   因ε≤1/16。
3. **6√ε<d<1。** 对三个右端有
   \[
   |x_U|\le d/2+2\varepsilon/d<1/2+\sqrt\varepsilon/3\le7/12.
   \]
   而r_A(U)≥1−ε≥15/16，所以
   \[
   |y_U|^2\ge(15/16)^2-(7/12)^2
   =1241/2304>1/4,
   \]
   即每个|y_U|>1/2。同号的U,V于是满足
   \[
   |y_U-y_V|
   =\frac{|y_U^2-y_V^2|}{|y_U|+|y_V|}
   <4\varepsilon+\frac{10\varepsilon}{d}
   \le\sqrt\varepsilon+\frac53\sqrt\varepsilon
   =\frac83\sqrt\varepsilon.
   \]
   另有|x_U−x_V|<2√ε/3，故
   \[
   \|U-V\|^2<
   \left(\frac49+\frac{64}9\right)\varepsilon
   =\frac{68}9\varepsilon<36\varepsilon.
   \]

综上可一律采用
\[
\boxed{\min_{P\ne Q}\|P-Q\|\le6\sqrt\varepsilon.}
\]
边界d=6√ε时可能恰好等号，所以这是本定理正式的非严格版本；不以形式上多余的严格号或严格阈值冒充证明。证明完毕。

## 3. 为什么这直接帮助审计七色候选？

上轮R2026-UNIT-STABILITY-A证明：ε<3−2√2的**任何**近单位平面图都K₄-free；但K₂,₃不同，精确单位图禁止K₂,₃作为五互异点的子图，正ε区间图却可存在。

本轮说明后者不是一个无结构的漏洞：**每份近单位K₂,₃都携带一对间距O(√ε)的逼近碰撞。**因此若近单位图采样使用最小网格点间距σ，并且ε≤1/16，K₂,₃在ε<σ²/36时自动消失。对之前O(ε^{-2})网格图，其采样间距本身也随ε缩小，不能据(2)直接消除所有K₂,₃。对从近单位图搜索精确NON6的算法，应把非邻点合并类作为合法的同态极限，不得要求所有原顶点都保持正距离分离。

这个尺度定理没有证明六色不可能，也没有给出前轮所缺的**统一顶点数N**或共同不可六染图H。它关闭的是有限ε网格中一种最基本的几何退化形式，并给出可直接纳入候选筛选和形变证书的严格容差。
