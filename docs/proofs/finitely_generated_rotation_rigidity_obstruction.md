# 稠密有限生成旋转不能替代全部代数旋转的 Haar 刚性

2026-10-07。分支限定 `R158-F`。完整的对偶群反例；不依赖Family158无五染定理。
只用离散阿贝尔群对偶、Haar概率及有限代数扩张。不是染色存在性证书。

## 1. 一般障碍

设E⊂C是一个域，N⊊E是包含Q(i)的真子域，H⊂N^×为任意群。
令D=Hom(E_add,T)，并令C_E是普通连续字符在E上的限制。
通常字符的频率参数化是从R²到D的连续映射；其闭球像紧，故C_E为可数个闭集的并，是Borel集。
在D中取闭子群

\[
A=N^\perp=\{d\in D:\ d(n)=1\ \text{对每个 }n\in N\}.
\]

令ν为A的归一化Haar概率，并视为D上的概率。

**定理 R158-F。** ν是H-不变概率，ν(C_E)=0，但ν不是整个D上的Haar概率。
更精确地，

\[
\boxed{\widehat\nu(z)=\mathbf1_N(z)\quad(z\in E).} \tag{1.1}
\]

**证明。** A是紧群D中闭条件的交，因此紧。若h∈H，则hN=N，
预合成d↦(z↦d(hz))是A的自同构；Haar概率唯一性给出H-不变性。

若z∈N，所有d∈A均有d(z)=1，故Fourier系数为1。
若z∉N，选一个Q-线性函数ℓ:E→R，满足ℓ|_N=0、ℓ(z)=1，
先在N⊕Qz上定义，再沿Q-基扩张。字符d_0(w)=exp(iπℓ(w))属于A且d_0(z)=−1。
用A内的平移d↦d_0d及Haar不变性，积分等于其负值，故为0。这证明(1.1)。

E/N是非零Q-向量空间，A无限：对于所选z，字符exp(itℓ(·))随实数t给出无限多个不同元素。
因此A的Haar概率给每个点零质量（所有点等质量，且任意多个点的总质量≤1）。
若一个普通连续字符属于A，它在稠密子集Q(i)上为1，连续性迫使它在C上为1。
所以A∩C_E仅含平凡字符，ν(C_E)=0。
但ν在非零频率1上的Fourier系数为1，整个D的Haar概率在该频率上为0，二者不同。证毕。

## 2. 任意有限生成的代数旋转群都受此障碍

取E=L_sol，或取全部复代数数。给任意有限生成旋转群
H=<u_1,...,u_s>⊂{z∈E:|z|=1}，令N=Q(i,u_1,...,u_s)。
它是有限数域，因而真小于E。例如取素数p>[N:Q]，由Eisenstein判别，
2^(1/p)的次数为p，不能在N中，却属于L_sol。
应用定理得到一个H-不变的wild概率，却不是Haar。

结论即使H在普通单位圆中稠密，甚至有多个乘法独立生成元，也不改变。
这里说的是**有限生成**，不是把所有有限秩群一并处理；无限根闭包可能有无界代数次数。
也没有证明“任何具体有限颜色证明都必须使用无限多个旋转”。紧致性仍可最终提取有限配置。

## 3. 一个具体的稠密例子

取H由u=(3+4i)/5生成，N=Q(i)，E=L_sol。
u不是单位根：若是，则u+u^(-1)=6/5既是代数整数又是有理数，必须为整数，矛盾。
因此H是无限循环群；圆群的闭真子群有限，故H在通常圆周中稠密。

反例的Fourier系数是

\[
f(z)=\begin{cases}1&z\in\mathbb Q(i),\\0&z\notin\mathbb Q(i).\end{cases}
\]

它正定，因为对任意有限z_j和复数a_j，按加法商E/N的陪集分组，有

\[
\sum_{j,k}\overline{a_j}a_k f(z_k-z_j)
=\sum_{B\in E/N}\left|\sum_{j:z_j\in B}a_j\right|^2\ge0.
\]

它不是通常连续函数：选有理r_n→√2，z_n=√2−r_n→0，但f(z_n)=0而f(0)=1。
它也不在全部K下径向不变：|(1+i)/√2|=1，但f((1+i)/√2)=0、f(1)=1。
因此不能用“旋转群稠密”加连续延拓来抹去这个反例；连续性正是尚未拥有的性质。

## 4. 对full15路线的确切含义

现有任何固定有限个代数刚体运动，其旋转系数都落在同一个有限数域。
本定理否定的是如下无额外假设的移植：
“只在这些旋转下不变且谱避开连续字符 ⇒ 谱就是Haar”。
平移谱概率、颜色指标、单位边零相关还有额外结构；本反例未满足或未检验那些结构。
所以不能反向声称full15必可行，也不能把这条方法障碍算成一个五染色。

有效的下一步必须利用颜色指标的共同乘法/正性关系排除这种谱，
或在可认证的有限化中增加真正需要的域和旋转闭包，
而不是只对旧H的指数加深、再援引上游的全K刚性。

有限有理坐标校准见`research/verify_radical_template_mechanism.py`。
它直接核对Q(√2,i)样本的陪集Gram矩阵、反射和有理旋转；一般性由本页证明承担。
