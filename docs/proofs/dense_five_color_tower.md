# T083：保留11进五色上界的高密度CM塔

2026-09-10。这里的域始终按通常复嵌入作为平面子集。
本条统一“分裂素数产生更多单位方向”与“另一个局部赋值控制颜色”
两种机制，**不改进原始Hadwiger–Nelson上下界**。

## 1. 精确结论与证据层级

存在包含`F_core=Q(i,√3,√5,√11)`的嵌套CM数域序列E_j，使得：

- 每个整个E_j的诱导单位距离图恰五色，整座并域亦然；
- 在这些域内有任意大的有限点集，其全部实际单位边至少为
  `c n^(1+10^(−6))`，其中c>0固定；
- 可以同时要求这些有限诱导图本身恰五色。

第一项是[T028](residue_field_ceiling.md)的安全扩域应用；后两项
依赖下面明确列出的外部类域塔及边数定理。这里证明如何验证其
假设并组合；不把有限模运算说成独立构造了无限塔。本条不声明
发表优先权，不把高边密度说成六色迹象。

## 2. 已阅读的外部输入

类域塔输入直接使用[Hajir–Maire, *Asymptotically Good Towers of
Global Fields*](https://www.math.uni-bielefeld.de/~rehmann/ECM/cdrom/3ecm/pdfs/pant3/maire.pdf)，
ECM 2000/2001，§2、PDF第3–4页，已阅读全部假设及Theorem 2.2。
设S为完全分裂集合、T′为允许分歧集合：S包含全部无限素点，
`S∩T′=∅`，T′中素点的绝对范数满足该文温和分歧条件。
其定理给出`r−d≤|S|−1+θ`；当基域包含μ₂且`T′=∅`时`θ=1`。
该页接着陈述有限非平凡pro-2群必满足`r>d²/4`的
Golod–Shafarevich界。这里这些是已阅读的外部深定理，非独立重证。

其余输入为[Sawin, arXiv:2605.20579v1](https://arxiv.org/html/2605.20579v1)，
2026-05-20；2026-09-10摘要页只列v1。精确位置是：

1. **Lemma 11(1)及其证明**：若有限奇素数集T中3模4素数的个数
   为奇数，令`Q₀=Q(√D), D=∏T`，则`B=Q(√q:q∈T)`在Q₀上
   全实、处处未分歧，Galois群秩为`|T|−1`。
2. **Lemma 12证明中的判别式计算；Proposition 10**：当CM域
   `E=F(i)`满足固定相对根判别式及给定分裂条件时，提供显式
   单位边数指数。后者包含理想范数、类数及几何计数输入。

以下没有把Lemma 11原来的“剩余次数至多2”误读成“完全分裂”；
我们重新指定Frobenius关系，并逐一检查保留的初始商及关系预算。

## 3. 初始域与两个用途不同的素数

取

`T={3,5,11,23,31,37,47,53}`，`D=10842986715`，`p=40429`。

这些数均为素数，T中恰有五个3模4素数，故`D≡3 (mod4)`。
令`Q₀=Q(√D)`，`B=Q(√q:q∈T)`。不同素数的平方类独立，
所以`[B:Q₀]=2⁷`。外部输入1给出B/Q₀处处未分歧且全实。

这一未分歧性也可逐个二次生成元检查：
`Q₀(√q)=Q₀(√(D/q))`，两个有理二次域的奇分歧素数不相交；
在2处，q与D/q中恰一个为1模4。至少一个用于基变换的二次域
在所考察的素数处未分歧，因此每一步在Q₀上未分歧。

11用于**保持染色目标**。T中除11外的素数都有模11单根：

| q | 一个平方根模11 |
| --- | --- |
| 3、47 | 5 |
| 5 | 4 |
| 23 | 1 |
| 31、53 | 3 |
| 37 | 2 |

Hensel提升使这些平方根都在Q₁₁中。因此B在11处的完备化为
`Q₁₁(√11)`；Q₀的相应完备化也是该域，因为D/11为平方单位。
Q₀只有一个11上素理想，而且它在B/Q₀中完全分裂。

p用于**生成很多单位方向**。直接整数检验给出`p≡1 (mod4)`，
并且T中所有q都为模p非零平方。因此p在B/Q及Q₀/Q中完全分裂，
Q₀恰有两个p上素理想；它们也都在B/Q₀中完全分裂。

具体p并不神秘；需要的是这些分裂条件。这里用一个可直接核验
的素数，避免把素数存在性再交给未展开的选择步骤。

## 4. Frobenius切割的完整预算

使用Hajir–Maire的记号，取基域Q₀、pro-素数2、`T′=∅`，并令
S由Q₀的两个实素点及以下三个有限素点组成：

- Q₀唯一的11上素理想；
- Q₀两个p上素理想。

令G是这个最大未分歧、S完全分裂pro-2扩张的Galois群。
这也可理解为在最大全实未分歧塔中杀掉三个有限素点的Frobenius。
B/Q₀已经满足全部条件，所以B仍是新塔的子域，G保留商
`Gal(B/Q₀)≅(Z/2)⁷`，并且`d=d(G)≥7`。

现在逐项核对外部深定理：`|S|=5`，全部无限素点都包含在S中，
与空T′不交；温和分歧条件为空条件；`μ₂⊂Q₀`，所以`θ=1`。
Theorem 2.2直接给出

`r(G)−d(G)≤|S|−1+θ=5`。

这里已计入两个实素点，不依赖最小呈示消元时的额外假设。
对所有d≥7，

`d²−4d−20=(d−7)(d+3)+1>0`，

所以`r(G)≤d+5<d²/4`。Golod–Shafarevich定理使G无限。

这些条件在Q₀/Q的非平凡自同构下稳定：11上素理想被固定，两个
p上素理想被互换。因此所得塔在Q上Galois。通过取有限商并将
核与其共轭、以及`Gal(tower/B)`相交，可选嵌套全实有限层F_j，
满足`[F_j:Q]→∞`、每个F_j/Q为Galois且包含B。

F_j/Q₀在所有有限处未分歧，三个被切割的素理想均完全分裂。
故每层仍在11处有完备化`Q₁₁(√11)`；p在F_j/Q中完全分裂。

## 5. 整个宿主恰五色

设`E_j=F_j(i)`。F_j包含`Q(√3,√5,√11)`，并嵌入局部域
`Q₁₁(√11)`。T028的同一证明给出`χ(F_j²)=5`，也就是
`χ(G(E_j))=5`：11的剩余域为F₁₁，`−1`非平方，所有实际单位
向量必积分；在每个加法积分陪集约化到121点五色目标。

该论证包含任意分母和全部实际单位边。下界来自已有Parts509。
嵌套并域也恰五色，因为任何有限图都处于某一有限层，可应用有限
图紧性；或者选择兼容的11进素点直接使用同一陪集构造。

## 6. 固定正指数与实际五色有限图

F_j/Q₀未分歧，且`disc(Q₀)=4D`，所以对`d=[F_j:Q]`有
`|disc(F_j)|=(4D)^(d/2)`。又因F_j包含√D：

- `E_j=F_j(i)`在2以外未分歧；
- `E_j=F_j(√(−D))`，而`−D≡1 (mod4)`，故2处也未分歧。

因此`|disc(E_j)|=|disc(F_j)|²`，相对根判别式恒为
`λ=(|disc(E_j)|/|disc(F_j)|)^(1/d)=2√D`。
p在E_j中也完全分裂，因为`p≡1 (mod4)`。

现在将Sawin Proposition 10应用于单元素集`S_Q={p}`，
`e(p)=f(p)=1`，`R=2`，`k(p)=k=16384`。所得指数增量为

`δ=[−log2 +(1/2)log(2π/e)+(1/2)log(k+1)`
`    −(1/4)logλ−(1/2)loglogλ] / log(4p^(k/2)+1)`。

这里可以不用浮点数严格证明`δ>10^(−6)`。设分子为N、分母为M。
用`8/3<e<3`与`π>3`，直接整数比较给出

`λ<220000`，`√λ<470`，`logλ<13`，`logp<11`。

后两个不等式分别由`220000·3¹³<8¹³`与`p·3¹¹<8¹¹`推出。
于是

`exp(2N)=π(k+1)/(2e√λ logλ) > 16385/12220`，

从`log x>(x−1)/x (x>1)`得到`N>4165/32770`。
另一方面`M<log(8p^8192)<3+8192·11=90115`。所以

`δ>4165/(32770·90115)>1/1000000`。

Proposition 10给出任意大的实际点集，单位边数至少
`c n^(1+10^(−6))`；有序点对改成无序边只改变常数。
该构造原来位于`I/√α`的复嵌入。取一个满足`β₀ c(β₀)=α`的
β₀∈I，用单位复数`√α/β₀`旋转整个图，即落入`I/β₀⊂E_j`。
所以这些点集的全部诱导单位边都受第5节的五染色控制。

若需有限图恰五色，在同一E_j内加入一个足够远的整数平移
Parts509副本。有限性保证可使两个点集之间没有单位边。总点数只
增加509，边数至少不减，固定幂指数不变；新图含五色核心且仍在
五色宿主内，故恰五色。

## 7. 意义、非结论与可重放部分

11并非从几何坐标任意选出的装饰参数：它在这里同时承担
“各生成根式的局部兼容性”与“具有五色表的各向异性剩余目标”。
p则承担完全不同的任务：分裂素理想的不同取向产生许多等范数
元素。两个素数的功能可以共存；高次数与单位方向数的增长本身
不会突破五色屏障。

这关闭的是**保留该11进目标的塔内六色搜索**，不是所有CM塔、
Sawin原来使用的塔或全部域外构造。定理没有给出平面五染色，
没有六色有限图，没有解决原始HN，也没有独立验证外部塔的
抽象无限群存在性定理。
