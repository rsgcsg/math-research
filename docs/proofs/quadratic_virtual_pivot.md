# T066：二次旋转的虚拟原域枢轴

2026-09-09。这个代数结论用于收敛T062留下的二次姿态方向，
不是新的高色图，也不要求枢轴属于实际有限模板或旧图。

## 精确结论

设F⊂R为任意子域，d∈F正且非平方，E=F(√d)。设

`g(q)=Rq+t`，`R∈O₂(E)`，`t∈E²`。

则恰有下列三种情形：

1. R和t的全部系数在F，`g(F²)=F²`。
2. R的系数在F，t不在F²，`g(F²)=F²+√d t₁`且与F²不相交，
   其中`t=t₀+√d t₁`、t₀,t₁∈F²、t₁≠0。
3. R的系数不全在F，存在唯一q_*∈F²使p_*=g(q_*)∈F²；
   `g(F²)∩F²={p_*}`，并可写成

   `g(q)=p_*+R(q−q_*)`。

最后一类的(q_*,p_*)就是虚拟F枢轴。实际模板可能不含q_*，
旧点集也可能不含p_*；结论不是在原图中添加一个锚点假设。

## 证明

先取保定向情形。写

`R=A+√d B`，`A=a₀I+b₀J`，`B=a₁I+b₁J`，

`t=t₀+√d t₁`，所有下标系数均在F。
若B=0，则R是F系数可逆矩阵，g(F²)=F²+t，立即给出前两类。

若B≠0，实子域的平方和正性给

`det B=a₁²+b₁²>0`。

故B在F上可逆。对q∈F²，g(q)的√d系数是Bq+t₁；所以

`g(q)∈F² ⇔ Bq+t₁=0 ⇔ q=−B⁻¹t₁=:q_*`。

令p_*=Aq_*+t₀∈F²，便得到唯一交点及所述正规形。
若g反定向，先在模板侧复合固定F系数反射`H=diag(1,−1)`，
对g∘H使用上述证明，再把q_*换回Hq_*即可。证毕。

这是任意实子域的证明，不用有限枚举或数值刚体拟合。
若不假设F⊂R，非零B的行列式可能为0，不能照搬本结论。

## 对T052和T062的后果

第三类的每条实际跨单位边`|p−g(q)|=1`可先平移到

`p'=p−p_*∈F², q'=q−q_*∈F²`。

于是它给出T052的两列方程

`(p'·q')c+(p'·Jq')s=(|p'|²+|q'|²−1)/2`。

若这些行的F秩为2，c,s就都在F，与第三类的R逃域矛盾。
故非平凡接触行的秩至多1；至少有一个非零行时恰为1。
这个论证只用了坐标原点的变换，完全不需要p_*、q_*是图中顶点。

因此T062的秩六姿态虽然允许二次逃域，却没有新增第四种
“二次旋转且无任何原域枢轴”的几何类型。仍须区分：

- 两列接触秩与七列提升秩不是同一个量。
- 第二类按整层像看是平移片层，但其任意多方向/非积分排列并未
  全部被T063/T065覆盖。
- 第三类转回单枢轴正规形，不等于整个双宿主五色，也不等于
  多个不同枢轴之间没有新耦合。
- T062的秩≤5可能允许更高次数或连续姿态，不受本二次域分类覆盖。

## 一个没有实际枢轴顶点的精确校准

取F=K、d=39、`R=(5I+√39J)/8`，并取

`t₀=(-83/84,5/8), t₁=(-1/40,-1/12)`。

此时`A=5I/8, B=J/8`，公式给

`q_*=(2/3,-1/5), p_*=(-4/7,1/2)`。

模板`Q={(0,0),(1,0),(0,1)}`不含q_*，故g(Q)没有任何K²点，
但整层g(K²)仍与K²恰交于p_*。√39不在K，因为√3已在K而√13
不在其八个有理平方类中。这个例子只校准虚拟交点，不声称有跨边、
指定七列秩或高色数。伴随检查器直接用有理数展开所有矩阵恒等式。
