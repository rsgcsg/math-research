# C028：循环区间矩、整数覆盖与划分耦合

2026-09-30。成熟 chorded-cycle 不等式的一个显式校准族。
不主张文献优先权，不把抽象图自动实现成平面单位图。

## 1. 一个可以完整决定的无限族

取整数 q≥2、n≥2q。在循环集合 Zₙ 上，对每个 a 取长度 q 的连续区间
Iₐ={a,a+1,…,a+q−1}，下标模 n。定义

    Qᵢⱼ = (1/q) Σₐ 1[i∈Iₐ]1[j∈Iₐ]。

它显然是完全正矩，Qᵢᵢ=1。这里的问题是：Q 是否真是某个随机划分的
同块概率矩，而不只是随机子集的缩放矩？

**精确答案：** Q 来自任意块数的划分律，当且仅当 q 整除 n。
进一步，Q 来自至多 k 块的划分律，当且仅当 q 整除 n 且 n/q≤k。

正向构造很直接。若 n=mq，把圆周按长度 q 分成 m 个连续块，从 s=0,…,q−1 中均匀选择一个边界偏移，按起点同余于 s 的长度 q 区间分块。
把这 q 份可能划分中的块合起来，恰好把 n 个 Iₐ 各列一次。
所以平均同块矩就是 Q，且每份划分恰有 m 块。

若一个至多 k 块的划分律实现 Q，设每次各块大小为 s₁,…,sₖ，允许空块。
由于 Q 每行和为 q，

    n q = Σᵢⱼ Qᵢⱼ = E[Σₕ sₕ²] ≥ n²/k。

因此 k≥n/q。剩余的整除必要性由下一节的已知有效不等式给出。

## 2. 为什么非整除恰好失败

对任何 n 点划分，记 eᵢⱼ 为同块指标。成熟的 q-chorded-cycle 不等式为

    Σᵢ (eᵢ,ᵢ₊₁ − eᵢ,ᵢ₊q) ≤ n − ceil(n/q)。

这里 q≤n/2；当 n=2q 时，对径弦在按 i 求和中出现两次，不能擅自去重。
[Irmai–Naumann–Andres 2024 稿](https://arxiv.org/html/2411.03407v1)
§4 Definition 1、Lemma 2 和附录 A.1 给出这个约定及有效性；该不等式
及 q=2 的奇圈情形是更早的成熟结果。本文不使用其完整面分类作为证明前提。

也可直接看其机制：若循环颜色词非常值，把它分成极大同色连续段，长度为 ℓ。
相邻同色对数是 Σ(ℓ−1)，跨度 q 的同色对至少有 Σ max(ℓ−q,0)。所以差至多

    Σ min(ℓ−1,q−1) ≤ Σ (q−1)ℓ/q = n(q−1)/q。

左端对每份真正划分是整数，先对逐份划分向下取整，再平均，得到所述界。
常值词的差为零，单独满足不等式。跨过其它颜色段的额外同色弦只会降低左端。

对上述 Q，每条循环相邻边的概率为 (q−1)/q，每条 q 弦的概率为零。
因此左端恰是 n(q−1)/q，与界的差为

    ceil(n/q) − n/q。

它在 q∤n 时严格为正，排除任何划分律；q|n 时恰为零，并有上一节的正构造。
这不是仅仅排除某个有限支持池，也不依赖划分律的支持大小。

## 3. 单独立集矩为什么仍全部合法

定义抽象图 Gₙ,q：点为 Zₙ；对于 0≤i<j<n，若 q≤j−i≤n−q 则连边。
每个 Iₐ 都是独立集。对于整数 k 满足 n≤kq，取随机独立集 X：
每个 Iₐ 的概率为 1/(kq)，余下概率 1−n/(kq) 取空集。
则

    E Xᵢ=1/k，Qᵢⱼ=k E[XᵢXⱼ]。

所以 Q 正好属于此前讨论的单独立集矩模型；特别地
Q−J/k=k Cov(X) 半正定，并满足由该模型推出的三角和子集鸽巢约束。
一般引理见[共同事件理论](full15_joint_event_theory.md#31-一般独立集矩引理不只是-psd)。

但 q∤n 时，这个同样的 Q 不能来自任何真正划分。
其原因是平均覆盖可以把循环分数地覆盖，互不相交的完整颜色类还必须
通过上述整数取整条件。完全正性本身不会恢复这一耦合。

尤其不能把这个矩的失败当成 Gₙ,q 不可 k 染：顺着 0,…,n−1 每 q 个点
分成一个连续块，最后一块允许更短，就给出 ceil(n/q) 色的实际染色。
当 n≤kq 时，Gₙ,q 已有至多 k 色；失败的是指定相关矩 Q，而不是普通可染性。

n=5、q=2、k=5 恰恢复 C027（重新标号后）的五边形矩。
其它参数的图目前没有这里所需的平面单位实现证书，不能据此提高 HN 下界。

## 4. 与 hypermetric 和 2-partition 界的区别

这一整数耦合也解释为何某些看似更强的划分不等式仍不值得在当前外放松上反复加入。
令 bᵢ 为任意整数，ν=Σbᵢ=kt+r，其中 t=floor(ν/k)、0≤r<k，负 t 也允许。
对于单集矩 Q=k E[XXᵀ]、E Xᵢ=1/k，令 Z=ΣbᵢXᵢ，则 Z 已是整数随机变量。
逐点整数恒等式 (Z−t)(Z−t−1)≥0（包括负 t），取期望给

    k E Z² ≥ (k−r)t²+r(t+1)²。

以不同块坐标 dᵢⱼ=1−Qᵢⱼ 表示，就有

    Σᵢ<ⱼ bᵢbⱼdᵢⱼ
    = (ν²−k E Z²)/2
    ≤ [ν²−(k−r)t²−r(t+1)²]/2。

所以这一整族 k-partition hypermetric 界已经被单集矩满足。
这也是对任意真正至多 k 块划分的有效界：把 b 在各块的和作为 k 个整数，
同样应用平方和最小值即可。这里给出的是直接推导，不把它宣称为新不等式。
[Chopra–Rao 1995](https://doi.org/10.1016/0166-218X(93)E0175-X)
是相应成熟家族的来源；上述写法明确处理所有整数权和余数，包括非正 ν。

类似地，对不交 S,T，令 a=|X∩S|、b=|X∩T|，则

    ab−C(a,2)−C(b,2) = [a+b−(a−b)²]/2 ≤ min(a,b)。

取期望并乘 k，就得到一般 2-partition 界，仍不超过单集模型。
因此关键不是不等式的名称或是否为某个多面体的面，而是它的证明是否
真正使用了多个颜色类在同一次结果中的互斥覆盖。

### 4.1 连整个割锥／ℓ₁ 度量条件也不足

对于上述任意单集矩，令 δₐ(i,j)=|1[i∈a]−1[j∈a]| 为子集 a 的割半度量。
由 E Xᵢ=E Xⱼ=1/k，直接得到

    dᵢⱼ=1−Qᵢⱼ=(k/2) E|Xᵢ−Xⱼ|。

因此 d 是非负的割半度量组合，已处于割锥。若用每个可能子集 a 为一个坐标，
令 fᵢ(a)=(k/2)Pr[X=a]1[i∈a]，则显式有

    ||fᵢ−fⱼ||₁=dᵢⱼ，||fᵢ||₁=1/2。

这是自足的有限维ℓ₁嵌入，不依赖求解器或某个未检查的度量分类定理。
所以添加任意对整个割锥有效的齐次线性不等式，也不会切掉这个单集矩见证。
C028表明：即使这些有界ℓ₁距离已经满足，d仍不一定能写成“完整随机划分将两点
分开”的概率。割锥、至多k块划分的凸包和两块cut polytope不能混为一谈。
这只是进一步定位缺失的覆盖耦合，不是否定全部度量方法或高阶提升。
