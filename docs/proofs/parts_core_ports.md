# T026：真实五色核心的三端口普适延伸与低交叠粘合限制

本结果针对固定的 Parts 509 点诱导单位距离图 G。G 的五色性是外部
已知结果，本地重新精确认证；本节新检查的是其五色边界关系，不宣称
文献优先权，也不声称平面色数的新上下界。

## 结论

1. 对 G 中任意至多三个顶点，任意使用五个颜色标签的 proper 预染色
   都能延伸为整个 G 的 proper 五染色。
2. 取中心顶点0与两组六边形
   `149,152,157,160,165,168` 和 `397,399,401,403,405,407`。
   这13点上的任意 proper 五色预染色亦能延伸为 G 的五染色。
3. 因而，按下述精确粘合条件排列的任意有限或单向无限 G 副本，其
   非空单位距离宿主的色数仍为5；这种构造不能产生六色下界。

注意：第2项只涉及所列两组六边形，不是所有六边形对、所有13点子集，
更不是整个单位圆上的任意四色预染色。

## 五色核心的独立资格检查

数据来自 [公开资料库](https://github.com/md-amer/hadwiger-nelson-e5)，
固定提交 `6d5ac08491f7cadbebd7d5b79e3f825d08eedf7b`。
其中坐标归于 Parts，论文入口为
[Graph minimization](https://arxiv.org/abs/2010.12665)。
本地未执行该资料库的 Python 验证脚本。

`parts_core.py`用受限算术 AST 读取原坐标，所有坐标化入
`Q(√3,√11,√5)`，并统一清分母为96。特别地，原文件的嵌套根号并不
需要更高代数域，因为

`sqrt(5(7±√33)/2) = (√55±√15)/2`。

两边平方相等；`√55>√15>0`指定正分支。3、5、11在有理数模平方群
中的平方类独立，故 `1,√3,√11,√33,√5,√15,√55,√165` 是有理数域上
线性独立的基，基系数比较是精确相等判定。

独立的 `verify_parts_core.py`不导入搜索器或其域运算，按平方自由数
之间的最大公因数重建乘法。从全部129286个点对直接重算，得到509个
互异点和2442条诱导单位边；保存的五染色在全部边上通过。

下界使用公开的2259条边子图及对应四染色否定证书。该子图每条边均为
实际单位边，但它不是诱导图；此处只用它证明下界。独立核对2036变量、
9548子句的 CNF 恰为每点至少一色、每条子图边两端异色及三角形
`0,149,152`的颜色重命名固定。没有“每点至多一色”子句也无妨：
任何满足赋值为各点选取一个被赋真的颜色，即给出 proper 染色；固定
三角形不影响存在性，因为任意 proper 染色均可统一重命名。

原 DRAT 经固定版本的 drat-trim 检查通过，并输出 LRAT 提示。
随后本地约百行标准库检查器 `verify_rup_lrat.py`逐项独立重放：

- 92649次子句加入；
- 5813255次提示子句传播；
- 最终导出编号238254的空子句；
- 没有接受 RAT 步骤，只接受 RUP 逻辑蕴含步骤。

每次加入 C，检查器假设 C 的全部文字为假，沿已存在子句进行单元传播，
直到矛盾，因而此前公式蕴含 C。归纳到空子句即证明原 CNF 不可满足。
它拒绝负的 RAT 提示、缺失/前向子句、非单位传播、没有矛盾及截断证明。
有小型正反自测，但没有声称 Lean/Coq 或形式化认证此 Python 检查器。

压缩后的 LRAT 已放入 `certificates/parts509_reduced.lrat.gz`，因此
`make check`能离线、只用标准库重证上下两侧，不只信任已保存的 PASS。
原文件哈希、工具固定提交、外部检查输出及本地 RUP 结果见
`parts509_drat_replay.json`。

## 全部三点关系的精确覆盖证明

搜索按五种三点划分类型组织请求：

`abc, ab|c, ac|b, bc|a, a|b|c`。

只要同一块中没有单位边，就是需要处理的合法预染色。用求解器寻找
完整五染色，并让每个完整见证同时覆盖大量请求，最终只需1744个见证。
这些见证保存于 `parts509_triples.json.gz`。

独立检查器先逐边检验每个完整见证，再对每对 a,b 构造见证索引集合
E_ab，其中恰含令 a,b 同色的见证。对每个 a<b<c，逐项验证：

| 合法模式 | 必须非空的见证集合 |
|---|---|
| abc | E_ab ∩ E_ac |
| ab\|c | E_ab \ E_ac |
| ac\|b | E_ac \ E_ab |
| bc\|a | E_bc \ E_ab |
| a\|b\|c | 全体见证 \ (E_ab ∪ E_ac ∪ E_bc) |

这是直接集合检查，不依赖搜索器的 SAT 标签或它的覆盖数据结构。
完成的精确计数为：

- 三点集合：21849334；
- 合法单块模式：20634369；
- 合法两块模式：64309908；
- 全异色模式：21849334；
- 合计：106793611种合法划分。

对任意给定的五个标签，其在端口上的相等关系唯一对应一个划分，选定
该划分的见证后统一重命名五个颜色即满足原标签。因此不是只对某个
参考 palette 或规范编号成立。至多两点的结论也由同一性质推出；另有
253个见证单独直接覆盖全部126844个非单位点对的同色和全部129286个
不同点对的异色请求。

## 两组六边形边界

独立几何检查确认所列12个邻点都与中心0相距1，邻点之间的全部单位边
恰为两个不相交的 C6。固定中心颜色后，边界其余部分至多用四个颜色。
每个 C6 的有标号染色数为 `P(q)=(q-1)^6+(q-1)`，故两者为 P(q)²。
消除颜色重命名后，分别恰用2、3、4色的划分数为2、724、21601，合计
22327。检查器验证22327个互异规范边界划分的完整五染色见证，故覆盖
全部可能边界；不依赖搜索侧对边界模式的枚举程序。

## 副本粘合的准确范围

设 V1,V2,… 为 G 的有限或单向无限个刚体副本，令 U_i=∪_{j≤i}V_j。
假设对每次加入 i>1：

1. `|V_i ∩ U_(i-1)| ≤ 3`；
2. 新顶点 `V_i \ U_(i-1)` 与旧副本之外的顶点 `U_(i-1) \ V_i`
   之间没有额外单位边。

每一步都取 U_i 上的**全部**单位边。旧图已经是诱导单位图，所以共享
端口之间的全部单位边此前已经存在，其旧颜色给出 V_i 上合法的预染色。
第1项保证它能由三端口定理延伸；第2项保证没有漏掉跨边。逐步延伸便
给出整个并集的五染色；它包含一个 G，故色数恰为5。

对于抽象图粘合，必须另保证新副本不在已经着色的共享顶点之间添加
此前不存在的新边。只说“交叠至多三点”并不自动保证这一点。

因此下一次提高下界，必须打破以上构造范围，例如产生四点及以上的
联合约束，或加入真实的跨副本单位边。此处没有证明所有四端口预染色
均可延伸，也没有排除这类更高交叠或带额外交叉边的构造。
