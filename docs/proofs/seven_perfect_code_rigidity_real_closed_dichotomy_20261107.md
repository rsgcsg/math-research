## 2. 七色实际上达到三角格完美纠错码的容量极限

三角格T的格点为(m,n)∈ℤ²，最近邻差为(±1,0),(0,±1),(±1,∓1)，图距为
\[
d_T((m,n),(a,b))=\max(|m-a|,|n-b|,|m-a+n-b|).
\]
T²把0<d_T≤2的18种差连边。T的闭一球B₁(v)是v及六个T邻点，恰好七个；它是T²中的七团。

**定理A（直接证明）。** 每份合法c:T²→[7]的每一个颜色类S_j=c⁻¹(j)都是T的1-perfect code（每个B₁(v)恰好含一个S_j点）。

证明：B₁(v)的七点两两在T中至多相距2，故在T²两两相邻，七色必须分别出现。任一颜色j在每个B₁(v)恰一次，正是一完美码。证毕。

**定理B（依赖Dejter完整分类；本轮给严格推论）。** 每份T²的七色染色，除七个标签的全局置换外，恰为两个互为镜像的线性方案之一：
\[
\boxed{c(m,n)=m+3n\pmod7,\qquad c(m,n)=m+5n\pmod7.}
\]
没有其他非周期的T²合法七色染色。

证明：由定理A各颜色类都是Dejter已分类的一完美码，所以它们各自是线性函数m+3n或m+5n模7的某个等值陪集。不同斜率的任意两个陪集**必交**：解同余m+3n=a、m+5n=b，得2n=b−a mod7；2在F7可逆，所以总有一个模7解，进而有无穷共同格点。互斥的七个颜色类不可能混合两种取向，故全部是同一斜率的七个陪集，只剩标签置换。证毕。两种形式经镜面对称变换相互对应。

**独立有限代数认证**：线性c(m,n)=am+bn mod7中有48个非零(a,b)，逐一检查18种图差只有12个合法。归一a=1时恰有b∈{3,5}；每份闭一球七种颜色齐全。三角格长度范数m²+mn+n²使同色子格最短非零范数为7，如(2,1)，正解释
\[
7=2²+2\cdot1+1²,
\]
与Eisenstein整数范数7/指数7晶格商一致。这是为什么经典七染可只写一句模7公式的数学机制。

## 3. 受限七色单六角模型的全部解与最优安全余量

**定理C。** 对边长1/√7<s<1/2的正六边形片染，假设每片内部只用一种颜色、全部精确单位距离点对合法，则**任何七色片染都只能是定理B的两种镜像图案加全局颜色置换**。该模型的同色距离集合恰好在(2s,√7s)有最大间隙；因单片内距离可逼近2s，相邻同色不同片的最小距离可逼近√7s，关于单位距离的最大对称安全带半宽为
\[
\epsilon_s=\min(1-2s,\sqrt7s-1).
\]
其在允许边长区间中的最大值为
\[
\boxed{s_*=\frac2{2+\sqrt7},\qquad
 \epsilon_*=\frac{\sqrt7-2}{\sqrt7+2}\approx0.1389982519}.
\]
证明：本仓库R2026-ROBUST7已将真实片间冲突图认证为T²；定理B给所有七片染的完全分类。R2026-ROBUST7又有精确距离两端，故只能在空档内禁距；两条单调仿射函数1−2s和√7s−1的最小值在交点s*最大。证毕。

**冻结推论：**这类有效尺度内的合法七色片染无法仅修改有限个六边形而得到另一份不同的合法七色片染，因为分类中任意不同的周期镜像/标签置换都在无穷多个格点不同。这是“完美码晶体”受限模型的有限扰动刚性。

**不允许扩张的断言**：上述不是其他七色平面着色的全局鲁棒最优性，不适用于格内多色、不允许把七片的逐对单位点对换成一组共同单位点（最多只能有三个点两两相距1），更**不证明普通平面χ≥7**。它只说明完美六角片染无法改成六片色。

## 4. 从七色假说到有限代数证书：实闭子域色数与全实色数恰好相同

**定理D（de Bruijn–Erdős + Tarski，完整书面证明）。** 任意实闭子域F⊂ℝ，单位距离图的平面色数满足
\[
\boxed{\chi(F²)=\chi(\mathbb R²).}
\]
尤其可数的全体实代数数F=ℝ_alg满足同一色数；故若χ(ℝ²)=7，则有**全部坐标为实代数数的有限精确7色临界单位距离图**。

证明：把任意ℝ²的合法染色限制到F²即有χ(F²)≤χ(ℝ²)。反向假设χ(ℝ²)>k，de Bruijn–Erdős紧致性给出在ℝ²中可实现的有限不可k染单位边图H=(V,E)。其n个互异点坐标满足一条有整数系数的实闭有序域存在一阶公式：
\[
\exists(x_i,y_i)_{i\le n}\quad
\bigwedge_{i<j}((x_i-x_j)²+(y_i-y_j)²>0)
\;\land\;
\bigwedge_{ij\in E}((x_i-x_j)²+(y_i-y_j)²=1).
\]
这条公式在实闭域ℝ为真，按Tarski实闭域完备性在任意实闭F也为真，故有同一抽象图H的F²实现（新增未指定的单位边无碍）。H不能k染，推得χ(F²)>k。对k=χ(ℝ²)−1得到反向不等式。证毕。

**严格边界**：不证明某张具体小图已经找到、不能擅称坐标可尺规作出（代数不等于尺规）、不能用任意非实闭数域替换F。此逻辑归约有经典数学先例，不主张发现优先权。

**算法推论（一侧有限见证完整性）：**枚举所有有限抽象图H；有限非6染可由穷举验证，是否存在精确互异实平面单位边实现可由Tarski量词消去判定。该枚举有有限成功证书 **当且仅当**χ(ℝ²)=7。若普通χ=6，枚举可能永远不会成功，不构成“χ=6不可判定”的声明。与R2026-SEVEN-PORT六色虹色圆口目标一致，且可把数学搜索对象限定到代数数域。

**情形χ=6**：
