# T139：有限秩旋转宿主的非零平移接触分类

2026-09-27。本地接续 `82a39606d926cc204a084761755db10a56c8dccc`。
本定理使用已发表的 Evertse–Schlickewei–Schmidt 非退化乘法群方程定理，
其余归约、所有退化族的分类与几何后果在下文完整给出。
不宣称首创、不宣称有效列出例外、不产生新的普通 HN 上下界。

## 1. 精确陈述

令 `H ≤ {z∈C: |z|=1}` 为有限秩乘法群，`r=dim_Q(H⊗_Z Q)<∞`。
等价地，H含一个秩r的有限生成子群H₀，且H/H₀为扭转群；不要求H本身有限生成，扭转也不必有限。
固定非零复数 a,b,t。对 x,y∈H 考虑实际单位接触

`|a x - (t+b y)|=1`。                                      (1)

除了以下三个明确的族以外，(1)只有有限多组解：

1. `a x=t` 且 `|b|=1`；
2. `b y=-t` 且 `|a|=1`；
3. `a x=b y` 且 `|t|=1`。

每个族中的所有 x,y（满足所列关系）确实给出单位接触。
可取一个非常粗但统一的例外解数上界

`B(r)=4·877·exp(3·36^18·(2r+1))`。                         (2)

这里计数的是给定 a,b,t 的解对，不是算法需要检查的指数窗口。
系数无需代数；一般存在性输入在特征零域 C 上成立。

## 2. 唯一外部输入及实际阅读范围

Evertse–Schlickewei–Schmidt, *Linear equations in variables which lie in a
multiplicative group*, Annals of Mathematics 155 (2002), 807–836，
[作者预印本](https://arxiv.org/abs/math/0409604)，Theorem 1.1（PDF第2页）：
在特征零域上，秩为 R 的 `(K*)^n` 子群内，非退化方程
`c_1 z_1+...+c_n z_n=1` 的解数不超过
`A(n,R)=exp((6n)^(3n)·(R+1))`。
非退化表示左侧没有非空子和为零。

本轮阅读并截图核对了定理陈述与非退化定义；没有声称本地重新证明论文的深层定理。
以下只需要 n≤6、R≤2r，统一用 `A=exp(36^18·(2r+1))`。
n=1的方程直接至多一解。有限程序只校准下面的七项支撑组合，不能认证外部无限定理。

## 3. 展开为六/七项 Laurent 方程

在单位圆上 `bar x=x^-1`、`bar y=y^-1`。平方展开 (1) 得

```
F(X,Y) = C - a bar(b) X/Y - bar(a) b Y/X
           - a bar(t) X - bar(a) t X^-1
           + b bar(t) Y + bar(b) t Y^-1 = 0,
C = |a|²+|b|²+|t|²-1.
```

六个非常数系数全部非零；C=0时删除常数项。非常数指数为

`E={(1,-1),(-1,1),(1,0),(-1,0),(0,1),(0,-1)}`。

因此非零项数 m 为6或7。任何一组解都能把这些项分成互不相交的最小零和块：
每块至少有两项，每个真非空子块的和非零。逐次选取最小零和子集即可构造这种划分。

在每块内选指数 e_0，把其余项的和除以 `-c_(e_0) x^(e_01)y^(e_02)`。
得到上述非退化方程；变量是 `x^(e_1-e_01)y^(e_2-e_02)`。
这些比值组成 H² 的单项式像，故秩不超过2r，而不是每个坐标另加一个2r。
对固定划分，各块比值只有有限多种可能。最多3块，每块最多A组比值。

固定这些比值后，若有一个解 (x_0,y_0)，全部复数解组成一个单项式方程纤维：
其齐次方程为 `X^v1 Y^v2=1`，v遍历块内指数差生成的格 L≤Z²。
这一步不需要引用另一个未说明的“有限并陪集”定理。
因为不存在单项块，L的秩至少1。

## 4. 满秩纤维只有有限多个点

若rank L=2，可在块内指数差中取线性无关v,w。
它们的坐标都在上述六/七项指数的差集中。
直接枚举该有限集合，或用六边形的边向量检查，有 `0<|det(v,w)|≤4`。

两条独立单项式方程在 `(C*)²` 中的共同纤维至多有 `|det(v,w)|` 个点：
整数初等行/列变换把系数矩阵化成 Smith 对角形，方程分别变成两个非零复数的根方程，
解数乘积等于行列式绝对值。更多方程只会减少解数。
所以每个满秩纤维至多4点，限制回H²后也不增加。

m≤7的划分数至多Bell(7)=877，块数至多3，故所有rank-2纤维的解总数至多 `4·877·A³`。
这即(2)。重复划分/重复计数只使这个上界更宽松。

## 5. 秩一纤维只可能给出三个显式退化族

若rank L=1，取与L正交的本原整数向量(p,q)≠(0,0)。
对任意z∈C*，`(X,Y)=(x_0 z^p,y_0 z^q)`都保留全部块内比值，
因此每个零和块仍为零，`F(x_0z^p,y_0z^q)`是恒零 Laurent 多项式。

其非常数指数为 `±p, ±q, ±(p-q)`，另可能有0。
除 `p=0`、`q=0`、`p=q` 外，最大的指数唯一出现，而且它的系数非零，矛盾。
具体而言：p,q异号时 `|p-q|` 严格最大；同号且绝对值不等时
`max(|p|,|q|)` 严格最大。指数集合对称，最大正指数始终存在。

因此只剩三种方向：

- p=0：X固定。按Y的±1次幂取系数，必须有 `a x_0=t`；常数项随之为 `|b|²-1`。
  所以基点及整个纤维属于第1族。
- q=0：Y固定。按X的±1次幂取系数，必须有 `b y_0=-t`；常数项为 `|a|²-1`。
  所以属于第2族。
- p=q：令α=a x_0、β=b y_0，方程变成 `|(α-β)z-t|²-1=0` 的 Laurent 恒等式。
  z的系数为 `-(α-β)bar(t)`；t≠0迫使α=β，常数项再迫使 `|t|=1`。
  所以属于第3族。

此处平方模写法只用来识别单位圆上的展开；恒等性始终是前述 Laurent 多项式恒等性。
没有在非单位复数z上错误地把共轭等同于倒数。
每个非退化例外解只能落入第4节的满秩纤维。因此定理证毕。□

## 6. 对旋转宿主复制的几何意义

设 `S={0}∪⋃_(a∈A) aH`，A有限且不含0。给定t≠0，将S与t+S叠放。
已有T138第6节的圆交点论证说明 `S∩(t+S)` 有限：若非零半径数为R，
交点数至多 `2R²+2`，这里只用有限半径，不依赖乘法群定理。

T139进一步给出单位边分类，而不只是交点分类：

- 第1族的边以t为端点，已是t+S内部的单位边，因为0∈S；
- 第2族的边以0为端点，已是S内部的单位边；
- 第3族正是 `p↔p+t` 的平移匹配，只在|t|=1时出现；
- 除此之外的跨副本单位边有限。

一端由0轨道产生时，与另一个固定半径圆求交，每个轨道至多给2个点；
这也只添加有限例外。因此除原副本内部边与可能的平移匹配之外，新增单位边至多
`|A|² B(r)+4|A|+1`（粗上界）。同一物理边多次表示不影响有限性。

适用于已验证的 `H′=<η,u,τ>` 与2082个非零轨道代表：r=2。
也适用于任意有限多个不同中心的刚体副本，逐副本对应用即可；
同中心的额外旋转可以吸收到各自的系数集合A中。

**没有由此推出五色延拓。** 有限例外本身可能包含强约束，且|t|=1有无限平移匹配。
即便两个副本各自五染，也必须共同处理交点、例外边、匹配和全部自由染色。
**也没有给出有效指数窗口。** 解数上界不是最大指数/高度上界；
扫描到若干解后不能凭此宣称“已经找全”。新结构把后续问题压到明确的例外集合，
而不把尚未计算的例外或颜色约束当成已完成。

## 7. 最小自检、假设边界和重放

三个无限族都真实存在。取无限阶单位 `v=(3+4i)/5`、H=<v>：

- a=b=2,t=1,x=y=v^n给第3族；
- a=t=2,b=1,x=1,y=v^n给第1族；
- a=1,b=-2,t=2,x=v^n,y=1给第2族。

v不是单位根：若是单位根，则v+v^-1=6/5既为有理数又为代数整数，必须是整数，矛盾。
所以这些例子确实无限，不能把任何一个退化族省略。

t≠0也不可省略：t=0、a=b=1，H=<v,exp(iπ/3)>中y=exp(iπ/3)x给无限单位接触，
它们不属于前三族。有限秩假设同样实质：若允许H为整个单位圆，a=b=1,t=3/2，
许多x附近的圆交点给连续无穷多个解，而前三族均不可能成立。

`research/test_translated_rotation_contacts.py`穷举六项/七项支撑的无单项划分，
校准秩一只有三种法向、满秩行列式至多4，并用有理复数检验退化例子。
这些有限检查不代替第2节的外部定理，也不列出当前2082轨道宿主的全部平移例外。

### 解数界不能当作统一指数窗口：一个显式反例族

仍固定H=<v>、a=b=1。对每个正整数N取 `t_N=v^N-2`，
则x=v^N,y=1给实际单位边 `(v^N, v^N-1)`。
由于v无限阶，`|t_N|²=5-4 Re(v^N)>1`。
`a x=t_N`、`b y=-t_N`、`|t_N|=1`均不成立，所以这是真正的有限例外，
而x的唯一H指数为任意大的N。
因此，秩r和轨道数量可以统一控制例外**数量**，却不能在不依赖系数/平移量的情况下统一控制指数。
本例不否定依赖完整代数输入的有效高度界，只否定从(2)直接读出指数截断。

## 8. 一个完整算完的秩一校准：有无限匹配，仍恰二色

令v=(3+4i)/5、H=<v>、S={0}∪H、t=1。对x=v^n,y=v^m，
H与1+H之间的单位接触恰为 `n=0` 或 `n=m`，没有其他例外。

证明：在高斯素数π=2+i处，v=π/bar(π)的赋值为1。
接触Laurent式七项系数是2、−1、−1、−1、−1、1、1，均为π进单位，
因此七项赋值为 `0,n-m,m-n,n,-n,m,-m`。
零和的最低赋值至少出现两次；前述六边形极值论证迫使n=0、m=0或n=m。
其中n=0是中心星，n=m是平移匹配；m=0则 `|x-2|=1, |x|=1`迫使x=1，也已包含。
这证明的是所有整数指数，不是有限样本。

整个S∪(1+S)的二分为 `{0}∪(1+H)` 与H。
H中两点若单位距离，其比值必须是原始六次单位根，不属于Q(i)；故H内部无边。
同理1+H内部无边。0与1+H有单位接触须H含原始三次单位根，不可能。
两集合不重合，原点到1有单位边，故色数恰2。
这说明“非零平移＋无限匹配”本身也不是五色压力；
当前真正有价值的下一项是H′Y的有效例外和完整颜色约束，而不是仅确认存在匹配。
