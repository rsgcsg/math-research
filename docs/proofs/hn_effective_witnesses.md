# T115：有限见证的有效性、算术层级与独立性限制

2026-09-12。以下是紧致性、有效实闭域判定及有限整数验证的推论，
不声明首创。没有构造 non-5/non-6 图，没有证明 HN 独立于任何理论。
通常平面色数及紧致性在 ZFC 中讨论；PA 只用于其有限算术翻译。
实代数转移及“真实答案若为7则可证”已明确出现于
[Madore §5.4](https://arxiv.org/html/1509.07023v1#S5)。本页补全这里
实际使用的证据格式与算术／forcing 量词，不将经典观察包装为新突破。

## 1. 有限证据格式

固定 k。一个证据 w 编码有限简单图 G、实代数单位同态以及 G 不可
k 染的有限检查。几何可用一个共同实代数原元：整数多项式 f、含唯一
实根的有理隔离区间，以及全部坐标在 Q[t]/(f) 中的有理多项式。
Sturm 运算验证实根；逐列边验证平方距离多项式模 f 为1。
非邻点允许重合；若像可 k 染，拉回也可 k 染 G，所以碰撞不损害下界。
组合检查可穷举全部 k^|V(G)| 赋值，也可附每个赋值的冲突边。

上述都是有限整数算法。将完整执行轨迹并入证据，可定义原始递归
谓词 W_(k+1)(w)，使每个接受的证据确实给一个有限 NON-k 单位图。
反之，每个有限单位同态由 [T084](hn_relation_lattice.md) 的实闭域
转移有实代数实现；有限个坐标生成数域，再由原元定理得到此格式。

## 2. 精确算术等价与逻辑天花板

**T115(a)。** 在 ZFC 中，对每个固定有限 k，

```text
χ(R²) ≥ k+1  ⇔  ∃w W_(k+1)(w),
χ(R²) ≤ k    ⇔  ∀w ¬W_(k+1)(w).
```

证明：右向左由单位同态的染色拉回。左向右由有限色紧致性取得
有限 NON-k 子图，再按第1节代数化并穷举验证。第二式是否定第一式。∎

因此下界是 Σ1、上界是 Π1 算术命题。这里不声称 PA 的语言直接
量化整个平面。每个**真实、标准有限**证据的具体运算都能在 PA
展开为有限证明；ZFC 再用上述等价推出平面下界。因此：

- 如果真实答案是7，真实有限 NON6 证据和已知七色上界使等号在
  ZFC 中可证；不能同时声称这个真实等号不可证。
- 若真实答案是5或6，真下界仍有上述证明；潜在不可证明性只能
  留在真 Π1 上界。本结论没有证明这种现象实际发生。
- 相同自然数对象与算术运算的 ZFC 模型对该算术句一致。因此通常
  保持 ω 的 forcing 扩张不能改变 HN 色数；增加实数或改变 CH
  不是直接改变普通 HN 答案的机制。
- 一致性不等于 Σ1 健全性；不能从某个理论声称的下界，未经健全性
  条件便逆推标准真值。也不把无选择公理的染色问题混入上述等价。

这排除的是错误的独立性论证机制，不是所有可能的独立性证明。
一个统一无界证据族的正确性与一份标准有限证据，又是不同量词。

## 3. 点数固定后，代数证据长度有可计算上界

**T115(b)。** 存在可计算 B(n)，使任何至多 n 点、具有平面单位
同态的有限图，都有编码长度不超过 B(n) 的上述实代数证据。

证明：至多 n 点的带标签图只有有限多个。逐一用有效实闭域判定
单位距离二次方程是否有解。对每个 YES 实例枚举第1节的证据，
直到找到一个；代数转移保证终止。取所有所得长度最大值，空集
时约定0。有限个过程均终止，故计算出 B(n)。∎

这不给实用渐近界，更不控制最小 NON5 的 n。它仅说明：给定 n 后，
代数高度不是另一项不可计算的存在性障碍。NON-k 的穷举冲突证据
也有 O(k^n n²) 的宽松编码上界；没有给特定 DRAT/SOS 系统的最短
证明长度下界。T113 的概率原子数与这些参数更不能混同。

## 4. 固定点数的近单位间隙同样有效

**T115(c)。** 存在可计算正有理 ε(n)，使任意至多 n 点图，若在
平面中所有列边长度都落在 [1−ε(n),1+ε(n)]，便有精确单位同态。

证明：枚举同样有限多个图，RCF 判精确可实现性。对 NO 实例逐次
用 ε=1/2,1/4,… 判近单位可实现性。[T097](near_unit_obstruction_compactness.md)
保证某次为 NO：否则固定每分支根点，路径长度给有界坐标，取收敛
子列便得精确同态。有限个 NO 实例的阈值取最小值；若没有 NO，
取1/2。算法终止且阈值为正。∎

这使固定图的认证逼近成为有边界的任务，不使任意 n 的搜索完备。
对连通 n 点图，令根点为0并定义 E_G=Σ_edges(||pi−pj||²−1)²。
若 E_G≤1，则每条边长≤√2，全部坐标在 [−2n,2n] 内；在此紧盒
上的非零最小值可用有效实代数方法界定。
[Jeronimo–Perrucci–Tsigaridas, Theorem 1](https://arxiv.org/pdf/1112.0544)
还给整数系数、统一偶数次数和系数界、紧连通半代数分支上的显式界。
本轮核对定理假设，未把其长常数公式实施成已认证数值程序。

### 精确 Gram 校准：完全图总误差

对 n≥3 个中心化平面点，令 ri=||pi||²、S=Σri、M=Σpi piᵀ，则

```text
Σ_(i<j)(||pi−pj||²−1)²
 = n(n−3)/6 + 3(S−n/3)²
   + n Σ_i(ri−S/n)² + 2||M−(S/2)I₂||_F².
```

证明：中心化给 Σ_(i<j)||pi−pj||²=nS；展开四次项给
Σ_(i<j)||pi−pj||⁴=nΣri²+S²+2tr(M²)。分离 ri 的均值和 M 的
标量部分，再完成 S 的平方，即得恒等式。半径1/√3的正 n 边形
使后三项为0，所以最小值恰 n(n−3)/6；K4 是2/3。∎

这是完整恒等式证明，不是局部优化的最小值声明。它校准 Gram
候选的几何误差工具，不是新的六色单位图。

## 5. 与成熟复杂性结果的边界

[Schaefer, Corollary 2.7 / 2.9、Theorem 3.1](https://ovid.cs.depaul.edu/documents/realizability.pdf)
分别讨论单位图识别的 ∃R 完全性、单射实现的强迫极小点间距，
以及允许碰撞的单位 linkage 识别。前两种几何模型不能与第三种
混同；一般输入的最坏精度也不是最小 NON5/NON6 见证的高度下界。
∃R 完全仍是可判定，不是 HN 不可判定性。

两端仍未闭合：下界缺实际有限 NON5；六色上界缺所有有限实代数
配置的统一可染证明。本文消除了错误的额外门槛，没有填上这两项。
