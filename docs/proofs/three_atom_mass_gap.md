# T148：排除三原子后的尖锐质量界是 9/10，而不是全支持反证

2026-09-29。一般有限线性代数命题；不宣称文献优先权。
证明含一个仅2600项、使用整数行列式的完整有限分类。

## 命题

设有限矩阵 D 的条目属于 {-1,0,1}。称 λ≥0、Σλ=1、Dλ=0 为可行律。
若不存在支持至多三列的可行律，则任一可行律中任意三个指定列的总质量至多9/10。
这个常数在该抽象矩阵类中最优。它不是任意三个局部模式的质量界。

## 证明：先求三列到原点的统一距离

对所选至多三列组成的 B，定义 δ(B)=min{||Bx||∞:x≥0,Σx=1}。
单纯形紧且没有零组合，所以 δ>0。证明 δ≥1/9。
只需研究有三个不同选定列的情形；重复列可合并。

最优 x 只有一项正时，非零整数列的∞范数至少1。
只有两项正时，下界是1/3。确切地，若 ||pu+(1−p)v||∞<1/3：
同号非零坐标不可能出现；如有反号坐标，则1/3<p<2/3，故任何仅一列非零的坐标亦不可能。
因此 u=−v，给零组合，矛盾。若没有反号坐标，则两列均非零必须分别出现单侧非零坐标，
迫使同时p<1/3和1−p<1/3，同样矛盾。

其余情形在LP

```
min t;  −t≤Bx≤t,  x≥0,  Σx=1,  t≥0
```

的最优面选一个顶点。若该顶点落在边界，已由上段处理。
否则三个 x_i>0 且 t=δ>0。除归一化外，须有三个独立的活跃法向量 (c_i,−1)，
其中 c_i 为 B 的某个带符号非零行，条目仍属于{-1,0,1}，且 Cx=δ·1。
这些三行组成的 C 必可逆：若 αᵀC=0，乘x得 δΣα=0，故Σα=0；
那么相同α也使三个法向量线性相关，矛盾。

因此 v=C⁻¹1>0，且 δ=1/(Σv_i)。所有候选C的行来自26个非零三元行。
行顺序不影响v，故穷尽 C(26,3)=2600 个无序行三元组即足够。
[标准库检查器](../../research/verify_three_atom_mass.py)用Cramer整数行列式计算v，
并以C·v=1逐项复核：108个候选有严格正v，最大的Σv_i恰为9，六组达到。
没有浮点LP、SAT状态或未遍历矩阵作为前提。于是δ≥1/9。

若选定三列的总质量为m>0，将其归一化得x。某行上这三列的净贡献绝对值至少m/9。
其余列每个条目的绝对值≤1，最多抵消1−m。因此m/9≤1−m，即m≤9/10。
m=0显然。证毕。

## 尖锐例与适用边界

取矩阵

```
−1  0  1 −1
 0  1 −1 −1
 1 −1  1 −1
```

其秩为3，唯一归一化正核向量是(2,4,3,1)/10。故没有至多三列的律，
前三列总质量仍达到9/10。检查器直接检查秩和乘积。
没有声称这个矩阵已由平面单位图和全等运动实现。

若原15域的六种三原子情形都被严格排除，此命题可用于其完整划分列：
任何可行全支持律至少有四原子，且任何三个指定完整划分至多占9/10。
这仍允许四个、更多或极多支持，不能当作全支持不存在的证据。
下一条有机会产生HN下界的负证据仍须是对**所有**合法完整词严格为正的势。
