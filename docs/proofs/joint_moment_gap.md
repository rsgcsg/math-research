# T024：完整多色信息首次在四点的2+2事件中超出单色矩

这解释T023背后的具体信息损失，并给下一轮joint模型一个最小校准对象。
不是平面色数新下界，也不宣称分割格线性代数的新颖性。

## 精确的维数结论

对n个标号点的所有集合分割（颜色数允许至少n），考虑分割分布。
记录每个顶点子集“其所有点同色”的概率，再记录总概率1。
这一线性观察映射的秩是`2^n-n`；完整分割列数是Bell数B_n。

证明：空集/单点事件均为常数，所以至多有1加所有大小至少2的子集，
共2^n-n个独立行。若这些行的线性组合恒为0，在全单点分割上求值
先排除常数项；再在“只有A是非平凡块、其他点各自单独”的分割上
求值，得到Σ_(B⊆A,|B|≥2)λ_B=0。按|A|归纳，所有λ_A=0。
故行独立，秩恰为所述值。

n=1,2,3时，秩分别是1,2,5，恰等于Bell数；所有单色矩能恢复整个
无色标签分布。n=4时，15种分割只有12个可观测维度，首次缺失3维。
这里的结论是关于概率分布，不只是某一个确定染色。

## 真实单位正方形上的显式同矩、不同joint分布

取点0=(0,0)、1=(1,1)、2=(1,0)、3=(0,1)。两条对角线是01和23；
全部单位边是02、03、12、13。记竖线分隔颜色类，定义两种分布：

`μ = 1/2 [01|23] + 1/2 [0|1|2|3]`，

`ν = 1/2 [01|2|3] + 1/2 [0|1|23]`。

它们都支持proper四染色，而且都在正方形的几何对称下不变。
全部顶点子集的单色概率完全相同：对角线01、23各为1/2，其余
大小至少2的子集为0；单点和空集事件为1。

但是完整联合事件“0与1同色，并且2与3同色”的概率，在μ中为1/2，
在ν中为0。等价地，两者作为随机颜色类集合的期望完全一样，
但两个对角线等色事件的相关性不同。

若统一使用四个颜色标签并随机重命名，两者单个随机颜色类的整个
分布仍相同（包括未使用颜色对应的空集），而完整四颜色划分分布不同。
所以提升单个颜色类的矩阶数，即使一直到所有顶点，也补不回此信息。

## 对后续程序的要求

至少显式保留`[c(a)=c(b)] [c(c)=c(d)]`这种两个非平凡颜色块的joint
事件，而不能只把三点单色概率扩成四点单色概率。
进一步可用完整集合分割概率作为变量，确保每个样本的互斥、覆盖和
颜色总数限制，而不是仅在期望中满足这些条件。

这只是模型所需的信息类型，不意味着某个固定阶数已足够决定原问题。
