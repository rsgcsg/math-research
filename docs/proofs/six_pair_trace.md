# T035–T036：六轨道残例的实共轭平方和阻碍

这不是旧six-orbit包的重放：该包仍未找到。这里独立覆盖共同三色名单
这一子问题，不把它升级为任意非均匀名单的完整五色延伸定理。

## T035：双菱形/三角形结构的trace-positivity阻碍

设E⊂R有域自同构σ，σ²=id且σ(√3)=√3。写x*=σ(x)，对坐标逐分量
作用。所有提及的不同顶点要求真实不同。以下三组条件不能同时成立：

1. a,b相距1，c,d是它们的两个不同公共单位邻点；
2. a,b*是某个单位菱形的对角顶点，其另两个顶点r,s还相距1；
3. c,d*相距1。

第二条指ar,as,b*r,b*s,rs全为单位边。由两个单位圆的交点构造，
第一条给

`c=(a+b)/2+ε√3 J(b−a)/2`，
`d=(a+b)/2−ε√3 J(b−a)/2`，ε∈{±1}；

第二条给`|a−b*|²=3`。应用σ同样得到`|a*−b|²=3`和
`|c*−d|²=1`。这里必须保留σ(√3)=√3，不能把任意抽象对换当成它。

定义实向量

`h=(a+a*−b−b*)/2`，`w=(a−a*+b−b*)/2`。

对两条共轭距离取平均，由平行四边形恒等式，得到

`3 = (|a−b*|²+|a*−b|²)/2 = |h|²+|w|²`。

又由等边三角形公式、σ固定√3：

`c−d* = w−ε√3 Jh`，`c*−d = −w−ε√3 Jh`。

所以

`1 = (|c−d*|²+|c*−d|²)/2 = 3|h|²+|w|²`。

两式相减迫使`|h|²=−1`，与E的实嵌入矛盾。证毕。

这不是一种抽象图的普遍Euclidean不可实现断言；否定的是**带指定共轭
作用且该作用固定√3**的实现。它也不要求任何旧锚点，故比单纯检查
fiber距离≤2更早。成熟结构是共轭平均＋实平方和非负性，不需要给
“holonomy”另造一个无法检验的解释。

## T036：至多六个锚定二点轨道，共同三名单时总能延伸

在T032的实二次扩域模型中，六个新点对全部允许某个共同三色集合时，
这份旧五染色可以延伸。等价的图结论是：任何可实现的这种六点对
匹配图均三色可染。≤5情形已由T033保证。

### 完整有限覆盖，而非90个样本

六个轨道有15对关系，原始标号空间为`3^15=14348907`。
交换某轨道的±成员不改变几何、可染性或轨道共同名单。
对每个底层简单图按轨道对字典序取生成森林，可把每条树边符号调整
为顺向。树上依根递归选择交换，始终能做到；其余弦的符号任意。
若图有m边、6个顶点及c个连通分量，只需`2^(m−6+c)`个规范符号词。

枚举全部32768个底层图得到460728个规范模型。独立检查器不导入
生成器：逐底层图构造森林，检查每个证书词树边全正、没有重复，且
每图词数恰为`2^(m−6+c)`。因此覆盖全部原始14348907种关系。

正类保存每个模型的完整12字符染色。菱形类保存一个被迫重合的顶点对；
检查器从边集重新构造所有单位四环，并用有理高斯消元验证
`R^T λ=e_a−e_b`确有解，即碰撞是这些精确等式的线性后果。
它不因搜索器报告“无三染色”就接受负例。

最后90例各给T035六个索引a,b,c,d,r,s。检查器核对所需每条边、σ的
成对作用和两组四点互异条件。一般平方和矛盾由上面的证明承担，
不是有限浮点几何失败或对所有实现的数值猜测。

一个代表的三进制代码为898492（15个轨道对字典序、小端编码，1顺/2交）：
可取`a=0,b=2,c=4,d=10,r=6,s=8`，共轭为`i↦i xor 1`。
无需先求它的浮点坐标，就能否定所需实共轭实现。

## 这个结果真正关闭和留下什么

关闭：六个此类点对、共同三名单的坏边界；从这批90残例的数值姿态
搜索中找HN突破；把菱形线性筛选的剩余误认为真实几何可实现。

尚未关闭：六轨道的**非均匀名单**（每份至少三色），七个或
更多轨道，未锚定点，以及超出同一固定√3实共轭模型的构造。
共同三名单可染不等于3-choosable。若原名单有四色，任取三色只适合
证明可约性的正方向：缩小名单后不可染不能反推原名单不可染。
历史六轨道普适延伸仍不能整体
升级为当前硬定理；本轮明确认证的是它的共同名单部分。

与Q005的连接：在锚定二点分支，六轨道若要失败，必须使用非均匀
名单并通过T032锚点平方条件；共同名单的首次候选现在至少七轨道。
再结合T034，去低度后的轨道核还必须有四度分支。即使某个名单真的
不可染，也仍缺外部完整颜色关系的activation，不能宣布HN下界。
