# 两个独立平移方向的完整宿主：Y + Z + Zω 恰五色

2026-09-28。基于已发布 a885b67c 的精确 Y 数据；不以尚未发布的上轮三支持反证为证明前提。
本文件解决一个无限子宿主，不改变普通 Hadwiger–Nelson 的上下界。
不宣称文献优先权。搜索与独立检查分别保存。

## 1. 定理

令 ω=(1+i√3)/2，Λ=Z+Zω，Y 为已有10077点、49858条实际单位边的配置。则

    χ(U(Y+Λ)) = 5。

Y+Λ 包含全部 m,n∈Z 的 Y+m+nω，而不只是有限三角格窗口。
有限证书 `certificates/triangular_lattice_five_coloring.json` 给出9624个数 a_i∈Z/5Z，染色为

    c(q_i+m+nω) = a_i + m + 2n (mod 5)。

这里 q_i 是每个 Λ 陪集在半开基本平行四边形 [0,1)+[0,1)ω 中的唯一代表。
完整接触表有79007条无向平移轨道；全部重新生成并核验异色。
下界5继承 Y⊆Y+Λ 和原有 χ(Y)=5。以下证明上界的无限量词。

## 2. 精确代表：不以浮点取整决定几何

原32维有理基中 e_0=1，e_9=i√3，坐标分母 d=480。
两个分子向量属于同一 Λ 陪集，当且仅当除0、9以外的坐标相等，且

    p_9−q_9 ∈ (d/2)Z，
    p_0−q_0−(p_9−q_9) ∈ dZ。

因此先按第9坐标模 d/2、相应第0坐标模 d 取得代数唯一陪集键。
对键代表 z，再写 z=α+βω，其中

    β = 2 Im(z)/√3，α = Re(z)−Im(z)/√3。

减去 floor(α)+floor(β)ω，得到 q_i。检查器在数域内精确计算 α、β，
先识别有理元素，再用整数平方根产生带有理端点的包围区间，直到区间两端向下取整一致。
非有理的实元素不可能恰为整数，因此不断收紧区间最终会终止；实现另有明确资源上限，
遇到上限只报错，不猜测。η 的实、虚部分分别为 (√5−1)/4、√(10+2√5)/4。
本例所有代表由精确算法得到，与生产器最初浮点提出的代表逐项相同；结论只依赖精确算法。

基的线性独立性保证每个实际点唯一写为 q_i+m+nω。这里的基坐标不是物理实部，二者不能混用。

## 3. 为什么所有无穷边只需25个整数偏移

若 q_i+λ 与 q_j+λ+m+nω 相距1，则

    |q_i−q_j−m−nω|=1。

q_i−q_j 的两个格坐标均严格位于 (−1,1)。任意单位向量 x+yω 满足

    x²+xy+y²=1，因而 |x|,|y|≤2/√3。

于是 |m|,|n|<1+2/√3<3，整数偏移必有

    −2≤m,n≤2。

这就是完整有限化证明，不需要一个经验窗口或有效数论猜想。
当 i=j 时，单位偏移恰有六个，取反向等价后保留 (1,0)、(0,1)、(1,−1)。
当 i<j 时检查全部25个偏移，方向约定始终是左点 q_i 与右点 q_j+m+nω。

## 4. 两套不同的完整接触枚举

正式检查器不导入生产器、NumPy 或 SAT，而用模181的范数一剩余向量逐桶寻找邻点，
再用模421淘汰候选。两个模映射都逐一验证全部1024项基乘法和共轭作用；
分母在两处可逆，所以模筛选只能淘汰不可能的边。

第一次筛选命中6430417个带偏移候选；第二次筛选后64770项用数域精确范数判定。
加上每个代表的三条同轨道边，最终79007项和生产器的结果完全一致。
原Y的全部49858条实际边也逐一取回，防止偏移方向、陪集移位或排序不一致。

整个新宿主也不对η旋转封闭，因此该定理不处理交替旋转和平移生成的全部点集。

## 6. 复现与研究收敛

独立标准库重放：

    python3 -S research/verify_triangular_lattice.py

它重建Y、精确取代表、完整枚举接触、核验公式，并执行小例、边界和篡改拒绝检查。
搜索器是另一个入口 `research/search_triangular_lattice.py`，需要注明版本的NumPy和PySAT。

此结果关闭在同一Y上任意加三角格整数平移来找NON5的路线，并加强上一轮单方向整数平移上界。
不能以有限周期/仿射模型失败反推无限图高色，也不能由一个周期点集可染推断全平面可染。
真正新增的几何候选必须越过这个完整宿主，并改变自由五色关系。

把周期点集编码为带整数位移的有限图属于成熟的覆盖/群作用语言；本例的新内容是具体完整核
及其通过全部边的五色证书，不是将这种语言本身宣称为首创。
关于一般无限图周期染色需额外假设的参照：Abrishami等，Periodic colorings and orientations in infinite graphs，
arXiv:2411.01951v3（2025-06-17修订）；本次阅读其HTML第1节和第5–6节，不将其中条件外推为本例周期搜索的负完备性。
