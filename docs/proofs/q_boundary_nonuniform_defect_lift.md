# T172：七窗口非均匀 defect 定价的精确最优解

2026-10-06（Australia/Brisbane）。本页接续 T170 的 gauge 规范化和 T171 的尖锐
uniform penalty 179。目标是允许七个 saturated K7 各自有不同 defect 价格，并允许
PRR 三角 defect 另有价格，从而保留“哪个窗口坏了”的身份信息。**没有 full15
终局，也没有普通 Hadwiger–Nelson 新界。**

## 1. 固定对象

沿用 T170 的逐词整数函数 L'。零缺陷面上

    L'(c) <= 336,

且 P/Q/R 聚合系数为 (-263,500,0)。

对第 j 个 saturated K7 记

    Z_j(c)=H_j(c)-2 >= 0,

其中 H_j 是该窗口同色点对数；PRR 三角缺陷仍记 T(c)>=0。

本轮寻找逐词不等式

    L'(c) <= 336 + sum_j k_j Z_j(c) + t T(c).          (1)

T171 取所有 k_j=t=179，因此七窗口总价为 1253。

## 2. 新的精确最优价格

完整 W22 actual proper 至多五色划分上，精确成立

    (k1,...,k7)=(88,126,43,94,179,138,124),  t=0.     (2)

也就是

    L' <= 336
          +88 Z1 +126 Z2 +43 Z3 +94 Z4
          +179 Z5 +138 Z6 +124 Z7.                    (3)

七窗口总价为

    S=88+126+43+94+179+138+124=792.

独立验证器把 (3) 展成整数点对同色目标，在全部22点、34条实际单位边上按
restricted-growth 五色规范做完整 branch-and-bound。尚未决定的正权点对全部假设将来
可以同色，得到只会少剪枝的乐观上界。精确最大值为0，所以 (3) 对全部 actual proper
至多五色划分成立。

## 3. 792 不只是可行，而且是整个非均匀方法类的全局最小值

证书给出七份 actual proper 五色划分。第 j 份满足

    Z_j=1,
    Z_i=0 (i!=j),
    T=0,

并且 L'-336 分别恰为

    88,126,43,94,179,138,124.

所以如果任意实数价格 a_1,...,a_7,t 使

    L' <= 336 + sum_j a_j Z_j + tT

对所有 proper 五色划分成立，那么代入第 j 个见证立即得到

    a_j >= k_j.

这里 T=0，因此无论 t 取什么值都不能帮助逃掉这些七个独立下界。相加得到

    sum_j a_j >= 792.

而 (2) 又确实达到792。因此：

> 对固定 T170 separator L'，允许七窗口和 PRR defect 任意实数非均匀定价时，
> 七窗口价格总和的全局最小值恰为792；PRR 价格可取0。

这比 T171 的“uniform K=179 尖锐”严格更细：第5窗口确实需要179，但其他六个窗口
不需要被迫一起付179。

## 4. 平均后的新 support-independent 必要式

在 P/Q/R 平衡概率律上，每个 saturated K7 都有相同期望

    E[Z_j]=12p+3r-2.

T170 仍给

    E[L']=-263p+500q.

因为本轮 t=0，只需 S=792。对 (3) 取期望：

    -263p+500q <= 336 + 792(12p+3r-2),

即

    500q <= 9767p + 2376r - 1248.                    (4)

再用已有实际 PRR 三角传递式

    2r-p <= 1

消去 r，得到

    1000q <= 21910p - 120.                            (5)

## 5. 严格改进 T171

T171 为

    1000q <= 34357p - 581.

旧右端减新右端恰为

    12447p-461 = 12447(p-1/27).

已有 p>=1/27，所以 (5) 在整个当前允许区域不弱，在 p>1/27 时严格更强，只在
p=1/27 边界与 T165/T171 相遇。

若未来能独立证明 q>=7/10，则 (5) 会推出

    p >= 82/2191 ≈ 0.037425833 > 1/27.

这仍只是条件推论；本页没有证明 q>=7/10。

## 6. 结构意义

这一结果把“大 penalty”的来源进一步拆开了。179 不是七个窗口共同的固有价格，而是
第5窗口的真实尖锐成本；其余窗口分别只有 88,126,43,94,138,124。尤其 PRR defect
本身在这个最优表示中完全不需要额外定价。

这说明下一步应该研究这些七个 isolated-defect sharp witnesses 为什么产生恰好这组数，
并尝试把 (3) 分解成少量跨窗口 matching/transitivity 不等式。相比继续优化一个统一 K，
现在已经有了明确的窗口级“局部曲率”数据。
