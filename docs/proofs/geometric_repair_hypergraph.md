# T044–T045：指定gate的Property-B超图不是任意七元超图

2026-09-08。依赖T037的21点gate、T041的全部刚体重合分类。
令H有一份合法四色染色c，考虑所有初始坏palette包含旧颜色α的
gate；每个gate j取七个α色端点组成Aⱼ。不同模块姿态不重复，
内部仍按T039分离；本节必要几何条件本身不需要假设没有额外跨边。

## 1. 任意两条修复超边相交至多两点

T041给不同边界Bⱼ、Bₖ相交最多四点，可能的重合数只有0、1、2、4。
全部三种四点重合在每个边界中都是**两条完整单位边**。独立检查器
从36个四点锚定证书去重得到三个映射，并直接检查这个pair闭合性质。

如果Aⱼ、Aₖ共享三点，它们都为α色，不可能包含单位边。然而四点
重合中任意三点都包含上述两条单位边中的至少一条，矛盾。因此

`|Aⱼ ∩ Aₖ| ≤ 2`。

这不是任意七元超图的性质。所有用三点及以上公共块反复复制的
Property-B构造，都不能原样实现成这些gate的同色修复超边。
换成别的gate姿态模板可能改变此结论，本定理不限制所有单位图。

## 2. 任意两个α点至多共同属于16个gate姿态

设物理点x≠y都染α，因c proper有|x−y|≠1。证书边界B中非单位
距离的无序点对重数完整分布为：78种重数1、1种重数2、1种重数4。

一个等长无序源点对有两个到(x,y)的有序映射，每个再有两种平面
等距变换（保持/反转定向）。所以经过x,y的gate姿态数不超过

`4 × max_nonunit_distance_multiplicity = 16`。

这不要求x,y属于原坐标域。进一步，除两种特殊非单位距离外，该
界是4；重数2的距离给8。重复同一姿态不增加新的超边约束。
定理只给上界，不声称16个姿态能同时满足整个网络的其余几何条件。

## 3. 直接可用的稠密候选筛选

一份候选七元修复超图若不满足上述任一条件，应先作为“模板几何
不可实现”排除，不需要进入Property-B SAT。符合它们也不保证可
实现，还必须给出实际刚体位置和全部单位边。

结合外部已读的m(7)≥128，若某common-color repair超图确实不可
二染，它至少含128条不同超边。由交叠≤2，每个三元点集至多属于
一条超边。设它有v个点，逐层数包含指定点/点对的超边得

`m ≤ floor(v/7 · floor((v−1)/6 · floor((v−2)/5)))`。

解释：包含固定点对的超边，其余五点必须彼此不交，故最多
floor((v−2)/5)条；对固定点再数它与其它点的关联，每条超边计6次；
最后对全部点求和，每条计7次。v≤31时右边至多110，故这种候选
必须至少有32个不同α色物理点。它只是筛选下界，不是紧界。

未声称高密几何不可能：点的单点复用数没有在这里得到绝对上界。
许多gate共享一个点仍可形成任意大星形，而这种星形超图本身容易
二染。因此“高端口复用”也不是足够的障碍，要同时保留交叠模式。

## 对接续问题的实质约束

### T045：无额外跨内部边时，点对复用进一步至多8

T044的16只数“经过两点的姿态”，还未检查这些姿态能否共同存在。
本轮继续精确展开两种例外非单位距离：平方距离1/3有16个姿态，
平方距离3有8个姿态；其它距离已由T044限制到至多4个姿态。

对16个姿态，证书给出8个不交的互斥姿态对，覆盖全部16个姿态；
对8个姿态，给出4个不交互斥对。每一对都有一条未列入任一gate
边集的实际跨内部单位边。因此在T039的无额外跨内部边假设下，
每对最多选一个，分别至多8和4个姿态。总体得到点对复用≤8。

互斥的结构原因也很短：每对源锚点(a,b)、(a',b')满足
`a'−a=b'−b=w`且`|w|=1`。用相同定向把这两对分别对齐到同一
目标(x,y)，两个等距变换有相同线性部分R，平移部分恰差−Rw。
因此它们送出的同一内部顶点o的两个像相距1。这条跨内部单位边
不是任一单模块自身边。独立检查器也逐对核验了此单位平移恒等式。

证书`repair_pair_fan.json`保存全部24个姿态的精确坐标（统一乘以
锚点平方距离，避免数域除法）和12个具体跨内部边见证。
`verify_repair_pair_fan.py`不导入搜索器，独立检查每姿态全部210
点对距离、锚点及定向，证明它们覆盖所有等距变换；再检查互斥边
及完美配对。**没有依赖搜索器的最大团计数或全局UNSAT标签。**

这比T044多用“模块间不许额外跨内部边”的假设。若允许这些边，
便不能套用上界8，但此时也必须重新计算模块联合关系，不能继续
把各gate当作彼此独立的NAE关系。

- 七初始坏gate已由T042关闭，不能继续用一次cascade作负证据。
- 同色超图路线：搜索对象必须至少满足七元、交叠≤2、pair-codegree
  ≤8及上述距离分层，不直接移植任意非Property-B七元图。
- 任意palette路线：使用T043的完整正击中/负全选/独立性约束。
  真正的repair-UNSAT仍只排除固定四色底色的一次重染，不等于HN下界。

有限几何分类由`verify_repair_cascade.py`独立重算；外部m(7)界没有
被冒称为本地重新认证的计算定理。没有新平面上下界。
