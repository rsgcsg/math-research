# T053–T054：逃域之后，换素数及有限多模首层编码也不能给六色上界

2026-09-09。起始干净基线`c283141`。这是对现有上界方法的限制，
**不是实平面七色下界，也不是E²不可六染的证明。**

令`K=Q(√3,√5,√11)`，`E_d=K(√d)`，其中`d∈{7,13,17,41}`。
以下T053/T054对这四个数域均成立；更一般地，d为正整数、
11不整除d且d模11为非平方时亦成立。

## 1. 外部输入：使用正确常数的有限域谱界

设q为奇素数幂，`q≡3 (mod4)`，D_q是F_q²上平方距离1的图。
其度数为`D=q+1`，非平凡特征值满足

`|λ|≤2√q`。

这里的2不可删掉。Vinh早期稿的摘要渐近常数与正文Lemma4/§3
所印系数并不一致，本证明**不采用正文的√q界**。
本轮从角色和公式重新推导，唯一深的外部输入为Weil–Kloosterman界：

`|Σ_(t≠0) ψ(at+b/t)|≤2√q`，a,b非零，ψ非平凡加性特征。

原文核验：[Keith Conrad, On Weil's proof of the bound for Kloosterman sums,
Theorem 3](https://kconrad.math.uconn.edu/articles/kloosterman.pdf)。
该PDF的文字抽取乱码，已直接查看第1、4、5页，核对未扭曲和扭曲版本，
本证明用未扭曲的Theorem3。没有声称独立重证Weil界。

### 从外部输入到所需谱界

固定ψ，所有加性特征为`ψ(ax+by)`，(a,b)遍历F_q²。
单位圆的大小由二次特征η的初等求和给出`q−η(−1)=q+1`。
对(a,b)≠(0,0)，用单位圆指示函数的加性特征展开与配方：

`λ_(a,b) = q^(-1) Σ_t ψ(−t) Σ_x ψ(tx²+ax) Σ_y ψ(ty²+by)`

`= η(−1) Σ_(t≠0) ψ(−t−(a²+b²)/(4t))`。

第二步中t=0项为零；使用
`Σ_x ψ(tx²+ax)=η(t)G ψ(−a²/(4t))`及`G²=η(−1)q`。
后一个高斯和恒等式亦可直接把G写成`Σ_x η(x)ψ(x)`，在G²中
按第二变量与第一变量之比求和得到。由于−1非平方，非零(a,b)
必有`a²+b²≠0`，所以Weil界适用，得到所述2√q。

### 色数界和精确截止

Hoffman界为`χ(D_q)≥1−D/λ_min≥1+(q+1)/(2√q)`。
为明确证据依赖，也给出其短证明：若独立集大小s、总点数N，令
`g=1_S−(s/N)1`，则`gᵀAg=−Ds²/N`且`gᵀg=s−s²/N`。
Rayleigh不等式推出`α/N≤−λ_min/(D−λ_min)`，再用`χ≥N/α`。

因此若D_q可六染，必须有`(q+1)²≤100q`，即

`q²−98q+1≤0`，从而`q≤97`。

最后一步不用浮点：该多项式在q=98时为1，此后每递增1，
增量`2q−97>0`。所以所有q≥98都由同一个无限证明排除。

## 2. T053：K的小剩余域唯一候选为F11；四种逃域均将它排除

**定理。** E_d的任一奇特征有限剩余域F_q，如果x²+y²在其中
各向异性，则`χ(D_q)≥7`。特别地，不能通过Madore的
`χ(E_d²)≤χ(F_q²)`直接获得五色或六色上界。

### 证明

各向异性等价于q≡3 mod4。写q=p^f，则p≡3 mod4且f为奇数。
F_p中的非平方在奇次扩张F_q中仍非平方：Euler判据的指数倍率
`1+p+...+p^(f−1)`为奇数。

数域赋值环包含所有整数。若√m在数域中，则`2v(√m)=v(m)≥0`，
故√m也在赋值环中；约化后m必须为剩余域中的平方（允许0）。
所以任何含K的数域的这种剩余域都必须容纳3、5、11的平方根。

结合第1节，若想得到≤6色，仅需检查全部q≤97的各向异性素数幂：

| q | p | 阻止K约化的非平方根式m |

| 3 | 3 | 5 |
| 7 | 7 | 3 |
| 11 | 11 | 无 |
| 19 | 19 | 3 |
| 23 | 23 | 5 |
| 27 | 3 | 5 |
| 31 | 31 | 3 |
| 43 | 43 | 3 |
| 47 | 47 | 5 |
| 59 | 59 | 11 |
| 67 | 67 | 3 |
| 71 | 71 | 11 |
| 79 | 79 | 3 |
| 83 | 83 | 5 |

全部14项由独立整数检查器重新分解素因数并直接枚举平方余数，
不是只检查素数而漏掉27。唯一未排除的是q=11。
但d=7、13、17、41模11分别为7、2、6、8，全为非平方；
因此√d又将F11排除，证明完成。

这不是说E_d没有任何各向异性剩余域。例如E_13在131处可嵌入Q_131：
3、5、11、13模131的根分别可取38、23、50、12，且均为简单根，
逐次Hensel提升给数域嵌入。问题是这个有限目标已经至少七色，
不再能给HN所需的≤6色上界。各个平方根的选择只涉及域嵌入，
不需保持实序。

## 3. T054：有限多个首层剩余信息联合编码也不能绕过该限制

仅知道每个目标不可六染，不能一般性地断言它们的图直积不可六染；
这里必须另外证明，不能误用一般Hedetniemi命题。

**定理。** 取E=E_d、有限个不同非零素理想`P_1,...,P_m`，
其剩余域`F_(q_i)`均为奇数阶且−1非平方。令

`A=∩_i (O_E)_(P_i)`，`ρ:A²→∏_i F_(q_i)²`。

不存在函数`f:∏_i F_(q_i)²→{1,...,6}`，使`f∘ρ`
成为A²全部实际单位边的合法染色。颜色函数f可以任意，
不限线性、不限逐分量独立使用颜色。

### 第一步：联合约化不仅覆盖顶点，还覆盖直积的每一条边

不同素理想互素，整数环中的中国剩余定理给
`O_E→∏_i O_E/P_i`的满射，所以ρ满射。
取直积中任一条边：在每个坐标，其方向`(u_i,v_i)`满足
`u_i²+v_i²=1`。这是**图的张量/类别直积**，要求每一分量都是边，
不是Cartesian product。

每个方向可写成

`u_i=(a_i²−b_i²)/(a_i²+b_i²), v_i=2a_i b_i/(a_i²+b_i²)`。

若u_i≠−1，取`(a_i,b_i)=(1+u_i,v_i)`，分母为`2(1+u_i)≠0`；
若u_i=−1，则v_i=0，取(0,1)。这个第二图表不能遗漏。
以CRT同时选a,b∈O_E提升所有(a_i,b_i)。则a²+b²在每个P_i处
都是单位；因E实且(a,b)非零，它也不为零。于是

`U=(a²−b²)/(a²+b²), V=2ab/(a²+b²)`

属于A，精确满足U²+V²=1，并约化到每个给定方向。
再CRT提升边的起点z，实际单位边`z → z+(U,V)`即映到所选直积边。

所以如果f∘ρ在A²合法，f就必须是整个有限直积图的合法染色。
这关闭“源图只使用有限目标少数边”的潜在漏洞；但仅对整个A²，
不是对某个指定有限实点集。

### 第二步：此处直积的谱界仍严格超过六色

对每个因子令`D_i=q_i+1`、`a_i=2√q_i/D_i`。
T053的证明已经给出q_i≥98，故`a_i<1/5`。
归一化邻接矩阵的主特征值为1，其余均在[−a_i,a_i]中。
直积的归一化邻接矩阵是这些矩阵的张量积，特征值是因子特征值的乘积。
任何负乘积至少有一个负因子，故其绝对值不超过`a=max_i a_i<1/5`；
其余因子的绝对值至多1。于是直积最小归一化特征值≥−a，
Hoffman界给`χ≥1+1/a>6`，完成证明。

重复同一个素理想的约化不增加信息，可先删去；改变剩余域坐标的
同构只是重标记，不影响结论。

## 4. 独立有限检查及范围

  检查指数的整数计数：两侧和的每个指数系数都为2，故是
  `2(1+ζ+...+ζ^(p−1))=0`。不靠浮点特征值及误差阈值。
- 六色3+3调色板分割的300个名单交集校准，供框架重审引用。

无限结论的依据仍是第1–3节证明、外部Weil界及整数环CRT；
以上有限检查不替代它们。

## 5. 没有排除什么

1. 没有证明χ(E_d²)≥7、≥6，或任何新的HN上下界。
2. 没有排除E_d²上的五色/六色染色。失败的是这一特定编码类别。
3. 没有排除更多赋值位数、依赖赋值深度的自适应状态、非积分方向、
   各向同性剩余域的特殊处理、2进方法或其他完全不同编码。
4. 没有排除对某个有限候选图恰好有用的模像子图；边满射针对整个A²。
5. 没有排除无限多个约化信息的联合使用；有限张量谱界不能直接外推。

因此当前上界分支不应继续只寻找“另一个低色数奇数有限域”，
也不应仅把几个首层剩余域拼起来。若继续E_13，必须明确提出一个
能越过上述限制、并兼容T030任意赋值深度的染色机制。
