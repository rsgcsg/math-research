# C029：消去未知点对，严格强于先删去未知节点

2026-09-30。本例用于检验 T159 的范围边界，是成熟变量消去／路径传递性
机制的一个精确几何校准，不主张该一般原理为新发现。

## 四点的严格差距

取实际平面点 (0,0)、(1/3,0)、(2/3,0)、(1,0)，编号 0、1、2、3。
完整诱导单位图只有边 {0,3}，普通色数恰为 2。
只观察三个相邻短步点对 S={{0,1},{1,2},{2,3}}，共同同色概率记为 s；
单位端点 q₀₃=0。S 确实是部分平移 1/3 的一个完整点对运输分量。
中间弦 q₀₂、q₁₃ 尚未作为观察坐标加入。

按 T159 的逐节点已知坐标规则，只建立 qⱼₖ−qᵢⱼ 的两对都已观察的 BW 节点。
一共只有 8 个节点。其正权节点恰为

    (3,0,1)：q₀₁−q₀₃=s；
    (0,3,2)：q₂₃−q₀₃=s。

这两个节点不相邻；另外的节点权为零或 −s。
所以对每个 0≤s≤1，这个向量都被“概率 s 选择上述二节点独立集、
概率 1−s 选择空集”的向量逐坐标支配。它因此满足这个诱导稳定集模型的
所有非负系数有效不等式，远不止边与奇圈约束。
这里使用的是稳定集多面体的向下闭包，不把负坐标强行当作非负概率。

## 只用两条完整 BW 边就能改进

允许暂时保留未知 q₀₂ 后，以下两对节点都是合法冲突边：

    (3,0,1) 与 (0,2,1)：q₀₁+q₁₂−q₀₃−q₀₂ ≤ 1；
    (3,0,2) 与 (0,3,2)：q₀₂+q₂₃−2q₀₃ ≤ 1。

相加消去 q₀₂，得到

    q₀₁+q₁₂+q₂₃−3q₀₃ ≤ 2，故 s≤2/3。

这只用完整 BW 的边不等式，不需要更长奇圈。
最初直接删掉含未知坐标的节点，会丢掉这个后续可以消去未知项的有效证明。
这是“保留隐变量后投影”和“先限制可见节点”不同的具体例子。

2/3 是尖锐的。均匀选择三份两块划分

    0|123，01|23，012|3

时，三个短步的同块概率都恰为 2/3，且端点始终异色。
它们在平移源域 {0,1,2} 和像域 {1,2,3} 上的完整无标签划分分布相同。
单份交替划分 02|13 则给 s=0，同样满足完整部分平移律。
混合这两个律便实现整个 [0,2/3]，都只需要两种颜色。
因此本例的真划分律、完整部分平移律以及完整 BW 边投影都恰给 [0,2/3]，
而逐节点已知坐标的诱导模型允许 [0,1]。

## 为什么它仍不是当前 Y 的突破

上面的消去只是标准路径／三角传递性。一般地，在 j/n 的 n+1 个共线点上，
把节点 (n,0,j) 与 (0,j+1,j) 的冲突边不等式对 j=1,…,n−1 相加，
未知前缀点对会望远镜消去，得到相邻同色指标和至多 n−1。
[已读的 chorded-cycle 来源附录A.1](https://arxiv.org/html/2411.03407v1)
也从这种成熟路径不等式出发；本例不把它重新命名为 HN 机制。

对当前原 Y 的 P/R 参数区域 T，max(p,r)≤3/5。
任何长度 L≥3、各路径边都在已知 E/P/R 中、且末端比较对也已知的普通路径不等式

    Σ路径边 q − q_末端 ≤ L−1

都自动成立，因为左端至多 3L/5≤L−1。长度 2 只是三角传递性：
两条 P 边用 2p≤2/3，两条混合边用 p+r≤1，两条 R 边的非平凡情形是
已有 2r−p≤1；R,R,单位边三角形已由 T159 完整核验为零。
因此这个具体的路径消去机制不会改善当前 P/R 区域。

加入其它实际分量时须重新检查，但同样不能把单集矩已经满足的度量路径界
误称为越过了完整颜色覆盖障碍。T159 未覆盖的其它未知项消去组合仍保留为未决，
本轮在这里停止，不继续开启新搜索。
