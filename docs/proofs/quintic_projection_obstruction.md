## 1. 为什么五次根的相对次数只有二，但并不在F中

由四个独立平方类\(-1,3,5,11\)，`F/Q`是16次多二次Galois扩域，
其Galois群指数为2。`Q(η)/Q`的Galois群是循环四阶群；
`Φ₅(X)=1+X+X²+X³+X⁴`的不可约性可由`Φ₅(X+1)`的5-Eisenstein
判据直接证明。因此`Q(η)`不可能包含于F：子域对应的商群也必须指数2。

另一方面，

\[
 t=\eta+\eta^{-1}=\frac{\sqrt5-1}{2}\in K,
 \qquad\eta^2-t\eta+1=0.
\]

故`[E:F]=2`，且`F∩Q(η)=Q(√5)`。这说明七次根并不是“第一个不在F
中的素数阶根”；它只是当前F上第一个仍具有完整相对次数`p−1`的奇素数阶根。
相对次数完整是[T076](cyclotomic_integer_stack.md)分类机制的假设，
并非原始HN必须满足的条件。

## 2. C016：三个真实单位方向已排除F线性保单位投影

**命题。** 不存在F线性映射`T:E→F`，使三个方向

\[
 1,\qquad\eta,\qquad\eta^2=t\eta-1
\]

的像均为单位方向。因此更不存在保持E的全部单位方向的这种映射。

**证明。** 设`z₀=T(1), z₁=T(η)`。若三方向保单位，则

\[
 |z_0|=|z_1|=|tz_1-z_0|=1.
\]

把T乘以`bar(z₀)∈F`，仍F线性且保留这三个模长；于是可令`z₀=1`。
展开第三式并利用`|z₁|=1`，得到

\[
 t^2+1-2t\operatorname{Re}(z_1)=1,
 \qquad \operatorname{Re}(z_1)=t/2.
\]

这里`t≠0`。由单位模长，

\[
 (\operatorname{Im}z_1)^2
 =1-t^2/4=\frac{5+\sqrt5}{8}.
\]

所以`z₁`只能是η或bar(η)，两者都不在F，矛盾。证毕。
等价地，`z₁+bar(z₁)=t`、`z₁bar(z₁)=1`强迫它满足η的同一个
不可约二次方程。这个证明不需要14方向Gram系统或SAT。

### 这个三方向见证在义务条数上确实最小

这里的最小性只指：向F的F线性映射必须保持模长1的**指定单位向量数**。
并不是单位距离图顶点数、色数障碍或域次数的普遍最小性。

任给两个单位向量`a,b∈E`，若它们F线性独立，则以它们为E的F基，
规定`T(a)=T(b)=1`即可。若`b=λa, λ∈F`，由两者模长1知`|λ|=1`；
规定`T(a)=1`并把a扩成F基，则`T(b)=λ`亦为单位。只有一个向量时同理。
因此任何至多两条这样的模长义务都有解，而本节三条无解。

特别地，三个二元子集都有显式权重；按`(T(1),T(η))`表示，它们为：

| 需保单位的方向 | 可用权重 |
| --- | --- |
| `1, η` | `(1,1)` |
| `1, η²` | `(1,2(t+1))` |
| `η, η²` | `(t−1,1)` |

用`t²+t=1`逐项即得表中两条指定像都是1。未要求被省略方向保单位。

## 3. 反例方向的整个列出边平移图仍恰二色

令`M=Z+Zη+Zη²`，仅把差属于

\[
 D=\{\pm1,\pm\eta,\pm\eta^2\}
\]

的点对作为边。因为η的Q最小多项式次数为4，`1,η,η²`在Q上
线性独立。因此每点有唯一表示`a+bη+cη²`，a,b,c∈Z，整个列出边图
同构于三维整数格的标准方向图。其显式二染色为

\[
 h(a+b\eta+c\eta^2)=(a+b+c)\bmod2.
\]

每条列出边恰改变一个整数指标1；图含边，所以恰二色。
复平面的其他加法陪集采用同一公式前减去一个固定代表，亦可染这些
指定方向的边。这里**只声明D方向的完整平移图**，不自动把未列出的
其他真实单位方向当作已处理，也不宣称整个E二色或五色。

四个物理点`{0,1,η,η²}`的全部六个点对直接检查后，诱导图确实是
二分星图`K_(1,3)`。独立检查还覆盖`−2≤a,b,c≤2`的125点全部7750
点对；此有限盒的300条实际单位边恰等于列出格边，并通过上述二染色。
有限盒的诱导边完整性不被外推到更大的物理点集。

## 4. 它确实逃离原来的11进安全域，但这仍不是下界

`sin(2π/5)`是实数，其平方为`(5+√5)/8`。在
[T028](residue_field_ceiling.md)的两种√5剩余取向`√5↦4,7`下，
这个平方分别约化为8、7，均不在F11的平方集`{0,1,3,4,5,9}`中。

因此没有延拓原赋值、且剩余域仍为F11的实域嵌入
`K(sin(2π/5))`：新根的平方是赋值单位，根也必须为单位，其剩余值
将给出8或7的平方根。所得矛盾说明原小剩余域机制不能直接复用。
这不排除其他赋值机制、任意普通染色，或任意真实有限联合图的五染色。

## 5. 参数重整的独立校准：13与23在同一圆锥曲线上

这一节不是C016的前提，也不额外声称新HN结果。
同时容纳三角格N=3、4壳的有理半径`x=t₃,y=t₄`满足

\[
 \bigl[\exists\beta\in\mathbb Q:\quad
 x^2=1-3\beta,\quad y^2=1-4\beta\bigr]
 \quad\Longleftrightarrow\quad4x^2-3y^2=1.
\]

此时β唯一，由`β=(1−x²)/3`给出。圆锥曲线本身也包含β非正的点；
要成为真实新中心层，还须另外施加β正性、扩域及相应赋值条件。

经点`(1,1)`取直线`y=1+r(x−1)`，第二交点为

\[
 x=\frac{-3r^2+6r-4}{4-3r^2},\qquad
 y=\frac{3r^2-8r+4}{4-3r^2}.
\]

对有理r分母不为0。代入展开得恒等式`4x²−3y²=1`。
`r=8/5`产生`(13/23,7/23), β=120/529`；`r=5/3`产生
`(7/13,3/13), β=40/169`。所以13与23是同一有理参数曲线的样本，
并非独立的“特殊素数机制”。两样本的真实差异仍由
[T069](contact_translation_closure.md)的各向异性与迹格间隙负责。
检查器另有七个有理参数的精确校准，与C016输出明确分开。
