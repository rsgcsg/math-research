# T174：P=0 见证一次性封死单 Q / 单 R 的非负 Horn 覆盖

2026-10-06（Australia/Brisbane）。接续 T165/C030 与 T170–T173。本节只研究
T165 的 W22 七窗口饱和边界面。**没有任意支持 full15 终局，也没有普通
Hadwiger–Nelson 新界。**

## 1. 结论

W22 当前逐点认证的事件共有 47 条 P、11 条 Q、31 条 R。对任意一条指定 Q 事件
Q_i 与任意一条指定 R 事件 R_j，都存在一份实际 W22 proper 至多五块划分，
同时满足：

- 七个 saturated K7 每个恰有两对同色点；
- T165 的 PRR 三角等式取等；
- **全部 47 条 P 事件均异色**；
- Q_i 同色；
- R_j 同色。

因此全部 11×31=341 个 Q/R 配对都有 P=0 见证。

这立即推出两个方法天花板。

第一，对任意固定 Q 与任意非负实系数 a_e≥0，不可能有边界面上的逐词有效式

[
x_Q\le \sum_{e\in P}a_e x_e.
]

第二，更强地，对任意固定 Q、固定 R 与任意非负实系数 a_e≥0，不可能有

[
\boxed{x_Q+x_R\le1+\sum_{e\in P}a_e x_e.}
\tag{1}
]

因为把相应 P=0、Q=R=1 的见证代入，左端为2，右端为1。

所以此前对“小 P hitting set”的失败不是支持数太小造成的；即使允许**全部47条P**
以及任意非负权重，单Q的 P-only cover 与“单R + P”的 Horn 类仍整体不可能。

## 2. 独立有限验证

标准库检查器 research/verify_pzero_qr_witness_ceiling.py 不读取
search_sparse_boundary_projection.py、NumPy/SciPy LP 输出或 producer artifact。
它重新：

1. 从固定 Y 几何和 P/Q/R 运输分量恢复 W22 实际事件；
2. 用 T165 七窗口与 PRR 等式定义同一个边界面；
3. restricted-growth 枚举 proper 至多五块划分；
4. 在递归过程中直接强制47条 P 全部为0；
5. 对每个完成叶记录其同时激活的 Q/R 配对；
6. 得到全部341个配对后，再从头逐条检查所存见证的全部实际单位边、七窗口、
   PRR 等式、47条P以及指定Q/R。

第一次独立验收只访问523个递归节点、135个完整 P=0 叶就已覆盖全部341个配对。
发布证书不保存341份重复染色表，而保存规范见证表的 SHA256 与一个显式例子；
检查器每次都会重新构造全部见证并验证哈希。

一个显式例子对应

[
Q=(33,7479),\qquad R=(229,4641),
]

按 T165 固定顶点顺序的 canonical 颜色词为

[
(0,1,2,2,3,4,0,1,0,2,3,4,1,3,2,1,4,1,3,1,0,1).
]

它在全部47条P上均为0，同时上述Q、R均为1。

## 3. 对 C030 路线的含义

C030 的目标边际为

[
p=1/27,\qquad q=7/10,\qquad r=14/27.
]

一种很自然的稀疏分离尝试是从颜色传递性寻找 Q≤R+ΣP，再利用 P 很小来压低 q。
T174 说明这种“单个正 R 负责解释 Q”的形式在边界面上从根本上行不通：对每个 Q/R
身份组合都有 Q=R=1 而全部P=0的合法词。

这与 T170 的 Q-only 正律、T171 的三类总量正律相互补充：

- 只看Q坐标不够；
- 只看P/Q/R三类总量不够；
- 现在连“一个具体Q + 一个具体R + 任意非负P组合”的整类局部 Horn 解释也被封死。

下一步必须至少使用以下之一：

1. **多个 R 身份共同出现**的关系；
2. 正负系数并存的 genuine partition facet；
3. 多窗口 patching / matching-synchronization；
4. 边界面之外的真实运输 lifting。

这与 clique-partitioning 文献中的 patching 思路一致，但本节结论本身完全由上述实际
W22 有限见证证明，不依赖外部 facet 定理。

## 4. 范围

T174 不排除：

- Q≤Σa_P P+Σb_R(1-R) 这类使用多个 R-complement 的分数覆盖；
- 同时含多个 Q 或多个 R 的不等式；
- 有负系数的有效式；
- 离开 T165 饱和边界面的 lifting；
- W22 外的真实运输约束；
- full-Y/full15 或普通 HN 的任何最终可能性。

因此它是一个**严格的方法天花板与路线收缩**，不是原问题终局。
