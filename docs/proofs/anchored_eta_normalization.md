# 固定点有限阶运动：不丢失支持数的调色板正规形

2026-09-28。下述命题及其证明不依赖尚未发布的 T141–T143 文件。
它是完整共同律的表示正规形，不是不可五染结论，也不改变普通 HN 的上下界。

## 1. 精确命题

设 X 为有限顶点集，g 是环境上的 r 阶置换，D=X∩g^{-1}X。假设：

1. X 含一个固定点 o，g(o)=o；
2. 存在 R⊆X，满足 g(R)=R 且 χ(G[R])≥k−1；
3. gcd(r,(k−1)!)=1。

设 c_i:X→{0,…,k−1}，0≤i<m，都是合法染色。设 σ 是 m 个状态的置换，π_i 是 k 个颜色的置换，且

```
c_{σ(i)}(g x)=π_i(c_i(x))，x∈D。
```

**正规形命题。** 可以分别重命名每份词的颜色，取 f_i=q_i∘c_i，使

```
f_{σ(i)}(g x)=f_i(x)，x∈D。
```

σ 和状态数 m 完全不变；每份完整划分也完全不变，因而所有其他完整划分分布条件同时保留。
不要求 m<r，不要求 σ^r=id，也不要求 g(X)=X。

对 m 个等权词，源、像划分多重集相等即给出这样的 σ；每个配对的划分相等可以提升为某个颜色置换。
因此在这些假设下把 g 的全部调色板置换设为恒等，是固定 m 的完备正规化，不是仅用于找正例的假设。
这里的 m 计等权词，允许重复；不能把有 m 个不等权原子的律直接说成 m 个等权词。

## 2. 完整证明

取 σ 中经过 i 的长度为 ℓ 的循环，记沿该循环的调色板乘积为

```
P=π_{σ^{ℓ−1}(i)}⋯π_{σ(i)}π_i
```

（右边的置换先作用）。在固定点 o 处迭代 ℓ 次，得到 P(c_i(o))=c_i(o)。因此 P 至少固定一个颜色，
其每个置换循环长度至多 k−1，均与 r 互素，故 Fix(P^r)=Fix(P)。

对 x∈R，所有中间几何点都留在 R，故可以合法地迭代 ℓr 次。σ^{ℓr}(i)=i 且 g^{ℓr}(x)=x，于是

```
P^r(c_i(x))=c_i(x)。
```

所以 P 固定 c_i 在 R 上使用的全部颜色。这至少有 k−1 个；k 个对象的置换若固定 k−1 个，就必须是恒等。
故 σ 的每个循环的调色板乘积都为恒等。

在每个 σ 循环选一个代表，令其 q_i=id，再依次定义

```
q_{σ(i)}=q_i π_i^{-1}。
```

绕一圈的结果是 q_i P^{-1}=q_i，所以定义相容。代入即有
q_{σ(i)}π_iq_i^{-1}=id，得到所需正规形。

其他运动若使用状态匹配 τ 和调色板 ρ_i，则将它改成 q_{τ(i)}ρ_iq_i^{-1} 即保持原恒等式。
更直接地，每份词的完整颜色划分不变，故任何其他划分分布条件都不变。证毕。

最后一步是平衡 gain graph 的标准 switching；这里实际需要证明的，是固定点、互素阶数和闭合高色子图
使每个状态循环的 holonomy 都平凡。上面的证明自足，不把外部术语当作缺失引理。
术语参照：Thomas Zaslavsky 的作者[词汇表](https://people.math.binghamton.edu/zaslav/Bsg/glossary.html)。

## 3. 对原 Y 的 η 的精确应用

使用原 Y 的完整 η 最大域，而不是一个较小观察域。η 的阶为5，固定4641号原点。
以下七个有序 Y 顶点构成一份实际 Moser 子图：

```
70, 545, 547, 5805, 497, 503, 3200
```

在这个局部编号下，其十一条列出单位边为

```
01, 02, 04, 05, 12, 13, 23, 45, 46, 56, 36。
```

三染色下，第一个菱形迫使0与3同色，第二个迫使0与6同色；边36矛盾。
四染色词为0120123。因此所需的 χ≥4 不依赖 SAT 返回值。

将这七点的全部五次 η 旋转像与原点合并，得到36个不同点，且全部属于原 Y。
有限证书保存了36个点的精确32维坐标、分母480、Y编号和 η 置换。
独立检查重建 Y，逐项核对坐标、运动像和十一条实际单位距离，并检查全部3^7=2187种三色赋值及四染色正词。
这里证明下界只需列出的真实边，不声称已经利用了36点诱导图的全部边。

取 k=r=5，则 gcd(5,24)=1。故原 Y 上任何包含完整 η 域的有限等权共同律，均可令 η 的所有颜色置换为恒等，
而不改变其支持词数、状态匹配或其他运动的完整概率义务。

对 m=5，σ 在共同重编号下只有七种循环类型：

```
1+1+1+1+1；2+1+1+1；2+2+1；3+1+1；3+2；4+1；5。
```

只试其中一种仍是受限搜索；声称固定 m 完备时，其他运动的匹配及调色板也必须自由。
即使全部七类在 m=5 下被排除，也仍不等于任意支持的共同律被排除。

## 4. 自我证伪校准：哪些假设不能直接删去

**没有固定点。** 在抽象 K5 上令 g 为顶点五循环，单词给五个顶点不同颜色，调色板为同一五循环。
此时 R=X 且 χ(R)=5，但单状态的共轭不能把一个非恒等五循环变成恒等。
这是抽象校准，不是宣称 K5 有平面单位距离实现。

**没有互素条件。** 取单位等边三角形及其中心，g 为120度旋转；三角形用三种颜色，中心用第四色。
r=3、k=4、中心固定、χ(R)=3=k−1，但调色板可以是非恒等三循环，不能由一个状态的颜色重命名消除。
这是实际四点平面校准。

**没有闭合高色子图。** 令 η 为五次单位根旋转，a=1/|1−η|，取 X={0,a,ηa}。
只有 a 与 ηa 是单位边；原点固定。颜色2、0、1配合调色板换位(01)满足部分运动条件。
X 中的 η 闭合部分只有原点，且任何颜色重命名都不能让相邻两点同色。
因此恒等调色板并非任意小局部域上的完备假设。

特别地，不能把本命题自动用于较弱的129点观察系统 F：这里验证的36点闭合子图属于原 Y 的完整 η 域，
未被证明包含在 F 的局部 η 域内。
