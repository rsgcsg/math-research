## 1. 唯一数学对象与完整行列

固定实际图Y和十五个最大域g_j:D_j→g_jD_j，Ω是Y的全部proper五色划分。
记a_j(c)、b_j(c)为源和像的完整划分。每列是

```
D[(j,p),c] = 1[a_j(c)=p] - 1[b_j(c)=p]。
```

同一个概率律满足全部运动，等价于 `Dλ=0, λ≥0, Σλ=1`，见[T114](finite_joint_support.md)。
有限词池C只保留部分列，但行必须包含C中每个词在**全部运动两侧**产生的所有模式。
其余行在这些列上全零，暂不存储不改变受限主问题。后来出现的新行必须立即加入。

对一个整数潜势y（未出现模式的系数取0），定义

\[
F_y(c)=\sum_{j,p}y_{j,p}
       (1_{a_j(c)=p}-1_{b_j(c)=p}).
\]

主问题求解器只提出y；程序用纯整数重算C上的每个F_y，并且只接受
`min_{c∈C}F_y(c)>0`。浮点LP的状态、目标值和舍入结果都不是证明。
若提出正权，也必须重构为有理数，并逐行验证精确平衡，才接受为正律。

## 2. 反例查询和两个不能省略的分支

给定以上候选，定价查询是

\[
c\in\Omega,\qquad F_y(c)\le0.
\]

SAT时，输出整个10077字符词；检查它满足所有实际边、所有事件的真实含义及该不等式。
这个词必是新列，因为旧列的F_y全部严格正。随后对所有十五运动加入其完整模式行。

无反例时，仅在有独立完整反证后才可以断言全词正间隙。整数y使严格正值至少为1，
可以把它送进[T105](arbitrary_motion_joint_compiler.md)。**当前生产器不具备一般大规模
UNSAT证明检查后端**：它将求解器否定保存为`UNSAT_UNCERTIFIED`，最终仍标记定价未决，
绝不生成全词障碍判定。本次实际记录的30个新列查询全部SAT，不依赖这一缺失后端。

稀疏策略先尝试更有用的 `F_y≤−1`；只有这个更强查询UNSAT后，才改查 `F_y≤0`。
前者UNSAT不意味着原分离成立：可能存在F_y=0的合法列。超时也不意味着不存在反例。
代码在更强查询UNKNOWN时停止该轮，不借更弱查询的成功偷偷证明更强查询不可行。

在**理想的精确主问题及完备定价／反证接口**下，每次循环增加一个新列，Ω有限，
故至多|Ω\C|次后得到正律或完整负证据。这个初等终止证明不提供实用规模界，
也不是对当前浮点提议、有界SAT及未完成负后端的程序作无条件完成保证。

## 3. 完整划分事件的线性大小编码

对一个指定d点、b≤k块的完整划分，给每块选一个代表。要求同块其余点与代表同色，
不同块代表两两异色：共有d−b个相等条件和b(b−1)/2个不等条件。
它们恰好刻画该完整划分，不需要猜一个调色板，也不需要列出d(d−1)/2个相等事件。

设x_{v,c}表示v取颜色c；每点恰一色、每条实际边异色。对点对v,w引入e，加入每个c的

```
¬x_vc ∨ ¬x_wc ∨ e
¬e ∨ ¬x_vc ∨ x_wc
```

恰一色保证 `e ↔ (v,w同色)`：若两点同色，第一行强迫e；若e为真，v的唯一颜色
由第二行传给w；不同色则不可能e真。令事件变量E与全部指定正/负e的合取双向等价。
因此E真**当且仅当**完整划分出现；不是只有一个方向的松弛。

负整数系数v·E改写为 |v|(1−E)+v，转成正权基数上界。程序展开重数并用totalizer编码；
系数展开超过预设上限时停止，不把资源上限作为不可行。编码先在C024全部四个合法带标签词上，
穷尽81个系数组合与5个阈值，共405个SAT查询，并与直接算术真值比较。
另有1851次辅助变量翻转校准；这些校准不代替上面的任意域证明。

有限校准还发现PySAT特定bootstrap路径不能直接接受空子句；把恒假条件改成新变量的一对
矛盾单位子句后通过全部405个查询。这是接口修复，不是数学反例或大实例负证据。

## 5. C024：最少四点即可各运动分别可行、共同不可行

取复平面上的四点

\[
A=0,\quad B=1,\quad C=\frac{1+i\sqrt7}{4},\quad D=\frac{1+i}{2}.
\]

其六个平方距离为

\[
AB^2=BC^2=1,\quad AC^2=AD^2=BD^2=\tfrac12,
\quad CD^2=\tfrac{3-\sqrt7}{4}.
\]

最后一个数严格在0和1之间（2<√7<3），所以全部实际单位图恰为P₃加一个孤立点。
其两个proper二色划分，可用 `0100` 和 `0101` 代表，点序为A,B,C,D。

定义实际等距运动

\[
 g_1(z)=\alpha z,\quad g_2(z)=1+\beta z,
\]
\[
\alpha=\frac{1+\sqrt7}{4}+i\frac{1-\sqrt7}{4},\qquad
\beta=\frac{\sqrt7-1}{4}+i\frac{\sqrt7+1}{4}.
\]

精确乘法给|α|=|β|=1，且它们在X的完整最大域分别是

```
g₁: A→A, C→D；    g₂: A→B, C→D。
```

另外两个点的像逐点不在X；检查器以Q(√7)算术检查，不使用近似重合。
每个二染色有A=C且A≠B。因此g₁-joint要求A=D几乎必然，g₂-joint要求B=D几乎必然。
各自分别有正律：`0100`和`0101`，但不可能同一个律同时满足。

取两个“同色”事件差，两个完整合法划分给列

\[
 D=\begin{pmatrix}0&1\\1&0\end{pmatrix}.
\]

每个单行都有概率解；两行一起没有。y=(1,1)给

\[
F_y(c)=2\,1_{A=C}-1_{A=D}-1_{B=D}=1
\]

对全部proper二色词恒成立。这是无条件完整负证据，不是固定权重失败。

### 点数最小性，不靠坐标网格枚举

设X至多三点，Ω₂(X)非空，且每个所选部分等距运动单独有joint。
若实际图无边，恒同色词同时满足所有运动。
若图连通，其proper二色划分唯一，单独可行即说明同一划分逐项相容，故共同可行。
剩下的非平凡情形只能是一条边加孤立点。给其两个proper二色划分各质量1/2：
任意单位点对必异色，任意非单位点对同色概率恰1/2。
一/二点部分运动保距离，故完整划分律相等；三点全运动是实际图的自同构，置换两个
合法划分而保持均匀律。故这一个律同时满足所有部分运动。
于是不存在至多三点的反例；以上四点反例最小。两个运动也显然是最少的数量。

### 直接编译为五点实际奇环

令E=g₁(B)=α，F=g₂(B)=1+β。点序A,B,F,D,E的全部单位边恰为

```
A—B—F—D—E—A。
```

AB来自原图，AE、ED来自g₁(P₃)，BF、FD来自g₂(P₃)。精确检查全部10点对没有别的单位边。
这是实际诱导C₅，不可二染且可三染。无需调用T105的巨大通用盒界。
C024并不声称“分别存在整个无限轨道的染色”，只声称指定有限完整域的各自joint；
也不把二色校准升级为任何五色HN障碍。

## 6. 跨领域解释和真正保留下来的方向

D的零凸组合是多组边际同时平衡；单运动时退化为有向图循环流，多运动时是共享同一列权的
多组流，而不是各自找环再平均。C024把这个量词差异压到一个2×2矩阵。
CSP语言提醒每列必须来自整个proper空间；有限概率边际语言提醒所有运动共享同一个概率律。
有限群或坐标变化并不替代这两个条件。

Chazottes–Gambaudo–Hochman–Ugalde的移位不变测度边际研究也区分局部不变与全局延拓：
一维和更高维行为不同。但其格移位结果不是当前单位距离实例的不可延拓定理。
本轮读取作者摘要，未以未读全文主定理作为新增证明输入。
SCIP官方变量定价说明强调：新增变量须加入所有相关约束；这是本轮全模式行维护的成熟对应，
不是从一般图的独立集定价到当前完整五色列的自动等价。

仍保留的主攻是一个真实实例上的完整正律或全词严格分离；几何备线是无条件五色关系收缩；
上界备线必须有所有有限实代数配置的覆盖机制。原始上下界仍5/7，不预定答案6。
