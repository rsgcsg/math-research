## 1. C025：最小支持为2，但所有共同律并非两词包的混合

V是T141的29点、30实际单位边配置，沿用其0–28局部点序。
每个运动g_j取自己的完整最大域 `D_j=V∩g_j^{-1}V`，a_j、b_j分别为源/像完整划分。
Ω₅(V)是V全部合法至多五块划分，P(V)为满足15个完整推前等式的概率多面体。

T141已经证明P(V)的最小划分支持数恰为2。本轮另构造三份不同的完整划分，由下列词表示：

```

p₁ = 14220144202300144420434014233
p₂ = 01040313100024431101424431002
```

每份词在全部30条实际边上异色，均匀分布


满足V的全部15个完整最大域。它不仅可行，而且是**整个P(V)的极点**。
完整词、模式、秩证据保存在[局部证书](../../certificates/localized_motion_packet.json)的
`three_word_extreme_law`；独立检查器直接重建全部实际边、运动域和完整模式多重集。

### 1.1 不依赖浮点LP的极点证明

只看η（原索引2）的13点完整局部域。按模式的位置块写，以下两行都来自真实的
`D[(j,p),c]=1[a_j(c)=p]−1[b_j(c)=p]`：

```
[[0],[1,4,7,8,12],[2,3,5,9],[6,10],[11]]       → (-1, 1, 0)
[[0,1,4,7,8,12],[2,5,9],[3,11],[6],[10]]       → ( 1, 0,-1)
```

在这三个原子上的列序是(p₀,p₁,p₂)。添加归一化行(1,1,1)后，3×3整数矩阵行列式为−3。
所以任何仅支持在这三个划分上的可行概率，都必须令三个质量相等，因而等于ν。

若 `ν=θ μ₁+(1−θ) μ₂`，其中0<θ<1且μ₁、μ₂∈P(V)，
则ν在这三个划分以外的质量为0、各概率非负，迫使μ₁、μ₂也不在外部使用任何划分。
由刚才的唯一性μ₁=μ₂=ν。这证明ν是整个可行多面体的极点，而不只是在一个受限词库里极端。

故ν不可能是两支持共同律的凸组合；即使允许任意新的两词包，也不能用非负混合产生它。
结论并不依赖T141的单词反证：在ν的三个原子中，任何可行律必须同时使用全部三个。
T141只说明同一系统还存在支持为2的其他可行律。

**C025的精确作用：** 在一个实际二维单位配置、真正的15个完整局部运动域中，
“最小支持为2⇒两词包的凸包覆盖全部可行律”已经错误。
这不证明全Y六域Γ或全Y15域也具有同一个不分解反例；它们的词与延拓条件不同。
两词包仍可作正向搜索素材，失败不能成为完备的负搜索结论。

## 2. 支持置换的三循环不等于实际旋转的五阶作用

在上述三划分中，η源/像模式的支持匹配是唯一的：

```
a_η(p_i) = b_η(p_σ(i)),     σ = [2,0,1].
```

所以σ是一个3循环。但几何中的η=exp(2πi/5)满足η⁵=id。
局部共同律只要求两侧模式分布相同，并不要求保存状态上的匹配满足σ⁵=id。
本例是这一差别的完整正证据：ν的局部η律乃至全部15个局部律均成立。

仅复制支持状态也不能使这份特定三原子律获得一个符合η五阶关系的作用。
精确地，假设有限状态集合I上的每个状态都标有这三个完整V划分之一，f:I→{0,1,2}；
假设置换T满足 `a_η(p_f(s))=b_η(p_f(Ts))` 且T⁵=id。
唯一匹配迫使 `f(Ts)=σ(f(s))`，迭代五次得 `f(s)=σ⁵(f(s))`。
3循环的五次幂没有不动点，矛盾。引入颜色重命名或同划分的重复状态不改变此论证。

这只否定**符合真实五阶群关系的该支持表示**，不否定局部共同律ν本身。
也不能反过来把σ⁵=id无条件加进所有有限共同律编码，否则会删掉这里已经认证的合法局部正解。
下一节通过补齐真实几何轨道，说明何时五阶关系确实成为必要条件。

## 3. T142：一般有限阶运动的循环延拓不等式

设g是实际空间上的等距运动，g^q=id，q≥1；V有限，

```
W = ⋃_(r=0)^(q−1) g^r V.
```

对固定k，取V上一组完整合法k色划分集合A（可以不是全部划分）。
令D=V∩g^(-1)V，对p∈A定义a(p)为p在D上的划分，b(p)为p在gD上的划分拉回D。
建立有向兼容图：

```
p → p′  当且仅当  b(p)=a(p′).
```

**循环延拓引理。** 若这个兼容图没有长度恰q的闭合游走（允许重复顶点），
则对W的每份合法k色划分c均有

```
Σ_(r=0)^(q−1) 1[(c∘g^r)|V ∈ A] ≤ q−1.
```

若概率μ在W全部合法k色划分上且满足g的完整不变性，则

```
μ{c:c|V∈A} ≤ (q−1)/q.
```

证明：令p_r=(c∘g^r)|V，r按模q取值。若全部p_r∈A，则对x∈D有
`c(g^r(gx))=c(g^(r+1)x)`，从而 `b(p_r)=a(p_(r+1))`。
真实恒等式g^q=id给p_q=p₀，于是形成A兼容图上的q步闭合游走，矛盾。
所以至多q−1项指示为1。若μ完整g不变，各项的期望相同；取期望并除以q即得。
证毕。

逐词部分实际上仅用真实点重合与划分限制，不依赖遗漏的颜色标号或给定支持匹配。
概率部分明确需要W上的完整g不变性；V上单步的局部推前等式不足以保证它。
这一必要不等式对任何支持数、任何非负实权重成立，不是词池内分离。

## 4. 实际五次轨道：86点110边，三划分总质量至多4/5

应用到本例g=η、q=5、A={p₀,p₁,p₂}。
由证书中的真实完整模式重建，有向兼容矩阵为

```

```

即每步沿3循环前进。因此只存在长度能被3整除的闭合游走，没有长度5的闭合游走。
这里的前进方向与第2节支持匹配σ相反，因为真实层序使用 `b(p_r)=a(p_(r+1))`。
检查器逐一核对全部3^5=243个长度5的标签序列，接受数为0；证明本身也由3不整除5立即得到。

五份29点映射及全部110条实际单位边。独立检查器从V坐标乘η重建五层，逐点确认η⁵=id，
再精确检查全部3655个点对，而非只检查方便列出的运输边。

**T142在本配置的结论：** W上每份proper五色词至少有一层的V划分不在A中；
W上每个η不变五色概率律均满足

```
μ{c:c|V∈{p₀,p₁,p₂}} ≤ 4/5.
```

第1节局部全15域正律ν把质量1放在A上，所以它不可能是W上任何η不变proper五色律的V边际。
这个结论是对所有可能延拓的否定，而不是对某个预定状态数或固定旧色词的否定。
因此，局部完整共同律与真实有限阶几何闭环的相容延拓，确实是不同层次的问题。

## 5. 和原10077点问题之间的关系

独立完整Y重建后，W有56个点已经在Y中，另30个点不在Y中。
故W不是Y的子配置；不能仅凭W上的η不变必要条件就宣称所有现有Y局部15域律必须满足此4/5界。
本轮没有证明该界独立于现有Y约束，也没有证明上述ν能先延拓成Y上的15域律。

本轮还逐一把p₀、p₁、p₂延拓成整个Y的proper五色词，三份完整词保存在
[独立延拓证书](../../certificates/cyclic_pattern_Y_extensions.json)，总检查重建Y后核验149574项边义务及V限制。
所以不能用“某一个局部划分本身不允许在Y中出现”解释这个例子；三种局部状态在全Y中各自都能出现。
但这些单独延拓未构成共同运动律。进一步固定三种局部限制、尝试三个全Y词共同满足Γ，
6000冲突预算实际6002冲突后仍UNKNOWN_FIXED_SUPPORT；既没有正律，也没有三词不可能性的独立证明。

有一个明确的增强有限实例：`Y⁺=Y∪W`，恰10107点；其中W是η不变的子集。
Y⁺上满足η完整最大域推前等式的任何律，限制到W后η完整不变，所以必满足上述4/5界。
这一推导只用域限制，不需要先求出Y⁺全部运动匹配。
若实际搜索Y⁺的正律/反证，仍须建立其声称对象的精确几何、完整域和独立证据；
本轮没有运行Y⁺全15域求解，也没有完成Y⁺全部跨边清单。

W⊂H′Y，故Y⁺也在已五染的T138宿主H′Y中，普通五染色已有该无限上界覆盖。
因此这30个点不会把普通图直接变成NON5；价值在于给有限共同律加入一个明确的真实几何闭环限制。
完整全等／平移共同律仍可能产生更强义务，但不能从这一个旋转闭环得到原始HN新界。

对局部V而言，新界确实严格：ν是满足全部15个局部域的已认证极点，却违反几何延拓界。
对全Y而言，新界是否提供新的有效排除、以及其余运动的共同相容性，仍是待检验的实际研究问题。
这是一项带有完整反例和尖锐常数的结构校准，不把“原子数2”或“群阶5”自身当作HN不变量。
