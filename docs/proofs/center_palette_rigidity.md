# T075：中心彩虹置换规则的强制周期与11进不连续性

2026-09-10。接续T074，检验其中心分壳是否能与整个数域的剩余
染色直接组合。这里得到一个严格的方法障碍，不是六色单位距离图。

固定`K=Q(√3,√5,√11)`、`α=2√10/13`、`Y=K²+αΛ`，
`Λ=Ze₁+Ze₂`、`e₁=(1,0)`、`e₂=(1/2,√3/2)`、`J(x,y)=(-y,x)`。
α不在K中，故`p+α(me₁+ne₂)`的表达唯一。

## 1. 精确假设与结论

取三个五色置换`σ₀,σ₁,σ₂∈S₅`，要求对每个色名a，
`σ₀(a),σ₁(a),σ₂(a)`两两不同，称为**彩虹条件**。令

`c(p+α(me₁+ne₂)) = σ_[m−n]₃(g(p))`， (1)

其中`g:K²→{0,1,2,3,4}`任意，不预设周期或剩余公式。
T074的加0、1、2是一个特例；任意三个不同模5偏移也都满足假设。

**T075. 如果(1)是Y的合法五染色，那么：**

1. g必须沿`H=(3/13)JΛ`周期：`g(p+h)=g(p)`，对所有p和h成立。
2. g是K²单位图的合法五染色，并且对每个Λ单位步e有
   `g(p+(7/13)e)≠g(p)`。
3. 对K上固定的11进赋值拓扑，g在每一点都不连续。尤其不能由
   任意有限11进精度的剩余信息决定，即使允许非线性表、按积分
   陪集选择不同表、或依赖点而变化的局部有限精度。

前两项也充分：任意满足它们的g配上上述彩虹置换，(1)就是合法
五染色。这个等价刻画未决定此类任意不连续g是否存在。

这是受限规则的必要条件，不给原始HN附加彩虹、连续或周期假设。
也没有排除一般三份独立函数`c=f_[m−n]₃(p)`或非分离中心规则。

## 2. 六个交叉不等式强迫相等

先证明一个与几何无关的小引理。若a,b满足

`σ_r(a)≠σ_s(b)` 对全部 `r≠s`， (2)

则a=b。否则置换的单射性又给出`σ_r(a)≠σ_r(b)`。于是三个
颜色组成的集合`{σ_r(a):r=0,1,2}`与另一个三元素集合
`{σ_s(b):s=0,1,2}`互不相交，要求至少六种颜色，与五色矛盾。
反过来a=b时，彩虹条件恰给出(2)。

所以这不是把两类颜色关系随意压成相等；相等是六个实际义务
与五色容量共同强迫的。更一般地，同一论证适用于k种颜色、s个
逐色互异的置换状态，只要`2s>k`且全部异状态交叉义务都存在。
这个容量条件不可直接放宽到六色：模6加0、1、2时，a=0和b=3
分别占用{0,1,2}和{3,4,5}，a≠b却满足全部交叉不等式。

任意公共输出颜色重命名可将σ₀正规化为恒等。独立枚举120²个
剩余置换对，恰552对满足彩虹条件；其13800个(a,b)义务全部只
允许a=b。没有把几何中心编号当作可自由置换的色名。

## 3. 两种N=4符号产生全部六个义务

取任意Λ单位步`e=u e₁+v e₂`。令`h=(3/13)Je`。对任意p和
中心z，以下两种都是真实单位边：

`p+αz — p+h+α(z±2e)`。

确实`h·e=0`，且`|h|²+4α²=9/169+160/169=1`。
两端中心状态之差为`±2(u−v) mod3`。单位步有`u−v≠0 mod3`，
两种符号与三个起点状态恰给出全部r≠s。应用第2节，得到
`g(p+h)=g(p)`。六个单位步生成Λ，故整个H都是g的周期。

同中心边在同一σ_r下比较，单射性给出g的单位不等式。
N=3边的核心差是`(7/13)e`，中心差为
`±((u+2v)e₁+(-2u−v)e₂)`，所以中心状态不变，给出第1节的
另一个不等式。反向检查同样成立：同中心和N=3由g的不等式处理，
N=4由周期相等和彩虹条件处理。T067的完整壳分类保证没有其它边。

## 4. 单个有理周期已经排除任何局部有限11进精度

取`e=e₁`，则`h=(0,3/13)`是g的周期。令`v=(0,1)`为实际
单位向量。对任意正整数k，取唯一`0≤t_k<11^k`使

`3t_k≡13 (mod 11^k)`。

它存在，因为3在模11^k可逆。于是

`v−t_k h = (0,(13−3t_k)/13) → 0`， (3)

收敛指11进赋值拓扑；无论所选K赋值在11上是否分歧，有理数的
11进阶趋于无穷都保证(3)。没有对实拓扑作此收敛断言。

对任意x∈K²，令`x_k=x+v−t_kh`。则x_k→x，而周期性与单位边给

`g(x_k)=g(x+v)≠g(x)`。

有限颜色集取离散拓扑，因此g在x处不连续。x任意，故处处不连续。
论证没有统一精度假设：只要g在一个点附近由有限剩余信息决定，
就与该点的上述序列矛盾。

例如固定赋值环A及其任意开理想I，若在每个K²/A²陪集C选择代表
r_C，再让g仅依赖C和`p−r_C`在`(A/I)²`中的像，该规则处处局部
常值，故不可能。
增加有限多层11进位、换任意非线性表，或各陪集用不同有限精度都无效。

初始`t₁,t₂,t₃,t₄=8,85,448,9765`。检查器核验前32个整数恒等式；
全部k以及处处不连续的结论来自上面的统一证明，不从32个样本外推。

## 5. 与T074、T057的边界

T074只在`P+(7/13)Λ+(3/13)JΛ`上定义核心函数，不是在整个K²
上定义。其整数标签染色不承诺11进连续，故与本定理无冲突。
本结果关闭的是“保留中心彩虹置换，再把核心词替换为有限11进
剩余规则”的全部组合，不是关闭中心分壳本身。

T057关于完整扩域和有限精度谱方法的障碍不能直接套到Y；这里用
Y中实际N=4边和一个有理周期得到独立证明，未借用那个更大宿主下界。
重新查看[Madore v1 Proposition 3.2](https://arxiv.org/html/1509.07023v1#S3)
的约化方法，只用于核对积分陪集与剩余上界的背景；T075及其
不连续性论证是本地推导，不归给该论文。

### 一个恰二色的无限校准宿主

取真实点集`B={(αm,k/13):m,k∈Z}`。单位边恰满足
`40(Δm)²+(Δk)²=169`。由正性，`|Δm|≤2`、`|Δk|≤13`，直接
枚举得全部差为`(0,±13)`与`(±2,±3)`。所有Δk均为奇数，故
`c₂(m,k)=k mod2`合法，且存在单位边，所以**χ(B)=2**。

然而在B上，同样的彩虹规则`c(m,k)=σ_[m]₃(g(k))`由两种Δm
符号强迫`g(k+3)=g(k)`；单位边又要求`g(k+13)≠g(k)`。相同的
`3t_k≡13 mod11^k`逼近说明g在Z的11进拓扑中处处不连续。
这里不连续规则确实存在：`g(k)=k mod3`与σ_r(a)=a+r mod5给
显式五染色。检查器对完整六种单位差和18个状态同时核验两条公式。

因此这个方法障碍甚至能出现在实际恰二色的宿主上，绝不能把它
解释为六色图证据；它真正排除的是指定规则与指定拓扑精度的组合。

## 6. E038：真正越过X的饱和平移探针

另检验`Y₁=X+Λ=P+(1/13)Λ+(3/13)JΛ+αΛ`。
等号由7和13互素给出，且它严格超出X：`3e₁/13`属于Y₁而不属于X。
前者由`3=6×7−3×13`得到。若它属于X，α中心必为0，核心点
必须落在Q(√3)²；P中x的√3系数和y的有理系数为0，迫使JΛ指标
c=d=0。写该核心点为`a₀e₁+b₀e₂`，余下两个指标只能是
`a=(3−13a₀)/7`、`b=−13b₀/7`。独立检查509个核心候选，没有
同时为整数者。因此严格包含已用直接有理数计算核验，与搜索器
接触编译无关。注意`e₁/13`反而已在X中：`−e₁+2(7/13)e₁`。

搜索器以正定迹枚举同中心接触，并先合并重合核心/状态标签。
