# 外部G29证书的独立精确重放

本文件核验Dúcz–Varga论文的外部结果，不把它算成本项目的新数学定理。
来源：[论文](https://arxiv.org/html/2606.28157v1)、
[作者验证包](https://users.renyi.hu/~akos/ep1070/)。

## 已完成的检查

`research/snail_replay.py`与`snail_geometry.py`使用Python标准库，
从论文的27点坐标矩阵以及新增p、q公式重建顶点（验证包顺序为p、q、原27点）。
不执行作者脚本，不反序列化SymPy对象数组，不信任预计算IEC矩阵。

精确实数域使用16维基

`sqrt(3)^a sqrt(11)^b sqrt(5)^c t^d, a,b,c,d∈{0,1}`，

其中`t²=(415+79 sqrt(33))/8`。前三根的平方类独立；t²在翻转sqrt(33)
的实共轭下为负（两个共轭的积为-527），因此它不是全实基础域中的平方。
所以这个二次塔的16个基元确实线性独立，系数比较是精确相等判定。

本地结果：

- 所有406对顶点距离已精确计算，诱导边51条；p、q都只邻接原v_3。
- 独立生成全部498168个独立集。
- 16859条全等关系均按指定对应逐对检查距离；2042个不同距离比较。
- 所有498168条整数对偶不等式通过，最小slack为0。
- 对偶下界为`4000716307/1000000018 > 4.0007`。

对每个独立集I，所检不等式为

`Σ_r y_r (1[L_r⊂I]-1[R_r⊂I]) - 4000716307*1[0∈I] + 1000000018 ≥ 0`，

这里y_r已化为共同分母后的整数。乘以任意可行独立集权重并求和，
全等项消失，覆盖点0的权至少1，故总权至少为上述有理数。

计算没有构造498168列的稀疏IEC矩阵，而是先按子集汇总整数系数，
再在独立集这个向下封闭族上作subset-zeta变换。每步删除一个点仍是
独立集，故普通子集和递推完整适用；这是精确整数加法，不是浮点LP验证。

## 重放与严格范围

下载作者的`data/snail.zip`到`references/cache/snail.zip`后运行：

```sh
python3 research/snail_replay.py --output certificates/snail_replay.json
```

下载包SHA256、全部计数与精确界保存在结果JSON中。没有重放论文的
两个blow-up构造，没有构造其巨大普通图，也没有证明原29点普通色数>4。
本核验只直接证明其geometric fractional下界；其对原问题的用途仍须
引用正确的外部blow-up定理。T023仍限制这种方法不能通过>5证明六色下界。

同包提供的23个最优面顶点，其支持并集恰含168个G27独立集。后续已经
取得并独立验证G27原对偶，零松弛支持与这168项完全一致；任何总权4的
可行geometric fractional律只能使用这些支持，但这不是对任意普通
G27四色划分的限制。完整joint后续已得精确结论T025，见
[G27完整joint支持](g27_joint_laws.md)。
