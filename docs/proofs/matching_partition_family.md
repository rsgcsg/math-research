# 独立数至多2的划分律；C027 五边形完全正矩反例

2026-09-30。匹配多面体部分是成熟定理的应用，不声明原创性；C027是本项目对一个具体错误充分性推断的精确校准。它不是HN新界，也不是原Y的全15域解。

## 1. 一个可以完整描述成对律的图族

设有限简单图G有n个顶点，且独立数α(G)≤2，记补图H。每个proper划分的颜色类只有单点或二点；二点类恰组成H的一个匹配M。反向给匹配加上剩余单点类，得到唯一proper划分。类数是n−|M|，所以

    χ(G)=n−ν(H)。

支持于至多k块proper划分的概率律，其非边同块概率向量的精确集合是

    conv{1_M : M是H的匹配，|M|≥n−k}。

根据 [Edmonds 的匹配多面体定理，1965 §2 Theorem(P)](https://nvlpubs.nist.gov/nistpubs/jres/69B/jresv69Bn1-2p125_A1b.pdf)，它可以写为

- 每个H边x_e≥0
- 每点的关联边概率和≤1
- 每个奇数大小顶点集S内的H边概率和≤(|S|−1)/2
- 全部H边概率和≥n−k

前三组是匹配多面体，最后是整数的总边数门槛。第四组没有引入额外分数顶点，证明如下。

## 2. 为什么总匹配数的整数门槛保持整性

两个匹配的对称差分成互不相交的交替路径与偶圈。若有至少两个非平凡分量，交换其中一个分量，得到另外两个匹配，且两者关联向量之和保持不变，因此原两匹配向量不可能是多面体的一条边。故相邻匹配顶点只在一个交替分量上不同，匹配数差至多1。

用一个半空间切多面体，新顶点若出现只能位于被切开的原边上。相邻匹配数是差至多1的整数，整数门槛无法在边的内部产生新的分数交点。因此总边数≥n−k的截面仍是满足门槛的匹配向量凸包。

这里门槛须是整数，且统计的是全部边。K2的匹配多面体是[0,1]，门槛1/2就会产生分数顶点；只对某个严格边子集加限制也不能照搬证明。相关标准结果和范围见 [Walter等的作者稿](https://www2.isye.gatech.edu/~sdey30/CCTPMCoo1.pdf)。

若只要求成对事件在给定部分映射下平衡，可以在该精确多面体上再加对应线性等式；可行点确实可以分解成同一个proper划分概率律。这并不表示成对均值确定这个律，也不自动满足完整域模式分布的相等。完整模式义务仍是另一层约束。

## 3. C027：在一个真实单位五边形上，单独立集CP矩仍可能不是划分矩

取单位边长正五边形，实际单位图G=C5，补图H也是五圈。每个proper划分的二点类是H的匹配，因此至多有两个同色非边点对。

构造候选矩Q：对角为1，G的单位边位置为0，H的五条边位置各为1/2。它有以下性质：

1. 选择H的每条边作为独立集，各给概率1/10，再给空集概率1/2。指标X满足每点包含概率1/5，且Q=5E[XXᵀ]，所以Q完全正
2. Q−J/5正定；20(Q−J/5)的精确顺序主子式为16、240、3200、26000、200000
3. 所有成对三角不等式、度数约束、三点奇集约束以及k=5的全部子集鸽巢下界都成立
4. 但五个允许同色点对概率的总和为5/2，超过每个实际划分的上限2，故不可能是任何proper划分律的成对矩

缺失的是五点奇集／blossom约束。这是针对特定Q的不可表示性，即使允许超过五种颜色也不能把它修好；它不否定五边形自身有三染色。

这里没有证明 [正十二边形打包所产生的特定平稳矩](full15_joint_event_theory.md#3-单个独立集的矩与完整划分律之间的缺口) 违反这个五边形约束，不能把任意CP反例替换成该具体平稳构造的计算结果。

## 4. 几何和枚举证书

令a=√5、b=√(10+2a)，取点

    (0,0), (1,0), ((3+a)/4,b/4), (1/2,(1+a)b/8), ((1−a)/4,b/4)。

独立检查器在a²=5、b²=10+2a中精确计算全部十个平方距离：五个为1，另外五个为(3+a)/2。由实际边直接筛选五点的52个划分，得到11个proper划分；再独立枚举H的11个匹配，逐一核对对应关系与最大二点类数2。

`make check-pentagon-partition-gap` 使用标准库重放几何、CP表示、正定主子式和blossom违反，比较 `certificates/pentagon_cp_partition_gap.json`。检查器为 `research/verify_pentagon_cp_partition_gap.py`；不调用SAT、SDP或浮点线性代数。

## 5. 用在哪里，不能用在哪里

该族给出一个确切的局部增强：非负、PSD或单独立集完全正性之外，还需颜色类不能重叠的匹配奇集结构。对于α(G)≥3，颜色类可含三个以上点，匹配编码便不再完整。

对平面单位图，这个族只能是小窗口：单位图不含K4，而[经典R(4,3)=9](https://doi.org/10.4153/CJM-1955-001-4)使α≤2的单位图至多8点。因此不能由此构造任意大的全Y精确模型，也不能称它已解决HN；它是一个成熟、可精确使用的局部多面体族。
