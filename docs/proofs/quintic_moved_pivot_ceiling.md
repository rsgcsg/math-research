## 2. 新块对整个F的邻点，非仅有限窗口

T092已证明：对r=c+isd、q∈F\{0}、N=|q|²，rq有F内邻点当且仅当

\[
\Delta_c(N)=N\bigl(1-(1-c^2)N\bigr)
\]

在K内为平方。全部邻点为(c±√Δ/N)q。平移a∈F不改变判据：
a+rq的邻点恰为a加上上述邻点，因F−a=F。

本轮对q=p−z、p∈P，分别检查c=(1−√5)/4、(1+√5)/4。
**每一种**全部509项恰分为：

- 1项q=0（原编号64），对应F内重合点a；
- 486项非平方，携带分裂素数及二次非剩余证据；
- 22项非零平方，恰为|q|²=1的全部22项，携带精确K平方根。

负项按T092的赋值论证排除K内平方：验证素性、基乘积映射、分母
可逆和非零非剩余；不把开方失败当负结论。正项直接平方校验。
下标分割覆盖0,…,508且无重叠。共轭角只改变d的符号，故覆盖四个j。

写U_z={p−z:p∈P, |p−z|²=1}，则对q∈U_z，完整邻点简化为

\[
N_F(a+r_jq)=\{a,\ a+A_jq\}.\tag{1}
\]

这是二次式的两个互异根；其余非零q无邻点。q=0的所有F内边由
整个F的染色负责，不把它误列成只有两个F邻点的外点。
检查器用(1)重建接触，而不使用生产器的开方算法生成邻点。

## 4. 三次实验后的收敛：不继续盲扫中心

E058检验原候选；E059检验角度共同加入是否有增益；E060实际移开
共同枢轴，产生了真实新跨边，仍被完整F接口修复。这不是同一个
UNKNOWN重复加预算，而是三份可重放正结果。

统一的筛选量有三层：

1. 平移是否只是换根后仍保留共同枢轴；
2. 新点是否有未被旧宿主覆盖的完整邻域；
3. 这些邻域是否限制**全部**合法五色状态，而非仅破坏旧色词。

E060达到第二层，但没有第三层证据。本轮不再把下一个任意平移或
增加副本数列为优先突破口。普通NON5搜索在H₀、H₁内部正式退休；
它们的联合未决定，但“尚未决定”本身不是选择它的研究理由。

**下一优先任务转回混合部分全等的完整关系。** 以已认证的E060
有限配置X=P∪R∪B为候选，先精确抽取域与像各含至少四点、跨副本的
真实部分全等（至少记录2+2划分事件），排除只重述整份Parts同分布
或已有七个两点义务的事件。随后在X的全部proper五色词上求精确
正分布，或给对所有色词有效的分离／定价反证。有限已知词列上的LP
不可行不够。该事件抽取与全词定价本轮尚未执行。

具体定价目标可以不依赖术语重命名：选定有限事件族(D,g,π)，其中
g:D→gD是已精确验证的部分全等，π是D上的完整划分。对每个合法
五色词c，定义向量b(c)的对应分量为

\[
\mathbf1[\operatorname{part}(c|_D)=\pi]
-\mathbf1[\operatorname{part}(c|_{gD})=g\pi].
\]

所选义务有正分布恰当且仅当0属于所有b(c)的凸包；这是有限分布的
定义，不另登记新定理。反证必须给有理y，使**每个**合法c均满足
y·b(c)≥1。下一步定价就是寻找违反此不等式的合法词，或认证不存在；
只检查当前保存的三份词不够。HN所需全等不变分布的必要性由T082
的全平面平均论证保证，不能给c本身强加逐事件相等。

精确缺口仍是无条件的完整关系不相容；本轮没有证明任何这样的
新颜色不变量。上界的任意代数扩域／共尾量词亦未推进到可决定HN。

成熟参照：[Abramsky–Brandenburger §§4.3、6](https://arxiv.org/html/1102.0264v7)
区分支持中存在全局赋值与概率模型存在全局延伸，并用关联矩阵编译
后者。本项目还必须额外证明全等义务是真实几何必要条件，不能借入
量子测量的特有约束。此处用于收敛语言，不作为T093的证明输入。
