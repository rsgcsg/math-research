## 1. 唯一关键差异：18条所选边，还是34条全部实际边

两边使用相同的21个顶点W、相同36P+12R的计数S、相同九条Q链接和右端9。
但13的检查器仅从原 `quotient.realizations` 取18条 `type=E` 实现作为异色约束。
12的模型保留W中**全部34条实际单位边**。前者是后者的松弛，不是同一个诱导单位图。

遗漏的16条实际单位边为：

```
(37,889), (229,873), (231,875), (231,889), (233,891), (233,5535),
(873,3483), (877,3477), (877,5535), (877,7479), (887,3483), (887,7489),
(891,5535), (3477,7479), (3483,7489), (5535,7479).
```

检查器在原32维数域内重查W全部210个平方距离，并重放实际P/Q/R运输分量。
这些是已存在于W的单位边，不需要增添外部点、额外颜色假设或新的几何对象。

## 2. 两个最优性结论的独立重放

对18边模型，以权重 `(2,1,1,1,1,2,2,1,2)`；对34边模型，以
`(2,1,1,1,1,2,2,0,2)`。分别遍历全部512个Q断链模式，合并未断链接，
保留对应模型的全部异色约束，并完整排除得分小于9的规范五色词。
非负部分得分剪枝及颜色重命名的完备性见 [T162完整证明](q_defect_lift.md#2-512个互斥情形的完整整数证明)。

本次独立分支覆盖分别访问34,417,616和4,365,160个递归节点，两个不等式均有效。
这个检查重新建图；没有使用原13检查器的运行状态或其搜索排序。

18边模型的六份正词分别给出

```
u0 >= 2,
u5+u6 >= 4,
u1+u2+u3 >= 3,
u3+u4+u8 >= 4,
u2+u7+u8 >= 4,
u1+u4+u7 >= 3.
```

前两式各取一次，后四式各取一半，恰得到 `sum u_i>=13`。
结合13权重的有效性，证明这个18边模型的总罚最小值确为13。
34边模型的九份单断链正词则逐坐标迫使 `u_i>=(2,1,1,1,1,2,2,0,2)_i`，
结合12权重的有效性证明最小总罚12。两套正词都直接核验相应模型，没有固定候选池反证。

## 3. 为什么13的正词不能用于34边模型

13证书的六份正词都合法于18边松弛，但违反真实34边中的单位边。
依照原证书顺序，违反边数依次为 `1,2,2,2,4,4`。
例如第一份词 `012323201234431010212` 令真实单位边 `(37,889)` 两端同色。

第五份词 `010234334024201001340` 在所选18边上合法，S=5，恰断第2、7、8条Q链接。
用12的权重其总分只有8，因此它证明**12不适用于18边松弛**。
但它同时违反实际单位边 `(233,5535)`、`(873,3483)`、`(877,7479)`、`(3483,7489)`，
所以它不是34边模型中的反例。第六份词同样在松弛模型中把12的得分降到8。
全部具体违反边保存在[审查证书](../../certificates/q_defect_scope_audit.json)。

## 4. 集成与研究含义

13的式子是一个有效但较弱的全Y必要式，因为全Y合法词一定满足所选18边。
然而，“13已经最优”仅限于18边松弛；不能据此关闭保留完整34边后的罚项改进路线。
实际全Y应使用更强的12界，即 `14p+4(1-q)>=1`，并保留所有范围限定。
