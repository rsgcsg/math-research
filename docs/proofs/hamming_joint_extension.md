# Hamming 延拓与完整颜色联合：MacWilliams 的准确使用范围

2026-09-12。有限等权词律的成熟编码解释与严格校准；不声明首创。
普通 HN 不因一个既有词律的非延拓而获得新下界。固定支持的普遍
小事件界见[有限联合表示](finite_joint_support.md)，不需要线性假设。

## 1. 三个不同命题

设 A 是一个有限、带固定几何点标号的域，g 是其到另一有限域的双射。
给定 m 个 k 色词 c₁,…,cₘ，定义码列

`u(a)=(c₁(a),…,cₘ(a)), v(a)=(c₁(g(a)),…,cₘ(g(a))) ∈ [k]^m`。

词取均匀权重，随后平均全局颜色群 S_k。这里讨论的是不带颜色名称、
但保留所有几何点标号的完整联合分划律。未做 S_k 平均时，不能直接
把有标签联合律与下面允许逐坐标颜色置换的结论等同。

**命题 1。** 以下三项等价：

1. A 与 g(A) 上的完整联合分划律相同。
2. m 个源码坐标在 A 上给出的等色分划，与 m 个像码坐标给出的分划，
   具有相同的多重集。
3. 存在 `σ∈S_m` 及 `π₁,…,πₘ∈S_k`，使对全部 `a∈A` 同时有
   `v(a)_j=π_j(u(a)_(σ(j)))`。

**证明。** 每个等权词在全域给出一个分划，完整分划律正是其归一化
多重集，所以 1⇔2。若分划多重集相同，可逐份匹配坐标；两个坐标函数
的等色分划相同时，使用过的颜色之间存在唯一对应双射，任意补成全字母
置换便得 3。3 显然保留分划，故推出 2。证毕。

3 正是码映射可延拓成整个 Hamming 空间的标准等距
`S_k wr S_m`。反向使用也成立：全 Hamming 空间的任何等距都具有这种形式。
可先归一化使它固定零列。零列邻点按变化坐标分组，同组两点距离 1，
不同组距离 2；等距因此置换坐标组并重标组内字母。再规范为固定全部
邻点后，按 Hamming 重量归纳：重量 r≥2 的点，由将一个非零坐标改零
所得到的各前驱及它自身重量唯一确定，因此全部点固定。

若不同几何点具有相同码列，须先商去重复列。二点保距保证码列相同当且
仅当像列相同，因此诱导的有限码映射才是良定义的双射。

**命题 2。** 全部二点同色计数相同，当且仅当
`d_H(u(a),u(b))=d_H(v(a),v(b))` 对全部 `a,b∈A` 成立。

证明是恒等式 `#同色坐标=m-d_H`。一般而言，命题 2 不推出命题 1。

## 2. 经典定理：线性码与线性映射缺一不可

原文核验入口为 Jay A. Wood，2011 年会议作者稿
[Applications of finite Frobenius rings to the foundations of algebraic
coding theory](https://ring-theory-japan.com/ring/oldmeeting/2011/report2011/27WOOD.pdf)，
§5.1 的 Definition 29 / Theorem 30，及 §5.2 的字符证明，印刷 pp.236–238。
此处读的是 Wood 给出的原始重证明，不声称取得并读完 MacWilliams 的
1962 年博士论文。另核验 Greferath 等
[arXiv:1309.3292v1，§1–2](https://arxiv.org/html/1309.3292v1) 的相同定义。
HTML 的动态 Date 不是论文发布日期。

**MacWilliams 延拓定理。** 若 `C≤F_q^m` 为 F_q 线性子空间，
`f:C→F_q^m` 为 F_q 线性且保持 Hamming 重量，则 f 延拓成
`(x_j)↦(a_j x_(σ(j)))`，其中 `a_j∈F_q^×`。重量保持已保证 f 单射。

为使当前 q=5 用法完全透明，给出有限域版本的短证明。令 V=C，源码的
坐标线性函数为 λ_j，像码坐标函数为 μ_j。重量相同意味着

`Σ_j 1_(λ_j(x)=0) = Σ_j 1_(μ_j(x)=0)`，对所有 `x∈V`。

取 F_q 上非平凡加性特征 ψ，有
`1_(ℓ(x)=0)=q⁻¹ Σ_(a∈F_q) ψ(aℓ(x))`。V 上各加性特征线性独立。
每个非零对偶方向因此给出：λ_j 与 μ_j 在对应射影一维方向上的
重数相同。零坐标重数再由总长度 m 相同得到。逐方向匹配坐标，
同一射影方向的两个非零线性函数互为非零标量倍，即得所需单项变换。
对一般 q，用非退化迹配对识别加性特征；q=5 直接取 `ψ(t)=exp(2πit/5)`。

**仿射推论。** 若源码为 `a+V`，码映射满足
`f(a+x)=b+Lx`，其中 L 是 V 上的 F_q 线性映射，则全部二点保距
保证 L 保重量，从而延拓为 `x↦b+M(x-a)`。这里 M 是单项变换。
因此在这些已证明的仿射假设下，二点计数足以决定完整 joint。

注意：仅仅“包含零”、仅有两个线性码、仅有相同重量枚举子、或者
“所有观测码点都落在一个线性 span 中”，均没有给出所需线性映射。
非线性的全空间字母置换本来就是合法 Hamming 等距，所以线性性只是
一条充分工具，不是完整 joint 的必要条件。

当前 k=5 可以赋予字母集 F5 结构，但任意 S5 重标未必为 F5 仿射映射。
不能把四个/若干颜色或四个码点解释成 F4 线性码；“子域上线性”的
扩字母情形也是另一条定理。可参照 Dyshko
[arXiv:1504.01355v1，§2 Examples 1–2](https://arxiv.org/html/1504.01355v1)
明确区分 F4 线性与仅 F2 加性。该例不作为当前 F5 词的证据。

## 3. 已独立执行的最小非线性校准

在三字母及以上的 Hamming 空间中，三个带标号码点已足以失败：

```text
          源码      像码
a         000       000
b         110       110
c         101       220
```

每对不同码点的距离均为 2。源码的三个坐标分划为 `011,010,001`，
像码的三个分划为 `012,012,000`。所以二点同色概率都是 1/3，
但三点全同色概率从 0 变为 1/3；没有全空间等距延拓。
另一不变量是每坐标使用的字母数：源码 `(2,2,2)`，像码 `(3,3,1)`。
补两个常零坐标即可成为 F5^5 内的校准。

这是**按码点数最小**的反例：一个或两个码点之间的任意等距总能延拓。
对于两点，只需先匹配相同坐标与不同坐标，再在每个坐标分别匹配
出现的一种或两种字母，并补齐字母置换。

它不是按码长最小。F5 中长度 2、四个码点也可失败：

```text
源：00,01,22,23
像：00,01,22,32
```

对应六个距离均相同，而源分划多重集为 `{0011,0123}`，像为
`{0012,0122}`。长度 1 的任何有限码等距都能补齐成字母置换，
所以长度 2 是可能失败的最小码长。这两种“最小”不可混写。

已用 Python 标准库直接检查两个例子的全部点对距离、各坐标分划，
并穷举坐标匹配，二者匹配数均为零。负结论另有上面的完整不变量证明，
不依赖搜索器。第一例所有点对 Hamming 距离小于词数，所以这三个
几何点若来自 proper 词，其原域必须是独立集；反例不构成 non-5 图。

## 4. 对五词数据可以立即执行的充分检查

无须源码本身已是整个线性子空间，也可以尝试一个可验证的线性补全：

1. 选一个码列 u₀ 及其像 v₀，令每个源码差列为 `x=u-u₀`、像差列为
   `y=v-v₀`。先验证重复源码的像相同。
2. 在 F5 上求所有 x 的 span，检查 `x↦y` 尊重全部线性关系。
   若是，则在 span 上存在唯一线性映射 L。
3. 穷举 span 中的全部向量，验证 `wt(Lx)=wt(x)`。当 m=5 时最多
   `5^5=3125` 项。
4. 通过后用 MacWilliams 定理得到全空间单项延拓，再恢复仿射平移，
   因而完整 joint 成立；最终仍应直接输出并核验分划/坐标匹配证书。

任一阶段失败，只关闭当前颜色标签下的该线性补全模型，不排除一般
Hamming 延拓或新自由词律。尤其样本内全部二点保距，不能替代步骤 3
在**全部 span** 上的重量检查。三点反例恰能说明此缺口：两个独立
源码差列映为线性相关的像差列；样本保距，但它们的线性组合不保重量。

**不追认 T109。** T109 已有的证明是 12 个射影字符在整运动群下被
统一置换、并附带逐字符颜色仿射变换。因此它直接满足命题 1 的第 3 项，
不需要先从二点统计推出 full joint。“染色由环上线性字符给出”并不
保证任意有限几何域的码列集合是线性子空间，也不保证新部分运动在
其全部线性 span 上诱导保重量线性映射。MacWilliams 在这里是可检验的
候选成熟工具，不是 T109 已经证明任意二点约束完备的理由。

若 E080 的某个域最终全部二点通过而完整 joint 失败，这就是一个
实际几何词律诱导的非延拓有限码映射；应抽取最小子域作为高阶事件。
仍只说明 **E080 这一词律** 失败。新五色词或不同权重的混合仍必须允许，
才能研究真正的全词 obstruction。

## 5. 标准库重放两个校准

下面只重放有限恒等式；不可延拓性的数学证明已在第 3 节给出。

```sh
python3 - <<'PY'
from collections import Counter
from itertools import combinations, permutations

def partition(column):
    names = {}
    return tuple(names.setdefault(x, len(names)) for x in column)

def check(source, target):
    width = len(source[0])
    distances = [
        (sum(x != y for x, y in zip(source[a], source[b])),
         sum(x != y for x, y in zip(target[a], target[b])))
        for a, b in combinations(range(len(source)), 2)
    ]
    src = tuple(map(partition, zip(*source)))
    dst = tuple(map(partition, zip(*target)))
    matches = sum(all(dst[j] == src[sigma[j]] for j in range(width))
                  for sigma in permutations(range(width)))
    if any(a != b for a, b in distances) or Counter(src) == Counter(dst) or matches:
        raise RuntimeError("calibration failed")
    print({"pairs": distances, "source": dict(Counter(src)),
           "target": dict(Counter(dst)), "coordinate_matchings": matches})

check(((0,0,0),(1,1,0),(1,0,1)), ((0,0,0),(1,1,0),(2,2,0)))
check(((0,0),(0,1),(2,2),(2,3)), ((0,0),(0,1),(2,2),(3,2)))
PY
```
