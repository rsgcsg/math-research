## 1. 缺陷代码的局部相位一致与定量长程相关

令T=ℤ²三角格，\(W_2=\{-2,\ldots,2\}²\)。42个**全局双完美码**模板
\[
b_{s,a,b}(m,n)={\bf1}_{\{m+sn\bmod7\in\{a,b\}\}},
\quad s\in\{3,5\},\ a\ne b,
\]
在任一窗口\(z+W_2\)有**两两不同**的25位模式。定义局部窗口中心z为*good*当它在该处与某份模板的25位模式匹配，此时模板唯一，记为\(T(z)\in\mathcal P_{42}\)；否则称为bad。注意T(z)是**全局模板（原坐标）身份**，不是重置中心为原点之后的余类编号。

**引理A（局部相位连续性）：**若两个格点中心z,w水平或竖直相邻，且都good，则\(T(z)=T(w)\)。

证明：两中心W2窗口交叠20个格点，两个模板在此处都等于真实b。此前42模板穷举程序对**所有不同模板、两种平移方向**证明没有两个不同模板能在该20格交集完全相同，所以必须同模板。证毕。

令\(z,w\in T\)，\(\ell=|z_1-w_1|+|z_2-w_2|\)为格点坐标ℓ¹距离。选一条长度ℓ的水平/竖直步路径\(z=z_0,z_1,\ldots,z_\ell=w\)。若路径所有ℓ+1个中心good，反复用引理A，全部使用同一42码，特别两个端点good且同相位。因此**任意确定性标记b**都满足
\[
\boxed{
{\bf1}_{\{z,w\ {\rm good},\,T(z)\ne T(w)\}}
\le \sum_{j=0}^{\ell}{\bf1}_{\{z_j\ {\rm bad}\}}.
}\tag{A}
\]
更强地，**good中心组成的每一个最近邻连通分量都只有一份相位模板**，任意不同相位的连接路径必须穿越bad中心。这是双重码局部相位的精确“域壁分离”。

## 2. 反例：双完美码精确饱和甚至**所有非缺陷片完全单色**仍不强迫真实颜色身份全局冻结

**定理B（适用于任意二值非周期序列的真正单位避距部分着色）。** 取上一轮经典模7蜂窝完美码
\[
k(m,n)=m+3n\bmod7
\]
及边长s=2/5的六角片，中心
\(C_{m,n}=((2m+n)\sqrt3/5,\,3n/5)\)。
冻结缺陷余类k∈{0,1}为**留白未涂区域**；其余五类k=2,3,4,5,6分别以真实标签1,2,3,4,5单色涂满整片开内部。由经典七色蜂窝每余类避开所有单位边，这是一份完全合法的五标签**部分**着色，且每个七格星缺陷位置恰为双码的两个陪集。

现在选一族彼此格点中心相距极远的纯格：
\[
v_t=(2+7t,0),\quad t\in\mathbb Z.
\]
它们全部在k=2的**同一原标签1余类**，中心距对于t≠u至少\(7\cdot(2\sqrt3/5)>14/3\)，而任意六角内两点距对应中心至多s=2/5。任选**任意**子集A⊂ℤ（可以是非周期、无限复杂、甚至非可计算的整数集合），把所有t∈A的格H(C_{v_t})**整片由标签1改成新增标签6**，其它纯格完全不动。

**结论：**这仍是一份**对所有真实单位长度点对逐点合法**的平面六标签**部分**着色，而且：
- 每个完整被涂的纯格仍完全单色，未染格仍恰是两个完美码余类，因此在**每个七格星恰有两个留白缺陷**；整个缺陷指示b的局部42模板相位**全局恒定**；
- 对所有t∈A的重涂格，同为标签6的任意两点严格相距大于
\[
7\frac{2\sqrt3}{5}-2\frac25>\frac{58}{15}>1,
\]
其中只用\(\sqrt3>5/3\)即可；同一新色片内部直径4/5<1；
- 从原色1改为新色6只**删除**原色1的单位冲突候选，且新增色6在全部原着色片中此前从未出现，因此没有产生任何新的同色单位边；
- 只要A同时含有某些t与不含另一些t，原k=2陪集中一部分纯格使用标签1，另一些使用标签6，**真实颜色身份已经在缺陷位置完全刚性、其余纯格全部单色的前提下出现跨格漂移**。如果A为非最终周期集合（例如t∈{±n²:n∈ℕ}或任意指定非周期序列），这份**部分**着色可以是非周期的。

**严格边界：**这个构造没有涂满两个缺陷余类，占平面面积2/7的全部开格依然未着色，**所以绝不是整平面六染**。它反证的仅是可能的错误强化：
\[
\text{双码mixed位置精确}\land\text{五个其它余类格全部单色}
\ \not\Longrightarrow\
\text{这五个余类的全局实际标签身份各自固定}.
\]
甚至“全部原纯格在每个星恰好形成5个不同标签”仍成立——被重涂余类k=2的那个星只把其五个主导标签中的原1替成6，其余k=3,..,6保持2,..,5。

因此旧R2026-TWO-DEFECT-SHADOW的五冻结冲突证明虽然完全正确，却不能凭缺陷位置刚性就对任意六染启用。更合理的未来桥梁应是：利用**两个缺陷余类也必须被全部涂满**的真实单位距离约束，证明这种稀疏或者密集的第六色身份漂移不可能与合法补全兼容；仅依赖“纯格的片间单位边与每七星K5”无法做到这一点。
