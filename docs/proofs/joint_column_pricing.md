# 全词定价实做：旧词库的严格分离仍被新正词击穿

2026-09-11，E063 / C019。原始HN界没有改变。本节的负结论严格限于
一份明确的155词库及其所有凸混合，不是对全部proper五色词的负结论。

## 1. 从原正律之外选择真实混合事件

沿用[E061–E062](joint_word_closure_and_frontier.md)的X=P∪R∪B。
仍是5084点、12920986个点对、24844条实际单位边，不删除任何边。

先试P中编号1,…,12、150给出的13个平移；按本轮选择规则没有找到
源和像都跨单副本的新四点组。这次筛选不登记为一般不可能定理，
也不把仅剩三个旧事件的测试登记为新的成功实验。

随即换到五个非原域平移：

\[
t_j=1+\eta^j\quad(j=1,2,3,4),\qquad t_B=1+\eta z.
\]

每个平移选择三个四点对应组；其源、像各自都不包含在任何一份
组成X的单Parts副本内。十五个新四点组**全部**使E062最终词的划分
在源与像之间改变。因此不是重述已被那个正律修复的事件。
再加上E061三个指定混合四点组，共18个四点全等映射。

这里还有比“又换五个平移”更准确的结构解释。写A(x)=ηx，T_a(x)=x+a，
则在全平面运动群中

\[
T_{t_j}=T_1A^jT_1A^{-j},\qquad T_{t_B}=T_1AT_zA^{-1}.
\]

这些运动本来就在E062生成的**全局群**里；新义务来自路径允许离开X
再返回，而不是新添群生成元。对每个选中的新四点事件，不存在一个
由E062五个部分映射及其逆组成、使四点的所有中间像都留在X中的
共同运动词来实现它：若存在，E062旧词的颜色置换逐步复合，就会
保持源像划分，与证书中已核验的划分改变矛盾。这是上一轮“域内共同
词闭包”范围之外的具体入口；不对分域使用不同词的任意拼接作此声明。

独立检查器验证所有点编号、全部实际单位边、平移的32坐标精确值，
以及每一对对应的差恰为指定平移。旧三份对应则在已独立重建的最大
全等映射内逐项检查。只需要认证这些映射真实，不需要假设它们穷尽
所有部分全等，也不需要通过数值近似判定距离。

对每个四点组保留全部15种划分，得到270个整数等式。特别保留全部
2+2划分，不能仅用单色矩替代。

## 2. 全词定价究竟检查了什么

令Ω为X的所有proper五色词。对每个事件及划分τ定义

\[
d_{e,\tau}(c)=1_{\mathrm{pat}(c|_S)=\tau}
              -1_{\mathrm{pat}(c|_{gS})=\tau}.
\]

把这些差排成270维整数列d(c)。存在所选事件族的相容概率律，当且
仅当0属于所有这些列的凸包；颜色名可再经S₅平均去掉。

**有限词库LP不是终点。** 从E062的五个完整词开始。若当前库的凸包
不含0，浮点LP只负责提出候选y；将其化成整数后，直接检查每个已列
词的y·d(c)>0。随后求解的是

\[
\exists c\in\Omega:\quad y\cdot d(c)\leq0.\tag{1}
\]

搜索(1)没有保留旧色框，没有要求c本身全等不变，也没有限制它来自
任何旧词族。其变量覆盖X的全部顶点与全部proper五色词。

### 编译正确性

1. 每点五个one-hot变量，全部实际单位边逐色排除同色。
2. 对需要的点对，辅助变量e_ij双向等价于颜色相等。给定两个one-hot
   颜色，五组蕴含强制e_ij恰取其真假值，不添加新的颜色限制。
3. 每个四点划分的指示变量双向等价于全部六个点对的等色/异色要求。
   所以它恰是该划分事件，而不是某个单向松弛。
4. 合并y对应的相同指示变量。负权项−wI改写成w(1−I)−w，将(1)转为
   非负整数权重的布尔和上界。决策图节点v(i,b)表示剩余容量b；
   已取的分支分别要求v(i+1,b−w_i)或v(i+1,b)。根为真并逐层施加
   分支蕴含。对剩余项数归纳，存在辅助赋值当且仅当该布尔和不超过
   上界。真/假终端按剩余权重和及负容量精确处理。

因此，完整建成的SAT查询与(1)等价。节点数上限、冲突预算、轮数、
整数舍入失败均可能使实现返回UNKNOWN；这不是数学上的不可行性。
本轮没有取得或使用任何负SAT证明。将来若(1)搜索报UNSAT，也必须
补上覆盖该编译及全部proper词的独立反证证书。

另以两个纯编码测试图穷举其120、1280个全部proper词，对26个整数
目标交叉检查SAT定价。测试图不必具有单位实现；这只是编译校准，
不能作为HN几何证据。真实几何由前一节的独立重建负责。

## 3. E063：150份候选分离式全部得到实际反例词

连续150轮中，每次都找到一个满足(1)的新完整五色词。独立检查器
逐个验证：全部24844条单位边proper；对应整数y对当时所有旧列严格
为正；新列的y·d(c)≤0。这也证明每个新列的事件向量确实不在当时
词库的凸包中，而不只是换了颜色名字。

150轮后有155个完整词。列生成达到轮数上限，原终止状态是
`UNKNOWN_ROUND_LIMIT`，不能据其运行长度推断接近joint障碍。

随后直接尝试一个充分的正构造：让一个自由proper词对全部18个
四点映射具有相同划分。得到一份新词c*，独立检查d(c*)=0。
故其S₅平均是这270个等式的精确正律，划分原子数为1。

## 4. C019：155词库的全部凸混合失败，不代表完整问题失败

证书还给出一个整数y*，对上述155个词全部满足

\[
\min_{c\in\mathcal L} y^*\cdot d(c)=3.
\]

因此任意库内概率混合都满足y*·Σλ_cd(c)≥3，不可能等于0。
这是对**这155个词及其所有凸混合**的严格不可能证明，不是只检查
155个孤立输入，也不依赖浮点LP报告的不可行状态。
颜色重命名不改变d，因此这也排除该库全部S₅轨道的任意凸混合。

但新词c*给d(c*)=0，所以完整Ω上的问题可行。两边均在同一个实际
单位图、同一个270等式事件族上成立。这就是C019：明确词库的严格
分离可以很强，而它仍不是全词分离。150次定价没有完成可行性判断，
也没有把候选几何逼近非五染；一个更直接的正构造就结束了这个候选。
