## 3. 抽象机制与下一门槛

这里用到的是已有端口关系语言的最基本粘合规则：若两个proper
k色词在交集B上有相同的颜色相等划分，则可重命名第二个词使它
在B上逐点一致；若没有遗漏的跨内部边，二者便能粘成全局proper
词。相等划分给使用颜色之间的双射，扩成整个k颜色集合的置换即证。
对两点B，只有“同色／异色”两种状态。本例两侧都同色，因此修复
并不依赖SAT搜索幸运，也不依赖11进有限表。

这**不表示所有两点粘合总可染**：若两侧全部合法词强迫不同的两点
状态，它们仍可能不相容。本例已经给出一对明确匹配的词，才可退休。
也不表示增加到三点接口就自动产生障碍。

因此第一优先的构造必须改变完整接口关系：例如多个桥接形成真实
闭环及跨内部单位边，或新增混合全等把匹配的边界划分全部排除。
精确缺口仍是所有合法五色词的关系不相容／分离证明，不能先固定
E045色词，不能只统计新副本点数，也不能把T085受限模型缺口带入
自由五色空间。下一具体候选是六份C017等长对所定位桥的联合：先
合并重合点、计算全部实际桥间边并排除同构重复，再测试自由关系。
