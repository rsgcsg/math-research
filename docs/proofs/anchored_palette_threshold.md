# C025：η正规形确实区分五色与六色，但并不区分图的色数

2026-09-29。一个真实平面单位图的构造性反例，说明T144的互素假设不能删去。
它不是六色下界：下述整个图仍然恰五色。

## 构造

取任一已认证的有限五色单位图G，例如仓库的Parts509，并取R>0使其全部顶点位于原点R圆盘内。
令L=3R+3，η为绕原点72度旋转，构造

```
X = {0} ∪ ⋃_{j=0}^4 η^j (G+(L,0))。
```

相邻两个副本圆盘的中心距离至少2L sin(π/5)>L>2R+1，
因此副本之间没有单位边或重合点。原点到每副本距离至少L−R>1。
每副本内的实际单位图恰为G，故诱导图是五份G加一个孤立点，χ(X)=5。
Parts509给出2546个点。若G的坐标代数，则选择足够大的有理R可使全部新坐标也代数；
证明使用严格距离下界，不靠浮点判边。

取G的一份proper五色词h，颜色为1,…,5。令P=(1 2 3 4 5)，固定颜色0。
在X上定义一个proper六色词c：c(0)=0，c(η^j(v+(L,0)))=P^j(h(v))。
因为没有跨副本边，它确实proper，并且c(ηx)=P(c(x))。
所以δ_[c]是一原子、完整η域上的**划分**不变律。

## 不能正规化

X本身η封闭且色数5=k−1，原点固定，运动阶5。T144的其他假设均满足，
唯独gcd(5,(6−1)!)=5而非1。任意重命名q若使q(c(ηx))=q(c(x))，
由q单射即得c(ηx)=c(x)，但P移动每个非原点使用色，矛盾。
一原子的自环holonomy是非平凡五循环，重命名只能共轭，不能消去。

因此，T144若删除互素条件，即使限制在真实平面单位图上也为假。
这里固定的是**给定划分律**；另选一份五色词当然可以让五副本同色命名而η不变，
但那改变了完整划分，不是原律的正规化。

## 背后原理

五色时固定点将颜色稳定子压到S₄，其中不存在五阶元素；六色时S₅首次容许五循环。
这是真正的置换群不变量，不是η坐标写法的偶然性。
七色稳定子也容许五循环，但本反例只用于六色；不声称已有满足χ(R)≥6的七色前提例子。
特别不能把“六色正规形失败”说成“平面需要六色”。
