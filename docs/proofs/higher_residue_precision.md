# T056–T057：任意有限位数也不能修复各向异性剩余编码

2026-09-09，起始干净基线`554d09c`。本轮将T053/T054从首层

## T056：局部环单位圆图的统一归一化谱界

设O为离散赋值环，极大理想由π生成，剩余域F_q满足q为奇数且
q≡3 mod4。允许任意分歧指数、剩余次数以及等特征/混合特征。
令R_n=O/(π^n)，S_n={(x,y):x²+y²=1}，G_n为R_n²上以S_n
为方向集的Cayley图。则

`D_n=|S_n|=(q+1)q^(n−1)`；

所有非平凡归一化特征值的绝对值均不超过
`a_q=2√q/(q+1)`，与n无关。

### 1. 每个单位方向恰有q个下一层提升

取S_(n−1)中的点z，任取提升z₀到R_n²。所有其他提升为
`z₀+π^(n−1)h`，h∈F_q²。n≥2时平方的二阶增量消失，条件成为

`2 z̄₀·h = (1−|z₀|²)/π^(n−1) modπ`。

因|z̄₀|²=1，z̄₀非零；2可逆，故这是一个非零线性方程，恰q解。
它们组成仿射切线，差空间为`T_z={h:z̄·h=0}`。
由|S_1|=q+1归纳即得度数公式。

### 2. 旧特征继承，新特征只有至多两个驻留方向

有限阿贝尔群的加性特征对角化Cayley邻接算子，特征值为
`λ(χ)=Σ_(z∈S_n)χ(z)`。

若χ在核`(π^(n−1)O/π^n O)²`上平凡，则χ来自R_(n−1)²；
每个点恰q个提升，λ与度数同时乘q，归一化特征值不变。

否则，固定F_q的非平凡加性特征ψ，χ在该核上的限制唯一写为
`h↦ψ(a·h)`，其中a∈F_q²非零。有限域迹配对的非退化性保证此表示。
每个提升纤维的特征和，除一个模长1因子外，是

`Σ_(h∈T_z) ψ(a·h)`。

它在a∉F_q z̄时为0，在a∈F_q z̄时为q：若线性映射在一维
切线上非零，就满射F_q，非平凡特征的总和为0。
这里需要F_q线性空间的完整相消，不能只检查某个F_p坐标。

满足a∈F_q z̄且|z̄|²=1的剩余方向至多两个。每个剩余方向
在S_n有q^(n−1)个提升，三角不等式因此给

`|λ(χ)|≤2q^(n−1)`，即`|λ(χ)|/D_n≤2/(q+1)`。

n=1的界由T053中已核验来源的Weil–Kloosterman界给出。
对n归纳，因2/(q+1)≤2√q/(q+1)，证明完成。
这是所有n的证明，不是有限精度实验外推。

## T057：有限多个素理想、任意有限精度的联合编码均不能六染

令K=Q(√3,√5,√11)，E=K(√d)，d∈{7,13,17,41}。
取有限个不同非零素理想P_i，剩余域F_(q_i)均为奇数阶各向异性；
任选正整数n_i。令

`A=∩_i (O_E)_(P_i)`，`ρ:A²→∏_i (O_E/P_i^(n_i))²`。

**结论：不存在任意函数f到六色，使f∘ρ成为整个A²的合法单位距离染色。**
既不限各模精度相同，也不限颜色函数线性或逐模独立。

### 1. 不能漏掉高阶环中的第二参数图表

对任一局部商环R及u²+v²=1，2可逆，至少1+u或1−u为单位。
若1+u为单位，取(a,b)=(1+u,v)；否则取(a,b)=(v,1−u)。
分别有a²+b²=2(1+u)或2(1−u)，均为单位，且

`u=(a²−b²)/(a²+b²), v=2ab/(a²+b²)`。

不能沿用域上的“u=−1就用(0,1)”作为全部例外处理。
例如模9中(8,3)也是单位方向，第二图表给(a,b)=(3,2)，
有理单位方向(5/13,12/13)的模9像恰为(8,3)。

对各个模分别选图表，用整数环CRT同时提升a,b。分母在所有P_i
处为单位，所以所得精确单位向量属于A²。起点同样可用CRT提升。
因此ρ不仅满射顶点，还覆盖有限目标张量积图的**每一条边**。
如果f∘ρ合法，则f必须染好整个张量积图。

### 2. 张量谱下界

T053的小域排除已给q_i≥98，因此a_(q_i)<1/5。
T056说明所有精度的归一化非平凡特征值仍在[−a_(q_i),a_(q_i)]。
张量积特征值是因子特征值的乘积；任何负乘积的绝对值不超过
`a=max_i a_(q_i)<1/5`。由T053已写出的Hoffman短证明，目标图
色数至少`1+1/a>6`，故至少七色，矛盾。

没有使用一般图直积色数等式。重复素理想可只保留最高精度。

## 连续完备化的推论，以及不可外推的边界

在上述有限个局部完备化的整数环平方的乘积上，任何到有限离散
色集的连续函数都因紧性而通过某个有限精度商分解：每点有一个
常色柱集邻域，取有限子覆盖，再统一提高精度即可。
所以也不存在这种连续的≤6色单位图染色。

这**不**排除数域E²上任意普通染色，也不排除只在稠密数域点上
逐点终止、但没有统一有限精度上界的规则。数域点集不紧，不能
把上面的有限子覆盖论证用在那里。更未把p进连续性当作HN假设。

当前明确尚未覆盖：各向同性剩余域、2进方法、无统一精度上界的
数域编码、无限多个模、非约化方法。有限源图的模像仍可能只用
目标的一部分，T057的边满射是关于整个A²，不是该有限源图。

## 成熟理论与独立有限校准

有限环Euclidean图的谱并非新研究对象。
[Medrano–Myers–Stark–Terras (1998)，作者上传全文](https://www.researchgate.net/publication/246193320_Finite_Euclidean_graphs_over_rings)
的Theorem2.1及2.3已给Z/p^n情形的度数和旧谱递推。
本轮核对了这些段落及证明；出版社PDF下载返回403，未声称已完成
PDF视觉核验。这里独立写出一般DVR的切线相消证明，用于当前
数域的方法排除；不宣称谱递推方法的文献首创。

`higher_residue_precision.json`由两参数图表生成圆周指纹，独立
检查器不用生成器，以直接平方表重建全部单位方向，并核验：

- 10个局部环：Z/p^n与Z[√p]/((√p)^n)，含n=2、3、4。
- 全部17,848个圆周点、每层恰q提升以及完整仿射切线差空间。
- 小环全部32,328个原始加性特征；相消用整系数圆分多项式倍数
  验证，不使用浮点特征值。

  这是符号覆盖，不冒称逐一枚举其全部高阶频率。

  且精确检查两模的像；包含上述幂零例外。
