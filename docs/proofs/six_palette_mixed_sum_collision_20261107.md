# R2026-SIX-MIXED-SUM：五标签饱和的四射线单位碰撞、符号弦覆盖及固定双标签扇区排斥

日期：2026-11-07。基础依赖：OpenAI Family158 Lemma 4.3, Lemma 5.2(2), Corollary 5.4（按任意有限标签数逐坐标使用）；本仓库 R2026-SIX-PALETTE-TOPOLOGY、R2026-SEVEN-EXTREMAL、R2026-COUPLING-4D。**原问题仍为 6≤χ(ℝ²)≤7；本文没有排除一般weak measurable六染或构造精确NON6有限单位图。**

本轮重点是从上一轮“唯一剩余标签在半径√3圆上受无理旋转约束”推进到**跨两份两单位向量和的真实单位距离冲突**。注意：角度γ满足cosγ=5/6与无理旋转的核心论证**已经在OpenAI原论文Lemma6.4中出现**，不能记为本项目独立发明。本文的新合成重点是确定一组具体局部三标签饱和伪状态的失败、提取几何符号弦覆盖引理，并严格排除整个具有固定双标签扇区的六色palette类别。

## 1. 完整依赖的形式：五个标签同时排斥 ⇒ 第六色密度一

设c:ℝ²→{0,…,5}为weak measurable六染，A_i为它的Lebesgue可测颜色类，P_x(e)为OpenAI §5的最大角向调色板。对固定中心x，若方向e是每个i∈F⊂P_x(e)的角向密度1点，方向v与e不平行，则Lemma5.2(2)断言 A_i 在x+e+v的**平面密度为0**，对每个i∈F均成立。若在x+e+v处有来自e、v两侧的**五个不同标签**密度0，则唯一剩余标签j具有平面密度1；这并不要求点的实际赋值c(x+e+v)已经等于j。Family158 Lemma4.3保证任意两个相距1的**密度1同色点**不存在。

**引理A（mixed-sum碰撞）**。设F⊂[6]、|F|=5。若存在单位方向e,e',v,w，各方向是相应标签角向密度1点，F⊂P_x(e)∪P_x(v)，且 F⊂P_x(e')∪P_x(w)，两组表示都非平行，并且
\[
\|(e+v)-(e'+w)\|=1,
\]
那么weak measurable六染不可能存在于这种palette状态。证明：对z=x+e+v和z'=x+e'+w应用上段密度排斥，F中的五色在两点密度0，余下同一色密度1；两点恰距1与Lemma4.3矛盾。注意本引理必须使用同一F以及同一组全局六色标签；“逐窗口重新命名颜色”不适用。数学反证由上游无限分析引理和几何等式承担，并非SAT打印的局部模型失败。

## 2. 定理B：三片交替60°开放弧的符号弦覆盖

记κ=π/3，并定义
\[
E=\{e^{it}:t\in(0,\kappa)\cup(2\kappa,3\kappa)\cup(4\kappa,5\kappa)\}.
\]
**定理B。** 对任何u∈ℝ²、0<|u|<1，存在e,e'∈E，满足
\[
\boxed{\|u+e-e'\|=1.}
\]
对于事先指定的有限集合非平行禁用方向，亦可选择解使e,e'避开那些方向。

证明：三片弧的首尾端点之有向差
\[
e^{i(n+1)\kappa}-e^{in\kappa}=e^{i(n+2)\kappa},
\qquad n=0,2,4,
\]
及其负向恰为六个60°间隔的单位向量d。因此对任意u≠0可选其中一个d使u·d≥(√3/2)|u|>0，从而
\[
|u+d|^2=1+|u|^2+2u\cdot d>1.
\]
在同一对应开放弧内，取e,e'分别逼近产生d的两个端点，仍有|u+e−e'|>1；令e=e'取同一弧任意内部方向，则|u+e−e'|=|u|<1。在这同一开放角度方形内连续连接两种配置，中值定理给内部解。

非平行补充：零水平集不可能只由有限条“e为固定禁用方向”或“e'为固定禁用方向”的垂直/水平坐标线组成。因为固定e后，方程|u+e−e'|=1随e'角度为非恒定实解析三角函数（|u+e|>0，因|u|<1）；固定e'时同理。而零集隔开开放方形中的严格正负区域，不能只是有限个孤立点；从而有一解同时避开有限个被禁止的角度。证毕。

这一定理可改写成“开放双扇区有向弦差E−E在单位圆全部六个正交方向附近作双侧穿越”，属于几何差集/连续变形机制；不是依赖有限离散图的抽象K₇。

## 3. 定理C：固定双标签占满三片交替弧时，互补三标签不可能具有正角测度

**定理C（本轮最主要的六色必要条件）**。假设存在weak measurable六染及固定中心x。令A⊂[6]为一个固定的双标签集合，假设
\[
A\subseteq P_x(e)\quad\text{对E中几乎每个e成立}.
\]
那么对每个与A不交的固定三标签集合B⊂[6]，其角度出现集
\[
T_B=\{v\in S^1:B\subseteq P_x(v)\}
\]
必须为零测。特别，对补余三片60°弧O=RE，P_x(v)几乎处处与A不交且**最多有2个标签**，因此在这种固定双标签结构下，不可能在E-O的所有60°邻接方向达到“2+3五标签饱和”。

证明：反设某个T_B有正测度。由角度Lebesgue密度定理，在T_B中取两条不同的角向密度1方向v,w，且0<|v−w|<1（取同一足够小的角度开弧）；它们同时是B全部三种颜色的密度方向。对u=v−w用定理B选e,e'∈E，使
\[
|(v+e)-(w+e')|=1
\]
且两组方向非平行。由于A在整个E各弧几乎处处出现，对每个e/e'的每个A标签都自动为角向密度1点。于是两个和点都有A∪B这五个标签的平面密度0。它们剩余的唯一标签相同且平面密度1，违反Family158 Lemma4.3。第一部分得证。

对后一结论，由Corollary5.4的60°排斥，P_x(Re)∩P_x(e)=∅ a.e.，而E内有A⊂P_x(e)，故O=RE内几乎所有P_x(v)都避开A。若其中有≥3标签的正测度角度，由有限标签数可取固定三标签B disjoint A的出现集正测，违背前半部分。证毕。

**关键量词。** 定理C不是“每个六染都有三片固定双标签弧”，也没有推导该前提必须出现。它排除的是一个自然且很宽的**固定颜色框 / 高饱和交替扇区**类别。真实六染若存在，仍可让两标签palette随角度不断变化，或在E内无法固定同一个A。把“没有固定双标签在三个大弧上”误写成全局NON6是无效推理。

## 4. 一个最小显式四射线反证配置

取
\[
v_1=e^{i\pi/2},\qquad v_2=e^{i7\pi/6},\qquad
e_1=e^{i(5\pi/6+\delta)},\quad e_2=e^{i(5\pi/6-\delta)},
\quad \sin\delta=(\sqrt3-1)/2.
\]
因0<δ<π/6，e_1,e_2都在E的(2π/3,π)开放扇区；v_1位于(π/3,2π/3)，v_2位于(π,4π/3)。直接有
\[
v_1-v_2=\sqrt3\,e^{i\pi/3},\qquad
e_1-e_2=-2\sin\delta\,e^{i\pi/3},
\]
故
\[
\boxed{|(e_1+v_1)-(e_2+v_2)|=\sqrt3-2\sin\delta=1.}
\]
这四射线是定理B的一份专门解析见证，不是普适定理C的全部证明。

如果E上各方向都含同一双标签A，且两条奇扇区方向v_1,v_2的palette包含同一个三标签B disjoint A，那么这两个和点会被强迫为同一个第六色，而几何等式证明它们相邻。因此这一类只涉及四射线的真实约束已经足以排除相应调色板状态。若B只在几乎处处定义，则将四射线整体旋转一个足够小的共同角度并选取B出现的共同角向密度点，保留各方向处于原扇区与精确单位等式；或者直接使用定理C的正测度版，无须在指定角度强行求值。

## 5. 为什么上一轮“全角度五标签饱和”仍需要进一步审计：18扇区抽象阳性、真实几何阴性

定义18个连续角扇区，每个宽π/9=20°。令n=⌊θ/κ⌋∈{0,…,5}，t=θ modκ，j(t)=2+⌊3t/κ⌋∈{2,3,4}；在边界用任意一致规则，不影响a.e.断言。令形式化抽象调色板
\[
P^{\rm toy}(\theta)=
\begin{cases}
\{0,1\},&n\text{为偶数},\\
\{2,3,4,5\}\setminus\{j(t)\},&n\text{为奇数}.
\end{cases}
\]
对所有非边界方向都有P^{toy}(θ)∩P^{toy}(θ+κ)=∅、相邻基数和5；事实上**任意两方向的palette并集至多5个颜色**。相邻60°方向五色饱和后，缺失标签唯一为j(t)，它在角度平移κ后不变。半径√3外圆的单位弦对应\(\alpha=\arccos(5/6)\)，满足π/9<α<2π/9；而j角向三染的每份同色区域要么来自同一20°扇区，要么隔着至少40°，所以外圆上的强迫颜色完全合法。

甚至可以在一个**独立**的外圆邻域 \(5/3\le r\le7/4\) 使用同一个18扇区三染j(θ−κ/2)：同色点的距离严格小于25/36或严格大于265/243。证明同扇区半径变化不超过1/12，角度不超过π/9；由π<22/7有
\[
d\le1/12+2(7/4)\sin(\pi/18)<1/12+7\pi/36<25/36<1.
\]
若属不同但同色的扇区，最小圆周夹角≥2π/9，故
\[
d\ge 2(5/3)\sin(\pi/9)>
2(5/3)\left(\frac13-\frac{1}{162}\right)=265/243>1.
\]
这个外圆三染只是一个**局部可行环域**，并不保证它与所有内层两角palette的排斥公式能共同延伸。

**阴性审计（本轮真进展）：**上述P^{toy}在E完整固定A={0,1}，在奇扇区三个标签从{2,3,4,5}中选取，因此由定理C**绝不可能**来自一份真实弱可测六染。更加直观，前面的四射线v_1与v_2分别在奇扇区，且它们模κ角度均为κ/2=30°，所以两份奇向palette同为{2,4,5}，两份偶向palette均为{0,1}。两处和点必被迫为标签3却距离1，构成可独立检查的有限几何矛盾。抽象18扇区在角度层/外圆层完全通过，并不代表它通过了真实平面**两角和点之间**的单位边规则。

所以未来不能把“已经可全角度五标签饱和且外圆三染”当成原题六色的正反证：它恰好是一个证明**局部层级不完备**的反例。经本轮审计，单圆心的**跨两角和点**几何关系比单纯无理外圆更早揭露该伪模型。
