# 整个整数平移宿主的精确五染色

2026-09-28。对象是原10077点Y的全部整数平移，并非全平面，也不是整个H′Y的平移饱和。

## 1. 结论与结构

令 Z_Y=⋃_{n∈Z}(Y+n)，采用原坐标中的实单位方向1。则其**整个诱导单位距离图恰五色**。
这不是根据有限窗口推断，也不是求解某个有限周期商失败后的反向结论。

在既有32维有理基中，第0个基向量为1，Y坐标分母d=480。把每个分子向量p换成
q=(p₀ mod d,p₁,…,p₃₁)，去重排序得到9740个代表q_i/d。每个Z_Y中的物理点唯一写成
q_i/d+n，n∈Z。唯一性来自所用有理基的线性独立性，不能把p₀/d误解为物理点的实部。

证书保存9740个颜色a_i∈Z/5Z。公式是

    c(q_i/d+n)=a_i+n (mod 5)。

因此颜色名字有周期5，单位平移将所有颜色同时循环重命名；不声称5是全部可能染色的最小周期。
下界5继承Y⊆Z_Y及原有χ(Y)=5。

## 2. 为什么有限表覆盖全部无穷边

每个有理基向量的复模是某个√r，r来自RAD，或再乘模为1的i、η。
用整数上界ceil√r逐项估计，得到所有代表满足|q_i/d|≤B=17。
若两个点q_i/d+n、q_j/d+m距离1，则h=m−n满足

    |h|≤|q_i/d|+|q_j/d|+1≤2B+1=35。

这是真正的无穷范围截断证明，与SAT预算无关。
当i=j，只需记录h=1（反向涵盖−1）。当i<j，逐一判定全部整数h∈[−35,35]。

完整重建得到60229条无向接触类型(i,j,h)，最大实际|h|仅为2。
它们代表全部边 q_i/d+n ↔ q_j/d+n+h，不是只有方便列出的边。
保存方向下各h计数为：−2:2，−1:11336，0:38366，1:10525。
方向取i≤j，因此无须在此直方图中同时列出每条反向边。

对每条类型，检查器验证 a_i≠a_j+h (mod 5)。任意实际边两端颜色差正是同一个差，
与n无关，所以全部无限边异色。这个有限表和公式证明上界5；结合第1节，下界亦成立。

## 3. 精确筛选与独立实现

生产器通过素数p=10000741的两个共轭剩余坐标筛选，独立检查器重新核验素性、分母可逆、
所有1024项基乘法和共轭作用。对整数分子差，其两个剩余坐标记为A、B，必要条件为

    (A−dh)(B−dh)=d² (mod p)。

所以候选满足 h=(A+B±√((A−B)²+4d²))/(2d) (mod p)。
p>70保证范围内每个剩余类至多对应一个整数h。注意分子是A+B，不是−A−B。
模素数只淘汰不可能项；剩余50846个候选逐一用原精确乘法核验实际复范数等于1。

生产器使用NumPy向量计算；标准库检查器逐对做整数标量运算，并重新计算完整结果。
所有原Y的49858条边另行检查可从表中取回；二副本诱导图与另一种剩余桶枚举得到的
独立边表逐字节一致。小整数扫描还校准二次式的符号。这里没有用两份相同哈希代替完整重建。

本轮草稿生产器曾有缺失依赖及二次式符号错误；修复后才生成最终表，旧草稿不作为证据。
正证书必须通过当前完整重建和原Y/二副本交叉校准，不能只检查已列边。

## 4. 有限实际构造的状态随之收敛

在得到无限公式前，实际查询了Y∪(1+Y)。独立的全部跨边枚举得到19821点、110046条单位边，
其中333个重合点、11590条两侧独有部分之间的新跨边；自由五染色成功。
早先口头更新中的111297条边是不准确的，正式证书和此文均以110046为准。

三副本的自由有限查询在100000冲突预算后返回UNKNOWN，历史运行保持该状态。
随后无限公式给出了所有副本数的正解，而不是声称那个旧查询当时返回SAT。
公式限制到有限窗口的独立校准如下：

| 副本数r，点集⋃_{0≤n<r}(Y+n) | 顶点 | 全部实际单位边 |
|---|---:|---:|
| 1 | 10077 | 49858 |
| 2 | 19821 | 110046 |
| 3 | 29561 | 170265 |
| 5 | 49041 | 290723 |

全部均恰五色。有限窗口只是校准，无穷结论依赖第2节的完备表，而不是这四个样本。
已认证的同一公式还使原Y中每个整数平移的完整限制划分保持不变。
它不保持所有原15运动域，也不决定全部15域的共同概率律。

## 5. 复现和路线边界

标准库独立重放：`make check-translate-kernel`。它重新构造原Y、完整接触表、五色公式及四个有限窗口，
并检查原Y和二副本完整边表。另有`make check-unit-translate`对原二副本证书单独重放。

搜索生产器使用NumPy与本轮固定PySAT轮子，示例：

```sh
python3 research/audit_full_law_preparation.py --write-cache references/cache/integer/input.json.gz
.venv/bin/python research/search_integer_translate.py --cache references/cache/integer/input.json.gz \
  --out-dir references/cache/integer/candidate --budget 100000
```

生产器输出的kernel与formula文件是候选；复制为证书文件后仍须完整独立重放。
“每步颜色加一”只作为找到正解的构造，不被当成所有五染色必须满足的假设。

这关闭了在同一Y上只沿单位实方向追加任意整数副本来找NON5的路线。
不关闭不同平移方向、交替平移和旋转生成的新点集、整个H′Y的平移饱和，或更强共同律约束。
下一项几何攻击必须增加该已染色宿主之外的真实关系，而不是继续扩大同一条带。
