# 2026-11-04：四点二点矩提升、五点弦圈阻碍与共享边缘

**R2026-COUPLING-4A/B/C。** 这是一个严格的有限概率多面体结论；没有证明χ(ℝ²)等于6或7，没有发现平面有限不可六染图，也未Lean形式化。精确有限证据：research/verify_four_site_partition_lift.py；校准收据：certificates/four_site_partition_lift_20261104.json。其外部多面体技术来自成熟clique partition研究，不宣称面不等式的首创。

## 一、把外部证明与原full15难点对齐

OpenAI Family158证明任意平面五染不可能，独立内核审核确认其无可测性假设。其分析链是任意染色→不变律→谱刚性→可测几何接口→矛盾。内部full15及2026-11-03 MOMENT-F路线使用的是有限点集上真实颜色划分的共同概率律：各窗口分别有可行律，不意味着它们具有同一份全局相容边缘。

前轮从平稳避单位距离二值场X(x)构造q(x−y)=E[X(x)X(y)]/δ，其中δ=E X(x)=π/(8√3)>1/5；q具有全域PSD和真正相容的三点五色law。本轮严格研究下一个门槛：四点局部二点提升、四点共同三点边缘，以及五点分割不等式。请勿把这三种量词互换。

## 二、R2026-COUPLING-4A：每个四点的二点相关总能提升

设X₀,X₁,X₂,X₃∈{0,1}具有任意联合分布及同一严格正均值δ。定义
\[
q_{ij}=\frac{\mathbb E[X_iX_j]}{\delta}.
\]
**定理：** 存在四点的随机等价关系Π，使Pr(i~j)=q_ij。由于四点划分最多四块，无放回地随机分配五色后得到真正的四点五色联合law，所有单点颜色均匀且二点同色概率恰为q_ij。

**证明：** 四点等价划分的15个0/1六坐标同色向量的凸包CP₄，是有22个面的六维多面体：六个非负q_ij≥0；十二个三角式q_ij+q_iℓ−q_jℓ≤1；四个星式（中心i，另外j,k,ℓ）
\[
q_{ij}+q_{ik}+q_{i\ell}-q_{jk}-q_{j\ell}-q_{k\ell}\le1.\tag{★}
\]
面描述不是浮点猜测：附带的标准库检查器枚举全部Bell(4)=15个点、全部C(15,6)=5005个六点集合；每个facet必含六个仿射无关顶点；以Fraction做精确高斯消元枚举所有支撑超平面，结果**恰为**上述6+12+4个面。

对于二值样本x，三角式的分子满足x_ix_j+x_ix_ℓ−x_jx_ℓ≤x_i。星式令t=x_j+x_k+x_ℓ∈{0,1,2,3}：x_i=0时左端−C(t,2)≤0；x_i=1时左端t−C(t,2)∈{0,1,1,0}≤1。因此取期望除以δ，所有面约束成立。故q∈CP₄，凸组合即所需的随机划分。证毕。

**平面推论，注意范围：** 对此前的平稳、等距不变避单位距离场，任何**单独选定**的四个平面点都存在严格合法的五色joint，且所有这样的joint共享同一q提供的单点及二点边缘；其整体二点核仍PSD。然而不同四点law在公共三点的完整边缘是否也一致，**本定理没有证明**。它不是四阶Kolmogorov射影族，不能称为全球五染色。

## 三、R2026-COUPLING-4B：规范三点law不一定与四点相容

一个完全有理的四元二值源：

| X₀X₁X₂X₃ | 概率 |
|---|---:|
|0000|1/3|
|0001|1/12|
|0011|1/6|
|0100|1/6|
|1000|1/6|
|1110|1/12|

每个EX_i=1/4；q01=q02=q12=1/3、q23=2/3、q03=q13=0。

前轮独立三点构造对012的同色三元组概率选择
\[
a_{012}^{canonical}=\max(0,(q_{01}+q_{02}+q_{12}-1)/2)=0.
\]
但**任何**实现全部六个q_ij的四点真划分都迫使Pr(0=1=2)=1/3：事件E02与E23相交会推出E03（零概率），E12与E23相交会推出E13（零概率）；E02与E12的概率均1/3，恰等于E23补事件的概率1/3，因此E02=E12=E23ᶜ几乎必然。

这组q仍然有真实四点实现：以1/3概率取{0,1,2}|{3}，以2/3概率取{0}|{1}|{2,3}。失败的是**独立先挑选三点边缘，再要求四点保持它们**，不是四点独立不可行。此例明确证明跨窗口的三点颜色身份属于不可省略的耦合变量。

## 四、R2026-COUPLING-4C：一般二值输入在五点已经不能提升

在5个循环下标上，取X=00000概率3/8；其余五种结果分别在{i,i+1 mod5}两个位置取1，每种概率1/8。每个EX_i=1/4，归一化二点相关为q_(i,i+1)=1/2，q_(i,i+2)=0。

但任意五点真实划分的同色指标e必满足经典2-chorded五环不等式
\[
\sum_{i=0}^4 e_{i,i+1}-\sum_{i=0}^4 e_{i,i+2}\le2.\tag{5C}
\]
直接证明：五个三点传递式相加，记A=Σe_(i,i+1)、B=Σe_(i,i+2)，得2A−B≤5。若B≥1，则2(A−B)≤5−B≤4；若B=0，则2A≤5，整数A≤2。取真实划分的凸组合仍满足(5C)。上述q却使左端=5/2，严格超出1/2。故它不能提升为**任何颜色数**的五点真实随机等价关系。

**几何边界：** 这个五点二值源是抽象有限概率，未被证明可表示成平稳、等距不变的平面单位距离自由随机集。它不意味着前轮圆盘q在五点违反(5C)，更不是NON5/NON6有限单位图。证明的是一般均匀边缘二值源的普适提升在四点已经尖锐。

## 五、与6/7终局严格分离

- 二点PSD、颜色对称与全部单位边零相关：前轮已有4色伪核。
- 所有三点的真五色joint且全体共享二点边缘：前轮已构造，但与全域五染不等价。
- 每个四点分别有合法五色joint且共享二点边缘：本轮4A；**没有共享三点边缘**。
- 单独规范三点law无法保证四点可拼接：本轮4B。
- 五点2-chorded可阻止抽象二值源的二点提升：本轮4C；必须验证真实几何支撑才可升级。
- 任意有限点集上的完全合法且射影相容六色law存在 ⇔ χ(ℝ²)=6；有限精确单位距离NON6图存在 ⇔ χ(ℝ²)=7（使用七色上界与紧致性）。两者仍未完成。

旧T159/E121处理2-chorded等分割面及固定Y运输系数；本轮说明这种面为什么在高阶耦合中重要，但没有从抽象面生成实际Y上的严格矛盾。应将下一突破义务明确为**同一份真实几何、全部颜色身份与跨窗口边缘的联合延拓或真正有限六色UNSAT证书**，而非继续单独提高二点谱或模拟局部矩阵。
