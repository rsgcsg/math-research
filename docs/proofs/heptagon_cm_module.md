## 2. 更一般的原理：CM模的单位方向可完全有限化

设E是CM数域，通常共轭记为bar，`N=[E:Q]`，M是E内有限生成加法群。
取M的Z基`b_1,…,b_s`。对每个嵌入σ，有`σ(bar x)=overline(σ(x))`。
因此`x bar x=1`使每个共轭模长都为1，而不只是选定物理嵌入的模长为1。

矩阵`G_ij=Tr_(E/Q)(b_i bar(b_j))`为有理对称正定矩阵：
相应二次型是全部嵌入的绝对值平方之和。若`x=Σn_i b_i`是单位方向，
则`n^T G n=N`，由正定内积的Cauchy不等式，

`n_i² ≤ N (G⁻¹)_ii`。

各整数坐标于是有有效有限界。在该有限整数盒中逐个检查`x bar x=1`，
恰得到全部实际单位方向。给定有理坐标的生成元，可用整数格基运算先求Z基。
这不是在物理平面上用距离容差找点，也不假设平面像离散。

这统一了“整数闭环”与“代数赋值”：前者给有限生成加法群，CM性质使
全部共轭同时有界；赋值则可能把昂贵的迹椭球枚举压成很短的完整方向表。
**非CM域不能直接套用**：所选共轭未必与其他嵌入交换。
有有限方向也不保证低色、周期染色完备或HN的统一规模界。

## 4. 两个共轭素点决定全部方向：无类数假设

7在Q(w)中分成`w≡2`与`w≡4`两支，因为
`w²+w+1=(w−2)(w−4) mod7`。再添z时各自完全分歧，
得到F的两个素点P、Q，剩余域F7，标准化`v_P(7)=v_Q(7)=6`，
`v_P(z−1)=v_Q(z−1)=1`；共轭交换P、Q。

将r写为

```
r = N/D,
N = w(z+z⁻¹)−w² = 3w+1 + w(z−1)²/z,
D = (z−z⁻¹)(z+z⁻¹).
```

`Norm_(Q(w)/Q)(3w+1)=7`。它在w≡2支消失而在w≡4支不消失，
故在F中其P赋值为6、Q赋值为0。修正项`w(z−1)²/z`两边赋值均为2。
两项赋值不同，不能相消，所以`v_P(N)=2`、`v_Q(N)=0`。
D在两边赋值都为1（其他因子剩余值为±2），于是

`(v_P(r),v_Q(r))=(1,−1)`。

各坐标分母只支持7，r在其他素点积分；由`r bar r=1`，它在其他素点
实际都是单位：一对共轭素点的非负赋值相加为0。

若`x∈L_m`且`x bar x=1`，加法的赋值下界给
`v_P(x)≥0`、`v_Q(x)≥−m`。共轭关系又给两赋值相反，
所以为`(j,−j)`，其中`0≤j≤m`。`x/r^j`在P、Q赋值为0，
在其他素点均积分，故是代数整数，且仍满足范数1。

**Kronecker步骤的证明。** 该整数α的全部共轭模长为1。
每个α的正幂的最小多项式次数≤12，其整数系数由单位模根的基本对称和
给出，因而绝对值统一有界。这些多项式及其根只有有限多个；
两个正幂必相同，α是单位根。于是`x/r^j∈μ42`。
反向包含显然，因为`r^j μ42⊂L_m`且范数为1。
不同j的赋值不同，各层不相交，完成完整方向定理。

也可用成熟的分式理想语言直接表述：`(r)=P Q⁻¹`，
理想和在各素点取赋值最小值，所以`L_m=O+rO+…+r^mO=Q⁻m`。
这里Q是素理想，不是有理数域；这个等式不需要Q主理想或类数1。
因此看似特殊的方向库，实为一个共轭素点允许的极点阶数过滤。
完整方向计数随m线性增长来自该不变量，而不是更高维参数搜索的经验拟合。

这里解释了为什么纯七次T078不能照搬：加入w使7的素点变成**共轭交换的一对**，
而不是一个共轭稳定素点；单位方向允许非零且互反的赋值。
84是42个单位根乘两个允许赋值层，不是数值角度库的偶然大小。

## 7. 任意支持主线的一个必要纠错

调研中提出过“把不同运动的两个相等事件相乘”。这不自动是合法的full15势。
例如B是均匀比特，令`S_1=T_1=S_2=B`、`T_2=1−B`。
每个`S_i,T_i`的边际律相同，但`E[S_1S_2]=1/2`而`E[T_1T_2]=0`。
所以各运动分别的完整域平衡，不推出任意跨运动同步乘积平衡。

合法全词负势仍必须是`Σ_j (f_j(source_j)−f_j(image_j))`，
或先证明额外组合确实属于这些差函数的线性张成。
同一运动内的高阶产品合法；不同运动的势相加也合法；混成一个同步产品则缺假设。
本轮没有把这一错误候选送入SAT，也没有虚构一个“更强joint obstruction”。
