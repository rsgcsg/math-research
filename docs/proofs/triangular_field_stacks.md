# T064–T065：完整三角格平移层的五染色

2026-09-09。从干净`4b34588`继续。原始HN仍未解决；这里决定的是
两方向、全部整数中心、每层整个K²的一个无限宿主类。

固定`K=Q(√3,√5,√11)`及T028的赋值环A，剩余域F11，
`√3↦5, √5↦4, √11↦0`。写

`e₁=(1,0), e₂=(1/2,√3/2), Λ=Ze₁+Ze₂`，`J(x,y)=(-y,x)`。

核心结论T065是：**若α为实数、β=α²∈K∩A且β>1/4，则
χ(K²+αΛ)=5。** A的条件是所选11进赋值非负，不是实数大小条件。
若α∈K，本来就是K²；真正新增的是α∉K的二次平移层。

不要求K部分分母有界，不限制中心、核心、跨边或预先指定背景。
这不是任意预染色延伸，也不是整个K(α)²或实平面的五色上界。

## 1. 完整几何分类先于编码

α∉K时，点`p+αz`（p∈K²、z∈Λ）的表达唯一。设两个点的差为
`u+αδ`，则1与α线性独立，单位距离恰等价于

`u·δ=0, |u|²+β|δ|²=1`。 (1)

δ=0给出原K²的全部单位边。δ≠0且`N=|δ|²`时，二维正交性给

`u=±(t_N/√N)Jδ, t_N²=1−Nβ`， (2)

前提是√N∈K、右侧有K中的平方根；没有根便没有这类跨边。
本文实际需要N=1或3，√N确在K。不用(2)断言一般N的根在K。

若δ=me₁+ne₂，则`N=m²+mn+n²`。由

`4N=(2m+n)²+3n²`

可知`0<N<4`时|n|≤2，再逐项检查得到N只有1、3，各六个向量。
故β>1/4时，实正性完全排除N≥4，并非用有限窗口猜测全部接触。
β>1/3则直接只剩N=1。

还要反复使用A的各向异性性质：若`x²+y²∈A`，则x,y∈A。
否则按负的最小赋值缩放并约化，会给F11中非平凡平方和为0。
这个论证不要求平方和等于1，原理与重新核对的
[Madore Proposition 3.2及证明](https://arxiv.org/html/1509.07023v1#S3)相同。
因此β∈A时，(1)中的所有u都在A²；δ∈Λ⊂A²。

## 2. T064：用一个121点目标处理所有单壳三方向接触

这里“单壳”指跨中心差只允许Λ的六个最短向量，并且
`u=±tJδ`，其中同一个t∈A。该假设不要求所有这些边都存在；
遗漏边不影响以下上界。每层仍允许整个K²的全部单位边。

### 两个困难剩余类也能剪切

设r为t的F11像。对中心标签(m,n)，选矩阵M_r，并映射为

`ψ(p,m,n)=overline(p−r_C)+M_r(m,n)^T`。 (3)

这里C是p在K²/A²中的陪集，r_C为各陪集固定代表；不能直接
约化任意分母的p。所有边的u都在A²，故其两端确实使用同一个C。

注意M的输入是**整数几何中心标签**，不是颜色或物理笛卡尔坐标。
F11中e₁、e₂的像为(1,0)、(6,8)。可选：

| r（相差符号共用矩阵） | M_r，按行列出 |
|---|---|
| 0 | `(1,6; 0,8)` |
| ±1 | `(0,0; 0,0)` |
| ±2 | `(3,5; 3,9)` |
| ±3 | `(5,8; 0,7)` |
| ±4 | `(1,5; 7,6)` |
| ±5 | `(3,7; 0,2)` |

除±2、±4外，取`a²+r²=1`，`M=a(1,6;0,8)`即可：
跨边像是`aδ±rJδ`，平方长1，所以在U中。
±2、±4的两张矩阵则把所有跨边像放入S；它们产生的新增方向
恰为同一组`±(1,3), ±(3,1), ±(4,4)`。
独立检查器逐一验证11个r、6个实际方向和2个符号，共132个输运。

同层边在(3)下仍为U边，跨层边成为S边。因此把Γ的五色表沿
ψ拉回得到全图五染色。若含一整层K²，则色数恰5。这是T064。
三角形中心回路已经包含在公式中，不再依靠单方向的二层奇偶性。

特别地，β>1/3且存在t∈A、`t²=1−β`时，(1)直接符合本定理；
不存在t时各层无跨边。上一轮的`K²+(2√2/3)Λ`遂已决定为五色。
原484点奇偶商仍是UNKNOWN，但无需决定它：本公式使用模11中心
信息，未必经过那个模2商。这不是把UNKNOWN重新解释成SAT。

## 3. T065：全部β∈A、β>1/4都恰五色

先给一个不需要实高度界的辅助结论。

### 可平方剩余值的整个加法片层

设α∉K、β=α²∈A，且β在F11的像是平方，允许0。则

`χ(K²+αA²)=5`。 (4)

证明：表达p+αw唯一，w∈A²。任意单位边写成u+αv，仍满足
`u·v=0, |u|²+β|v|²=1`。故|u|²∈A，各向异性迫使u∈A²。
选a∈F11满足a²=barβ，对每个K²/A²陪集取固定代表r_C，令

`ψ(p+αw)=overline(p−r_C)+a barw`。

单位边像的平方长为

`|baru|²+a²|barv|²+2a baru·barv=1`。

故映入F11单位图，五色表给上界，K²子图给下界。证毕。
特别是Λ⊂A²，所以(4)包含所需三角格宿主，但不是全K(α)²。
α系数中的任意负赋值分母不在(4)的假设内。

### 非平方剩余值使两种壳层互斥

余下barβ∈{2,6,7,8,10}。由第1节，β>1/4时只须考虑N=1、3。
若某壳确有跨边，则`t_N²=1−Nβ`有K根；其平方在A，所以t_N∈A。
因此`1−N barβ`必须是F11中的平方。完整五行计算是：

| barβ | 可能的接触壳N |
|---|---|
| 2 | 无 |
| 6 | 3 |
| 7 | 1 |
| 8 | 1 |
| 10 | 3 |

表中的“可能”不保证K中有根；但足以证明两种壳**不能同时存在**。
没有壳时各层分离；仅N=1时直接用T064。它只需要单壳边分类，
不需要另行要求β>1/3。

仅N=3时，六个差生成子格

`Λ₃=Z(e₁+e₂)+Z(−e₁+2e₂)=√3 R_(π/6)Λ`，

在Λ中指数3。其三个陪集由`m−n mod3`区分，所有跨边留在同一
中心陪集内。对某陪集减去固定平移，再整体旋转−π/6，得到

`K²+α√3 Λ`，

其接触恰变为最短壳、跨K位移为`±t₃Jδ`。旋转系数在K且
在A中，故K²和积分性均保留。于是每个分量用T064五染。

具体坐标分解为：c=(m−n) mod3取0,1,2，

`m=c+a−b, n=a+2b`，

`a=(2m−2c+n)/3, b=(n−m+c)/3`。

这是任意整数的恒等式；441个小整数输入只是独立校准。
综合各情形得到T065，且下界始终来自一整层K²。证毕。
