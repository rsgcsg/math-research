## 2. 一般的多数原子引理

设Ω是有限集合，a_j,b_j是从Ω到某个有限模式集合P_j的映射。
若概率μ满足所有推前等式，而μ({c})=p>1/2，则a_j(c)=b_j(c)对所有j成立。

证明：反设对某j有a_j(c)≠b_j(c)，定义

```
f(d) = 1[a_j(d)=a_j(c)] - 1[b_j(d)=a_j(c)].
```

有f(c)=1且其他d的f(d)≥−1，所以 `E_μ f ≥ p-(1-p)=2p-1>0`。
另一方面推前等式给 `E_μ f=0`，矛盾。证毕。

因此，只要没有单一不变点，所有共同律的原子质量都≤1/2。
这里原子是**完整划分**，而不是可以人为重复的支持状态或颜色重命名后的同一划分。
若一个两原子共同律的权重不相等，较重原子质量>1/2，便违反该引理；因此两原子权重必各为1/2。

最小直观校准是实线上三个点0、1、1/2以及反射x↦1−x。唯一单位边是0—1。
不存在单个反射不变的合法二色划分：反射交换端点的两个颜色，却固定中点。
两份不同划分 `{0,1/2}|{1}` 与 `{0}|{1,1/2}` 的均匀混合则完全不变。
所以“单词失败但混合成功”不是不可染色，且这个机制并不始于本轮的五色大实例。

## 2A. 推回Y：一个29点完整划分柱事件的质量至多一半

若μ是Y上的Γ共同律，记ν为把每份完整Y划分限制到V后的分布。
V的每个运动域都包含在Y对应的最大域中；源、像同时按相应位置限制。
所以完整Y推前等式再次限制后，恰是V的完整域推前等式，ν也是V的Γ共同律。

V没有Γ不变单一五色划分。对ν应用多数原子引理，得到对每个完整V划分p：

```
μ{c∈Ω₅(Y): c|V=p} ≤ 1/2.
```

这比“每个全Y原子≤1/2”更强：即使很多不同Y色词在这29点上恰好有相同划分，
它们的总质量仍不能超过一半。该不等式对任何Γ共同律、因而对任何可能的全15域Y共同律成立。
全Y上的两词Γ正律限制到V后仍有两个不同原子，因此上界在Γ系统中可达。
没有证明其在全15域Y系统中可达，因为该系统的存在性本身仍未知。

此结论不依赖固定支持数，也不以某一份词库为量词；但它是可行律的必要条件，
不是一个已经对所有单个proper词为正的分离式。

## 2B. 一个无固定背景、对每份proper五色词成立的尖锐颜色关系

对V的每个proper五色划分c，定义 `M_j(c)=1[a_j(c)≠b_j(c)]`，j∈Γ。
局部单词否定精确等价于下列逐词不等式：

```
Σ_(j∈Γ) M_j(c) ≥ 1  （对V的每一份自由proper五色划分c）。
```

因此该不等式也对任何全Y色词的V限制成立，而不需要假定它来自某种支持表示。
全Y两词Γ正律中的每个词，限制到V后恰只有第9个运动改变完整划分，所以常数1尖锐。
这是实际几何上的完整颜色关系，不是只针对保存词池的数值观察。

但它**不是共同律的严格分离式**：共同律只要求源、像模式的边际分布相同，
不要求同一次抽样中的源、像模式相等。两词可以互换它们，故一个合法共同律也可能使
`E[M_j]=1`。不能把这个全词关系冒充`E[a_j模式指示−b_j模式指示]=0`的矛盾。

## 3. 两词正证据：直接比较完整划分，而非信任求解器匹配

证书保存两份各10077字母的词c₀,c₁。检查器逐条检查两份词的全部49858条实际边，
确认它们是不同的全Y划分；再对每个j独立重建源、像的**完整位置块**，比较

```
{a_j(c₀), a_j(c₁)}_multiset = {b_j(c₀), b_j(c₁)}_multiset.
```

全部Γ通过，原15域中的其他9域全部失败。两词各自都满足Γ\{9}，但都不满足第9域；
在第9域上，两个源划分与两个像划分交叉匹配。这只是相应完整域上的限制划分互换，
不是宣称第9运动把整个Y置换到自身，或给出整个几何群在两状态上的作用。

故 `(δ_c₀+δ_c₁)/2` 是Γ的精确完整共同律。检查不使用搜索时的支持匹配、调色板、
浮点数或某种周期假设。只看点对期望或只保留u的部分信息都不是本次正证据。

另有六份完整合法词c^(j)。每份在所有Γ\{j}完整域上单独不变，但在第j域失配。
检查器验证六份词的299148项边义务及全部对应完整域。因此不可删减性也有正证据，
不是求解器称“minimal core”后未经检验的断言。

## 4. 单词否定的编码等价与独立反证

对每个顶点v、颜色a∈{0,…,4}，设布尔变量X_(v,a)。
每个顶点恰一色，每条实际边禁止同色。对每个j∈Γ独立引入5×5置换矩阵P_j，
每行每列恰一项为真，并对每个真实映射v↦w加入

```
¬X_(v,a) ∨ ¬P_j(a,b) ∨ X_(w,b)     (a,b=0,…,4).
```

该公式可满足，当且仅当存在单份完整proper五色词在全部Γ域上划分不变。
正向：置换说明全部相等关系被保存。反向：相同的源像划分给出源域已用颜色到像域已用颜色
的一一对应；未使用颜色数相同，可以任意补为S₅中的一个置换。
不同运动的P_j之间**不加任何群关系**；不固定旧E083/E111调色板、不固定顶点颜色，
也不假设某个指定支持覆盖。于是反证的量词覆盖全部单一proper划分，而非固定旧公式。

固定点产生的75条重言式被丢弃，重复文字被合并；这些纯逻辑规范化不删去任何有效约束。
完整标准CNF有50535个变量、454872条子句，DIMACS SHA256为

```
6de47c72a1f236a9b1b2405c118412e9f2e529856d5ef0d68262bd4e4f418c66
```

生产器[motion_packet_cnf.py](../../research/motion_packet_cnf.py)与检查器分别实现编码；
检查器先从真实几何重建完整CNF并核对哈希，再按证书的严格递增子句编号取出21366条初始子句。
仅这个子公式便有6521步hinted-RUP反证，含3993681次带提示单位传播，最终得到空子句。
选择子公式不会使负结论变弱：它的每条初始子句都来自完整公式，不可能引入不存在的几何边。
但这些子句仍包括运动划分不变性，**不是**原实际图本身的不可五染反证。

提示导出、无用推导裁剪和SAT求解器均不被独立检查器信任。
每一步都从已检查的初始/先前子句，否定待证子句后重放单位传播矛盾；最终必须出现空子句。
只支持RUP，不把RAT、超时或无证据的UNSAT当结论。
最初直接发送未规范化公式的尝试被现有检查器按其输入规则拒绝，修正后从新公式重新求解；
保存的证书只使用后一个已经重放的版本。

以上反证排除支持1，第3节正证据给支持2，故最小支持恰2。
结合多数原子引理，每个原子质量≤1/2，且显式两词律达到上界，T140得证。

## 5. 对全词分离的一个严格后果，以及不能推广的结论

对于任意实函数φ_j:P_j→R，只要j限于Γ，恒不可能有ε>0使

```
Σ_(j∈Γ) [φ_j(a_j(c)) - φ_j(b_j(c))] ≥ ε     对所有c∈Ω。
```

证明：在已认证的两原子Γ共同律下取期望，左侧为0，右侧≥ε，矛盾。
这关闭的是Γ全部完整模式势的严格分离，不仅仅某些点对事件系数。
即使某个Γ受限编码非常难，继续在只包含Γ的负势中调权也不能突破。

相反，任何全15域律也必须满足Γ，因此T140给它一个必要条件：没有质量>1/2的完整划分原子。
**不**因此证明全15域最小支持是2、3、5，或证明全15域无解。
Γ均匀两词律的其他9个完整域均失配，不能把它伪装成全15域正解。

把所有候选律限制为“先在Γ内找两词包，再混合这些包”可作为正向构造启发，
但不能以其失败作全词否定。[C025/T142](cyclic_pattern_extension.md)已经在本29点实际V上找到
一份全15局部域的三原子极点：两个模式行加归一化行的行列式为−3，证明它不能由两词共同律混合得到。
所以“最小支持2⇒两词包凸包完备”不只在抽象模型里失败，在真实的当前局部几何上也失败。
这不直接构成全YΓ或全Y15域的不分解反例，因为局部律能否延拓到Y是额外要求。

更早的抽象校准也保留：取五状态、a=id、b=(01)(234)。
共同律满足μ₀=μ₁、μ₂=μ₃=μ₄，最小支持为2；但后三状态的均匀律不能由两支持律混合得到。
随后T141把C025的实际三原子律与真实η五阶闭环比较，在86点扩展上取得尖锐4/5延拓界；
局部可行、最小支持、真实几何延拓三个层次分别有明确证据，不能相互替代。
