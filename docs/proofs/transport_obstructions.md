# 颜色关系编译的必要条件

所有图都指proper k-coloring，允许少于k色。要求gadget至少存在一个
k-coloring，避免空关系的真空结论。以下均为本轮直接推导，不声明优先权。

## T007：多一颜色足以破坏非平凡 pair copier

若图G有(k-1)-coloring，两条不同的端口边不可能在所有k-coloring中
拥有相同palette。

证明：取(k-1)-coloring。若两palette已不同则结束；否则在输出边选一个
不属于输入边的端点，单独改为未使用的第k色。染色仍proper，输入palette
不变而输出palette改变。不同简单边必存在这样的端点。证毕。

推论：非平凡、可k染的完美copier本身必须χ(G)=k。于是5色copier
不能从始终4染的宿主获取；6色copier本身就已给出六色单位距离图。
这个推论不排除有χ=k的柔性copier，也不排除其他关系或联合编码。

## T008：分离集的颜色稳定子决定可传信息

设 `V(G)=L⊔S⊔R`，L和R之间无边。输入端口完全在L，输出边在R。
固定任一proper k-coloring c，记C=c(S)、B=输出palette。
任意固定C中每种颜色的置换π，只在R侧重命名颜色，仍给出proper染色。
所以若输出palette被输入唯一确定，则B必须被 `Sym([k]\C)` 固定。

设q=k-|C|。若q≥3，大小2的B被该群固定当且仅当B⊆C。
若q=2，还可取B=[k]\C；若q≤1，该群平凡。
证明：未固定颜色组成一个传递轨道， invariant subset要么包含整个轨道，
要么不含；2元素装不下q≥3轨道。证毕。

因此单点分离集(k≥4)不可能确定性传输一整条边palette；两点分离集且
k≥5时，只可能在分离集的两个不同颜色本身就是该palette时传输。
这解释了单点铰链有几何自由度，却不能自动带过二色信息。
若有跨模块边、额外端口或反馈回路，分离集假设会失效，需重新分析。

## T003：同一颜色作用下没有确定性 duad–syntheme 转换

任何无预染色的图关系R都对全局S_k重命名不变。因此一个只读输入状态、
唯一决定输出状态的gadget必须给出等变函数。

取六色duad T={1,2}。其稳定子H=S_2×S_4会任意置换剩余四色。
15个syntheme在H下有两个轨道：含T的3个、不含T的12个。没有单点轨道，
因此没有H固定的syntheme，也就没有S6等变函数 `duads -> synthemes`。
反向也没有：一个syntheme的稳定子可置换三条pair，并交换各pair内端点，
没有固定的duad。程序穷举720个置换，独立检查这些轨道和稳定子。

外自同构给的是扭曲作用后的对应，不是同一六种物理颜色作用下的对应。
所以不能用“都15个状态”直接编译无参考的唯一转换器。

允许多值relation、附加参考frame或联合端口时，结论不排除可实现性。
特别是duad与syntheme的无参考二元关系只可能是以上两个轨道的并：
空、含T、不含T、全体。它们应作为最小自然原语，而不是硬指定某个bijection。

## T009：无参考的确定性 pair 变换只有恒等

当k≥5，固定输入pair的S_2×S_(k-2)稳定子，在所有2-subsets中只固定
输入pair本身。因此每个S_k等变函数 `binom([k],2)->binom([k],2)` 是恒等。
这不排除多值关系回路造成矛盾，却排除了仅凭无参考确定性pair gate就
实施一个固定的非平凡颜色置换。实现holonomy需要说明参考frame及其传输。

## T010：二维join阻碍比等边三角形更一般

若两个不同端口点都与Q每点距离1，则Q包含于两单位圆交集，所以|Q|≤2。
因此若χ(Q)≥3，`Q ∨ (2K2)`绝不可能有单射二维单位距离实现。
更直接地，Q与任一端口边形成包含K4的join时也已不可能。
这里是几何不可能性，不是仅在某坐标搜索中没有找到。

## 与成熟理论的连接

这些结论都来自标准的图染色重命名与群稳定子，给information–mobility
直觉一个可检验版本。下一步不是给每种现象发明新术语，而是先用
稳定子轨道筛掉不可能的接口，再给幸存接口附上真实距离与组合证据。

## T014：任何非零距离的确定性点等色已经足够突破

设有限单位距离gadget强迫两个不同点u,v在所有k染色中同色，距离r>0。
则可明确地用有限个刚体副本构造不可k染的单位距离图。

取正整数q使1/q≤2r。把单位线段分为q份，每份上方取距两端都为r的
点，得到2q条长r的路径段。对每段放入一份等色gadget识别其两个端口。
所有路径端点被迫同色，但总路径两端距离1，矛盾。可取
`q=max(1,ceil(1/(2r)))`，所以2q个副本足够。新增真实单位边与偶然
顶点重合不影响此否定推理；每一份刚体副本内部仍单射。

若输入坐标实代数，可取分点坐标i/q、每个顶点高度
`sqrt(r²-1/(4q²))`，并用代数刚体变换放置副本，全部坐标仍实代数。

这说明无条件的点等色不是已经比HN容易很多的“普通导线原语”：
得到它本身就足以完成对应下界。共享一个端点的两条不同边的完美pair
copier也强迫另外两个端点同色，因此同样直接满足此判据。
