# T015：Moser角两三角格接缝的完整有限化与饱和

令Λ=Z+Zω，ω=(1+i sqrt3)/2，ρ=(5+i sqrt11)/6。
则Λ与ρΛ只交于0；非公共部分之间的所有单位边恰为

`a ~ ρa, a∈Λ, |a|²=3`，共六条。

证明：若非零a,b∈Λ且a=ρb，则ρ∈Q(i sqrt3)，与其sqrt11虚部矛盾。
设|a-ρb|=1。写b conjugate(a)=u+i sqrt3 v，其中u,v有理。
距离方程是 `1=|a|²+|b|²-(5/3)u+(sqrt33/3)v`。
其他项有理，所以v=0，a,b共线。取该格直线上的primitive格向量g，
写a=mg,b=ng，m,n非零整数，N=|g|²正整数。则

`3=N(3m²+3n²-5mn)`。

若m,n异号，括号≥11，不可能；同号可同时变号使之为正。
括号等于`3(m-n)²+mn`。m≠n时≥5，不可能；m=n时为m²，
故m=n=1、N=3（同时负号等价）。因此a=b且|a|²=3。
反过来，此条件下距离平方为`3*(2-2*(5/6))=1`，成立。

共用原点与每格六个单位邻点的边另行保留；它们不增加跨格新信息。
于是所有实际接触都在各格半径2内，扩大到半径3、4或无限不会再加跨边。

## E007：二进制列族的完整受限接缝关系

对T005的列族，所有非平凡接触的奇列只有m=-1与m=1，也就是j=-1,0。
允许分别全局重命名两格B色，将各自s_-1归零，剩下的局部增量各为0或-1。
原点颜色为A_0=0，因此相对六色置换有5!=120种。

穷举4个增量对和全部120置换，每个增量对都留下**53种**置换。
半径3和4的更大表分别包含64个边界词对，每项仍为53，已保存certificate。
由于定理确定了无限格的全部跨单位边，这个计算证明：任意两条双无限
二进制增量序列，在此Moser角焊接下都能通过某个相对颜色重命名拼接。

结论的范围：这是两个指定列族在指定角度、共原点位置下的**无限延伸定理**。
它不分类其他角度、平移、第三个模块或绕环的共同相对置换；也没有给出
全欧氏平面六染色。单个接缝能延伸不代表多个接缝可同时延伸。

这条路线在“仅增大此角两格半径”这一参数上已经饱和。合理的后续改变是
加入第三个独立方向，使三个接缝共享同一组相对颜色frame，并检验联合关系。
