# T159：已知 P/R 节点的 BW 全长度奇圈族精确闭合

2026-09-30。这里决定的是一个明确定义的不等式族的参数区域，
不是整个 Y 的划分律可行域，更不是 full15 或 HN 的解。

## 1. 固定的合法行族

仍取原 Y 的全部实际单位边 E，以及 T155/T157 的真实运输分量 P、R。
令 U=E∪P∪R，指定同色概率 q_e 为：E 上 0、P 上 p、R 上 r。
未属于 U 的点对没有被赋值，也没有因距离相同而自动并入任何分量。

对互不相同的 i,j,k，只要 {i,j}、{j,k} 都属于 U，就建立一个辅助节点

    t=(i,j,k)，z_t=q_jk−q_ij。

第三对 {i,k} 不必已知。对每份真正划分，z_t∈{−1,0,1}；若 z_t=1，
则 j、k 同块，而 i 与二者不同块。记正对 pos(t)={j,k}、
隐含负对 neg(t)={{i,j},{i,k}}。两个节点相邻，当且仅当

    pos(t)∈neg(s)，或 pos(s)∈neg(t)。

相邻节点不可能同时取值 1。因此任一划分的正值节点构成独立集，
给出有效的辅助边约束 z_s+z_t≤1，以及任意奇辅助圈 C 的约束

    Σ_{t∈C} z_t ≤ (|C|−1)/2。

这是 [Borndörfer–Weismantel 1997](https://edocs.tib.eu/files/e001/247304964.pdf)
§3 的 lower-triangle 构造，换成同块坐标后的形式；原文使用不同块坐标 x=1−q。
本地还对两个节点可能涉及的全部六点重叠类型穷举划分，独立核验上述冲突判据。

**本文行族**是这个逐节点只含已知 E/P/R 坐标的诱导辅助图的全部边和奇圈约束。
它包含每个循环边与二阶弦都属于 U 的简单 2-chorded odd cycle。
它不包含先经过未知坐标节点、再在总和中消掉未知项的所有可能 BW 推论。
这个区别是本定理范围的一部分，不能省略。

## 2. 精确答案

加上 p,r≥0，上述整个行族的精确参数区域为

    T = { (p,r): 3p≤1，2p+r≤1，2r−p≤1，p≥0，r≥0 }。

其五个顶点为

    (0,0)，(1/3,0)，(1/3,1/3)，(1/5,3/5)，(0,1/2)。

必要方向有实际源节点见证：

- 3p≤1：辅助三角形
  (5535,877,4641)、(7479,5535,4641)、(877,7479,4641)
- 2p+r≤1：辅助三角形
  (887,229,4641)、(3483,887,4641)、(229,3483,4641)
- 2r−p≤1：辅助边
  (887,229,4641)、(229,305,4641)

检查器逐对核验已知坐标、相邻关系和准确的 p/r 系数。
真正需要证明的是：无限多长度的其它辅助奇圈不会再收紧 T。

## 3. 一个有限图上的通用星形引理

设有限简单图的节点分成 A、B、C 三类，满足：

1. A 内部没有边
2. A∪B 诱导图是二部图
3. 每个 A 节点至多有一个 B 邻点
4. 没有类型 C-A-B 的三角形
5. 没有类型 C-A-B-B-A 的五圈

C-C 边完全不受限制。对 0≤t≤1/5，赋权

    y_A=(1+t)/2，y_B=(1−t)/2，y_C=t。

则全部辅助边和任意长度的奇圈不等式成立。

边约束由权值直接核验：唯一可能超过 1 的 A-A 边被条件 1 排除。
对长度 2m+1 的奇圈，设三类节点数为 a,b,c。A 独立，所以 a≤m，
等价于 a−b≤c−1。圈权超过 m 的差恰为

    [1−c+t(a−b+2c)]/2。

若 c≥2，这个差至多 (2−c)/5≤0。若 c=0，二部性排除该圈。
若 c=1，则 a−b 是非正偶数；差为 t(a−b+2)/2，正差只能发生在 a=b。
此时每个 A 节点都必须与唯一的 C 节点相邻：否则它在圈上的两个不同邻点
都属于 B，违反条件 3。因此 a≤2，剩余可能恰为条件 4、5 禁止的三角形或五圈。
证明完毕。这是任意规模的计数证明，不是“搜到某个长度没有反例”。

若原辅助图还有非正权节点，先检查全部边约束。包含一个非正节点的奇圈，
删除该节点后，剩下偶数个节点可沿路径配成相邻对；总权至多 m。
所以只须处理正权诱导图。

## 4. 原 Y 的全部有限假设已经核验

在 T 的斜边 r=(1+p)/2、0<p≤1/5 上，正权节点恰分成：

- A：正对在 R、显式负对在 E，权 r，共 78142 个
- B：正对在 R、显式负对在 P，权 r−p，共 20968 个
- C：正对在 P、显式负对在 E，权 p，共 70350 个

以下是完整输入上的精确检查，不只是某个窗口抽样：

- A-A 边为 0；A-B 边 31178 条；B-B 边 5476 条
- A-B 子图有 67932 个连通分量，其中 20968 个是恰含一个 B 的星
  （允许没有叶子），另有 46964 个孤立 A 节点
- 每个 A 的 B 邻点数至多 1；B 中心图有 20968 点、5476 边，无自环且为二部图
- 逐个检查全部 70350 个 C 节点，未出现条件 4 或 5 的禁形；每个 C 至多有 556 个 A/B 邻点

A/B 的边集分别由原文四种边形式和正对／隐含负对判据重建，结果逐边相同。
每个 C 的 A/B 邻点集也由这两种描述独立比较，包括四种边形式的反向邻接。
因此不是仅接受某个最短路程序“没有找到反例”的输出。

几何上的一个解释是：R 对之间由 R,R,P 三角形连接的相互作用图只有
68 条两两不相接的边，另有 1336 个孤立 R 对；R,R,单位边三角形为零。
这些稀疏关系说明高权部分为何退化为星形／二部结构。
实际证明仍以完整辅助图假设的重放为准，不从漂亮的方向图直接猜测结论。

## 5. 从有限假设到整个参数区域

将第 3 节取 t=p，便覆盖 T 的整条斜边，包括端点 p=0。
其余需要检查的顶点是 (0,0)、(1/3,0)、(1/3,1/3)。
原点所有节点权为零；后两点的任意节点权都至多 1/3。
长度 n≥3 的奇圈总权因此至多 n/3≤(n−1)/2，边约束也成立。

所有行都是 p、r 的线性不等式。由凸性，它们在 T 上全部成立；
结合第 2 节的三个实际强制约束，T 恰好是这个行族的参数区域。

加入 T157 的五色七点计数 12p+3r≥2，得到的区域恰好是
[T158 的九点五边形](nine_point_pr_polygon.md)：

    H = T ∩ {12p+3r≥2}。

因此，在当前两分量和逐节点已知坐标的条件下，继续枚举更长奇圈不可能
提高 1/27 或缩小 H。不是算力暂时不够，而是这个明确的方法族已经被证明达到上限。
这仍没有给出整个 Y 上共享同一概率空间的划分律。

后一个检查还核验固定首三元组与全部 120 个第二三元组的重叠类型，每种都枚举
六点的 203 个划分，确认冲突公式。有限校准不替代第 3 节的任意规模证明。
两个检查器都在优化模式下失败关闭，默认重放只比较收据，显式写入选项才更新。
几何与 P/R 运输闭包仍引用已独立重建且固定哈希的 T155/T157 输入。

包含标准 q=2 家族的多项式分离方法已有
[Müller 1996](https://doi.org/10.1007/BF02592097)和
[Caprara–Fischetti 1996](https://doi.org/10.1007/BF02592196)等来源；
BW 的奇圈提升给出可分离的更大合法族。本文没有把这一成熟算法宣称为新发现。
本次对实际固定输入的贡献，是用完整有限结构检查和星形引理决定这个受限族，
不再依赖巨大的逐源最短路扫描。

这里没有覆盖：未知坐标在多行相加后才消去的 BW 组合；其它真实运输分量；
所有高阶划分事件；一般更高阶 q-chorded 家族；全 Y 或原 full15 的正负答案。
half-chorded odd cycles 的分离复杂度也不能从 q=2 直接照搬：相关旧声明已有更正。
这些范围边界在后续研究中保留。
