## 1. 紧接E093实际执行了什么

[E093](operator_release.md)逐个删除旧算子后，十三种删除仍被三步
事件反证排除；只有η没有被当时的根传播确定。本轮没有把未判定
写成正例，而是立即执行唯一尚未排除的单组改变：

- 五个10077点色词全部重新选择，检查全部49858条实际单位边；
- E083旧14组中，η的词置换及逐词调色板置换全部自由；
- 新u的词置换及逐词调色板置换全部自由；
- 其余13组旧算子保持E083原值，不固定色词字面值；
- 两个自由运动分别使用5289、29点完整最大域，不加几何群关系。

保存词只用于核对旧底座原本可满足，不作为新词的硬冻结或相位约束。
自由辅助变量在商变量后依次分配，没有旧三点调色板锚定。

十三组旧算子产生443500条布尔等式，压为6668类；proper底座为
49132子句。加入自由η/u后为139918变量、2044702子句。冻结公式SHA：

`849c0e85ba7e4a3ffb0bfa7d45b4cf369e403e4a9f384d7ecf805b36ebe3fb3a`。

## 2. 从求解器观察到严格反证

每次冲突上限均为20000，没有扩大模型或增加预算。首次CaDiCaL195
报告25冲突、33决策的UNSAT，原始轨迹1122100行。这个状态最初

随后在**同一冻结公式**上用Glucose3导出证明，报告13冲突、57决策。
7527行原始轨迹去掉删除行后只有13条增广。删除可以安全忽略：
保留额外的旧子句不会使一个本来有效的RUP推导失效。生产器将其
转换为带显式传播提示的文本LRAT；转换本身不作为可信证据。

独立入口不导入SAT、生产器或proof converter：它重建实际几何、
十三组旧等式的BFS商、proper子句、两个自由算子编码，确认公式SHA
相同，再用项目的小型RUP-only检查器核验：

```text

```

因此数学负结论依赖独立重放，不依赖求解器的UNSAT文字、冲突数量
或搜索难易。原首次查询状态保留，不事后篡改成自带证明的历史。

## 3. 反证甚至不使用η义务

独立收集13步证明实际引用的初始子句，得到1081条：

| 原公式块 | 子句范围 | 被引用数 |
| --- | --- | ---: |
| 十三组固定算子商上的proper底座 | 1–49132 | 619 |
| 自由η完整义务 | 49133–2033167 | **0** |
| 自由u完整义务 | 2033168–2044702 | 462 |

将这1081条按原编号排序，重新编号全部初始子句、增广和提示，
再次独立RUP重放13步，末空编号1094。裁剪公式SHA：

`64d654880371d3fb1451a95939002ae88ccd8c2082814ab372f097b787dc4d9a`。

所以得到比原查询更强的严格结论：**连η概率义务一起删除，只保留
另外十三组旧算子及自由u，也不存在这样的proper五词律。**
这里的“删η”不是把它强制成恒等，也不是放弃其字面颜色后暗保留
旧η置换；反证实际没有引用该整块的任何子句。

作为解释性审计，核心中的u端口子句只涉及源词下标4的18个源端口；
其余u子句是置换约束。这不把反证变成18点的几何障碍：商类本身
依赖十三组**全域**旧等式和整个图的proper义务。固定表示的全局
信息已经进入这些类，不能从小RUP核倒推出小实际non-5图。

## 4. 与E093合并后的精确方法天花板

设有一个五等权proper词模型保留旧14完整域并加入u。如果其旧
词／颜色算子与E083保存表示最多只有一组不同，则：

- 不同组不是η时，E093对应的三步事件反证排除它；
- 不同组是η时，本页删η后的RUP反证排除它；
- 没有不同组时，E089已排除。

因此在此固定标号的表示比较中，成功模型必须至少有**两组旧算子
真正改变**。同时重排词及其调色板、并共轭全部算子不会绕过结论：
若一个模型在这种gauge变换后距旧表示至多一组，逆变换仍给被排除
的同型模型。这不是最小支持数、不可实现性或证明复杂度下界。

停止“旧包只改一组算子”的整条修补路线，不通过增加同族SAT预算
继续过拟合。两组改变只是必要条件，不是值得无条件逐对枚举的承诺。
后续需真正共同设计新表示／新模式，或找到对**全部proper词**有效
的分离；仍然没有任意full-joint反证或实际NON5见证。

更一般支持数、非均匀概率律、不同的算子实现、不同几何原型均未被
本页排除。E084原来的自由五词15域查询仍是UNKNOWN，不能由此改写。
