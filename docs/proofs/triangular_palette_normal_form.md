# 三角格上的五色平移等变性：全部调色板只剩三个斜率

2026-09-29。这个自足命题分类一种**有额外假设的染色方法**，不分类全部合法染色，
不改变普通 Hadwiger–Nelson 上下界。有限排列穷举只是独立校准；一般证明如下。

## 1. 精确命题

令 ω=(1+i√3)/2，Λ=Z+Zω，X⊂C 非空且 X+Λ=X。
设 c:X→{0,1,2,3,4} 为满射的合法单位距离染色，并存在两个固定颜色置换 P,Q，使

    c(x+1)=P(c(x)), c(x+ω)=Q(c(x))    对所有 x∈X。

则一次统一重命名颜色后，必存在 b∈{2,3,4} 使

    c(x+m+nω)=c(x)+m+bn (mod 5)    对所有 x∈X、m,n∈Z。

因此，对含 Y 的任何三角格饱和宿主，全部“两个平移分别由固定调色板实现”的五色方案，
恰好属于这三个钟式分支。满射性此时由 χ(Y)=5 自动给出。

本命题不要求 X 离散，也不要求 Λ 陪集只有有限多个。若只有有限多个，则与完整有限
位移接触核相结合，三个分支分别成为一个有限模5差异约束问题。

## 2. 完整证明

平移1与平移ω交换，故 P Q(c(x))=Q P(c(x))。满射性给 P Q=Q P。
A=〈P,Q〉 是在五个颜色上忠实作用的有限阿贝尔群。

每个 A 轨道都由某个实际点的 Λ 轨道实现。点 x,x+1,x+ω 形成单位等边三角形，
因此 c(x),P(c(x)),Q(c(x)) 三者不同。每个颜色轨道至少有3个元素。
五个颜色不可能分成两个这样的非空轨道，故 A 传递。

一个传递阿贝尔置换群是正则的：若 a∈A 固定一个颜色 v，对任意颜色 w=h(v)，
有 a(w)=a h(v)=h a(v)=w。忠实性迫使 a=id。因此稳定子平凡，|A|=5。

P 没有固定颜色，因为 x 与 x+1 总邻接，所以 P≠id。在阶5群中 P 生成整个 A。
沿其循环标号使 P(t)=t+1；于是 Q=P^b。前面的三角形要求 b≠0、b≠1，
即 b∈{2,3,4}。对正负整数平移反复使用两个等式，即得公式。证毕。

反过来，满足该公式且通过完整接触核的色值当然给出上述平移等变五染色。
公式本身不保证跨不同 Λ 陪集的所有单位边异色；这些接触仍须逐一验证。

## 3. 两个不能略去的校准

**一般五染色未必等变。** 在实际三角格上先取三染色 c(m+nω)=m+2n mod3，
再仅将点0和10分别改为颜色3和4。此时五色全部使用且仍合法：改变的点使用原来未使用
且彼此不同的颜色，其他边继承原三染色。若平移1能由固定有限置换P实现，某个正整数r
使P^r=id，就会有 c(r)=c(0)=3；但颜色3只在原点出现，矛盾。
因此三个斜率的搜索否定，甚至若全部得到独立反证，也只排除等变方法而非普通五染色。

**四色时不一定是循环群。** 三角格的合法四色规则 (m mod2,n mod2) 使用
两个坐标翻转，调色板群是 Klein 四元群，不是循环群。五这个数在证明中对应
“两个大小至少3的轨道放不下”以及“传递阿贝尔群阶为素数”，并非随便选取的常数。

## 4. 与本轮计算的关系

1. 原 Y+Λ 的 b=2 正证书已经重新生成，并由另一套精确代表/完整接触枚举验收。
2. B=∪_{r=0}^4 η^rY 的 B+Λ 有20461个平移陪集与173328个完整接触类型。
   本轮三斜率查询未决定其等变五染可行性；不存在已认证的负结论。
3. 周期相位模型允许 ω 平移在不同格层有不同颜色效应，已经超出本命题的假设。
   本轮所试二相位模型也未得到正证书；有限相位失败仍不是普通图反证。
4. B+Λ 自身一般不在 η 下封闭，因为 ηΛ≠Λ。不能因 B 已 η 封闭就把整个宿主
   宣称为旋转和平移的共同闭包。

这里不宣称新群论原理或文献优先权。作用是把当前正构造分支的量词说清，
以及证明“再试一般固定颜色置换”不会超出已经列出的三个斜率。
