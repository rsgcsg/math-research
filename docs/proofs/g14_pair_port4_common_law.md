# T156：两个成对轨道与四端口模式的共同精确律

2026-09-30。有限正证书；原始 HN 与任意支持 full15 仍未解决。

## 同一个律，而非两份可行性的拼接

[T155](g14_selected_pair_orbit_law.md) 的两个成对运输分量分别含1860个平方距离1/3事件 P、780个平方距离4事件 Q，生成森林共2638行。[T154](port4_exact_rational_law.md) 是四组四端口的50个完整模式差行。两者分别有正律，不保证联合有律，因此本次固定这两个事件族，检验同一组权重能否满足全部义务。

已找到并独立验证：81个全Y合法五色词中，39个词以正有理权重组成共同律，公分母300531，总权重1。

- 每个候选词都通过全部49858条实际单位边检查，共4038498次
- 每个候选词在全部P事件上异色、全部Q事件上同色，因此2638条成对森林行逐词为0
- 同一39个正权重使冻结的50个四端口完整模式差行同时精确为0

因此整个这2688行张成空间不可能对所有 proper 全Y词严格分离。这里不声称2688行整体线性独立，也不声称39是最小支持数。

## 一般机制

当一批事件差在某个 proper 词集合上逐词为0时，任意支持于该集合的概率律都自动满足这批行。于是联合正构造可先限制到这个集合，再求其余行的共同权重。本次选择的集合是 P事件全异色、Q事件全同色的集合，简称 p=0,q=1 面；它是额外选取的构造面，不是由 full15 假设强迫的条件。

这一步是找正见证的合法缩小。若这个构造面上的其它义务不可行，也只能排除该面，不能据此排除所有 proper 词上的共同律。

## 搜索与证明分离

从T155的单词出发，在不再增加行的条件下做80轮全Y定价，得到80个新词，形成81词候选池；每次定价都保留上述面约束。数值LP只用于找候选，最后恢复精确有理权重。

正结论仅依赖保存的词、实际几何、精确映射和有理权重，不依赖定价算法的最优性、80轮的完备性或SAT求解器可信性。未保存80份完整CNF为正结论的证明依赖；压缩证书保留来源摘要。

## 完整域范围审计

把同一39原子律放回原15个完整源／像域逐一比较完整划分分布，15个域全部不平衡。每个域有39种源模式、39种像模式，78个非零残差；证书为每个域记录一个模式及其精确源质量、像质量和差，检查器重新计算。

所以本律不是任意一个完整域律，更不是 full15。该断言来自混合后的精确审计，不能只凭某个支持词失配而作出。
