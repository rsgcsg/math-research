# T048：单点解除根色强制；域外根接触与真实修复

2026-09-08，起始干净本地基线`706ff9c`。依赖T037局部名单恒等式、
T040任意平面点的端口邻接上限、T046根点支持与T047精确耦合。
本轮不新增HN界，也不假设当前参考模板覆盖一般二维单位距离图。

## 1. 一种比“使gate变好”更强的单点动作

spindle记为`o,a,b,c,d,e,f`，边沿用T037。若各名单大小至少3，且
`L(a)≠L(b)`，则**o的每个允许颜色都能延伸**，不只保证存在一种。
`L(d)≠L(e)`同样足够。

证明：固定根色x后，a,b删去x。由T037，左三角形尖端支持不是整个
L(c)的唯一情况，是`L(a)\{x}=L(b)\{x}`且大小为2。这要求原来两份
名单都恰为该二集合并上{x}，即L(a)=L(b)，与假设矛盾。
所以c可取L(c)中任意颜色，至少三种；另一尖端支持非空，cf可异色。
于是所有x∈L(o)均延伸。

对T037的单位边pair gate，先给边界一份{0,1,2,3}四色染色。只把
a的两个端口之一改成新色4，a的新名单不含4，b的未变名单含4，
故二者必不同。**一次端口重染就使根点支持等于其整个三名单。**
改动b、d、e所附端口之一也一样。可选端口集合为

`W={9,10,11,12,15,16,17,18}`，共8点。

注意：必须只改变这对翼点名单中的一份；任意改变很多端口不自动
保留这种不对称。也不能只改根点自己的边界对就声称消除了强制。

独立检查器枚举全部旧三角形端口palette与被改端点，并逐根色直接
枚举三角形合法染色，共2160例，验证改变后尖端支持始终为完整L(c)。
普适结论来自上述短证明，不来自只检查五色输入。

## 2. T048：根接触网络的同步修复定理

设H是一个有限二维诱导单位距离图，并给定其一份四色染色。
在H上附加t个指定21点gate的刚体副本，允许任意实平面姿态，要求：

1. 各gate全部边界在H中，**不同gate的边界互不相交**；
2. 各内部七点彼此分离，且不在H中；
3. 内部到H的边只有各自gate的原有附加三角形边；
4. 不同gate内部之间的实际单位边只连接其根点o；把全部这些边组成
   根接触图J，不漏掉真实单位边；
5. J是2-degenerate，即其每个非空子图都有一个度至多2的顶点；
6. 存在H中的独立集I，每个gate的八点集合W_i恰选一点，且I不含
   其他点。这是指定端口集合的独立横截，不是一般存在性假设。

则把I改成新色4后，H与全部gate能共同五染。原来有多少单模块坏
gate或根点强制冲突不影响结论。

### 证明

独立性保证H的重染proper。边界不交保证每个gate确实只改了它的
一份翼点名单，其他端口未变；由第1节，该根点支持恢复为完整三
名单O_i。根点自己的边界对没有被修改，故每个O_i仍恰有三色。

逆向使用J的度≤2剥离顺序，从O_i逐个选根色即可：每次至多两种
颜色被已染邻点排除。固定这些相容根色后，由第1节分别延伸各模块。
假设3、4保证没有被这次拼合忽略的内部约束，因此得到全图五染。

### 两个可直接验证、无需假设横截存在的推论

**(a) 总共至多4个gate。** 任意点至多与任一gate的14个端口中的
两个单位相邻（T040），对W_i这个子集也成立。依次选点时，此前
最多三点，至多禁止W_i中的6点，小于8；边界不交还排除了选点重合。
所以独立横截存在。根图至多4点且有真实二维单位实现，不含K4，
于是2-degenerate：否则某个子图最小度≥3，在≤4点上只能是K4。
因此满足1–4的任意至多4个gate，对任意给定H四色染色都能这样修复。

**(b) 任意多个gate的共同旧颜色情形。** 若存在α∈{0,1,2,3}，使每个
W_i都含α色端口，则每个W_i选一个α点即可。H的同色类独立，条件6
自动满足。只要J满足5，就得到任意规模的同步修复，不需要有界全局度。

这里(a)数的是**全部gate总数**，不是“初始坏gate数”；不要与T042
的七个坏gate、任意多个好gate相混。T042不允许内部跨边，T048允许
根边但要求边界不交，两者的适用域不同。T047有七条内部匹配，且
边界相交，所以不能直接套T048；它的修复在下一节另行独立核验。

## 3. E024：T047坏边界的全部单点新色修复

固定T047的40点诱导图和其边界染色b，b只用{0,3,4}三色。
对26个物理边界点，各改为未用颜色1或2，共52个精确输入。
一次只改一个**物理点**；两份gate共享的端口不能各改各的。

全部输入都保持边界proper，完整延伸数如下：

| 完整五色延伸数 | 单点修改数 |
|---|---:|
| 0 | 4 |
| 32 | 40 |
| 44 | 4 |
| 72 | 4 |

所以48种单点修改已能修复。仅有的4个失败输入，是把第0个gate的
端口7或第1个gate的端口8（原色均为3）改成1或2。这仍使两根点
被迫为0，根边依然矛盾。其余输入各保留完整五染色见证。

检查器不相信搜索计数：从每份修改后的边界重新产生内部名单，
穷举各spindle全部三名单词，再逐对检查七条对应匹配；原T047独立
几何检查保证这是完整跨内部约束。零值也被穷尽和强制根色双重解释。

这不是所有旧色重染、所有多步修复或整个26点边界的分类，只是
这份具体坏边界的**全部单点未用色修改**。结果说明T047还不是修复陷阱。

## 4. C006：已离开原安全域，根强制仍能单点修复

取原gate坐标p_i∈Q(√3,√11)²为第一份，第二份为

`q_i = R p_i + t`，

`R=[[-4/5,-3/5],[3/5,-4/5]],  t=(5/8, √39/8)`。

|t|=1，R正交。因为√13独立于K=Q(√3,√5,√11)，第二根点的
y坐标√39/8不属于K。因此这份**坐标实现**不在K²内，确实进入
K(√13)²。没有声称该抽象图不能另外在K²中实现。

完整精确检查42点互异、全部861个点对，诱导单位边恰为两个gate
的64条边加一条根边`p_0q_0`，没有共享边界或其它跨边。这也可由
系数比较校准：令w=p_i−Rp_j∈Q(√3,√11)²，则|w−t|²=1要求
`w_y=0`及`w_x∈{0,5/4}`；本两份配置仅根对满足。但独立检查器
直接在八维根式域中平方全部861个点对，不依赖这项剪枝。

给每个gate根边界对染(1,2)，其余六对染(0,2)。两根名单为{0,3,4}，
其余名单为{1,3,4}，故各有24延伸而根色都被迫为0。联合原边界无解。
只把第一gate的端口9由0改为4，便有完整五色延伸，已保留见证。
另保存并核验无条件四色染色；含spindle给下界4，故此图χ=4。

因此“逃离T028的坐标域”与“产生根强制冲突”即使同时发生，也仍
不足以构成无条件下界。T048(a)进一步说明：不仅这一份边界可修，
在保持其根接触/私有内部结构且给出任意四色边界宿主时，这种双gate
仍可同步修复；不必对每个域外姿态重跑完整边界枚举。

## 5. 收敛后的下一处缺口

本轮不继续堆叠只有根接触的双模块：它们在上述四色宿主结构下已
被统一修复。更有区分力的对象至少要改变某项条件，例如：

- 有真实几何的多个内部接触点，导致单根支持不再足够；
- 边界交叠使“一模块只改一翼”的同步选点失效，且排除其他修复；
- 根图不在当前2-degenerate安全类，且实际根名单与几何能共同激活；
- 外部宿主必须真正使用第五色，同时其所有合法边界都不能逃逸。

这只是本结构类的逃逸条件，不是一般六色UDG的必要条件。尤其
不能从“根图不是2-degenerate”直接推断不可三名单染。

原问题仍未解决。T048是新普适修复定理，E024与C006是精确校准，
没有把条件UNSAT、逃域或一次局部强制升级成HN下界。
