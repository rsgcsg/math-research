# T029–T031：逃离同域上界以后，真实跨边发生了什么

沿用 `K=Q(√3,√5,√11)` 及T028的11进赋值。以下均不宣称新色数下界。

## T029：二次旋转的跨单位边只来自共线原向量

设d∈K在K中非平方且实嵌入中为正，c,s∈K、s≠0、c²+ds²=1。
令J(x,y)=(-y,x)，`R=cI+√d sJ`。对p,q∈K²，展开距离并比较
K上线性独立的1、√d，得到

`|p−Rq|²=1 iff p·Jq=0 且 |p|²+|q|²−2c(p·q)=1`。

第一式即p、q与原点共线（允许零）。同理p=Rq迫使Jq=0，因此
`K²∩RK²={0}`。新根式打破坐标域上界，但单个同原点旋转仍强烈限制
跨边方向。

### T031：非公共跨边图的次数与无环性

只保留两片层间、两端都不是共享原点的跨边。固定非零p，T029给出
q=tp，且 `t²−2ct+1=1/|p|²`，所以跨度数至多2。

若c∈Q且2c不是整数，则这个跨边图**没有有限环**。证明如下：沿一条
非回溯跨边路径，各原向量都在同一条K直线上，可写成a_n u。
相邻关系为 `a_n²+a_(n+1)²−2c a_n a_(n+1)=1/|u|²`。
二次方程的另一个根给出

`a_(n+2)=2c a_(n+1)−a_n`。

如果有长度N的环，递推矩阵M=[[0,1],[-1,2c]]的某个非零状态被M^N
固定。因c²≠1，其两个复特征值λ、λ^(-1)不同，至少一个满足λ^N=1。
于是2c=λ+λ^(-1)是有理代数整数，必须是整数，矛盾。
这里最后一步也可不用代数整数语言：λ^n+λ^(-n)是变量2c的首一整系数
n次多项式；当λ^N=1时该多项式取值2，有理根定理迫使2c为整数。

因此非公共跨边图是路径、射线、双无限路径和孤点的并。四种E016旋转
全满足此条件；实际有限核心中的跨边甚至全是matching。
这是**仅跨边图**的结论，绝不表示加入片层内部单位边后的全图无环，
也不表示两个任意五色图由一个跨边森林连接后一定五色。

## T030：√13旋转产生任意深度的真实单位向量

取 `R=(1/8)[[5,-√39],[√39,5]]`。有理共线点p=(a,0)、q=(b,0)
形成跨单位边恰当 `a²+b²−(5/4)ab=1`。这条椭圆有有理参数化

`F(t)=4t²−5t+4`，
`a=4(t²−1)/F(t)`，`b=t(5t−8)/F(t)`。

直接展开可证恒等式。F的实判别式−39，故有理t时分母不为零；模11
却有简单根7、8。在t≡7支，F'(t)≡7。逐次提升得F(t)被11^m整除的
整数t；若还被11^(m+1)整除，改为t+11^m使赋值恰为m。两个分子模11
均非零，因此对每个m≥1都可取得 `v_11(a)=v_11(b)=−m`。

实际单位向量为 `(a−5b/8,−√39 b/8)`。在K(√13)上任何延拓的11进
赋值中√39/8是单位，所以第二坐标赋值恰−m。任何固定赋值窗口都不能
包含该域的全部单位方向。

t=7给出 `a=64/55,b=63/55`，实际差向量
`(197/440,−63√39/440)`，且 `197²+39·63²=440²`。
这是真实欧氏单位边，不是只有模11成立的伪边。
valuation_escape.py检查前24层的精确有理式和赋值；无限性由上述提升
及非零分子证明，不由有限校准外推。

## 自然机制与剩余障碍

T028成立的原因是剩余域上的x²+y²各向异性：零只有平凡表示，负赋值
首项不能相消。引入√13后，剩余域变为F121，−1成为平方；T030把
这种相消落实为任意深度的实单位边。

但赋值方向不再有界不等于需要六色。它只否定直接复用T028的陪集独立
染色/固定赋值窗口，不排除其它编码。局部域的可测/Borel结果也不能
自动升级为普通实平面染色结果。

下一道具体障碍：不同中心的T030跨边，其共享完整颜色关系是否产生
不可消解的闭环；或反过来是否有兼容任意赋值深度的五色延伸法。
当前四个双核心均五色，T029/T031又限制单中心跨边。尚无闭环的五色否定
证书，也无K(√13)²全域五染色；不把逃过一个上界当成新的下界证据。
