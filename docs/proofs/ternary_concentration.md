# 无三原子解的平衡系统：任意三列总质量至多9/10，且代数意义下尖锐

2026-09-28。下面是一个完整的有限线性代数结论。
它给全15域支持反证一个不依赖总支持数的推论，不是普通HN的新上下界。

## 1. 命题

设D是有限矩阵，条目属于{-1,0,1}，可行概率λ满足Dλ=0、λ≥0、1ᵀλ=1。
若不存在支持至多三列的可行概率，则任意可行λ在任意三个指定列上的总质量至多9/10。
同理，无单列解时单列质量≤1/2；无至多两列解时两列总质量≤3/4。
这三个常数分别在抽象矩阵类中尖锐。以下证明三列情形；一/二列是相同论证。

## 2. 紧致多面体归约

取三列组成B，其原质量向量为x≥0，总质量s=1ᵀx，剩余质量r=1−s。
由Dλ=0及每项绝对值≤1，逐行有|Bx|≤r。
r不为0，否则这三列本身给一个可行律。令z=x/r，则z≥0、|Bz|≤1。

考虑Q={z≥0:|Bz|≤1}。它的衰退锥是{v≥0:Bv=0}。
若有非零v，归一化后就是至多三列的可行概率，与假设矛盾；故Q有界。
Q非空且闭，因此线性函数1ᵀz在某个顶点取得最大值。

设该顶点恰有d个正坐标，d≤3。固定其他坐标为零后，必须有d个线性独立的约束
从|Bz|≤1中取等号，否则正坐标内有可双向微扰的方向，违背极点性。
将符号吸收到每行中，得到一个可逆d×d的{-1,0,1}矩阵A，满足A z'=1且z'≥0。

对d=1,2,3全部有限矩阵进行精确穷举，分别得到

`max{1ᵀ A⁻¹1:A可逆且A⁻¹1≥0}=1,3,9`。

该步遍历3、81、19683个矩阵，使用整数行列式与有理数Cramer公式，没有数值LP。
完整不足50行的实现 `research/ternary_mass_bound.py` 属于证明的有限穷尽部分；
`make check-full15-support` 每次重做，不信任保存的最大值。
故1ᵀz≤9，进而s/r≤9，即s≤9/10。证毕。

## 3. 尖锐反例，也否定了错误的7/8猜测

取四列矩阵

```
D = [ -1   0   1  -1
       0   1  -1  -1
       1  -1   1  -1 ].
```

其前三列矩阵的行列式为−1，且D(2,4,3,1)ᵀ=0。
所以D秩3，归一化的正核唯一，权重为(2,4,3,1)/10。
没有至多三列的可行概率，前三列却承载9/10>7/8的总质量。
因此不能由既有1/2、3/4界直接猜测三列界是7/8。

这还可写成真正的“模式分布差”抽象系统：将D的每行配上其负行。
对每个二模式观察，列值+1用源0/像1，−1用源1/像0，0用源0/像0实现。
正负两行恰为两个模式的差值。此说明模式差结构本身不改进9/10常数；
并未证明该四状态抽象系统能由当前Y或某个实际平面单位图实现。

## 4. 对当前研究的严格用途

[全15域六情形反证](full15_support_exclusion.md)排除了至多三原子律，因而任何可能的全15域律
都满足上述三完整划分质量界。若多份划分给同一个完整D列，可先将其质量合并。
不能把这个界用于任意三个低阶局部模式；也没有证明9/10在当前实际系统中可达。

这是必要条件，不是“坏边概率至少1/10”：剩余质量允许使用其他完整合法划分，
它们仍可能共同满足全部约束。没有全词严格分离，所以普通HN界不变。
