# T081：高单位边密度可以与整个宿主二染色共存

2026-09-10。所有域都按指定复嵌入视为通常复平面的子集。
本条是成熟赋值方法的本地已证应用，不声明发表优先权。
外部边数定理是所引预印本的定理；这里不声称独立重放了其类域塔。

## 1. 一般结论

设数域E⊂C被复共轭c稳定，存在非平凡非阿基米德赋值v，使得

1. `v(c(x))=v(x)`；
2. 剩余域κ的特征为2，且c在κ上诱导恒等自同构。

则整个E的诱导单位距离图恰二色。剩余域不必是F₂。

证明：实际单位差w满足`w c(w)=1`，故

`0=v(w c(w))=2v(w)`，即`v(w)=0`。

记R为赋值环。约化后`res(w)²=1`，而在特征2的域内
`X²−1=(X−1)²`，所以`res(w)=1`。每条单位边均在同一个
加法陪集E/R内。选一个F₂线性映射`λ:κ→F₂`，使`λ(1)=1`；
这可由包含1的F₂基构造。每个陪集固定代表t，并定义

`color(x)=λ(res(x−t))`，`x∈t+R`。

单位边的颜色差恰为1，所以这是二染色。0与1是实际单位边，
给出相反不等式。证明没有使用可测性、周期性或系数分母限制。□

与[T078的共轭稳定机制](cyclotomic_field_coloring.md)相比，关键推广
是允许任意特征2剩余域，然后取非零加法泛函，不要求剩余域本身
只有两个元素。一般的积分陪集到剩余图方法可对照
[Madore, Proposition 3.2](https://arxiv.org/html/1509.07023v1)。

## 2. 未在2处分歧的实域：任意次数仍恰二色

设L⊂R是数域，至少有一个2上素理想p满足`e(p/2)=1`。
令`E=L(i)`。则整个E的诱导单位图恰二色。

证明：完备化`L_p/Q₂`是未分歧扩张，因此2仍是其一致化元。
`i−1`满足多项式`X²+2X+2`，该多项式在L_p上Eisenstein。
于是`L_p(i)/L_p`为全分歧二次扩张：p在E中只有一个上方素理想，
复共轭稳定它，且在剩余域上为恒等。应用第1节。

这里Eisenstein也可直接从根的赋值看出：归一化`v(2)=1`后，
方程三个项的最低赋值必须至少出现两次，强迫`v(i−1)=1/2`。
故局部二次扩张的分歧指数为2、剩余次数为1。□

特别地，该结论适用于任意未在2处分歧的实数域序列，**不受次数
增长影响**。若这些域嵌套，整座`⋃ L_j(i)`也二染：任意奇闭路只
含有限多个域元素，因而位于某一已证二染的有限层，矛盾。

## 3. 2026年边数突破的一个实际构造族全部二染

主来源是[Alon等，arXiv:2605.20695v1](https://arxiv.org/html/2605.20695v1)，
2026-05-20；2026-09-10检索的摘要页仍只列v1。
精确定位为§2.1，Theorem 1.1的证明，紧接Lemma 2.2的两段说明。
作者取只含奇素数的有限集T，在T外未分歧的全实数域L_j，并令
`K_j=L_j(i)`。该条件包括2处未分歧；不是对所有CM域的断言。

因此第2节应用于每个K_j。其实际点集来自某个平移的
`p^(−2k) O_(K_j)`的Minkowski窗口，再投影到一个复嵌入。
除去共同平移，所有点在K_j中；窗口平移的复坐标本身无需在K_j。
任意两点的**实际**单位差都由第1节覆盖，不仅限于边数下界证明
预先挑选的方向。

外部Theorem 1.1对这族点集给出某个固定ε>0的
`|E(G_j)|≥|V(G_j)|^(1+ε)`，同时这里严格得到`χ(G_j)≤2`。
点集有边时等号成立。因而同一族还满足
`α(G_j)≥|V(G_j)|/2`，不能提供六色下界或五色不可能性。

这是**对实际高密度构造的染色诊断**，不是从“平均度大不蕴含色数
大”这句一般常识替代检查。低次域上的有限例子只是校准；大次数
以及任意分母已经由证明覆盖。

## 4. Sawin的更强指数不能被上述理由整体退休

[Sawin, arXiv:2605.20579v1](https://arxiv.org/html/2605.20579v1)，
2026-05-20，Theorem 1给出`n^(1.014114)/C`量级的单位边对数。
其Lemma 12及Theorem 1证明使用不同的局部条件：实域F在2处分歧，
`K=F(i)`在F上所有有限处未分歧；在所指定的22个小素数上反而
要求K/F分裂。不能把第2节误套到这些F。

Lemma 11(1)及Lemma 12的证明还使F包含所选T中的全部`√q`；
这里T含3、5、7、11。因此整个K含仓库的五色域
`F_core=Q(i,√3,√5,√11)`，由T028有`χ(G(K))≥5`。
这并不证明Sawin最终选择的某个有限窗口本身至少五色。

11进方法的具体失效可直接写成单位向量：

`w=(10+i√21)/11`，`w c(w)=(100+21)/121=1`。

取子域`M=Q(√−21)⊂K`。模11的`X²+21`有两个单根±1，
所以11在M中分裂。在`√−21≡−1 (mod11)`的素理想处，
分子`10+√−21≡9`非零，而分母11为零，故w的赋值为负。
共轭素理想处赋值为正，乘积范数等于1。延伸到K的任意上方
赋值只会乘以正分歧指数，不能消掉这个极点。

实际上，因该分裂二次子域已经在K内，K上不存在共轭稳定的11上
素理想：稳定素理想在M上的限制也应稳定，矛盾。因此T028的
原11进积分约化不能原样延伸。**这里既没有得到整个K的五染色，
也没有得到六色图，更没有证明所有非赋值方法失败。**

消除第1节的二染色。这个原封不动的路线不值得作六色搜索。
Sawin的不同局部结构仍可作为候选素材；须另证颜色或独立集约束，
不能把其边数增长当成色数增长。
