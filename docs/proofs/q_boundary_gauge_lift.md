# T170：T165 边界 separator 的 gauge 规范化与更强无条件 lifting

2026-10-06（Australia/Brisbane）。本页只改写并加强已经认证的 T165/C030
联合边界不等式；**没有 full15 终局，也没有普通 Hadwiger–Nelson 新界**。

## 1. 七个零缺陷窗口就是七条可用等式

T165 在边界面 D=0 上工作。对七个 saturated K7，记

    H_j(c)=该窗口内的同色点对数。

在 D=0 上每个 H_j=2。原 T165 整数式记为 L(c)<=2，其 P/Q/R 系数和为

    (-2267, 500, -501).

因此对任意整数 g_1,...,g_7，都可以在该面上改写为

    L'(c)=L(c)+sum_j g_j H_j(c) <= 2+2 sum_j g_j.

这不是新假设，而是同一个 face inequality 的 gauge 表示。

## 2. 一个显式小系数 gauge

取

    g=(3,0,-19,23,210,-1,-49),    sum g_j=167.

把每条 P/R 事件的系数加上包含该点对的所有窗口的 g_j；单位边项虽然也被
H_j 带入，但 proper 染色上恒为0，所以可以省略。Q 都在窗口外，系数不变。

精确得到：

- 新右端：336；
- P/Q/R 系数和：(-263,500,0)；
- 全部正系数和：969；
- 全部绝对值和：1701；
- 最大绝对系数：71；
- 非零 P/Q/R 系数：76。

特别是 **R 的总系数恰好消失**。因此任意支持在 D=0 面上的 P/Q/R 平衡律满足

    -263 p + 500 q <= 336.                         (1)

在 p=1/27 时，(1)仍给出

    q <= 1867/2700,

所以它和 T165 的边界结论完全一致，但聚合形式显著更简单。

## 3. 更小的 support-independent lifting 罚项

对任意 proper 五色词，仍令

    D=sum_j Z_j + T >=0,

其中 Z_j=H_j-2，T 是 T165 的 PRR 三角缺陷。D 是非负整数。

- D=0 时，由(1)的逐词版本有 L'<=336；
- D>=1 时，所有 e(a,b) 都是0/1，所以 L' 至多为全部正系数之和969。

于是逐词有

    L' <= 336 + 633 D.                              (2)

旧 T165 对其原始表示只能用罚项1321；这里显式降为633。

对任意 P/Q/R 平衡概率律取期望。T165 已精确给出

    E[D]=85p+19r-13,

而本轮 gauge 给

    E[L']=-263p+500q.

代入(2)得到新的无条件必要式

    500q <= 54068p + 12027r - 7893.                 (3)

再用已有三角传递式 2r-p<=1，即 r<=(1+p)/2，得

    1000q <= 120163p - 3759.                        (4)

## 4. 633 在这一 gauge + 粗 lifting 类中已经最优

上节的633不是一次启发式调参值。固定“R 聚合系数消失”就等价于要求

    sum_j g_j = 167.

允许 g_j 是任意实数。对每条非Q的P/R项，记原系数为 a_i，它落入的饱和窗口集合为 J_i，
变换后系数为

    b_i = a_i + sum_{j in J_i} g_j.

取证书指定的33条非Q项。它们有两个精确性质：

1. 原系数总和恰为 -700；
2. 七个窗口中的每一个，在这33条里都恰出现7次。

因为对任意实数 x 都有 max(0,x)>=x，所以全部非Q正系数和至少为这33条
变换后系数之和：

    sum_i max(0,b_i)
      >= -700 + 7 sum_j g_j
       = -700 + 7*167
       = 469.

11条Q不属于任何饱和窗口，gauge完全不改变它们；它们本来全为正，系数和固定500。
所以任何满足 sum g_j=167 的实数 gauge 都有

    全部正系数和 >= 469+500 = 969.

本页显式整数 gauge 恰好达到969，因此这是该 gauge 类中的全局最小值。对应的统一粗
lifting 罚项至少为

    969-336 = 633,

而本页也恰好达到633。

这里的“最优”范围必须严格保留：它只针对
“加七个窗口等式、要求R聚合消失、然后以全部正系数和作为 D>=1 时统一粗上界”
这一方法类。它**不**证明633是所有可能 separator、非均匀 defect 罚项、
matching-synchronization 分解或更强局部上界中的最优常数。

## 5. (4) 严格支配旧 lifted scalar

T165 的旧标量式是

    1000q <= 254704p - 8742.

旧右端减新右端恰为

    134541 p - 4983 = 134541 (p-1/27).

而已有 T157/T163 给 p>=1/27。因此：

> 在全部当前允许的 p>=1/27 区域，T170 的(4)不弱于旧式；
> p>1/27 时严格更强，只在 p=1/27 边界取相同值。

例如，如果未来能独立证明 q>=7/10，则(4)立即给

    p >= 4459/120163 ≈ 0.0371079284 > 1/27.

这仍然只是条件推论；本轮**没有**证明 q>=7/10。

## 6. 机制与下一步

这次改进说明 T165 的大系数很大一部分只是“选了一个差的 face 坐标系”，不是
障碍本身的内在复杂度。七个窗口等式可以像 polyhedral patching/gauge 一样吸收
大系数，同时保留真正跨窗口的 Q 信息。

下一步应继续两件事：

1. **停止**在 `sum g_j=167` 的同类 gauge 中继续压“全部正系数和”：上节已证明633最优；
2. 若要继续加强 lifting，必须换机制，例如给不同 defect 非均匀罚项、证明比“全部正系数和”
   更小的局部上界，或直接利用 matching-synchronization；
3. 把剩余76个非零系数按重叠窗口/匹配同步分解，寻找少数局部
   transitivity / matching inequalities 的组合证明，而不是再次做89维黑箱搜索。
