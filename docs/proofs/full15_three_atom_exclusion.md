# T147 / E113：完整十五域没有至多三原子共同律

2026-09-29。范围是已有 Y 的全部15个最大运动域、全部合法五色完整划分，
**只排除支持数≤3，不排除任意支持，不改变普通HN上下界。**

## 1. 有限目标与完备归约

Y有10077点、49858条实际单位边，15个部分运动、域的顺序及坐标均由
`audit_full_law_preparation.reconstruct`重新构造；规范输入SHA256是
`90674956a11ac0b6627fb12c6bc108f1c4ddf2ca037c39a9271cf6ba896c0957`。
对每个运动，要求同一概率律在其**整个最大域**上的源、像划分分布相等。
不是只固定旧词，也不是只观察129点核。

假设有支持≤3的律，选取其支持子集上支持最小的可行律。
一原子可重复为三份等权词；两原子若非等权，重原子在每个模式平衡式中不可能被轻原子抵消，
因而它本身是一原子解。两原子等权可表示为(2,1,1)/4，其中两份轻原子是同一完整划分。
最小支持恰为三时，由[T146权重分类](three_atom_weight_types.md)，只有均匀或(2,1,1)/4。
所以只需排除这两种权重的三槽表示，**不必要求三个槽的划分互不相同**。
这也使本定理不必把较弱S的二原子否定作为前提。

完整η域有已检查的固定原点、36点η封闭至少四色配置及阶数5。
[T144加权正规形](weighted_eta_transport.md)允许先在三个完整划分上统一选择代表，
使η的兼容运输边逐字母相等，不增加支持、不改变其他分布义务。

均匀权重时，η匹配在支持重编号下只有恒等、换位、三循环三型。
(2,1,1)时只有重原子自配且轻原子恒等、自配且轻原子互换、重/轻拆流三型。
六个情形完全覆盖。不能删除拆流，不能额外要求η支持置换的五次方为恒等。

## 2. 编码何以既充分又必要

每种η关系先在(三槽状态,Y顶点)上取等价类，类有五个恰一色变量。
每条实际边在每槽投影后排除同色；类内出现真边时成为五个否定单位子句，与恰一色矛盾。
这正是全Y的proper要求，未固定任何旧词。

其余14个运动各自有自由支持匹配与自由颜色置换，**不同运动不共享匹配**。
均匀用三槽；(2,1,1)用四个运输槽(0,0,1,2)，两个0引用**同一份**颜色变量。
这是三个原子的整数运输实现，不是要求原子间存在保持权重的确定置换。
相等的重复模式多重集总能匹配；每个匹配槽的模式相等可延伸为五色调色板置换。

支持矩阵和每个调色板矩阵的每行、每列均恰有一个真值。
对每个源点a、像点b，辅助五位元组z选择被匹配目标槽在b的颜色：

```
S_st ⇒ (z_d ↔ x_t,b,d)
x_s,a,c ∧ P_s,c,d ⇒ z_d
```

恰一色、匹配和置换使这些子句恰好表达逐字母的颜色置换关系。
因此其余14个域均保留全部匹配、全部调色板，并允许重原子质量拆到两个轻原子。
最后只在η运输图的每个**无向连通分量**选一个槽，将实际三角形(4641,231,875)
的颜色命名为0、1、2；该分量的共同重命名正是剩余对称性，故不删解。

以上给出数学上的存在性等价；有限校准不代替这个证明。

## 4. 得到什么，必须停止哪种外推

六份反证与上述归约给出T147：任何可能的完整15域律至少有四个不同完整划分。
[T148](three_atom_mass_gap.md)进一步给出任意三个完整划分总质量≤9/10。
这不是支持数上界，不是全词严格势，不能送入T105宣称得到NON5。
小反证的子句数也不是最小平面NON5见证的点数或证明复杂度下界。

下一主攻不是自动把m改成4、5、6，而是能跨所有支持的严格势，或一次构造真正相容的完整律。
一份通过全部实际边的词若使候选势≤0，就已否定该候选；仅“求解变难”不增加证据。
