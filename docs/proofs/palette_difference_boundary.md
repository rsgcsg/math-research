# 四色差标签为何特殊：仿射调色板与平移不变量

2026-09-29。由Haugland [v4 §4](https://arxiv.org/html/2608.04542v4)的A/B/C标签启发的
初等解释和最小机制校准，不另编T，不主张新的一般定理或HN进展。
它与[C025](anchored_palette_threshold.md)的五阶稳定子机制不同。

## 1. 四色的三种无向边标签不依赖颜色名字

将四个颜色写成F₂²。每条proper边的端点差属于三个非零向量，反向差仍相同。
仿射群AGL(2,2)有4·(4−1)(4−2)=24个元素，在四点上的忠实作用就是整个S₄。
因此任意重命名q都有q(x)=Mx+b；差变成M(x−y)，只是把三种标签整体重命名。
Haugland的A/B/C正是这个一因子分解，平行边同标签这一性质在任意颜色改名下保留。
这项群论事实不证明任何给定几何图的平行边必须同标签。

## 2. 五色不能照搬

把五色写成F₅时，仿射置换只有5·4=20个，而S₅有120个。
若某个重命名使q(x+d)−q(x)仅依赖d，则取x=0并作望远镜求和，q−q(0)必为F₅加法同态；
双射进一步迫使q(x)=ax+b、a≠0。所以只这些仿射置换保持所有平移差关系。

实际五点集依次取(0,0)、(1,0)、(0,3)、(1,3)、(4,4)，颜色依次0、1、2、3、4。
完整平方距离依词典序为1,9,10,32,10,9,25,1,17,10，只有两条平行单位边0→1与2→3。
其有向色差都是1。交换颜色0与2后，差分别为4与3，不再相同；
即便把反向视为同标签，{±1}和{±2}也不同。两份词的完整划分完全相同，且都proper。
因此这项差标签性质不是五色划分的不变量。图本身二色即可，不是五/六色下界。

## 3. 一旦真有平移不变差，闭路压缩为群同态

设Γ是由步集S生成的阿贝尔群，A是阿贝尔颜色群。假设c:Γ→A满足：
对每个d∈S，c(x+d)−c(x)=h(d)与x无关。负步的差自动为−h(d)。
任一y是有限个正/负步之和，沿路径望远镜求和得c(x+y)−c(x)与x无关；
取x=0可知它等于c(y)−c(0)。于是φ(x)=c(x)−c(0)满足φ(x+y)=φ(x)+φ(y)。
反之任意这样的φ给平移不变差；该染色在Cayley边上proper当且仅当所有允许步d都有φ(d)≠0。

无需Γ有限生成，也无需其平面嵌入离散；只需每个点可由有限路径到达。
但前提极强：它把所有颜色信息压成阿贝尔同态。证明几何约束强迫该前提，才是有用的新结构定理；
不能先把一般五色词限制为仿射词，再将该子类失败当作NON5。
Haugland v4明确未证明所列局部四色词延伸到全格，本节不填补那个缺口。

并直接检查上述全部十个平方距离及重命名反例。这个校准不替代第3节的一般证明。
