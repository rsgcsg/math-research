## 1. 先尝试证伪最显眼的负方向

T138保存的无限五色公式在12个运动上各有一个二点失配，另有此前的u二点失配。
这13个具体事件看似容易组合，但原E083的第5个词已经同时令13个差值全部为零。
所以只用这些事件的任意线性势，不能对全部合法五色词严格为正。
这不是LP数值迹象，而是该完整合法词上的直接代入。

继续扩大到u的29点最大域的全部406个点对，再加上述12个其他运动二点事件。
允许Y的所有点自由重染，不固定旧支持、旧词、周期或调色板作用。
实际SAT构造出一份10077字母五色词，使全部418个事件差为零，且全部49858条实际单位边异色。
最终保存的见证SHA256为
`6e9f556d26fda218c22e439f56773f9ec180153634c69d8d46dd07ec34bb2933`。
使用重建后的独立编码器复现时，CaDiCaL195记录2315冲突；统计仅为搜索记录，不承担证明。

对于一份确定词，全部点对相等关系相同，当且仅当整个划分相同。
因此该词满足**u完整29点域的每一个划分事件**，不仅是406个点对矩。
对其余12个选定事件亦成立，故它严格否定以下势函数族的全词正间隙：

`任意u完整域函数的源像差 + 任意实系数乘这12个具体二点事件差`。

因为在这一个合法词上，每一项都等于零。这个反例不依赖系数范围或数值精度。

检查了全部15个完整域：只有u通过，其余14个都失败。
所以它不是15域共同律；也不证明所有二点方法都不足，只关闭上述明确事件族。
负搜索必须引入其他运动的更多真正联合颜色信息，不能只不断调整这418项的系数。
证书保留完整词与事件，独立检查器重建全部几何和最大域后直接验算。

## 2. 一个实际工程问题及修复范围

探索扩大事件基的LP循环时，两次实验进程在第9轮附近遭遇内存限制而中断。
它们没有给出SAT、UNSAT或数学上的不可行结论，未新增为已完成实验。
旧的某条定价实现将整数系数展开为重复文字，再做总数计数；这种实现的规模会随系数数值增长。

新增 `event_pricing_cnf.py` 使用二进制加权和，规模取决于系数位数而不是系数的一元展开长度。
已检查71位整数系数，不将浮点LP输出直接当作精确目标。
该模块支持二点同色事件，也支持任意给定有限域上的完整划分事件。
数值LP仍只能提议势，合法反证需要精确有理势清分母后的整数系数与正间隙。

## 3. 编码与目标完全等价的证明

输入n点、全部实际边、k色，以及整数系数α_e和整数阈值T。
使用x_(v,c)表示点v取颜色c。每点至少一色与两两至多一色，加每边同色排斥，
恰好刻画全部proper色词，没有冻结某个背景。

二点事件的辅助变量E_(a,b)由对每种颜色c的两类子句约束：

`¬x_(a,c) ∨ ¬x_(b,c) ∨ E`；`¬E ∨ ¬x_(a,c) ∨ x_(b,c)`。

在每点恰一色下，前者强迫同色时E真，后者强迫E真时两点同色；故完全等价。
a=b时直接给E真。

完整划分事件只需每个块的根与本块各点相等，再使不同块的根两两不等。
其合取与完整划分相同完全等价；新辅助变量与该合取双向重化。
空域事件恒真。域点顺序、无重复点和规范块标签全部验证。

聚合同一事件变量的系数后，目标为 `Σ_v a_v E_v`。
把a_v<0的项改写成 `a_v+(-a_v)(1-E_v)`，得到精确常数偏移O与非负带权文字和S。
因此原条件等价于 `S≤T-O`。

设全部正权和为W，用 `bit_length(W)` 位存S。逐项加入一个权值w乘一个布尔文字：
每个位用两个XOR产生和位，进位为 `(x∧y)∨((x xor y)∧carry)`。
各AND/OR/XOR都使用双向真值表CNF。任意部分和≤W，故不发生最高位溢出。
二进制比较器逐个禁止“高位等于阈值、当前位第一次大于阈值”的前缀；
这些恰好是所有S>阈值的情况。负阈值直接矛盾，阈值≥W时条件恒真。

由此，每个proper色词有唯一的事件/电路辅助赋值，且该扩展满足CNF当且仅当原整数目标≤T。
独立检查器 `verify_event_pricing.py` 用另一套实现重建完整CNF及其SHA256，
不导入生产器、求解器或浮点优化库。
96个小查询穷举7776份颜色赋值，另有7206次辅助位翻转拒绝；它们是有限校准，
一般等价性来自本节证明。声明的变量/电路资源上限触发时拒绝输入，绝不返回数学不可行。

## 4. 负证据路径：求解器输出不是结论

`run_event_pricing.py`运行有冲突预算的查询。结果分为：

- SAT_WITNESS：直接检查完整合法色词和精确目标；
- UNKNOWN：预算耗尽，无结论；
- UNSAT_UNCERTIFIED：求解器否定，但没有成功认证；
- VERIFIED_NO_WORD_AT_OR_BELOW_TARGET：独立重建语义CNF并验证每一步hinted-RUP后才允许输出。

`rup_hint_export.py`只是不可信的提示生成器，从DRUP式添加序列为每个子句构造单位传播提示。
删除记录可忽略而保留更强的旧公式；但一般RAT添加不享有这种处理，遇到非RUP步骤就拒绝。
最终正LRAT由仓库既有的小型 `verify_rup_lrat.py` 检查；不是调用求解器给自己盖章。
没有宣称支持全部DRAT/RAT格式、已经完成形式化认证，或能在固定预算内认证所有否定实例。

**阈值必须正确。** 对整数目标，证明没有score≤T的词，只得到score≥T+1。
T=-1时仅得score≥0；只有T≥0才有严格正间隙。非负与严格正不能混同。

实际校准：

1. C024的四点实际二色几何与两个完整域由旧独立程序重建。
   以两个完整“端点同色”划分事件、系数(1,1)、T=0得到严格gap≥1，
   保存了求解器生成、另一程序转换、最终独立重放的完整RUP反证。
   C024本身是已有反例，不当作本轮HN新结果。
2. 在当前全部Y图上，对τ把实际单位边(31,193)送到(6269,2135)的事件，
   用系数10^12、T=-1产生并独立重放115步RUP反证。
   两对本来都必须异色，目标恒0；返回的严格正标志明确为false。
   这是大图语义/阈值校准，不是五色障碍。

这补上了一个可运行、可独立复核的定价负证据通道；
它没有使旧E105中任何UNKNOWN变成UNSAT，也没有发现全15域严格分离。
旧主循环没有被静默替换，调用者必须显式选择这个新接口。

## 5. 复现与独立检查

只需标准库的证据重放：`make check-next`。
搜索另需 `python-sat==1.9.dev15`，不进入独立验证链。

```sh
python3 research/audit_full_law_preparation.py --write-cache references/cache/full-law.geometry.json.gz
python3 research/run_event_pricing.py --cache references/cache/full-law.geometry.json.gz \
  --request request.json --output result.json --conflicts 20000
python3 -S research/verify_event_pricing.py --result result.json
```

request.json的例子（得到的是非负校准，不是HN下界）：

```json
{"schema":"event-pricing-request-v1","events":[[0,31,193,6269,2135]],"coefficients":[1000000000000],"target":-1}
```

二点记录格式为[运动序号,源点a,源点b,像点x,像点y]，逐点核对真实映射。
完整划分记录格式为 `{ "motion":0, "source":[31,193], "pattern":[0,1] }`，
像域由实际运动自动生成；pattern是按源点顺序的规范限制增长标签。
请求可以保存新完整模式的势，但单个正向SAT反例不能自动平衡其余模式行。

重建E111保存的见证可运行 `build_event_research.py --cache ... --output ...`。
合法见证的独立检查不要求不同平台、不同求解器版本输出同一色词；
本轮重复构造在固定环境得到相同词，数学结论只依赖所保存的可核验见证。
