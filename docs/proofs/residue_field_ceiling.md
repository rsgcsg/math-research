# T028：Parts 坐标域的整个单位距离图恰五色

令 `K=Q(√3,√5,√11)`，取其通常实嵌入。则 **χ(K²)=5**。
这里包括所有K坐标点、所有实际单位边、任意分母，不限规模、周期、
交叠大小或跨边数；不是指定生成方向的Cayley子图。

这不是新平面上下界，也不宣称文献优先权。约化机制是
[Madore (2015), Proposition 3.2 / Corollary 3.4](https://arxiv.org/html/1509.07023)
的成熟方法；其Lemma 4.5已给F11²五色表，Proposition 4.6应用于
Q(√3,√11)。本轮独立生成另一张表，核验√5扩域及Parts坐标，再结合
已经离线认证的五色核心得到等号。

## 环版本与有限证据

在 `B=Z[1/6,√3,√5,√11]` 上，映射
`√3↦5, √5↦4, √11↦0`，整数模11、6取逆，给出环同态B→F11。
八个多二次基向量的像依次为 `(1,5,0,0,4,9,0,0)`。
全部64个基乘积已独立检查；单位距离等式x²+y²=1被保留，单位边
不可能压成一个点。因此有限目标的五色表可拉回B²。

`residue11_coloring.json`给出121点的颜色；独立检查器重建全部726边
逐边核验。另核验四种√3/√5符号选择的Parts映射，合计9768次边检查，
每种映射的顶点像都覆盖F11²。Parts分母96只含2、3，故包含于B²。
由其已认证χ=5得到χ(B²)=5，也得到χ(F11²)=5；后者下界来自同态，
无需另跑四色UNSAT。存在性不保证任意预染色延伸，不替代T026/T027。

## 允许任意分母的完整证明

不能直接把1/11约化。取 `L=Q_11(π), π²=11`。3、5在Q_11中有根：
从模11简单根5、4出发，若a²−d被11^m整除，则唯一选择
`h≡−((a²−d)/11^m)/(2a) (mod11)`，使a+11^m h提升为模11^(m+1)
的根。兼容序列在Q_11中收敛。于是K嵌入L；此域嵌入只保留多项式
等式，不保持实序，不把11进距离当成欧氏距离。

L的赋值为
`v(A+Bπ)=min(v_11(A),v_11(B)+1/2)`，A,B∈Q_11。
两项赋值分别为整数与半整数，不能相消；也可用
`v_11(A²−11B²)/2`和范数乘法检验乘法性。赋值环为
Z_11+πZ_11，剩余域F11，约化取A mod11。限制到K得赋值环A，
剩余域仍为F11。

若x²+y²=1且min(v(x),v(y))<0，不妨v(x)≤v(y)。除以x²并约化
得到F11中的 `1+(y/x)²=0`，与−1非平方矛盾。故所有单位向量在A²，
每条边两端在同一加法陪集K²/A²中。在各陪集减去固定代表，再约化到
F11²并用五色表即可。K可数，可按固定枚举选各陪集的首个代表。
由Parts⊂K²得下界5，完成等号。

不要求所得染色在实拓扑下连续、可测或周期；也未证明其延伸到R²。

## 推论与安全扩域

坐标始终在K的任意构造均至多五色，包括所有K系数正交变换、K平移、
任意副本数、任意交叠与所有真实跨单位边。包含Parts时恰五色。
它比T026关闭更大的同域组合，但T026本身不限制变换数域，假设不同。
离开B但只增加分母亦无效，因为结论覆盖整个K。

任何含K且嵌入L的实数域E也有χ(E²)=5。对正有理数d=11^e u、
v_11(u)=0，若u mod11在{1,3,4,5,9}内，√d∈L：11已有平方根，
u用简单根提升。故任意多个这样的二次扩域仍保留五色上界，例如√14。
任意有限个兼容扩域均嵌入L；无限并亦可由有限图紧性得到五色性。
若u为非平方余数，则√d不在L，否则单位部分的根约化后给u的平方根。
这仅表示该局部约化不再适用，不表示新域色数大于5。
