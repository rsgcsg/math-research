# T158(b)：P/R 投影中的完整匹配窗口族上限

2026-09-30。固定原 Y 与 T155/T157 已认证的两个实际运输分量。
这是一个有界方法族的完整核验，不是 full15 的共同律，也不改变 HN 的 5–7 界。

## 1. 问题和区域

记 E 为 Y 的全部实际单位边，P 为平方距离 1/3 的指定 1860 对分量，
R 为平方距离 4/3 的指定 1472 对分量。不能把同距离但不在这些分量中的
事件自行并入。令 p、r 分别是这两个分量的共同同色概率。

考察所有满足以下条件的点窗口 W，而不是任意挑选的一份窗口：

1. W 内每条非单位边都属于 P 或 R
2. 实际诱导单位图 G[W] 的独立数不超过 2

条件 2 使每个颜色类最多包含两点，因此 proper 划分恰好对应
补图的匹配；至多五块等价于匹配数至少 |W|−5。
[匹配族的精确描述](matching_partition_family.md)已证明：非负性、
匹配度约束、全部奇集约束，加这个整数匹配数截断，恰好描述各窗口的
至多五块划分成对概率凸包。这里使用的是 Edmonds 的成熟定理，
不把这一一般对应声明为新发现。

定义区域 H 为以下五个有理点的凸包：

- (1/27, 14/27)
- (1/6, 0)
- (1/3, 0)
- (1/3, 1/3)
- (1/5, 3/5)

等价的五个半平面是

    r ≥ 0，3p ≤ 1，12p+3r ≥ 2，2r−p ≤ 1，2p+r ≤ 1。

**固定族结论：** 对每个 (p,r)∈H、对每个上述 W，都存在 W 上的
proper 至多五块概率律，使 W 内每个 P 对的同色概率为 p、每个 R 对为 r。

量词是“对每个窗口各自存在一个律”。没有证明这些局部律彼此相容，
更没有证明可以同时延拓到整个 Y。不同窗口的完整模式耦合不包含在本结论中。

## 2. 为什么这是完整枚举

条件 1 等价于 W 是图 U=(Y,E∪P∪R) 的一个团。
U 有 10077 个顶点、53190 条边。两种不同算法得到完全相同的团集合，
不仅比较数目，还逐个集合比较并保存各阶规范哈希：

- 递增顶点的共同邻点递归
- 带支点的 Bron–Kerbosch 极大团枚举，再生成去重子集

各阶团数为：二阶 53190、三阶 31782、四阶 15340、五阶 10380、
六阶 3380、七阶 380。没有八阶或更大团。
极大团的阶数分布是：二阶 6326、三阶 19922、六阶 720、七阶 380。
因此无需假设一个搜索截断，也无需从几何经验推测窗口大小。

条件 2 被直接检查为：W 的每个三点子集都包含至少一条真实单位边。
全部五阶合格窗口有 2280 个，非单位对构成 K₂,₃，其中四对在 P、两对在 R。
全部六阶合格窗口有 380 个，非单位对构成 K₃,₃，其中六对在 P、三对在 R。
七阶没有合格窗口。较小窗口的完整分类在收据中。

特别地，不存在所有非单位对都属于 P∪R 的实际诱导单位五圈。
因此 C027 中真正越过单独立集矩的五边形奇集反例，不能直接放进当前
这两个分量的投影；加入该类约束不会凭空产生新界。

## 3. 所有约束为何都不能切掉 H

合格窗口中的匹配度左端只出现以下系数类型：

    0，r，p，p+r，2p，2p+r，3p。

它们在 H 上全部至多 1。
三点奇集约束已被这些度约束控制；五点奇集唯一新增形式为

    4p+2r ≤ 2，

恰好是已有的 2p+r≤1。没有七点合格窗口。
六点至多五块的匹配数约束为

    6p+3r ≥ 1。

它由 12p+3r≥2 和 r≥0 推出：将前式左端乘 1/2，再加 3r/2。
更小窗口的匹配数下界 |W|−5 非正，自动满足。
非负性也在 H 上成立。

独立检查器还直接用有理数将全部实际出现的度、奇集和匹配数系数
代入 H 的五个顶点逐项核验。线性性随后覆盖整个 H。
由匹配多面体及整数截断定理，每个窗口的这些可行边概率都能由
proper 至多五块划分的概率混合实现，证明结论。

注意，“匹配奇集约束一般重要”与“它们在当前两个分量投影中不再增强”
并不矛盾。失效原因是实际可用窗口的结构退化为二分匹配，而非奇集
理论本身无效。若引入其它真实运输分量，或使用独立数至少 3 的窗口，
必须重新检验，不能沿用本次上限。

## 4. 认证范围和复核

`research/verify_pr_matching_window_ceiling.py` 只需 Python 标准库。
它以固定语义哈希读取此前已独立重建的完整 Y 几何和 P/R 分量；
本次不冒充重新计算全部几何距离。几何与实际运输闭包的证明分别见
T155/T157 及 `check-y-full-geometry`、`check-g14-pr-bound`。

默认执行比较保存收据，不覆盖它；只有显式 `--write-receipt` 才写收据。
优化模式失败关闭，并拒绝删单位边、删 P 节点和改变 R 节点三个输入篡改。
两种团算法都不使用 SAT/LP 求解器，也不依赖浮点容差。

证据：`certificates/pr_matching_window_ceiling.json`。
该收据只认证上述固定族；H 在其它更大或独立数更高窗口中的可实现性、
全部 P/R 行的共同全 Y 律，以及 full15 完整律，均不是这个检查器的结论。
