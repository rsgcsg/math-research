# T149：连通实际五色单位图仍无统一有限阶的划分律识别

2026-09-29。Boolean奇偶边际机制的几何应用，非文献优先权声明。
这是[既有有限支持压缩](finite_joint_support.md#7-固定有限支持的高阶差异可以压缩不要求等权)
的范围补充，不是CSP不可判定性、染色困难或HN下界。

## 命题

对每个整数r≥1，存在有限**连通、诱导单位距离、色数恰5**的平面图X，及其全部proper
五色完整划分上的两个不同概率律μ、ν，使它们在每个至多r点的标号子集上诱导完全相同的划分律。
可取|X|=509+4(r+1)，两律各有2^r个不同完整划分、等权且正负支持不交。

因此，不存在一个对所有这种X、所有支持数都有效的固定物理点数r，单靠r点边际识别完整划分律。
这里没有要求这些律满足任何额外运动不变性。

## 证明：用树保留独立开关，不牺牲连通或五色核

取已认证的连通Parts509诱导单位图G及其proper五色词h。选横坐标最大的顶点p，
将h的颜色重命名使h(p)=2。令n=r+1，加入

```
v_t = p+(t,0),     t=1,…,3n；v_0=p，
w_j = p+(3j,1),    j=1,…,n。
```

新点两两不同且不在G：其横坐标严格大于p。下面穷尽全部新增实际单位对。
任一q∈G到v_t的横向差≥t。t≥2时不能相邻；t=1若距离为1，必须同时q_x=p_x、q_y=p_y，即q=p。
q到w_j的横向差≥3j≥3，也不相邻。v_t之间只有相邻整数索引单位相邻；
w_j到v_t的平方距离为(3j−t)²+1，等于1恰在t=3j；不同叶点相距至少3。
所以全部新边恰为一条接在p上的链，以及每个w_j到v_(3j)的一条边。

给链v_t颜色2+(t mod 3)，保留核心h；每个叶点w_j可独立选择颜色b_j∈{0,1}。
其父点颜色2，故每个b∈{0,1}^n都给整个诱导图的一份proper五色词。
包含G给χ(X)≥5，上述词给χ(X)≤5；新树接在G上，X连通。

μ对Σb_j为偶数的2^(n−1)个词均匀取样，ν对奇数的词均匀取样。
G必用满五色，特别有固定颜色0的核心顶点q₀。由w_j是否与q₀同块即可恢复b_j，
所以这2^n份**完整划分**都不同；两律确实不同、支持不交，不是仅颜色名字不同。

对任意|U|≤r的点集U，最多看见r<n个叶点，其余点的颜色恒定。
若看到ℓ个叶点，每种指定bit模式在偶、奇两类中都恰有2^(n−ℓ−1)个扩展，
故两者的带标签限制分布已相等；忘掉颜色名后的划分分布当然也相等。证毕。

Parts509的全部实际边、χ5正负证据见既有[核心检查器](../../research/verify_parts_core.py)。
新检查器另直接重放核心全点对/五色词，并对其实际边做连通遍历；
一般新增边的完备性由上述横坐标不等式证明，不依赖浮点选择最大顶点。

## 独立有限校准及严格非结论

`python3 -S research/test_connected_partition_marginals.py`还用五点整数路径作为几何校准核心，
对n=2,…,8穷尽所有新点对、所有2^n份色词、奇偶划分支持，以及每个真子集叶点的边际。
整数路径仅用于小计算，色数不是5；命题的χ5来自Parts509及完整书面构造。
不把整数校准图、数值误差或抽样算作五色核证据。

这一结果关闭“仅凭连通＋实际单位几何＋χ5就能给任意支持律一个固定阶识别”的希望。
它**不**否定以下更强结构假设下的可能性：固定Y、受运动平衡约束的特殊律、消去树枝后的约化系统、
临界图、或依赖支持数/图规模的阶数。附加树上的自由开关正是本例机制，不能隐去。
特别没有构造局部可行而全局不可五染的图；X本来就有大量五染。
这不是一个HN有限障碍，也不证明任意固定阶事件势都不可能找到原15域的反证。
