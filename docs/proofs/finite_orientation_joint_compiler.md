# T096：有限方向群的joint反证可显式编译成实际有限NON5图

后续 [T105](arbitrary_motion_joint_compiler.md)已去除有限方向群假设；
本页有限群情形与8指标优化仍成立，且通常给出更小的构造界。

2026-09-11。有限平均与边界计数的直接证明，不声明首创；本定理
不提供当前尚不存在的全词分离式，也不改变HN界。
它把T082在当前有限方向群内的存在性桥梁改成一个定量构造。

## 1. 输入与结论

令X为任意非空有限平面点集，Ω_k(X)为其**全部实际单位边**的合法
k色词。取有限正交群H≤O(2)，有限向量族s₁,…,s_q，并令m=q|H|。
坐标指标是(h,j)∈H×{1,…,q}，定义整数线性映射

\[
 T(n)=\sum_{h,j}n_{h,j}h(s_j),\qquad n\in\mathbb Z^m.
\]

无需假设这些向量独立，T可以非单射。给定若干实际部分全等
g_e:x↦r_ex+a_e，r_e∈H；源有序点组A_e及像g_eA_e均在X。
假定已给出整数向量v_e满足a_e=T(v_e)，记ℓ_e=∑|v_e(h,j)|。
指定该点组的颜色划分τ_e，并定义

\[
 d_e(c)=1[\operatorname{pat}(c|_{A_e})=\tau_e]
       -1[\operatorname{pat}(c|_{g_eA_e})=\tau_e].
\]

**T096。** 若有实数y_e及δ>0，使得

\[
 \sum_e y_ed_e(c)\ge\delta\quad\text{对所有 }c\in\Omega_k(X),\tag{1}
\]

取任意非负整数N满足

\[
 2N+1>\frac{\sum_e|y_e|\ell_e}{\delta},\tag{2}
\]

则下面这个**实际点集**的诱导单位图不可k染：

\[
 Y_N=\bigcup_{n\in\{-N,\ldots,N\}^{m},\ u\in H}(T(n)+uX).
 \tag{3}
\]

其点数至多|X||H|(2N+1)^m。若Ω_k(X)为空，本来就有反证；
下面证明也覆盖这种情况。若输入全为实代数数且y、δ有理，(3)
是有限精确可构造对象；大小界不等于可承受的运行代价。

## 2. 不借助无限染色或紧致性的证明

反设Y_N有合法染色C。记B={−N,…,N}^m，L=2N+1。
对每个(n,u)∈B×H，定义X上的词c_(n,u)(x)=C(T(n)+ux)。
因为该映射是刚体运动，它把全部单位边保为单位边，故c_(n,u)∈Ω_k(X)。
即使不同索引给出重合点或同一刚体副本也没有问题：保留索引重数平均。

对事件e，有

\[
 (T(n)+u\,\cdot)\circ g_e(x)=T(n)+ua_e+ur_ex.
\]

左乘u把指标(h,j)置换成(uh,j)，因此有整数向量w_(u,e)，
T(w_(u,e))=ua_e，且‖w_(u,e)‖₁=ℓ_e。
所以当n+w_(u,e)∈B时，像组的事件指示值等于
索引(n+w_(u,e),ur_e)上的源组事件指示值。

上述索引配对是单射；u↦ur_e是H的置换。对每个u，未配对n的比例
至多ℓ_e/L：单坐标平移整数w损失至多|w|/L，再用并集界。
当这个上界>1时仍有效。源端和像端各剩相同数量的索引，每个事件值
在[0,1]，故**平均差的绝对值至多ℓ_e/L，而不是需要两倍此值**。
因此

\[
 \left|\mathbb E_{n,u}d_e(c_{(n,u)})\right|\le\ell_e/L.
\]

这里未对C在Y_N外取值：所有原事件及像事件都在(3)中；配对只在
两索引均在B时使用，剩下项只用[0,1]界。现在平均(1)即得

\[
 \delta\le\sum_e y_e\mathbb E d_e
 \le\sum_e|y_e|\ell_e/L<\delta,
\]

矛盾。额外单位边、不同副本重合只会增加C必须满足的约束，不会损坏
论证。证毕。没有要求C可测、周期、平移等变或满足固定色框。

同一证明也允许T使用任意m个向量作指标，只需对每个u∈H、事件e
显式给出T(w_(u,e))=ua_e且‖w_(u,e)‖₁≤ℓ_e。指标不必被H
置换；配对只使用这个平移表示及u↦ur_e的置换。下面用此版本压缩。

### 完整划分块的更紧界与规范不变量

若同一源组和同一运动的全部划分行合为一块b，设系数为y_(b,τ)，
则该块的源端取值总在[min_τ y_(b,τ),max_τ y_(b,τ)]内。
上述配对证明直接给出误差界

\[
 \frac{B(y)}{2N+1},\qquad
 B(y)=\sum_b\ell_b\bigl(\max_\tau y_{b,\tau}-\min_\tau y_{b,\tau}\bigr).
\]

因此(2)中的分子还可换成B(y)。每块所有系数同时加一个常数不改变
分离式，因为完整划分指示值之和在两端都为1；B(y)也保持不变。
这说明原始系数绝对值和依赖坐标规范，**块内振幅／严格余量**才是
这个编译界真正使用的比值。只选部分划分时可给遗漏划分补系数0。
全词严格余量δ必须另行认证，改善B/δ不能把库内反证升级。

## 3. 对当前η配置的具体编译界

令η=e^(2πi/5)，z为原Parts的p64。当前所有E061–063运动的正交
部分都属于20元群

\[
 H=\{x\mapsto\epsilon\eta^j x,\quad
       x\mapsto\epsilon\eta^j\bar x:
       \epsilon\in\{1,-1\},\ j=0,\ldots,4\}.
\]

这些映射确实闭合；十个旋转互异，十个反射与旋转分离。
取s₁=1、s₂=z，故m=40。不必求一个最小整数基。
旋转η与共轭的平移量为0，ℓ=0；平移1、z的ℓ=1；
桥x↦1+ηz−ηx及平移1+ηz的ℓ≤2；四个平移1+η^j的ℓ≤2。
因此，对这些运动的任意大小源组、任意完整划分事件，若全词分离式
有余量δ，记W=∑|y_e|，取N=⌈W/δ⌉便满足(2)，并得到

\[
 |Y_N|\le5084\cdot20\,(2\lceil W/\delta\rceil+1)^{40}.
\]

这个上界很粗，但不需要新的Gram存在性猜想：坐标由实际平移与
有限正交群直接生成。允许整个最大域事件，不限两点或四点。
若未来引入不在H的正交部分，不能直接沿用这个40维盒公式。

### 继续压缩：当前平移模实际上只需8个整数指标

原始Parts文件的p64为

\[
 z=-\tfrac12-\tfrac{\sqrt3}{6}i,\qquad \bar z=-1-z.
\]

因此可取8个平移向量η^j、η^jz（j=0,…,3），即
M=Z[η]+zZ[η]。η⁴=−1−η−η²−η³与上述共轭式保证M在H下保持。
不必证明这8个向量Z线性独立，整数重数同样允许。

记f(s)为η^s在前四幂中的系数1范数，s模5；其值为1,1,1,1,4。
逐项表示当前平移即可给出一致界：

| 平移量a | max_(u∈H)‖w_(u,a)‖₁ |
| --- | --- |
| 0 | 0 |
| 1 | 4 |
| z | 8 |
| 1+η^j，j=1,…,4 | 3 |
| 1+ηz（含桥的平移量） | 9 |

证明这些上界无需数值近似：旋转只使幂指标平移，负号不改变范数。
对z作反射得−η^s−η^sz，范数2f(s)≤8。
两不同幂之和，若都在前四幂中则范数2；若一项为η⁴，其余一项
恰消去一个负系数，范数3。
1+ηz在旋转下为η^s+η^(s+1)z，范数≤5；在反射下为
η^s−η^(s−1)−η^(s−1)z。常数部分两不同幂之差范数≤5，
z部分≤4，故总和≤9（s=0达到9）。各表项的最大值可直接达到。

于是令W=∑|y_e|，可改取N=⌈9W/(2δ)⌉，得到更小的显式界

\[
 |Y_N|\le5084\cdot20\,
       (2\lceil9W/(2\delta)\rceil+1)^8.
\]

按完整划分块振幅计算B(y)时，可再用表中各自的ℓ而非统一9。
这是**平移模**的8指标，不是X整个坐标域只有8维，也不将X归入
已知低色安全宿主。η与z的特殊性在这里反映两个精确整关系，而不是
“五次旋转比较有效”的经验判断。

## 4. 当前负证据为什么仍不够

C019的分离式仅在155个库内词上严格为正，违反T096的**所有Ω₅(X)**
输入量词；已有新词使整个向量为0，所以无法代入定理。T095的
两端口正词也不提供任何(1)。SAT UNKNOWN同样不能代入。

这次确实减少了一个构造层面的不确定性：一旦得到当前运动群内真正
全词有效的整数分离证书，joint负结论能立即编译为有限真实NON5配置，
不必另猜一个二维闭环。尚未完成且最重要的一层是**找到并独立认证
这样的分离式**；本文没有掩盖或解决它。≤6仍是独立开放端点。

下一次全词分离搜索可固定δ=1并最小化B(y)，将每块平移冗余消去；
或固定B(y)≤1最大化全词最小值。两种写法只用于候选生成，必须用
独立整数负证据认证“所有词”。当前已修复事件族仍无正余量，不能
以改变归一化为由重开它；新完整最大域事件才可能改变可行性。
