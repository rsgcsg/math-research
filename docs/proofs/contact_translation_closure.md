## 1. 一个统一的分离工具：T069

对`x∈K²`定义真正的正定范数

`||x||_Tr² = (1/8) Σ_{σ:K→R} |σ(x)|²`。

八个实嵌入独立改变√3、√5、√11的符号。若使用平方自由基
`(1,3,11,33,5,15,55,165)`，这个平方范数就是各坐标系数平方
分别乘该基根式的平方，再求和。它满足三角不等式。
实际单位向量在所有嵌入下仍满足平方和1，因此其迹范数也等于1。

设q为奇素数，−1在Fq中非平方，3有非零平方根r；
设a,b为不被q整除的非零整数，定义

`L = (a/q)Λ + (b/q)JΛ`。

每个`l∈L`唯一写成

`l = (a/q)(u e₁+v e₂) + (b/q)J(s e₁+t e₂)`，

其中u,v,s,t为整数。唯一性直接来自x、y两坐标的有理部分与√3部分。
令P为任意集合，坐标属于`Z_(q)[√3,√5,√11]`，其中Z_(q)只允许
分母不被q整除的有理数。设P的迹直径至多D，且

`min(|a|,|b|) > D+1`。 (1)

则有：

1. `P+L`中的`p+l`表达唯一；
2. `P+L`的单位边恰为同一个l处原P的单位边；没有任何不同l之间
   的单位边，甚至不能靠改变核心编号绕过它。

这不是一般“分母不同就不接触”的说法。各向异性、两个√3剩余
取向、系数积分和迹间隙缺一不可。

### 分母分离引理

若d的坐标属于上述环，且`|d+l|²=1`，则必有

`l∈aΛ+bJΛ`。 (2)

证明：将单位等式乘q²。对√3分别取r和−r，并把√5、√11送到
Fq代数闭包中的任意相应平方根，得到两个环同态。qd约化为0，
而ql的两坐标都落在Fq中，因此约化后为两个Fq坐标的平方和0。
−1非平方强迫这两个坐标分别为0。

将坐标乘2，对√3的两种符号分别得到

`a(2u+v) ∓ brt = 0 mod q`，
`± arv + b(2s+t) = 0 mod q`。

相减，再利用q不整除2abr，得到t=v=0 mod q，随后u=s=0 mod q。
四个中心整数都被q整除，故(2)成立。证毕。

若仅知道`d∈L`且d系数在Z_(q)中，也有同一结论(2)：直接比较
有理与√3系数即可，无需使用单位等式或各向异性。

### 迹间隙

对`l=aV+bJW`，V,W∈Λ，混合项`V·JW`为√3的有理倍数，
取全部实嵌入的平均后消失。因此

`||l||_Tr² = a²|V|²+b²|W|²`。 (3)

非零三角格向量的平方长是正整数，所以非零l至少有
`||l||_Tr ≥ min(|a|,|b|)`。
若`p+l=p'+l'`，则l−l'=p'−p系数积分；由(2)的直接版本和
`||p'−p||_Tr≤D`得l=l'，继而p=p'。
若两点距离1，则对d=p'−p应用分母引理，再用

`||l'−l||_Tr ≤ ||d+l'−l||_Tr+||d||_Tr ≤ 1+D`，

结合(1)只能有l'=l。剩下恰是P本身的单位边。这证明T069。
证明逐点对成立，不要求P有限；无限集合只需同一个迹直径上界D。

正定迹、赋值约化分别已有成熟理论来源；这里的新本地推导是把
两种约束合起来，对这个无限接触平移闭包给出精确分离结论。
没有宣称这些工具的文献优先权。

## 2. T070：旧参数的全部接触平移闭包恰五色

取

`α=2√30/23, β=120/529, L=(13/23)Λ+(7/23)JΛ`，

并令

`X = P + L + αΛ`。

这里允许L的四个整数指标和αΛ的两个整数指标全部无界。
X包含沿两壳接触位移反复添加Parts平移副本所得的所有点；即使
把尚未由某个有限起点连到的副本也全部加入，结论仍成立。

**X的完整诱导单位图恰为P的诱导图与下述放置图B的笛卡尔积，
因此χ(X)=5。** 这关闭的是X，不是T067的整个`K²+αΛ`。

### 核心的精确大小与同层分离

P坐标分母96不被23整除。全部509点直接整数计算得到迹半径
至多2，且迹直径恰4。模23有√3=±7，而−1非平方。
取a=13,b=7，满足`7>4+1`。所以T069适用。
每一固定α中心内，全部无限L副本只有各自原核心的单位边。

### 跨层边与全部编号

α不属于K，故每个点的α中心唯一。T067已经完整分类：非零
中心差只有N=3或4，并且跨K位移为

`±(13/(23√3)) Jδ`（N=3），
`±(7/46) Jδ`（N=4）。 (4)

N=3时第一类位移恰为`(13/23)`乘Λ的六个单位向量。
具体若δ=me₁+ne₂，则其对应整数指标为

`u=−(m+2n)/3, v=(2m+n)/3`，且u²+uv+v²=1。

N=4时第二类位移恰为`(7/23)J`乘Λ的六个单位向量，指标为
`s=m/2,t=n/2`。两类位移都在L中。

若一条跨层边两端是`p+l+αz`与`p'+l'+αz'`，则(4)迫使
`p'−p∈L`。核心的积分性及迹直径4，由T069证明中的唯一性步骤
推出p=p'。故所有跨层边都只连接相同核心编号。

定义B的顶点为L×Λ，边为(4)规定的全部放置接触。X中每条边
恰好改变“核心”或“放置”两个因子中的一个；反过来每条因子边
都确实给出X的单位边。表达唯一还排除了未合并的重合点。
因此这是图同构`G(X) ≅ G(P) □ B`，不是只有一个方向的同态。

### 无须求解器的整个B三染色与X五染色

写`l=(13/23)(u e₁+v e₂)+(7/23)J(s e₁+t e₂)`，置

`d(l,z) = (u−v+s−t) mod3`，取代表0,1,2。

任一B边恰改变前一或后一对指标一个三角格单位向量，而单位
向量的指标差在模3下非零，所以d是合法三染色。无需依赖中心z。

对任意一份合法核心五染色c_P，整个X的显式五染色是

`c(p+l+αz) = (c_P(p)+d(l,z)) mod5`。 (5)

核心边只改变c_P，放置边只改变d，且两种变化均不为0 mod5。
X含P，故五色下界与(5)吻合。证毕。

这个笛卡尔积着色是初等构造，不将其包装成新的一般图积定理。
23⁴个剩余标签、两份环同态的128个基乘积、24个跨壳输运及
核心全部129286点对的迹直径已独立核验；无限范围依靠以上证明。

### 同一机制实际覆盖的更大范围

将P换成任意`P₀⊂Z_(23)[√3,√5,√11]²`，只要其迹直径严格
小于6，整个`P₀+L+αΛ`仍至多五色；包含一份Parts时恰五色。
证明完全相同：取D<6使7>D+1，P₀本身的五染色来自T028。
例如以0为中心的迹闭球半径2内的**全部**此类K点都可作P₀。

因此在这个迹范围内更换、旋转或增加有限核心也不能绕开分离，
前提仍须保留坐标的23积分性。实平面上看起来很大的边数和复杂度
不能替代越过这两个明确假设。这个推论不覆盖无界迹的整个K²。

## 3. 改变算术共振，而不是扩大旧X

要突破T070，可以改变α、核心姿态或实际K平移集合；只在同一个
L中继续加副本不行。一个更小的具体双壳参数是

`α'=2√10/13, β'=40/169, t₃=7/13, t₄=3/13`。

仍有`1/7<β'<1/4`、barβ'=10，且两根确在K中，所以T067仍给
整个`K²+α'Λ`的六色上界。其完整色数目前仍只确定为5或6。
N=1会要求√129/13，而129=3·43的平方类不在K中，故没有该壳。

对应接触平移格为`L'=(7/13)Λ+(3/13)JΛ`。T069不适用：
模13的−1为平方，且小系数3也不能超过核心迹直径加1。
仅“不适用”不是新障碍的证据，下面给出真正的单位接触：

`−e₁ + (7/13)(3e₁+e₂) = (23/26,7√3/26)`，

其平方长为`(529+147)/676=1`。
P含0和−e₁，故这是一条在同一α'中心、不同L'平移、不同核心
编号之间的实际单位边。旧X中T069所禁止的结构现在确实出现了。
它只证明旧分离机制被打破，不证明这些边排除了全部五染色。

## 4. E035：完整联合有限探针与T071的无限提升

取七个中心`m²+mn+n²≤1`。每中心放16份完整Parts：平移指标
为0、前一Λ或后一JΛ的十二个单位步，以及前一Λ指标
`(2,0),(3,0),(3,1)`。最后三个点将上述真实共振纳入探针。

首先不固定任何核心旧颜色、接口名单或调色板激活状态，所有核心
颜色共同求解，只用一个点的色名规范。单位边完整重建：同层独立检查
全部33158296个基本点对后平移到七中心；跨层由完整平方类分类
列出每个可能位移，并额外逐边直接核验16维整数单位距离等式。

有限探针有57008点、318990边；每中心8144点、39462条同层边，
其中390条连接不同核心平移。两壳跨边分别30540和12216条。
这些数字不代表高色下界。57008点全模型在20000冲突预算内
UNKNOWN，丢掉中心标签的8144点/53205边模型在100000冲突预算内
也UNKNOWN。随后采用更受限的**正构造**：只让每份核心独立置换
既有五色词。80点/355边的颜色类目标立即给出五色正见证。
该见证已经独立逐条核验整个实际图，故有限图本身恰五色。
这不是把UNKNOWN当成SAT，更不是用受限模型的失败声称源图失败。

## 5. 当前路线判断

全平面的上下界仍是5与7。T028、T063–T067是受限无限宿主的
真正上界，T069/T070是排除一个自然但无效扩张的结构结果。
它们不是“距离六色下界只剩一步”。

统一机制已经相当清楚：

`全部精确接触 → 算术/迹筛选 → 保留完整联合颜色关系`。

向上界走时，要证明低色同态覆盖全宿主；向下界走时，要证明
真实源图所有颜色关系都无法共同满足。压缩目标的UNSAT只关掉
编码；可修复的指定背景只关掉固定边界。T070说明甚至“逃域＋
无限多核心＋全部接触”仍可能是可分离图积，必须检查这一点。

本轮后只保留两条主线：

1. **下界主攻：** 超出T069分离类的真实混合接触，当前明确例为
   α'。寻找能反馈到多个核心编号的闭合关系；不靠堆积跨边条数。
   更具体地，先扩充L'平移的**不同共振方向**，共同求解全部颜色；
   每副本置换模型仅作快速正证据筛选，它失败后仍须全颜色关系
   的负证书。旧参数若再用，必须明确破坏23积分性或迹直径<6，
   不能在T070推论内只更换核心形状。
2. **上界辅线：** 判断这类双壳宿主能否有不经过T068固定目标的
   五染色，或是否存在可扩至任意实代数宿主的六色机制。后者目前
   没有足够的统一定理，不能把单个薄宿主的上界外推到全平面。

六色pair-core、固定背景小修复、旧X继续扩张暂不增加预算。
这是有证据的路线筛选，不是对最终5/6/7答案的概率承诺。
