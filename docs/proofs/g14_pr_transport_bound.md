# T157：原15运动中的 P/R 运输迫使 1/27 ≤ p ≤ 1/3

2026-09-30。支持数无关的必要条件与一个构造面的严格排除。**不是 full15 不可行证明，不改变普通平面 5≤χ≤7。**

## 1. 固定对象与量词

Y仍是原来的10077点、49858条实际单位边。P是T155中平方距离1/3的1860个无序点对运输分量。R是从原u失配点对 (233,239) 出发，沿原15个实际部分等距及逆映射闭合得到的平方距离4/3分量：1472个点对，1471条生成树行。

考虑支持于全部 proper 至多五块Y划分的任意概率律。若这个律使P与R两分量的所有运输行平衡，则各分量的同色概率为常数，分别记 p、r。它们是每个事件的共同概率，不只是全分量计数的平均。

**结论：** 这样的律必须满足 p≥1/27；另有 p≤1/3。原15完整域共同律必满足这些成对行，因此也满足该必要区间。没有证明区间充分或尖锐。

## 2. 七点计数与三点传递性

取七点

    [4641,877,887,3483,5535,7479,7489]。

21个点对中恰有6条实际单位边、12个P事件、3个R事件。这里“完整七点对表”不是单位距离 K7；仅6条边是单位距离。至多五块划分在七点上至少有两个同块点对；单位边不能同块，所以

    12p+3r ≥ 2。

接着取三点 229、4641、305。两对 (229,4641)、(305,4641) 在R中，(229,305) 在P中。对任何划分，同色的传递性给

    e(229,4641)+e(305,4641)−e(229,305) ≤ 1，

其中e是同色指标。期望得到 2r−p≤1。

将第一个不等式乘2、第二个乘3并消去r，得

    24p+6r ≥ 4， 6r−3p ≤ 3， 因此 27p ≥ 1。

独立标准库检查器不仅按32维代数基重算点对平方距离，也枚举七点上全部159个局部 proper 至多五块划分，核对同色P/R事件最小值2；三点的全部5个划分核对传递式最大值1。

上界也来自同一组点：877、5535、7479是实际单位三角形，4641与其三条连线都在P中。中心色至多匹配三角形一个顶点，所以3p≤1。

## 3. 真正的行空间严格势：p=0 面上不可能有任何支持的R律

七点构造中的三个R事件为

    (877,7489), (887,7479), (3483,5535)。

定义

    F = 2[e(877,7489)+e(887,7479)+e(3483,5535)]
        −3[e(229,4641)+e(305,4641)]。

在P事件全异色的 proper 词上，第一个中括号至少为2，第二个至多为1，因此 **F≥1**。F的R事件系数总和为6−6=0；R运输图连通，故F属于R行张成空间。证书进一步给出30条实际森林运输行的整数线性组合，独立检查器逐项验证其系数恰好重构F。

任何平衡R行的概率律都满足 E[F]=0。若同时平衡P行且p=0，非负的P同色指标都几乎处处为0，于是 E[F]≥1，矛盾。这个反证允许任意支持数与任意实权重，不能靠增加候选词数修复。

因此 [T156](g14_pair_port4_common_law.md) 中的39原子律，以及整个 p=0 的构造面，都不能延拓为同时满足这些R运输行的律。这不是只反驳那39个词；也不是 full15 的全词反证，因为 full15 并没有强迫p=0。该证明甚至不需要T155的平方距离4事件Q或条件q=1。

## 4. 方法的位置与后续边界

这是“真实几何有限配置＋划分计数＋等价关系传递性＋实际运输行”组合出的局部证书。它取代了在p=0面上继续加词的搜索，但仅给一个非零同色概率下界。

它仍属于三角／子集鸽巢型成对不等式，**没有突破 [单独立集矩外放松的普遍可行性](full15_joint_event_theory.md#3-单个独立集的矩与完整划分律之间的缺口)**。该可行性障碍禁止把继续搜索同类不等式当成自动得到HN反证的方法。原full15问题还需更强的真实共同模式信息或一个完整正律。

一般概率方法及双禁距结论不是本次新发现。Péter Ágoston 在 [Polymath16第14线程，2019-10-25 16:37评论](https://dustingmixon.wordpress.com/2019/08/05/polymath16-fourteenth-thread-automated-graph-minimization/) 已讨论以 amenability、同色距离概率和有限点计数证明双距离非五染。De Neve等后续[原作者论文](https://backoffice.biblio.ugent.be/download/01K94Y89D25FFMV0FYQ44CTS2P/01K94YA8NYKGWB7A5CE3HMDXKV)给出了相关显式双距离图。本条的项目成果是把上述有理界精确落实到当前Y、原15运动和一个可重放的30行证书；不主张全平面概率界最优或文献优先权。
