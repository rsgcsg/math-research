# T101–T102 / E068：从小障碍转移到拓扑下界的几何天花板

2026-09-11。原始 HN 未解决。T101 是本地有限认证与证明；T102 是
使用已读原文的外部 Zig-zag 定理所得的本地推论，不主张发表优先权。

## 1. 换线并实际执行：Kneser 候选

KG(n,k) 的顶点是 [n] 的 k 元子集，边是不相交性。其普通色数为
n−2k+2（n≥2k）；本轮阅读了 Matoušek 的原始组合证明 §§1–3，
不是仅凭搜索摘要采用此数值。
[原文](https://kam.mff.cuni.cz/~ksemweb//clanky/Matousek-Kneser_comb_proof.pdf)。

因此 KG(12,4)、KG(14,5) 都是抽象六色候选。但色数公式不提供任何
二维单位实现。我们先寻找 G=M(C₅) 到它们的同态；若存在，则 T099
直接排除它们的单位同态，允许非邻接点碰撞。

**T101(a)。所有 k≥2、n≥3k 的 KG(n,k) 均无平面单位同态。**

下面每行是 G 的一个顶点；aᵢ 是原五圈，bᵢ 是 twins，w 是 apex。
两列分别给出到 KG(6,2)、KG(9,3) 的同态（底集从 0 编号）。

| 顶点 | 2 元集合 | 3 元集合 |
| --- | --- | --- |
| a₀ | 1,4 | 2,6,7 |
| a₁ | 0,5 | 0,1,3 |
| a₂ | 1,3 | 2,4,8 |
| a₃ | 4,5 | 3,6,7 |
| a₄ | 0,3 | 0,1,8 |
| b₀ | 2,4 | 4,5,6 |
| b₁ | 2,5 | 1,3,5 |
| b₂ | 2,3 | 4,5,8 |
| b₃ | 2,4 | 3,5,6 |
| b₄ | 2,3 | 1,4,5 |
| w | 0,1 | 0,2,7 |

逐一核验 G 的 20 条边，两端集合均不交。不要求该映射单射。
任意整数 k≥2 可写为 2a+3b，a,b≥0。在互不相交的底集上拼接
a 份第一列、b 份第二列，便有 G→KG(3k,k)。扩大底集给出
G→KG(n,k)。若后者有单位同态，复合会违反 T099。□

这还给出整个上述族共同的正近单位间隙：近单位同态复合回同一个
G，再用 T097。不提供间隙的数值。

**T101(b)。若 G→KG(n,k)，则 n/k≥29/10。**

给每个 aᵢ 权重 3，每个 bᵢ 权重 2，w 权重 4，总权重 29。
每个独立集权重至多 10：含 w 时不含 twins，至多两个 aᵢ；
不含 w 时，所选 aᵢ 个数为 0、1、2，相应最多能选 5、3、2 个 twins，
所得权重至多 10、9、10。这里两个不相邻五圈顶点的邻域并有三个点。
若有上述同态，每个底集元素对应一个独立集，每顶点恰出现 k 次，
故 29k≤10n。□

独立检查器又穷尽 103 个独立集直接核验该整数不等式。无需接受
浮点 LP 最优性，也不声称已求得任何未知单位图的 fractional 值。

于是 KG(14,5) 不可能承载这个旧障碍。我们实际生成并核对了它的
2002 顶点、126126 边；它无三角形，因为三个不交五元集需要 15 元。
短暂的 14:5 和 29:10 多重染色 SAT 探测为 UNKNOWN，没有作负结论；
14:5 的不可能性来自上面的严格权重证明。

然而，“旧障碍不能映入”并不意味着该候选可以实现。下一节马上
用更成熟的定理将它连同整族关闭。

## 2. 已读外部输入：任意颜色数的 Zig-zag 定理

Simonyi–Tardos，*Local chromatic number, Ky Fan's theorem, and circular
colorings*，arXiv:math/0407075v3（2004-11-26）。本轮阅读 Definition 3、
Proposition 8 及其证明、§3.3 Zig-zag 定理及证明。
[原文](https://arxiv.org/html/math/0407075v3#S3.SS3)。

按该文定义，topologically t-chromatic 指 coind B₀(G)≥t−1。
定理说：任意有限此类图、任意数量有序颜色的 proper 染色，都含
两侧交替、全部 t 色互异的 K⌈t/2⌉,⌊t/2⌋。关键是**任意颜色数**，
不是只适用于最优染色。Proposition 8 给出 Kneser 与 Schrijver 的
相应拓扑参数。这些是外部定理，不登记为本地 SAT 认证。

## 3. T102：Zig-zag 四色已与平面单位同态冲突

**T102。若有限图 G 满足上述 topologically 4-chromatic 条件，
则 G 没有到平面单位距离图的同态。特别地，对任意有限平面单位图 U，
coind B₀(U)≤2；对任意有平面单位同态的有限图亦然。**

证明：假设 p:V(G)→R² 是单位同态。选择线性函数 ℓ，使它在有限
物理点集 p(V(G)) 上单射；只须避开有限个差向量的垂直方向。
按 ℓ(p(v)) 的大小给不同物理点赋不同有序颜色，重合物理点赋同色。
这是 G 的 proper 染色，因为边长为 1，边端不会重合。

Zig-zag 定理给出四个异色顶点，记它们的物理点为 a,b,c,d，满足

ℓ(a)<ℓ(b)<ℓ(c)<ℓ(d)，

且 {a,c} 与 {b,d} 之间四条交叉距离均为 1。异色确保四个物理点
两两不同。两个不同圆心 a,c 的单位圆至多相交两点；b,d 是它们的
两个不同交点，关于中点 (a+c)/2 中心对称。因此 a+c=b+d。
应用 ℓ 却得到 ℓ(a)+ℓ(c)<ℓ(b)+ℓ(d)，矛盾。□

这不需要单射实现假设；同态中的碰撞由物理点颜色显式处理。
只含抽象 K₂,₂ 当然不构成单位障碍：它可以实现成菱形。起作用的是
**对任意有序 proper 染色都强迫交替 K₂,₂** 的量词。

这个 coindex 天花板本身是尖锐的：单位等边三角形 K₃ 的 B₀ 是
三维 cross-polytope 的边界，即带对径作用的 S²，故 coind B₀(K₃)=2。
所以该下界工具最多给三色，而普通单位图已知能需要五色。
这正是必须区分“拓扑下界的参数”与“普通色数”的具体例子。

### 直接后果与严格非结论

- KG(n,k)、SG(n,k) 在 n−2k+2≥4 时都无平面单位同态；所以
  KG(14,5) 及其 196 点 stable 子图不是剩余突破口。
- T099 的小证书仍有独立价值，但 M(C₅) 的失败已能放在同一个
  成熟的拓扑／顺序／中点框架下解释，不必总重新展开 3208 节点树。
- 凡明确满足上述拓扑四色假设的其他升色或 Borsuk 类候选，同样停止。
  不能把“色数由某种拓扑方法证明”泛化为所有拓扑不变量或所有方法。
- 已知五色单位图的这个 coindex 下界至多三。这证明普通色数与该
  特定拓扑下界之间已有差距，**不证明单位图可三／四／五／六染**。
- 对每个被排除的固定连通图，T097 给正近单位间隙；未给整个任意大
  Kneser 族统一的数值间隙，也未禁止其点数爆炸的近单位模型。
