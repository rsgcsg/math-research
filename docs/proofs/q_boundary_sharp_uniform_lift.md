# T171：T170 固定 separator 的尖锐 uniform defect penalty = 179

2026-10-06（Australia/Brisbane）。本页继续 T170，但改变的是 lifting 机制本身：
不再用“全部正系数和”粗估 D>0 的词，而是在**全部真实 W22 proper 至多五色划分**
上精确求最小统一 defect penalty。没有 full15 终局，也没有普通 HN 新界。

## 1. 对象

T170 已给出 gauge 规范化后的逐词函数 L'。在 T165 的零缺陷面 D=0 上，

    L'(c) <= 336,

且 P/Q/R 聚合系数为

    (-263, 500, 0).

这里

    D(c)=sum_{j=1}^7 Z_j(c)+T(c) >= 0

是整数：七个 K7 的额外同色对缺陷加 PRR 三角缺陷。T170 为任意 D>0
统一使用正系数和得到

    L' <= 336 + 633 D.

633 已在那种“正系数和粗上界”类中最优，但这不意味着真实 proper 划分能同时实现
所有正项。

## 2. 精确结果：633 可降到 179，而且179尖锐

完整 W22 有22点、34条实际单位边。对任意整数 K，考虑

    F_K(c)=L'(c)-336-K D(c).

独立检查器把 D 展开成点对同色指示器的整数线性式，并把 F_179 直接变成一个
加权 clique-partitioning 目标。它按 restricted-growth 颜色规范递归枚举所有
proper 至多五色划分；单位边立即剪枝，对尚未决定的正权点对只取“全部未来都能同色”
作为乐观上界。这个上界故意忽略传递性，因此只会少剪枝，不会误删反例。

精确最大值为

    max_c F_179(c)=0.

所以对每一份 proper 至多五色词都有

    L'(c) <= 336 + 179 D(c).                         (1)

179 不能再减。证书给出按 T165 固定顶点顺序的一份 actual proper 五色划分：

    (0,1,2,3,1,2,0,1,0,3,4,4,4,4,3,1,2,1,4,1,0,0).

逐34条实际单位边检查后，它满足

    D=1,   L'=515.

因此

    L'-336-178D = 1,
    L'-336-179D = 0.

故 **179 是这个固定 T170 separator 的最小整数 uniform defect penalty**。
这比 T170 的633是另一层结论：633是粗方法类最优，179利用了真实五色划分之间
不能同时激活全部正项的联合结构。

## 3. 新的 support-independent 必要式

对任意 P/Q/R 平衡概率律取期望。仍有

    E[L']=-263p+500q,
    E[D]=85p+19r-13.

由(1)得到

    -263p+500q <= 336+179(85p+19r-13),

即

    500q <= 15478p + 3401r - 1991.                  (2)

再用已有传递式

    2r-p <= 1

消去 r：

    1000q <= 34357p - 581.                           (3)

## 4. 严格改进 T170

T170 的标量式是

    1000q <= 120163p - 3759.

旧右端减(3)的右端恰为

    85806p-3178 = 85806(p-1/27).

已有 p>=1/27，所以(3)在整个当前允许区域都不弱；在 p>1/27 时严格更强，
只在边界 p=1/27 相等。代入 p=1/27 仍得到 T165 的

    q <= 1867/2700.

若未来能独立证明 q>=7/10，则(3)会给出

    p >= 1281/34357 ≈ 0.0372849783 > 1/27.

本页没有证明这个 q 下界。

## 5. 结构含义

T170 说明“选差的 face 坐标”制造了1321的大罚项；T171进一步说明即使在最佳
粗 gauge 表示中，633仍高估真实划分很多。真正控制 lifting 的对象不是单项系数，
而是**窗口匹配、跨窗口传递性与单位边共同限制哪些正项能同时激活**。

因此下一步应：
1. 从 K=178 的 D=1 尖锐见证附近提取导致 L'=515 的最小 matching-synchronization
   模式，尝试给179一个解析分解；
2. 搜索非均匀 defect 罚项，尤其区分七个 Z_j 与 PRR 的 T；
3. 把同一机制接到 V 外真实运输窗口，而不是继续优化已闭合的单一 uniform K。
