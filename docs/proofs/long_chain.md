# T021：任意长及双向无限平移层链的完整条纹延伸判别

这是T020的统一推广，解决Q003。是受限条纹族的计算机辅助结构定理，
不是对任意平面染色的activation，也不决定Hadwiger–Nelson。

## 定理

沿用Λ、ρ和u=(2,-1)，δ=(ρ-1)u。令I为任意非空整数区间，允许有限、
单向无限或双向无限。考虑完整诱导单位距离图

`H_I = ρΛ ∪ ⋃_{k∈I}(Λ+kδ)`。

在中央格及每个平移层上各指定一条任意双无限T005二进制增量词，允许
各格独立S6颜色重命名。记相邻层的相位差支持为

`D_k={s^(k+1)_j-s^k_j mod3 : j∈Z}`。

那么这些指定词能拼接为H_I上的proper六染色，**当且仅当不存在连续
三个接口k,k+1,k+2满足D_k=D_(k+1)=D_(k+2)=Z3**。

该条件不依赖中央格所取的词，不要求任何词周期，不限制I长度。

## 1. 完整几何与必要性

T019的几何论证对任意两个整数层号都适用：不同平移层不相交，只在
相邻层之间有单位边，且全部是同本地坐标的匹配边。
中央格与第k层只在ρku相交；另外六条非公共跨边的本地坐标是ku+v，
v∈R={N(v)=3}。公共点邻边由内部proper性和公共点颜色一致性自动满足。

若三个连续接口全覆盖，T018的互补三元组证明平移到这些四层：首尾
中央格本地坐标是(2k,-k)与(2k+6,-k-3)，都在偶列、n模3相同，
所以中央格要求首尾共有一个颜色，三个互补接口却使其A色集合不交。
这证明必要性，且给出了局部有限阻碍。

## 2. 与层号无关的规范端口

每层独立循环重命名B色，使s^k_(k-1)=0；令a_k=s^k_k∈{0,-1}。
中央格记t_k=s^central_(k-1)，b_k=t_(k+1)-t_k∈{0,-1}。

第k层输入颜色的规范化L_k为A_i→A_(i+k)、B_i→B_(i+k)。
公共输出颜色的规范化G_k为A_i→A_(i+k)、B_i→B_(i+k-t_k)。
如果原始层frame为P_k，规范frame为`p_k=G_k P_k L_k^-1`。
这个规范化把公共点移到颜色A_0，把本地接触坐标移到0附近。

节点类型只有τ_k=(a_k,b_k)四种。相应的合法frame集合V_τ⊂S6满足

`p(A_0)=A_0`，且`p(c_a(v))≠c_b(v)`对全部v∈R成立，

其中c_a只需用到s_-1=0、s_0=a。四种V_τ各有53个frame。

相邻规范输出之间的变化为

`h_b(A_i)=A_(i+1), h_b(B_i)=B_(i+1-b)`。

因此当前p、下一q的完整匹配约束是

`h_b(p(A_i)) ≠ q(A_(i+1))`，

`h_b(p(B_i)) ≠ q(B_(i+d+1))`，对i∈Z3、d∈D_k。

规范化后的D_k仍满足-a_k∈D_k；它是否全覆盖保持不变。
对非全覆盖接口任选一个缺失余数r≠-a_k，把D_k扩大到Z3\{r}。
于是接口只有全覆盖F或漏一个余数M_r三种最大约束。扩大约束的正解
当然也是原来实际词的正解，不要求扩大后的抽象支持能被词实现。

## 3. 有限闭合证书证明所有长度

`research/long_chain.py`在上述120个固定A_0的排列中计算关系，再以
可达frame集合的包含关系剪枝。它找到36个非空不变集合，储存在
`certificates/long_chain_invariant.json`。

证书的每行是(τ,f,S)，其中f∈{0,1,2}为末尾连续F数，S⊂V_τ。
独立检查器不导入搜索器，反而在实际第0、1层的共同颜色坐标中重新
建立匹配关系，并验证规范坐标与实际公共点、六条接触边吻合。
随后直接检查：

- 四种初始V_τ均包含至少一个f=0的证书集合；
- 每个S非空且属于对应V_τ；
- 对任意下一节点类型及任意不形成FFF的最大接口，其前向像包含
  对应下一类型、下一f的某个证书集合。

全部416个闭合义务通过。归纳可知任意有限输入串只要没有FFF，真实
可达frame集合就包含一个非空证书集合，因此存在同一组联合frame。
这是对所有长度的归纳证书，不是检查某个最大长度后外推。

### 表背后的重置机制

令F1_τ={p∈V_τ:A_1不在p的A色集合内}，
F2_τ={p∈F1_τ:A_2在p的A色集合内}。其大小分别为39、11。
检查器还独立验证了更强的精确关系恒等式（节点类型任取）：

`V --F--> F1 --F--> F2 --F--> 空集`。

F1经过任意合法M_r，像恰好恢复全部下一V。
F2经过M_r，像是一个大小50、51或53的集合K。
所有这样产生的K都有`K --F--> F1`及`K --M_r--> V`。
初始V也满足这两个恒等式。每种类型共8种不同K（含V）。

这解释了为何没有更长的隐藏障碍：一旦遇到漏余数接口，可延伸状态
回到能重新经历两个F的类。只计可达集合的大小并不足以证明这一点；
检查器验证的是上述具体集合的像恒等式。

## 4. 无限区间

若I无限且无FFF，每个有限子区间都有联合frame赋值。
将I枚举为k_1,k_2,...，对递增有限子区间的解逐次取子列，先固定
p_(k_1)，再固定p_(k_2)，依次进行；每次只有有限个frame可选。
所得对角极限在每个固定节点及相邻接口上满足约束，因为这些约束
只依赖有限多个frame。这得到整个I的统一赋值。
逐格T005染色再由完整几何分类拼成H_I的proper六染色。

因此双向无限、非周期的情形也已解决。定理只问指定词是否有颜色
重命名能拼接；即使某输入被排除，也不意味着H_I本身不可六染。

## T022：同一宿主的无条件色数其实恰为4

对任意非空I，`χ(H_I)=4`。这比“存在某种六染色”更明确地封住了
在该宿主内追求无条件5/6色下界的路线。

给出以两个模2位编码的显式四染色：

- 第k层本地坐标(m,n)：`C_k(m,n)=(m+n, m-k) mod2`。
- 中央旋转格本地坐标(m,n)：`C_*(m,n)=(n, m+n) mod2`。

这是[Dúcz原文定理3.1](https://arxiv.org/html/2606.12325v1#S3.Thmtheorem1)
在本宿主上的特化，但这里还给出不依赖论文结论的直接检查。

每个单格的单位方向都不是(0,0)模2，两位线性映射可逆，所以内部proper。
相邻平移层的匹配边第二位翻转。公共点(2k,-k)在两个公式下都是(k,k)。
对六条非公共中央跨边，写本地坐标为ku+(p,q)，两端颜色分别是

`(k+p+q,k+p)`、`(k+q,k+p+q)`（模2）。

两者相等要求p=q=0模2，与p²+pq+q²=3矛盾。由完整几何分类，全部
单位边均已覆盖。因此χ(H_I)≤4。

任取一层，以其与中央格的公共点为原点，包含两个三角格Λ和ρΛ。
点0,1,ω,1+ω构成两个共边三角形；任意三染色迫使0与1+ω同色。
旋转副本也迫使0与ρ(1+ω)同色，而两个顶点1+ω和ρ(1+ω)距离1。
这个七点Moser spindle不可能三染，给出χ(H_I)≥4。

### 收敛结论

T021完整解决指定条纹词的拼接；T022完整解决这些宿主自身的色数。
两者均不能代替原始Hadwiger–Nelson，也不是一个能决定它的更广义定理。
本方向不再靠加层数、扩大半径或在同一Moser ring内添加点继续搜索下界。
有价值的可迁移技术是完整joint relation、相位差支持、可达集合的闭合
证书和重置恒等式。

本轮状态集合的包含剪枝与成熟的有限自动机antichain方法相同类型；
参见[De Wulf–Doyen–Henzinger–Raskin作者资料页](https://lsv.ens-paris-saclay.fr/~doyen/antichains/antichains.html)。
这是方法归类，不是把已知自动机方法本身称为新数学成果。
