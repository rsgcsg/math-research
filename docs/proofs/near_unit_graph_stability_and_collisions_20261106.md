# R2026-UNIT-STABILITY：近单位七色图的 K₄ 禁止阈值与碰撞同态

2026-11-06。独立有限维欧氏几何证明。它是对 [R2026-ROBUST7](robust_seven_hexagonal_limit_20261104.md) 及 [R2026-R7-GRID](finite_robust_seven_grid_and_stress.md) 的精确补充，**没有决定 χ(ℝ²)=6 还是7**。K₄/K₂,₃的精确单位实现障碍属于经典单位距离图事实；本页的新工作是统一的带宽稳定性证明、尖锐K₄门槛和同态/碰撞的定量区分，不主张独立文献优先权。

记 G_ε 是点集ℝ²上所有长度属于[1−ε,1+ε]的边构成的图，ε∈[0,1)。对于抽象有限图H，ε-实现允许不同顶点被映到同一坐标**吗**？本页区分：
- *injective ε-实现*：全部顶点分别映到互不相同的点，且每条边误差≤ε；
- *edge-faithful ε-实现*：允许非相邻点碰撞，但任意边端点须有规定的近单位距离；
- *unit homomorphism*：H→U(ℝ²)，每条边精确长1，非邻点可以碰撞。

这一差异对于渐近图列和有限证书提取是本质的。

## 1. 平面四点最优直径/分离比：精确常数√2

**定理A。** 对平面中任意四个不同点，记最小点距为a>0、最大点距为b，则
\[
\boxed{b\ge\sqrt2\,a.}
\]
而且此常数尖锐：边长a的正方形恰有直径√2a。

无需正则性或计算机辅助的完整证明：

- 若四点凸包为四边形，其四个内角之和360°，至少一个角≥90°。该角两邻边均长≥a，故跨过该角的对角线长≥√(a²+a²)=√2a。
- 若凸包为三角形，有第四点P落在该三角形内部或边界。P至三顶点的三条射线夹角之和360°，至少有一夹角≥120°；该角对应两顶点都距P至少a，按余弦定理，这两顶点相距≥√3a>√2a（在边界处仍成立）。
- 若凸包为线段，沿线排列的四个点有三个相邻间隔均≥a，故最长点距≥3a。

若四点所有六个距离都在[1−ε,1+ε]，则
\[
\frac{1+\varepsilon}{1-\varepsilon}\ge\sqrt2
\quad\Longleftrightarrow\quad
\boxed{\varepsilon\ge\varepsilon_4:=3-2\sqrt2\approx0.171572875.}
\]
取正方形边长a=1−ε₄=2√2−2，两个对角线距离√2a=1+ε₄，故阈值**精确达到**。

**推论A1（真实几何七色障碍必须无K₄）。** 对0≤ε<ε₄，**整个无限图**G_ε及其每个有限子图都不含K₄。这也适用于此前通过Voronov定理或实际有限有理网格构造得到的任意小正宽度的七染不可行证据。尤其：
\[
\varepsilon_*=\frac{\sqrt7-2}{\sqrt7+2}<\frac17<3-2\sqrt2=\varepsilon_4
\]
（左侧由√7<8/3，右侧由√2<10/7），所以整个经典蜂窝七染安全窗口里的所有区间NON6图都**K₄-free**。因此该区间七色压力不可能由一个真正的四点近等距团解释，必须由较长程图结构驱动。

注意上一轮六角片冲突图T²虽有七团，但其边含义是“每对整片可选某两个不同单位点”。这不等于原平面点图内有K₇；本定理甚至排除每四块同时挑代表点形成全部近单位距离。

## 2. 哪些“被精确单位距离禁止的抽象图”会在任意小带宽中出现？

**定理B（碰撞同态精确判别）。** 对任何连通、至少一条边的有限简单图H，下述等价：
\[
\boxed{\begin{aligned}
&\text{对每个 }\varepsilon>0\text{ 都有 injective }\varepsilon\text{-实现于ℝ²};\\
\iff\;&\text{H有一个非必单射的 unit homomorphism }H\to U(\mathbb R^2).
\end{aligned}}
\]

证明：（→）取ε_j↓0的单射近单位实现，把H中选定的根顶点移到原点。取固定生成树，从根到任一顶点最多|V(H)|−1条边，每条≤1+ε_j，所以全部坐标在同一个有限圆盘中。有限个坐标的序列可同时收敛到极限；每条H边长度在[1−ε_j,1+ε_j]内，因此极限长度恰为1。非邻顶点可能碰撞，但相邻顶点不能，得到真实unit homomorphism。（←）若存在H到精确单位图的同态，原本相同坐标的互不相邻顶点分别施加彼此不同、范数小于ε/3的扰动；精确的原边两端在新赋值下距离变化小于2ε/3<ε，所有顶点已互异，得到单射ε-实现。证毕。

推论：对每个**固定**、没有unit homomorphism的连通H，存在ε_H>0，使ε<ε_H时H根本不可能作为G_ε的子图出现。该结论是对有界有限图类型取极限的最小严格形式，而不是一个对所有H统一的阈值。它也解释了前轮N₇(ε)有界⇒NON6精确单位图：7染不可行的H若存在unit homomorphism，像图必不可六染，因为像图的任何六染可拉回给H。

## 3. K₂,₃ 的反向例子：精确禁止，却**没有任何**正带宽禁止阈值

K₂,₃不能以五个不同点精确单位距离实现：固定左部两个不同点A,B，它们的两个单位圆最多有两个交点，无法容纳右部三个互异的共同单位邻点。这个经典障碍在ε>0时失效。

任取t∈(0,ε)，设置
\[
\begin{aligned}
A&=(0,0),\quad B=(1,0),\\
C&=(1/2,\sqrt3/2),\quad D=(1/2,-\sqrt3/2),\\
E&=(1/2,\sqrt3/2+t).
\end{aligned}
\]
五点互异；A、B至C、D的四条边恰好为1，而A、B至E的两条边长都为
\[
\sqrt{1+\sqrt3\,t+t^2}\in(1,1+t)\subset(1,1+\varepsilon),
\]
因为√3<2。于是对**任意正ε**都能实现六条近单位边。其极限t→0中E与C合并，得到一个合法非单射unit homomorphism。

**结论：** K₄作为不可实现子图在近单位扰动下有严格的最优半宽ε₄；K₂,₃虽然在精确注入式单位图中被禁止，却没有任何正的禁止半宽。对于“把区间图拉直到单位图”的探索，必须区分**稳定禁止**与**因顶点碰撞消失的禁止**；不能据精确单位图的所有抽象禁用子图直接约束正宽度网格图。

## 4. 与下一次证明χ=7的严格耦合

Voronov保证每个ε>0的G_ε都非六染；上轮R2026-R7-GRID甚至构造O(ε^{-2})规模的有限有理区间NON6图，但该证明依赖Voronov的圆盘闭覆盖定理、不是独立SAT反证。本轮A说明ε<ε₄时**所有**这类图均K₄-free；B说明每个固定有限拓扑的渐近可实现性由unit homomorphism而不是单射unit embedding判定；K₂,₃说明顶点碰撞不能忽略。

一个七色证明所需的升级不是将某个大而有碰撞极限的图直接称为精确单位图，而是：
\[
\exists N,\ \forall\varepsilon\downarrow0,\
\exists\text{至多N点的区间NON6图}
\Longrightarrow
\exists\text{有限精确单位NON6图}
\Longrightarrow\chi(\mathbb R^2)=7.
\]
**尚没有证明这个统一N**，也没有另一条无条件排除全体六染色的论证。K₄-free是必要结构信息，远不足以推导NON6。完整六染色的存在性仍不能排除。
