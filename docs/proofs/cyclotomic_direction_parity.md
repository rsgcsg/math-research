# T080：四幂投影障碍的全部列出方向平移图仍二色

日期：2026-09-10。证明加独立有理证书；不是新的平面色数界。

沿用[T079/C015](cyclotomic_sparse_coupling.md)中的
`F=Q(i,√3,√5,√11)`、`ζ=exp(2πi/7)`和14个单位向量的集合D。
令`Γ=Σ_(d∈D) Zd⊂C`，只在差属于`D∪(−D)`的点对之间连边。

**定理。** 这个完整、无限的列出方向Cayley图恰二色。因而仅把
C015的14方向作任意有限或无限次平移、叠加、闭环，不能获得三色
障碍，更不能获得不可五染图。这里必须保留“边方向仅限±D”条件。
若补入这些点之间的其他真实单位边，所得诱导图不由本定理决定。

## 一个明确的奇偶特征

每个Γ中的点有唯一的四幂表示

\[
 z=\sum_{j=0}^3(r_j+s_j\sqrt3+t_j i+u_j i\sqrt3)\zeta^j,
 \qquad r_j,s_j,t_j,u_j\in\mathbb Q.
\]

唯一性来自`[F(ζ):F]=6`及`1,√3,i,i√3`的Q线性无关性。
定义Q线性函数

\[
 L(z)=\sum_{j=0}^3 r_j-t_0+
       \frac{3u_0+12u_1+12u_2+11u_3}{8}. \tag{1}
\]

对D中的14向量，按照原证书的固定次序，直接代入得到：

| 方向标签 | L值 |
|---|---:|
| 四个axis方向 | 分别为1 |
| triple_013、triple_023 | 分别为1 |
| mixed_3_2_-1、mixed_3_2_1 | −1、257/463 |
| mixed_2_3_-1、mixed_2_3_1 | −397/463、323/463 |
| mixed_-10_9_-1、mixed_-10_9_1 | 35809/5217031、743041/5217031 |
| mixed_-9_10_-1、mixed_-9_10_1 | 1275761/5217031、568529/5217031 |

表中每个既约有理数的分子、分母都为奇数。设
`Z_(2)={a/b∈Q:b为奇数}`，其剩余同态为
`ρ:Z_(2)→F₂, ρ(a/b)=a mod2`。由加法性，(1)把整个Γ映入
Z_(2)，并对每个d∈D满足`ρ(L(d))=1`。于是

\[
 c(z)=\rho(L(z))
\]

是Γ的二染色：每条列出方向边都使c翻转。图中有边，所以色数
恰为2。这个论证处理任意整数系数及任意长度的路径，不依赖有限
盒、有限周期或对关系长度的截断。证毕。

同样，任意点集中的任意图，只要所有边差都属于±D，其连通分量
都包含在Γ的平移陪集中；平移上述规则即可二染。整平面上定义这种
列出方向图时，可以逐个加法陪集选择代表，不声称这给出任何正则
或可测的代表选择。

## 一般机制：应检查整数关系，而不是几何Gram秩

对任意有限非零向量集合`D={d₁,…,d_m}`，上述Cayley图二分当且仅当

\[
 \sum_j n_jd_j=0,\ n_j\in\mathbb Z
 \quad\Longrightarrow\quad \sum_j n_j\equiv0\pmod2. \tag{2}
\]

若图二分，按关系走出的闭合游走长度为`Σ|n_j|`，必须为偶数，
而它与`Σn_j`同奇偶。反之，(2)保证
`c(Σn_jd_j)=Σn_j mod2`不依赖表示，且沿每条边翻转。
本例的L是(2)的简短对偶证书：对零关系应用`ρ∘L`立即得到(2)。

C015的约束是**F线性映射**保单位，利用了复Gram数据及F标量相容性；
普通图染色没有这些要求。T080表明，连列出方向的无限平移闭包都能
二染。这比仅指出原点加14方向是星图更强，直接停止只扩大这些
方向的列出边搜索。该方向集的Q秩为10，整数关系格的秩为4；
关系格的存在或秩本身不是奇环，关键是关系对总系数奇偶的作用。

## 范围与下一道真正未闭合的门

本定理没有证明以下任何一项：

- Γ的**全部诱导单位图**二色或五色；
- `F+Γ`、四幂宿主H₄或整个`F(ζ)`可五染；
- 添加F中的五色核心后仍可用L染色；
- 所有七次方向、所有四幂单位向量都满足该奇偶规则。

例如F含等边三角形`{0,1,(1+i√3)/2}`，其三条边立即排除任何
二染色，但仍然只需三色。其第三顶点的L值是11/16，不在Z_(2)，
所以该顶点本来就不属于Γ；不能直接把现有公式延伸过去。
这说明“接入核心打破二色”是必要的
机制检查，不是接近六色的证据。

真正有价值的下一问题必须保留额外诱导边或五色核心的**全部自由
染色**，并寻找不能通过任何五色规则满足的真实联合。仅因C015
投影失败，就选它的14方向去无限增大平移盒，没有剩余下界价值。
