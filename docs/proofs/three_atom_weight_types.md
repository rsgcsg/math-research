## 1. 一般命题及完整证明

设完整事件差矩阵D的条目属于{-1,0,1}，概率律满足Dλ=0、λ≥0、Σλ=1。
假设不存在支持至多两个原子的可行律。若存在恰三原子的可行律，则其权重在重排后必为

```
(1/3,1/3,1/3) 或 (1/2,1/4,1/4)。
```

证明：限制D到三个支持列，得矩阵B。正权核向量使rank(B)≤2。
若rank(B)=0，一个支持列本身就是正解。若rank(B)=1，三个列向量共线；
若有零列仍给一原子律，否则正凸组合等于零迫使有两个反向的非零列，二者即可用正权形成二原子律。
两种情况都违背假设。因此rank(B)=2，其正归一化核是一点。

记三个正权重为a,b,c。一个非零的{-1,0,1}行与它们正交，不可能只有一个非零项。
若恰有两个非零项，其方程是一对权重相等；若有三个非零项，其方程是一个权重等于另两个之和。
取两个独立非零行：

- 两条不同的相等式迫使a=b=c，归一化得各1/3。
- 一条和式与一条相等式只能让和式右侧的两个权重相等，否则迫使某个权重为0。
  因而得到1/2、1/4、1/4。
- 两条和式若左侧相同则不独立，若左侧不同则同样迫使第三权重为0。

没有其他情况。证毕。

这不是一般“三原子概率必须等权”的断言；无小支持解的假设和D的特殊整数条目都很重要。
同一论证还表明，每份这样的三原子律在自己的三列支持上唯一，故是整个概率可行集的极点。

## 4. 实际执行的有理数校准

以下标准库代码枚举所有规范的三列非零{-1,0,1}行以及两行的正核。
本轮已原样执行：13个行方向、78个独立行对、6个正核行对，权重集合恰为上述四个有序向量。
校准检查的是这段有限分类，不是原15域SAT查询；它未静默加入make check-eta-support。

```python
from fractions import Fraction
from itertools import product, combinations
rows = [r for r in product((-1,0,1), repeat=3)
        if any(r) and next(x for x in r if x)>0]
weights=set(); independent=0; positive=0
for a,b in combinations(rows,2):
    v=tuple(a[(j+1)%3]*b[(j+2)%3]-a[(j+2)%3]*b[(j+1)%3]
            for j in range(3))
    if not any(v):
        continue
    independent+=1
    if all(x>0 for x in v) or all(x<0 for x in v):
        weights.add(tuple(Fraction(x,sum(v)) for x in v))
        positive+=1
expected={(Fraction(1,3),)*3}
for heavy in range(3):
    expected.add(tuple(Fraction(1,2) if j==heavy else Fraction(1,4)
                       for j in range(3)))
assert len(rows)==13 and independent==78 and positive==6
assert weights==expected
print('PASS: three-atom weight types, not a full-domain obstruction')
```
