# T095 / E064：整个5084点图的两端口关系饱和

2026-09-11。有限精确正认证及其直接推论，不是新HN上下界。
对象X、32维代数坐标和点序完全沿用[E061–062](joint_word_closure_and_frontier.md)：
5084点、12920986个不同点对、24844条实际单位边。

## 1. 精确结论与证明

**T095。** 对任意S⊂X、|S|≤2，任何在诱导图X[S]上合法的
五色预染色都能延伸为整个X的合法五染色。

证据没有固定参考色框，也没有限制到11进色词：

1. 重新直接核验E063的156个完整词，每个词均满足全部24844条边。
2. 每个顶点在这些词上的156维颜色签名两两不同。因此，任意两个
   不同顶点都在至少一个词中异色；这是覆盖全部12920986对的证据。
3. 对每个顶点，按颜色类作位集并集，精确求出已经有同色见证的伙伴。
   除掉自身和实际单位邻点后，恰剩下E063定位的14对。
4. 对这14对分别在完整proper五色CNF中要求两端颜色均为0；每次都有
   完整正词。独立检查器不信任SAT标签，直接检查每一条边和端口同色。
5. 加入这些词后，所有12896142个非单位点对都有同色见证。

两个有序颜色标签的任意异色请求，可以从第2步见证经全局S₅重命名
得到；任意同色请求同理来自第5步。单位点对不能同色，且无需覆盖
非法预染色。单点与空集也显然延伸。证毕。

这说明X上没有非单位强迫异色对，也没有不同顶点的强迫同色对。
这是**整个两端口关系**的结论，不只是14个指定查询的结论。

## 2. 立即继续的联合攻击

分别可延伸不能推出同时可延伸。因此又建立了一个新完整CNF，
同时要求14对全部同色，允许不同点对使用不同颜色；没有沿用逐对
查询的固定颜色或冻结旧词。该联合查询也找到一个完整proper五色词，
并由同一独立检查器检查全部边及14个等式。

这关闭这14个缺口作为“一起要求同色”反例的用法，不声称任意28端口
预染色可延伸，也不声称任意14对、任意同异组合或全等概率律可行。
这些正词无需满足E063的18个四点等式或E062的五个最大域；不能把
不同见证提供的性质拼成一个未经认证的共同见证。

## 3. 一般性机制与准确的退出范围

T026对单个Parts核心已经证明三端口延伸；T095把**两端口**延伸
认证到具有实际跨方向耦合的十副本联合X。三端口性质不能从Parts
自动传递到这个联合，当前没有这样声称。

作为直接推论，若顺序加入X的刚体副本，每个新副本与此前并集
交叠至多两点，且新旧非公共部分之间没有额外实际单位边，则整个
有限或单向无限并集可五染。归纳时，已有颜色在交叠诱导图上合法，
T095给出新副本延伸；无额外跨边保证没有漏约束。单向无限时保留
先前颜色逐步取并集即可。这沿用T026的粘合机制，不另宣称新理论。

**必须保留无额外跨边假设。** 只说“每两个副本交集≤2”不够：
新副本与整个旧并集的交集可能更大；闭环也可能带来多个共同接口。
所以不能把逐对满关系或树状修复当成整个约束网络可满足。

结构性换线：停止X内部任何二端口强迫关系搜索，保留三种活动方向，
不新增第四条。第一优先转为**多个接口同时作用的完整划分关系**，
需要一个实际可实现的联合约束不能被所有proper词的凸混合修复。
具体仍未认证的入口是E063五个新平移的整个最大域，或一个不被
两端口顺序粘合吸收的真实闭环；不是继续给这14对或旧18组加预算。
单个等变词失败仍受T094限制，不能当成完整joint负证据。

随后[T096](finite_orientation_joint_compiler.md)已把这一路线与整数闭环
构造接通：当前有限方向群中的全词分离可显式编译为有限真实NON5图，
并把平移盒压到8指标；不是只留下“将来寻找几何实现”的路线图。

原问题还缺什么：下界需要全词有效且可检查的反证（几何真实性本次
已具备，但不存在负证据）；若走joint路径，还须保留约束确为原始
五染必要条件。上界需要覆盖所有有限实代数配置的统一六色机制。
χ=6仍有这两个独立终局缺口；“几层”不是可据以预测轮数的进度条。
