# 一个64点实际二色例子：几何共同律与抽象图对称不能互换

2026-09-29。以下反例直接针对“二端口关系完全饱和后，普通图EPPA应当保五色”的潜在捷径。
结论不需要任何未发布结果，也不是原始HN下界。所有有理坐标及有限常数由独立标准库程序重算。

## 1. 同一实际配置的四种性质

存在64点的有理平面配置 X，其诱导单位图恰为六维超立方体 Q6，有192条边。它同时满足：

- 普通单位图恰二色。
- 每个至多二点的局部合法五色赋值都能延拓（实际上三色已经足够实现两种相等类型）。
- 存在一原子的二色划分律，保持 X 的**全部真实欧氏部分等距映射**。
- 不存在保持 X 的**全部抽象图部分同构**的五色概率律，哪怕允许任意实权重和任意支持数。

因此，任何普通图EPPA补全 H（X作为诱导图嵌入，X的每个图部分同构延拓为H的自同构）
都至少六色。这不是说X六色；普通χ(X)=2。H也没有被要求或证明是平面单位图。

## 2. 实际坐标和诱导边

取 m=(2,4,6,10,14,16)，令

    v_j=((m_j²−1)/(m_j²+1), 2m_j/(m_j²+1)),
    p_ε=Σ_j ε_j v_j，ε∈{0,1}⁶。

六个方向精确为单位向量。逐一计算64个有理点及2016个不同点对可核验：点全部不同，
距离为1当且仅当两位向量恰有一个比特不同。故实际诱导图恰为Q6，而非只列出方便的边。
检查器使用 Python Fraction，从上述六个整数重新生成全部坐标；不依赖浮点拟合或SAT。

c(p_ε)=Σ ε_j mod2给合法二染色，有单位边故χ=2。
任何二分图的局部二端口赋值都可用至多三色延拓：保留二分底色；
若同侧两点要异色，只将其中一点改为第三色；若异侧非邻两点要同色，将这两个非邻点都改为第三色。
然后统一重命名即可获得任意允许的指定五色(a,b)。这也说明二端口满关系本身远弱于联合相容。

## 3. 一份划分就保持全部真实部分等距

所有坐标的分母均为奇数。令 Z_(2) 为奇分母有理数环，ρ:Z_(2)→F2为约化。
在该环的平面上定义颜色 α(x,y)=ρ(x+y)。对任意点p,q，

    ρ(|p−q|²) = α(p)+α(q)，

因为在F2中平方等于自身。故颜色是否相等，只由两点的**真实平方距离**决定。
本例每个单位方向的α值均为1，所以α正是上述比特奇偶色。

真实欧氏部分等距保持每一对的平方距离，因而保持所有颜色相等关系，也就保持整个限制划分。
于是该单份二色划分给出全部真实部分等距的完整共同律。这里没有用颜色函数的可测性。

## 4. 若错误地要求所有图非边相同，五色就会被排除

抽象图的任意两个不同非邻点构成同样的二点无边图。因此，若一个概率律保持所有图部分同构，
任意不同非邻点同色的概率必须是同一个p；边的同色概率为0。

64点分到至多五类时，同色点对数量至少为

    4*C(13,2)+C(12,2)=378。

把两个相差至少2的类均衡一步会减少这个数量，所以最小值由13,13,13,13,12取得。
Q6的非边数是 C(64,2)−192=1824。取期望得

    p ≥ 378/1824 = 63/304。

另一方面，令 f(ε)=(-1)^{ε_1}。它的和为0，且Q6邻接矩阵A满足Af=4f。
对每份染色，矩阵 M_c=[1_{c(x)=c(y)}] 半正定，因为

    fᵀ M_c f = Σ_颜色 (Σ_{x属于该颜色} f(x))² ≥0。

取期望后 M=(1−p)I−pA+pJ，故

    0 ≤ fᵀMf =64(1−5p)，即 p≤1/5。

但63/304>1/5（315>304），矛盾。该否定覆盖全部合法五色划分和全部实概率，不依赖小支持。
它排除的是**图部分同构**共同律，不是真实几何共同律，后者上一节已给出一原子正解。

具体看，按二进制掩码索引，{p0,p3}→{p0,p7}（固定p0）是二点无边图的部分同构，
但两个平方距离不同，而且前一对奇偶同色、后一对奇偶异色。检查器保存这两个不同有理长度。
因此这个图部分同构根本不是可以加进HN共同律系统的真实部分等距。

## 5. 有限EPPA补全的色数后果

假设有限H是X的图EPPA补全且可五染。固定一份H染色，在有限群Aut(H)上均匀平均，
再限制到X。X的每个部分同构都有H中的延拓；平均的平移不变性使所得到的X概率律保持它。
这与第4节矛盾。因此χ(H)≥6。没有证明最小可能恰为6，也没有构造H的单位平面实现。

更一般，Q_d有n=2^d个顶点。相同的非边概率论证给

    p≥(n/k−1)/(n−1−d)，p≤1/(d−1)，

从而 k≥n(d−1)/(n−2)>d−1，所以任一此类概率律需要至少d种颜色（d≥2）。
这是一类二色图的抽象对称补全颜色代价无界的简单证明，不是普通图色数的无界结论。
本文件只认证上面的具体d=6有理单位实现，不将所选六参数外推到其他d。

## 6. 对本项目的作用及来源范围

[原Y的二端口满关系](Y_two_terminal_completion.md)不能独自推出五色EPPA补全，也不能
允许把原15个几何运动换成任意图局部同构。成熟的图同态/有限模型语言仍有用，但必须保留距离承诺。
反过来，本例不否定某个特殊几何族的保色数补全定理；只否定“所有图部分同构”这个过强替代。

EPPA定义参照 Bradley-Williams–Cameron–Hubička–Konečný，
[EPPA numbers of graphs, arXiv:2311.07995v3](https://arxiv.org/abs/2311.07995v3)，
本次读作者摘要与版本/发表信息，不调用其大小界。上文概率、谱和有限群平均证明自足。
与仓库已有T120/C023相关但不重复：这里给真正的普通二色、二端口满关系、所有几何部分等距一词可行，
却在五色层被抽象图部分同构排除的同一个实际配置。

运行 `python3 -S research/verify_cube_symmetry_gap.py` 可重建全部2016个点对、192条单位边，
核验每个合法二端口相等类型的明确三色见证、距离奇偶恒等式、特征向量及两个严格相冲突的有理界。
谱论证适用任意概率的部分仍由第4节证明，不冒称枚举了5^64个染色。
