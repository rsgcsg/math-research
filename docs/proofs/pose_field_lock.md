# T051–T052：几何锚定会把候选重新锁回五色安全域

2026-09-09，起始干净基线`74438c4`。T049–T050及C007已由上轮
独立证书和整库检查通过。本轮不再手选一个新坏palette，而是直接
检查真实activator能否按计划摆放。以下是初等平面刚体代数的推论，
编号用于项目引用，不宣称该代数方法的文献首创或HN新界。

## 1. T051：两个精确位置锚点强制整份刚体副本属于原域

设F⊂R是任意子域，M⊂F²为给定点配置，g为任意实平面等距变换，
允许反射。若存在a≠b∈M，使g(a),g(b)都在F²，则

`g(z)=Uz+t`的全部矩阵与平移系数在F中，因而`g(M)⊂F²`。

### 证明：不引入平方根的重建公式

记x=g(a)、y=g(b)、v=b−a、w=y−x，J(u₁,u₂)=(-u₂,u₁)。
有`d=|v|²=|w|²>0`，且d∈F。对某个ε∈{+1,−1}（变换定向），

`g(z) = x + [ w(v·(z−a)) + ε Jw(Jv·(z−a)) ] / d`。

因为(v,Jv)和(w,εJw)是等长度的正交基，等距变换的线性部分必须
把前者映成后者。上式只用F内加减乘除，证明所有系数在F。
关键是除以平方长度d，而不是单位化向量后随意引入√d。

“两个位置锚点”指两个顶点确实与已知物理点重合，不是只知道它们
各有一条到旧点的单位边。后者距离约束不固定像点，不能套本定理。
边是否交叉、模板是否图论平面图、原图有多少种染色都不参与证明。

### 逐个附加的闭包推论

起始宿主H₀⊂F²。每一步加入某个F²点模板的刚体副本，只要它至少
有两个不同顶点已经落在此前宿主中，就仍全部落在F²。归纳给出
任意有限或按此顺序构成的无限并仍在F²。两点可以来自此前不同的
副本，只要此前点已经在同一个F坐标框架中。

所有额外真实单位边、边界交叠和内部交叠均可保留，不需要clean
gluing假设。若整个初始框架先被任意实等距变换移动，先整体逆变换
回来即可；原并图与F²中的图同构，色数结论不变。

## 2. 对Parts及当前gate的无条件activation禁止结论

取`K=Q(√3,√5,√11)`。T028已证明整个K²诱导单位图恰五色。
Parts、指定21点gate及其40点耦合的规范坐标都在K²中。因此：

**推论。** 从K²中的任意宿主开始，按T051的两位置锚定规则加入
任意多个K模板，整个诱导单位距离图仍至多五色；若包含Parts则
恰五色。模块数、边界关系强弱及额外跨内部边都不影响这个上界。

特别地，把当前gate的全部边界都放在一个Parts副本中，如果这种
摆法存在，就已把gate至少两个不同顶点固定到同一个K宿主；该gate
必落在同域。即使加入新的内部耦合，它也不能使整个图不可五染。
这覆盖的不只是T038的constant-pair坏关系，任何K坐标刚性模块都
一样，包括未来逻辑更强但坐标仍在K中的新模块。

这里不证明某份给定的Parts五染色必能延伸；只证明**存在一份**
整个并图的五染色。T047、C007的条件坏边界仍可存在，没有被否定。
T026的三端口普适性也仍有独立价值，因为它是逐份预染色的全称命题。

也没有假定所有14/26个端口确实能被某个Parts嵌入容纳：推论是
“若如此放置则不可能给六色下界”，不是一个存在性构造。

### 直接的结构筛选

对可按上述两锚顺序附加的候选，不必先展开高阶边界关系或跑SAT，
T028＋T051已给无条件五色上界。一个基于这些模板的六色候选，
必须包含**不能被这种安全域闭包吸收的部分**，或使用本来不在K²
中的模板。闭包停住并不表示不可五染，更不表示全图需要六色。

## 3. T052：一个共享枢轴时，跨单位边的约束秩

仍设旧点p及模板点q在F²中。已有一对共享枢轴，把它们分别平移
到原点后，剩余姿态是正交变换。反射可以先把模板作用一次F系数
反射，因此只需讨论旋转

`R=cI+sJ, c²+s²=1`，c,s∈R。

一个旧点p和旋转点Rq实际相距1，当且仅当

`A c + B s = C`，

`A=2p·q, B=2p·Jq, C=|p|²+|q|²−1`，均属于F。

把已知跨单位边的(A,B)组成一个两列矩阵。

**定理。** 若该矩阵在F上的秩为2，则c,s∈F，整个姿态锁回F。
若实际姿态不在F，则全部非平凡跨单位边的系数行只能有秩1；
只要至少有一条非零行，姿态至多属于一个二次扩域。

### 秩2的证明

取`D=A₁B₂−A₂B₁≠0`，由两个真实单位边方程直接得到

`c=(C₁B₂−C₂B₁)/D`，

`s=(A₁C₂−A₂C₁)/D`。

它们都是F元素。若更多边存在，只是进一步筛选这个已确定姿态，
不会把它重新推出F。枢轴平移已在F中，故完整等距变换在F中。

### 秩1的完整二次分支

取非零行(A,B,C)，`N=A²+B²>0`，`Δ=N−C²`。
设`u=-Bc+As`。由c²+s²=1可得u²=Δ，故

`c=(AC−Bu)/N, s=(BC+Au)/N, u=±√Δ`。

- Δ<0：无实姿态；
- Δ=0或Δ为F平方：所有可行姿态都在F；
- Δ为正非平方：至多两个姿态，在F(√Δ)中，且不在F。

其余跨边的系数行若与(A,B)成比例但C不按同一比例变化，则整个
系统不相容；如果是实际姿态，增广矩阵(A,B,C)秩也为1。
若所有行均为零，则这些边没有提供旋转约束，不能据此说只有二次自由。
涉及枢轴的已有单位边常正是这种零行，不能把它们计为独立接触。

这是关于**跨边方程的代数独立性**，不是跨边条数或图论环数。
很多边可以重复同一条方程方向；两条边也可以已足够锁域。
此结论不限于T029预先选好的`c∈F,s=√d·s₀`形式。

## 4. 原跨边实验的秩校准与姿态锚点重建

`pose_field_lock.json`从E016四个已经认证的Parts双核心抽取全部
非公共跨边，独立检查器重新用平方自由根式乘法构造(A,B,C)：

| 旋转根式 | 实际非公共跨边数 | 系数秩／增广秩 |
|---|---:|---|
| √7 | 3 | 1／1 |
| √13 | 21 | 1／1 |
| √17 | 30 | 1／1 |
| √41 | 4 | 1／1 |

共58条，全部满足B=0、A≠0及`C=cA`。独立检查器不使用搜索器
的行运算，直接重建系数和全部相对于首行的二阶子式。
这些边的**几何完整性**来自E016已有的全部1032256跨点对认证，
本次秩检查不冒称替代那份全点对检查；两者均在`make check`中运行。

另在T045的24个两位置锚定姿态上，逐点检查第1节重建公式，共504个
像点、两种定向均覆盖。一个真实秩2例为
`q=(1,0), p₁=(1,0), p₂=(3/2,√3/2)`，旋转c=1/2、s=√3/2。
两条跨边都为单位边，系数行独立，旋转如预期位于K中。

因此E016中的“21或30条跨边”并不意味着有21或30份独立姿态信息。
其逃域恰伴随全部跨边法向量的秩亏损，与T029的径向限制吻合。
但低姿态秩也不自动意味着颜色关系可满足；颜色joint问题仍须另证。

## 5. 对真实终局攻击的收敛

当前能给出的不是HN解答，而是一个更严格的候选入口：

1. **先做域闭包筛选。** 一个K模板若已有两位置锚点，或一个枢轴加
   两条独立跨边约束，就不用当作逃域候选。若整个构造这样闭合，
   已有无条件五色上界，无须继续尝试palette activation。
2. **只对剩余的相对姿态求真实joint。** 一枢轴的非平凡逃域只剩
   秩1二次分支；须同时保留两种共轭姿态的几何、全部单位边和宿主
   边界关系。未共享枢轴的平移/旋转组合不被T052覆盖，不能硬删除。
3. **不把不在K当作不安全的充分证据。** T028还覆盖保留F11的安全
   扩域；算出Δ后仍需检查该扩域是否已被现有上界覆盖。
4. **不把“必须两点锚定才可实现”当一般假设。** 整体刚性网络可以
   通过同时求解多个相对姿态闭合，而没有这样的逐步构造顺序；
   这种真正未被安全域吸收的耦合仍开放。

因此，把更强逻辑gate的全部端口直接塞进Parts，不是当前可行的
逃逸方向；继续做同模板固定边界失败也不会改变这个几何上界。
真正剩余的是不能按安全域顺序锚定的联合几何，及其所有边界能否
共同延伸。它仍然很难，不能据此声称已接近原问题的最终答案。
