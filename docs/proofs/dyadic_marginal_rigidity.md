# T118：有限 2 精度最优四色边际的刚性与相对延拓障碍

2026-09-12。T118；完整证明及独立有限校准。
这里的“至少八色”始终附带**保持指定种类的 R₂ 四色边际**这一假设，
不是普通单位距离图的新下界。该假设对普通平面七染色并不成立。

## 1. 精确结论

沿用

\[
L=\mathbb Q(\eta,z,\nu),\quad
R_2=\mathbb Z_{(2)}[\eta,z,\nu],\quad A_1=\tfrac12R_2,
\]

其中 η=ζ₅，`z²+z+1/3=0`、`bar z=−1−z`，
`ν+bar ν=5/3`、`ν bar ν=1`。令 c 是 R₂ 上的 proper 四染色，
并假设存在有限 h，使 c 仅依赖 `p mod 2^hR₂`。

**命题。**

1. c 已下降到模2，且经 `R₂/2R₂≅HG(F16)×HG(F16)` 的两个配对
   图坐标之一拉回一个 HG(F16) 的 proper 四染色。允许任意非线性的
   四染色和任意颜色重标，不仅是此前的两个线性 mask。
2. 任意保持 c 的 A₁ proper 染色至少需要八种颜色。
   尤其不能保持这个边际而通过一、二、三种新颜色得到五、六、七染色。
3. 仅排除第五色的相对障碍已有一个 **34点、49条实际单位边的二分图**；
   至少八色的相对障碍可由至多119个显式点组成。

量词边界：不声称每个 R₂ 四染色都有有限精度；不排除把 R₂ 重新染成
五色后延拓；不排除 R₂ 使用非有限精度四色的延拓。普通 `χ(A₁)≥8`
是错误推论，因 A₁ 本身是平面子集，有普通七色上界。

## 2. 全精度谱的取等刚性

记 `O_h=GR(2^h,4)`，H_h 为顶点 O_h²、差方向满足 xy=1 的图，
Q=16^(h−1)。[全精度范数证明](dyadic_finite_precision_ceiling.md)
的 c=0 情形给出：

- 主特征值是 15Q，只有平凡加性特征取得；
- 最小特征值是 −5Q；
- 只有两个加性坐标导子都为1时才能取得 −5Q，因而该特征空间
  中的函数均下降到模2；
- 第一导子层的其他值为 −Q、3Q、7Q；更高导子层绝对值至多 Q。

有限域原始谱可独立完全重放：

```text
值       -5  -1   3   7  15
重数      60 105  60  30   1
```

这并非只在假想边目标上作断言。同一证明第7.3节对 n=0 的 CRT / 共轭比值
构造表明：每个 H_h×H_h 方向，都是 R₂ 的实际单位方向的剩余类。
又 R₂ 是加法群，所以任意起点上的目标边都有实际源边提升。因此有限精度
proper c 确实是整个 H_h×H_h 的 proper 四染色。

此直积图的度数为 225Q²，最小特征值为 −75Q²。最小空间恰为

\[
(E_{-5Q}\otimes\mathbf1)\ \oplus\
(\mathbf1\otimes E_{-5Q}).
\]

理由是只有主值 15Q 乘最小值 −5Q 可取得 −75Q²，两个非主值的
负积绝对值至多35Q²。主值简单性也由上述严格谱隙得到。

Hoffman 的独立集界是总点数的1/4。四个非空色类必须各自取等；
Rayleigh 商的取等条件因此使每个色类指示函数形如

\[
1_I(x,y)=\tfrac14+F(x)+G(y),
\]

其中 F、G 下降到相应的模2 HG 坐标，可以取为实函数。
一个取值仅为0、1的加性分离函数只能依赖一个坐标：若 F 和 G 均非常数，
分别取其最大、最小值；四个角的取值不能同时落在 {0,1}，因为两个
严格正振幅各至少1，而总振幅就至少2。故 F、G 至少一个恒定。

若两个非空色类分别依赖不同的因子，它们必相交。这不可能；所以全部
四个色类依赖同一个因子。于是整个四色下降到一个 HG(F16) 因子，证明第1项。

## 3. 每一个 HG(F16) 最优色类在每行、每列都恰有四点

HG(F16) 的四个色类各有64点，且中心化指示函数属于 −5 特征空间。
任意非主轴向加性特征 `(a,0)` 或 `(0,b)` 的特征值都是−1：在另一
坐标固定为0的参数下，单位方向求和就是全部非零域元的非平凡特征和。
因此中心化指示函数没有轴向频率。对一行或一列求和只保留相应轴向
频率及主项，故每行、每列的每种颜色数量均为 `16/4=4`。

这对任意 proper 四染色成立，不要求线性、仿射或固定颜色标签。

## 4. 显式完整轴邻域

置

\[
h=\eta+\eta^{-1},\quad h^2+h=1,\qquad
t_0=\eta z+\eta^{-1}\bar z,\qquad
u=\frac{1+3(h+1)z}{2}.
\]

这里 h、t₀ 都是实数。利用 `z+bar z=−1`、`z bar z=1/3` 和
`(h+1)²−(h+1)=1`，直接得到 `u bar u=1`。
u∈A₁\R₂。在模2的四个分量中，`2u=(6,6,0,0)`，故两个配对
HG 坐标中的像都为 (6,0)。使用
`F16=F2[T]/(T⁴+T+1)`、η↦8、z↦6或7的四位整数表示。

令 T 为以下16个实代数数：

\[
T=\{\epsilon_0+\epsilon_1h+\epsilon_2t_0+\epsilon_3ht_0:
       \epsilon_j\in\{0,1\}\}.
\]

在 z↦6 的分量中，这四个基元的像依次为 `1,7,14,12`，在 F₂ 上
线性独立，故 T 的剩余像覆盖整个 F16。它们不含 ν，故四分量中的
第0、1分量相等，两个 HG 因子的以下图像也完全相同。

对 t∈T 定义

\[
q_t=\frac{1+2tz}{1+2t\bar z},\qquad
y_t=u(1-q_t)=\frac{2ut(\bar z-z)}{1+2t\bar z}.
\]

分母在每个2进分量中都为单位；由 R₂ 是完整2整阶，y_t∈R₂。
t 为实数保证 q_t 范数一，所以 `|u−y_t|=|u q_t|=1`。
又 `bar z−z≡1 mod2`，故 y_t 在每个配对 HG 因子上的像遍历
完整水平行 `{(x,0):x∈F16}`。

因此对任意 r∈R₂，u+r 有16个 R₂ 邻居 y_t+r；在任一因子上，
这些邻居遍历某个完整水平行。由第2、3节，无论 finite-precision 四色
边际 c 是哪一个，这16个邻居必见齐其四种颜色。

## 5. 同一陪集迫使四种额外颜色

u+R₂ 中的每一个点都被上述16个邻居禁止使用 c 的任何颜色。
而 u+R₂ 与 R₂ 的实际单位图平移同构，且 `χ(R₂)=4`；因此这一整
陪集还需要至少四种不在 c 的原始四色中的颜色。总计至少八色。

这里仅需一个有限的四色下界核心。令 a=−1−3z，取 R₂ 中的七点

\[
M=\{0,1,a,1+a,\nu,\nu a,\nu(1+a)\}.
\]

两个共享原点的菱形在任何三染色中都迫使各自的长对角两端同色；
而远端之间满足
`|(1+a)(1−ν)|²=3(2−5/3)=1`，矛盾。这是实际 Moser 七点核心。
将七个中心取为 u+m（m∈M），并各加入16个边界点 y_t+m，得到
至多 `7+7·16=119` 个明确代数点的 pinned 八色障碍。只需要上述
单位边子图即可证明相对下界；不宣称这119个点的普通图八色。

若只取两个中心 u、u+1，则34个点的全部实际单位边恰为

- 每个 y_t 到 u；每个 y_t+1 到 u+1；
- 各16对 y_t 与 y_t+1 的匹配边；
- u 与 u+1 之间的一条边。

共49边。这是16个四圈共用一条中心边的二分图。固定边界 c 后，
两个相邻中心都禁止原四色，故需两个额外颜色；不固定边界时只需二色。
这是相对 palette obstruction 与 ordinary non-five witness 的具体区别。
