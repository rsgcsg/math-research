# 六色最小 defect：反例、无限族与真正成立的 matching 定理

本文件的命题已在本轮给出证明，不宣称文献新颖性。
坐标 `(m,n)` 表示欧氏点 `(m+n/2, sqrt(3)n/2)`。距离平方为
`dm²+dm*dn+dn²`，单位方向按逆时针为
`(1,0),(0,1),(-1,1),(-1,0),(0,-1),(1,-1)`。
定义 `D(v)=6-|c(N(v))|`。proper 六染色中 D>=1；D=1 当且仅当
六个邻点看到其余五色，重数为 `(2,1,1,1,1)`。

## C001 / T004：行仿射族的完整分类

考虑 `c(m,n)=m+f(n) mod6`，记 `a_n=f(n+1)-f(n) mod6`。
中心第 n 行六邻色与中心色的差为

`1,-1,a_n,a_n-1,-a_(n-1),1-a_(n-1)`。

全部 wheel 最小 defect，当且仅当每个相邻增量对属于以下表。

| previous a_(n-1) | following a_n | 重复颜色差 |
|---|---|---|
| 2 | 3 | -1 |
| 3 | 2 | +1 |
| 3 | 3 | 3 |
| 4 | 4 | 3 |
| 4 | 5 | -1 |
| 5 | 4 | +1 |

证明：proper 排除增量0,1；把剩余16种代入上述六个差，要求其支持
恰好为1,...,5，得到表。程序另外穷举全部36对，避免依赖手工删选。

因此有两个闭合分量 `{2,3}`、`{4,5}`。第一分量是禁止22的二元序列；
第二分量是禁止55的二元序列。这是golden-mean shift，而非有限个周期相。
长度L的第一分量增量词有F_(L+2)个，纵向增长率log(phi)。这里是单方向
条纹熵，不是声称整个二维染色系统有正面积熵。

取交替增量2,3。写 `n=2t+r, r∈{0,1}`，得到

`c(m,n)=m+5t+2r mod6`。

其周期由 `(6,0),(1,2)` 生成，基本域12个顶点。
偶数行中心a重复a+1，奇数行中心a重复a-1。
例如 `(0,0)` 与 `(4,1)` 都为颜色0，但重复伙伴分别是1和5。
所以最小defect **不蕴含颜色级伙伴函数，更不蕴含全局syntheme**。
这个反例在整个无限三角格成立，增加同格overlap半径不能排除它。

## C002 / T005：任意二进制接缝族，重复始终对径

取两组颜色 `A_0,A_1,A_2` 和 `B_0,B_1,B_2`，下标模3。
任取双无限序列 `s_j∈Z/3Z`，满足

`s_j-s_(j-1) ∈ {0,-1}`。

定义

`c(2j,n)=A_n`,

`c(2j+1,n)=B_(n+s_j)`。

这是proper六染色，每个wheel恰好一个defect，而且重复总在对径邻点。

证明：奇列中心的六邻点里，两竖直邻点是B的其他两色；四个偶列邻点
的A下标依次为 `n,n+1,n,n-1`，因此A_n在水平对径处重复。
偶列中心两竖直邻点是A的其他两色。其四个B邻点下标为

`n+s_j, n+1+s_(j-1), n+s_(j-1), n-1+s_j`。

若两个s相同，水平对径的一对重复，其余两色各一次。
若s_j=s_(j-1)-1，第二、第四项相同，形成另一方向的对径重复；
其他两项是剩余两色。因此所有点proper且D=1。反过来，在这一形式
中若增量为+1，四个B点只使用两色，D>1；允许增量已精确分类。

每一段增量可以独立选0或-1，因此长度L有2^L种增量词；固定s_0后
可选择非周期双无限词，得到无横向周期的合法染色，仍有竖向周期3。
这不是声称已分类全部六色最小defect染色。

### 两个完美相之间的零额外defect接缝

令s_j=0 (j<0)，s_j=-1 (j>=0)。左侧matching是
`{A_i,B_i}`，右侧matching是 `{A_i,B_(i-1)}`，接缝处仍处处D=1。
所以不能从“两个matching相不同”直接推导缺陷密度增加或有限结束。

### 紧凑可读周期见证

取s_j=-j mod3。周期为 `(6,0),(0,3)`，18格的色表为

```text
n=0: 0 3 0 5 0 4
n=1: 1 4 1 3 1 5
n=2: 2 5 2 4 2 3
```

数字0,1,2表示A，3,4,5表示B。颜色0的重复伙伴分别可以是3、4、5。
`phase_checks.py` 检查全部18种位置以及一般增量的每种局部情况。

## T006：equitable 的额外假设确实恢复 matching

假设无限三角格有proper六染色，处处D=1，且同色顶点的邻色重数完全
相同。这就是equitable/role coloring。则存在一个固定perfect matching P，
其商矩阵恰为 `J-I+P`。因此路线图的matching结构在这个额外假设下成立。

证明：令p(a)是颜色a唯一的重复伙伴，b_ab=1+[p(a)=b] (a≠b)。
在越来越大的方盒中取各颜色频率的收敛子列，极限记为d_a。
每色的闭邻域覆盖全图，所以各d_a≥1/7>0。跨方盒边界的边仅O(R)，
内部边按两端计数给出详细平衡 `d_a b_ab=d_b b_ba`。

选d_a最大的a，令b=p(a)。平衡式为 `2d_a=d_b b_ba≤2d_a`，
所以d_b=d_a且p(b)=a。若有d_c<d_a，a,c之间平衡迫使p(c)=a；
b,c之间又迫使p(c)=b，矛盾。因此所有d_a相同。平衡现在说明b_ab=b_ba，
从而p是无不动点的对合，即perfect matching。证毕。

注意：此证明使用了三角格边界/面积比趋零，不应不加说明套到非amenable图。
它证明商矩阵形式，不证明每个matching只有一个几何相、不证明所有相周期、
不证明原始平面染色处处最小defect或equitable。

## C003：defect 支持可以是两个三角形

若把颜色分成两个固定三元组，要求重复伙伴始终留在自己的三元组，
6×6、8×8、9×6周期SAT模型都不可满足。但半径2、3、4、6的开放patch仍可满足。
随后8×12、12×8周期模型都找到SAT，揭示前面的失败仅是周期约束。

把SAT结果压缩后得到以下无需SAT的显式无限公式：

`q=(m-2n) mod8`, `g=floor(q/4)`,

`c(m,n)=3g + ((q mod2)+g-n) mod3`。

其周期由 `(8,0),(6,3)` 生成，基本域24个位置，索引为(q,n mod3)。
直接代入6个邻方向，24种情况均proper且D=1，每个颜色的重复伙伴
恰好可以是同组三元组的另外两种颜色。因此支持图恰为 `K3 ⊔ K3`，
不是matching，甚至不是二分图。完整有限代入表由`check_triangle_support`
产生和检查，是周期提升的精确证明证据；不借用SAT的否定结果。

这否定了“即使没有唯一伙伴，所有defect至少还跨一个固定3+3二分”的
补救猜想。下一层模型必须允许奇圈支持，或明确用真实几何排除它。
