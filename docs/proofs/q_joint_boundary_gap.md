## 1. T164：T162 还有一个单颜色类的精确对偶证明

记 T162 的36条 P 和12条 R 计分实现组成集合 F，九条 Q 链接为 b_i，
权重仍为 w=(2,1,1,1,1,2,2,0,2)，其和为12。取六个实际点

    H={229,231,233,877,887,4641}。

对实际单位图 W21 的任一独立集 A，包括空集，定义

    f(A)=sum_{ab in F} 1[a,b in A] - sum_i w_i 1[b_i subset A]。

精确的逐颜色不等式是

    f(A) >= 2 |A intersect H| - 3。                         (1)

### 有限证明及其完备性

检查器从全部实际单位边重建图，以最小可用顶点递归生成独立集：每次先输出当前集，
再把一个新顶点加入，并从剩余顶点删除其邻居。每个非空独立集按其唯一递增顶点序列
生成一次；空集也包含在内。对全部8232个独立集直接计算整数 f 和右端。
第二种算法逐一检查全部2^21=2097152个子集，用最低位递推判定独立性，核对集合完全相同。
两者不读优化器输出，几何使用精确数域运算。

| H 内点数 | 独立集上的最小 f(A) | 对应下界 |
|---|---:|---:|
| 0 | −3 | −3 |
| 1 | −1 | −1 |
| 2 | 1 | 1 |
| 3 | 3 | 3 |

H 的诱导单位图恰含229--887、231--4641、233--877三条边，故更大的交集不可能。
共564个独立集在(1)取等。这个证明是精确有限核验，不声称为一般图的解析分类。

若 c 使用至多 k 个颜色，把颜色类补空集到恰好 k 个。每个 H 顶点出现一次，故

    sum_color f(A_color) >= 12-3k。

左端等于 S(c)−sum_i w_i e(b_i)。于是对任意正整数 k 和任意 proper 至多 k 色词，

    S(c)+sum_i w_i(1-e(b_i)) >= 24-3k。                    (2)

k=5 就是 T162。这里没有声称每个 k 的界都尖锐；T162 的逐链接系数最优性仍由
已认证的九个单链接失效词证明。这是一个独立、显著更小的 T162 验证路线。

## 2. (1) 的准确方法边界：它已经对分数颜色类覆盖成立

定义一个分数颜色类覆盖为独立集上的非负权重 ν_A，满足

    sum_A ν_A <= k，   sum_{A containing v} ν_A=1（每个实际点 v）。

其点对矩是 M_ab=sum_{A containing a,b}ν_A。任一随机 proper 至多 k 块划分都会
产生这样的覆盖：ν_A 是颜色类 A 出现个数的期望。反方向没有被假定。
将(1)按 ν_A 加权得到

    sum_{ab in F} M_ab - sum_i w_i M_{b_i} >= 12-3k。

故(2)也对这些覆盖的点对矩成立。这明确定位了 T162 的强度：它尚未超越此单独立集
矩外放松。不能仅凭“颜色容量”的叙述，把它当作排除了分数颜色覆盖与完整划分之间的缺口。

## 3. T165：在 p=1/27 面上严格收紧 q 上界

对象是 W22=W21∪{305} 的完整所选边际模型：34条全部实际单位边，以及47条 P、
11条 Q、31条 R 事件；每条事件分别有公共均值 p、q、r。概率支持数任意。

### 第一步：边界迫使每一份划分同时在七个窗口取等

T163 中的七点计数和实际 PRR 三角都在 W22 内：

    12p+3r>=2， 2r-p<=1。

所以 p=1/27 迫使 r=14/27。证书指定以下七个重叠窗口：

    [31,33,227,229,231,875,877]
    [33,35,229,231,233,877,887]
    [35,37,231,233,235,887,889]
    [227,229,873,875,877,3477,3483]
    [229,231,875,877,887,3483,4641]
    [231,233,877,887,889,4641,5535]
    [877,887,3483,4641,5535,7479,7489]

每个窗口的全部21个点对恰分为6条 E、12条 P、3条 R。七点分入至多五块至少产生
两对同色点。令 Z_j 为第 j 个窗口的同色对数减2，则每份 proper 五色词有 Z_j>=0，
而在指定边界 E[Z_j]=12p+3r−2=0。因此 Z_j=0 几乎处处，七个窗口同时成立。
对实际三角 (229,4641,305)，还令

    T=1-e(229,4641)-e(305,4641)+e(229,305)>=0。

它的期望也为0，故 T=0 几乎处处。此论证没有固定支持数。

### 第二步：一个完整整数分离式

证书列出全部89条实际 P/Q/R 点对及整数系数 α_ab，定义

    L(c)=sum_ab α_ab e(a,b)。

系数表以实际点编号存储；不是浮点对偶向量。各类系数和为

    sum_P α=-2267， sum_Q α=500， sum_R α=-501。           (3)

在 Z_1=...=Z_7=T=0 的所有 proper 至多五块划分上，精确有

    L(c)<=2。                                             (4)

独立 Python 检查器从实际几何重建约束，并按 restricted-growth 规则枚举：首颜色0，
此后只允许已有颜色或一个新颜色，至多五色。用颜色类位掩码检查单位边；用每个窗口
各色占用数维护同色对数。仅当违反单位边、某窗口已超过2对、完成窗口不等于2对，
或已完成 PRR 三角的 T 非零时剪枝。这些剪枝只去掉不满足必要等号条件的词。

完整遍历11909676个递归节点，得到5648160份规范 proper 划分，最大整数 L 恰为2。
与独立 C++ 发现程序的完整计数一致；验收器不导入该程序、其事件矩阵、浮点优化器或
压缩词池。这证明(4)，不把求解超时或有限候选支持失败当成否定。

对(4)取期望并代入(3)，得

    -2267p+500q-501r<=2。

因此

    p=1/27 ==> r=14/27， q<=1867/2700≈0.69148148。         (5)

这严格改进 T162 在同一边界给出的95/108≈0.87962963。
**未声称1867/2700是最优上界，也未声称排除了整个 p=1/27 面。**
T163 的 (1/27,1/3,14/27) 精确正律仍然存在于这个22点模型。

### 第三步：一个保守但无条件有效的提升

L 中全部正系数之和为1323，所以每份词都满足 L<=1323。令

    D(c)=sum_{j=1}^7 Z_j(c)+T(c)，

则 D 是非负整数。D=0 时由(4)有 L<=2；D>=1 时由粗上界有 L<=2+1321D。
对任意支持的平衡律取期望，E[D]=85p+19r−13，于是

    500q <= 114552p+25600r−17171。                       (6)

这不假设 p=1/27，故对任意全Y P/Q/R平衡律也必要。常数1321只是安全罚项，不主张最优；
此界主要在原下界附近有用。再用2r−p<=1可得1000q<=254704p−8742。
不能把(6)解释为 full15 的不可行证书。

## 4. C030：实际22点、逐事件均匀的分数覆盖不是完整划分律

证书给出 W22 上99个实际独立集的正有理权重，公分母为6110370。直接整数检查得到

    sum_A ν_A=5，
    sum_{A containing v} ν_A=1（全部22个点），
    M_ab=1/27（全部47条P），7/10（全部11条Q），14/27（全部31条R）。

权重之和是5而不是1；这不是99份整图着色组成的概率律，独立集也不是一份划分中的
共同颜色类。检查器验证所有独立集不含任何实际单位边，并逐顶点、逐点对交叉相乘，
没有只核对三类事件的平均总数。

M=sum_A ν_A 1_A 1_A^T 是一个完全正矩阵，单位边矩元为0、对角元为1。
还可把每个向量增广成(1,1_A)，从而同时见证总质量5和所有单点覆盖约束。
它通过本节单颜色不等式及相应外放松；其 (p,q,r) 也满足 T157–T160/T162 已记载的
无条件标量必要式。然而，如果有相同所选点对矩的 proper 五块划分律，(5)将要求

    7/10 <= 1867/2700，

矛盾。两者差为23/2700；整数分离量 E[L]−2=115/27>0。
因此该精确分数覆盖的这些实际边际不能来自任何 W22 proper 五块划分律。

这是现有真实 P/Q/R 颜色核中的联合一致性缺口，比单纯“算法没找到延拓”更明确。
它不是全Y的分数律、full15的反例或新的平面色数界，也不主张是此类分数缺口的首例。
