# E043：五次旋转三中心的真实联合仍投影到 Parts509

2026-09-10。这里是一个新有限候选的独立精确认证，不是数域上界或
HN 新下界。没有将周期商、固定旧颜色失败或求解器 UNKNOWN 当成负证据。

## 1. 精确对象及结果

令 P 为已经独立认证的 Parts509 坐标集，按复坐标识别平面，令

`F=Q(i,√3,√11,√5), η=exp(2πi/5), ω=(1+i√3)/2`。

取真正的有限平面点集

`G = P ∪ ηP ∪ [η(P−1)+1] ∪ [η(P−ω)+ω]`，

图边为点集中**全部**实际单位距离对。三个中心确实属于 P，其原始
编号分别为 `0,153,150`，坐标分母统一为96。每个旋转保持方向，
本实验没有加入反向旋转或任意其他中心。

完整精确结果：

| 项目 | 数量 |
|---|---:|
| 不同物理点 | 2033 |
| 不同点对 | 2065528 |
| 诱导单位边 | 10169 |
| 属于某个原始副本的边 | 9768 |
| 副本内边之外的真实跨边 | 401 |

自由五色求解只固定原始三角形的三个颜色以消除全局颜色重命名，
没有固定任何 Parts 完整色词；在100000冲突预算内，91次冲突后
得到 SAT。完整2033点色词保存并由独立检查器逐边核验。

但正解还有更强、更简单的解释：每个副本的顶点都映回其原始 Parts
编号，此映射在物理重合点上一致，而且将**每条真实单位边映为 P
的一条实际单位边**。因此这个具体 G 有图同态 `G→P`。由于包含
P，结合原有 Parts 五色下界，得到这个有限诱导图恰五色。

这项投影不是仅验证一份色词的偶然异色：它意味着 P 的任意合法
染色都能通过同一个映射拉回 G。证书也保存了对原 Parts 色词的
四个恒等颜色 frame，作为另一份独立可直接核验的正构造。

## 2. 精确代数与所有点对的覆盖

令 `t=(√5−1)/2`。有

`η²=tη−1, conjugate(η)=t−η`。

由于 F 是多二次 Galois 扩张，其 Galois 群指数为2；它不可能包含
Galois 群为循环四阶群的 `Q(η)`，因为子扩张的群是该群的商。
而 F 已含√5，所以 η 在 F 上恰有次数2。因此 `{1,η}` 是 F 基，
和 F 的16维有理基一起给出真实数域 E=F(η) 的32维有理基。
坐标系数比较不是在一个可能额外塌缩的形式代数中进行。

本实验的每个点写为 `(u+ηv)/96`，u,v 使用整数 F 基系数。
未旋转副本有 `v=0`；中心 a 的旋转副本写为 `a+η(p−a)`。
完整系数元组去重，而不是按标号出现计数，所以三个与原始 P
共享的旋转中心各只计一个物理点。

对任意差 `w=u+ηv`，直接展开共轭得

`|w|² = u·bar(u)+v·bar(v)+t·u·bar(v)`
`        + η[v·bar(u)−u·bar(v)]`。

搜索器按两个 F 系数分别检查，使用两倍常数项避免 t 的分母2。
独立检查器不采用这个分拆公式：它由平方自由根式的 gcd 乘法
建立所有32×32个两倍基乘积，直接计算
`2w·(2bar(w))=4|w|²`，和目标 `4·96²` 比较。

两个程序都扫描全部2065528个不同物理点对。搜索器先在完全分裂
素数1021中筛选，再精确检查11848个幸存对；独立检查器另用4261，
从五次单位根反推√5的剩余像，并核验全部1024个基乘法等式后筛选。
该独立筛选留下10400对，全部用上述32维直接乘法检查。若实际距离
平方为1，其环同态像必为1，所以筛选不可能遗漏任何实际单位边。
这里不是用有限域条件冒充实单位距离，只用其必要性排除非边候选。

完整物理点表和完整边表分别得到以下 SHA256，两个程序一致：

- 点表：`c58eb951f41848d3df99eff586a786a9a4a8e87fc365660f5f78b511cd93e6cc`
- 边表：`b13fece42133e72a2c8f6c3ba89fd0d4ce6933f1273525fbb08269e1ea8850e2`

## 3. 真正的成功／失败机制

原始副本到三个旋转副本之间，没有任何不已属于某个副本的实际边。
401条新增边全部在三个旋转副本之间：

| 旋转中心对 | 新增单位边 |
|---|---:|
| 0 与 1 | 129 |
| 0 与 ω | 136 |
| 1 与 ω | 136 |

独立检查器从每点所属副本和原始编号重新验证：物理重合没有产生
相异原始编号，每条新增边的两个原始编号本来就由 P 中单位边连接。
所有副本内边当然也保单位。故投影证据覆盖全部10169条实际边，
不只覆盖新增边，不依赖求解器的 SAT 字符串或搜索器的接触分类。

所以“401条新跨边”和“越过旧多二次数域的姿态”在这里仍没有产生
新的颜色困难：整个有限联合关系被原 P 的已有单位边吸收。继续
更换这四份副本的颜色 frame 不会带来下界收益；它们连恒等 frame
都已经相容。这是本轮对一个具体新入口的结构性否定结果。

## 4. 范围、非结论与重放

没有证明任意中心集合、无限平移闭包、完整 F+ηF=F(η)、整个
E 平面或原始 HN 的五色性。有限投影性质不能外推到上述宿主。
也没有证明这一抽象图的所有单位实现都必须逃离旧域。

证书：`certificates/quintic_core_probe.json`。它固定原 Parts 坐标
文件的 SHA256，并保存生成参数、完整自由五色词、正 frame 及
投影诊断。原始五色下界的离线 RUP/LRAT 重放仍由已有
`verify_parts_core.py` 等项目检查负责，本检查器没有另造一个
五色下界，也不把源坐标文件里的状态字符串当成证明。

```sh
.venv/bin/python research/quintic_core_probe.py --budget 100000 --centers 3
python3 research/verify_quintic_core_probe.py
make check
```

后续应改变真正破坏上述投影的几何，而非增加这次易解 SAT 的预算。
原问题没有新上下界；本轮得到的是一个真实新宿主的有限恰五色
证据，以及足以解释它的完整图同态。
