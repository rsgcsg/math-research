\frac{(|U|-7|\mathrm{Mix}\cap N_T[U]|)_+}{|N_T[U]|}.
}
\]

**证明（注意严格的覆盖重数）：**
1. 把v∈U称为未被混色片覆盖的中心，若B₁(v)∩Mix=∅。它的7片都存在占比≥1−η的主导颜色；鸽巢原理保证两片H,K具有同一个主导颜色i。
2. 取其单位点对p∈H,q=p+u∈K与共同内部半径r。令D=B(p,r/2)，对角度\(|\theta-\arg(u)|<r/4\)，其单位方向w满足|w−u|<r/4，所以D+w⊂B(q,r)⊂K。两个完整六角片中非颜色i的总漏失各≤ηM。于是对每个这种θ，能够同时落在颜色i上的x∈D与x+w的面积至少
\[
|D|-2\eta M=\pi r²/4-\pi r²/8=\pi r²/8>0.
\]
角度区间长r/2，所以每个未覆盖的星贡献至少 \(\pi r^3/16\) 的未归一化坏针质量，并且其坏针起点x严格落在所选星的一片H内。
3. 当我们对所有星的上述坏针子集求和时，每个固定(x,θ)在至多**七个**星里被计数：唯一包含x的六角片H_z至多属于七个B₁(v)，无论每个星选择哪一对片都成立。因此
\[
7J_{\Omega_U}(c)\ge(\pi r³/16)\cdot|\{v\in U:B₁(v)\cap Mix=\varnothing\}|.
\]
4. 一个混色格z最多属于七个星B₁(v)，所以未覆盖星数≥|U|−7|Mix∩N_T[U]|。合并得公式。最后用r³=(3/20)³、M=6√3/25计算\(r³/(224M)=9/(143360\sqrt3)\)。证毕。

**热力学解释与新的证明桥梁：**如果把U取成三角格越来越大的Følner方块，周期c的全平面单位针能量E_per恰好满足
\[
\boxed{E_{\rm per}(c)\ge C_*\,(1-7d_{\rm mix}^{+})_+}
\]
其中\(d_{\rm mix}^{+}\)是沿该网格Følner序列的混色格**上密度**；这一推论用周期有界函数g(x)的空间平均收敛和|N_T[U]|/|U|→1。若Eper=0则\(d_{\rm mix}^{+}\ge1/7\)，回收前轮必混色结论；若混色低于1/7的固定比例，则无论如何安排余下全部颜色，都必留下严格正的单位坏针能量。

**这是一个真正“有余量”的几何结构二择，而不是七色下界**：至今没有证明当强混色格密度≥1/7时仍被迫有正坏针能量。下阶段最尖锐的缺口恰好是**第二种情形**，可用R2026-SIX-MIXED-SUM的多位置调色板共同标签、full15共同law或跨六角片界面结构攻击。不得用单片Shannon面积熵、低阶二点PSD去自动替代这一证明。
