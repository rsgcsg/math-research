# T171：连 P/Q/R 三类总量也无法分离 C030

2026-10-06（Australia/Brisbane）。接续 T170。T170 已证明 C030 的 11-Q 均匀向量
((7/10)^{11}) 在 T165 边界 proper 五块划分的 Q 投影凸包内。本页进一步证明：
即使保留 P、Q、R 三类事件的**总同色数**，仍然看不见 C030 的矛盾。

没有新的普通 Hadwiger–Nelson 界；任意支持 full15 仍未解决。

## 3. 推论：任何 class-total 线性式都不够

设一个线性不等式只通过三个总量观察划分：

[
aN_P+bN_Q+cN_Rle d.
]

若它对所有 T165 边界 proper 五块划分有效，则对上面的四原子混合取期望，
必然也在 C030 的总量点上成立。因此**不存在任何只依赖三类总和的线性严格分离式**
可以解释 C030。

这比 T170 再前进一步：

- T170：只看11条 Q 的全部身份信息仍不足；
- T171：即使加入 P/Q/R 三类总量，也不足。

所以真正 separator 必须使用**至少某些具体边的身份**，而不是只知道“P类一共多少、
Q类一共多少、R类一共多少”。T165 的非均匀89项整数系数因此不是单纯缩放三个总计数。

## 4. 仍然不是 C030 正律

四原子混合只匹配三类总量。它不使每条 P 都等于1/27、不使每条 Q 都等于7/10，
也不使每条 R 都等于14/27。检查器显式拒绝把它误认成逐事件平衡律。

因此本结果只是一个投影可行性定理，不是 full Y/full15 正律。
