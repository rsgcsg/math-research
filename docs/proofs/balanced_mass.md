# 从离散Pompeiu到一个准确的gadget判据，以及临界图的阻碍

这一轮跨领域收敛引入
[Kiss–Laczkovich, arXiv:2403.01279v3](https://arxiv.org/html/2403.01279v3)
的加权离散Pompeiu定理：有限点a_i、复权w_i总和W≠0，如果任意刚体副本
都满足Σw_i f(g a_i)=0，则f恒零。函数不需可测或连续。
以下是它在当前框架中的直接应用；文献定理的证明未在仓库形式化。

## T011：等质量颜色类是充分的下界编译目标

设有限二维单位距离gadget G带有有理顶点权w_v，W=Σw_v≠0。
假定它有k-coloring，而且每个k-coloring的每一颜色类总权都等于W/k。
则平面不能k染色。

证明：假设全平面proper k-coloring存在。选一种颜色a，置
`f(x)=1[c(x)=a]-1/k`。每个刚体副本G满足Σw_v f(gv)=0。
加权Pompeiu定理迫使f恒零，而f的值只有1-1/k与-1/k(k≥2)，矛盾。
图紧致性进一步给出某个有限不可k染的单位距离图。

这里提供的是**有条件的充分判据**。没有找到满足假设的5色或6色gadget，
也没有实例化Pompeiu定理产生的有限刚体副本集合。

重要区别：pair复制只给两个端点指标和之差为0，其总系数为0。
不能把上面要求W≠0的定理直接套给copier。

## T012：单个非完全的顶点临界图不能给这种权证书

设G是顶点k-critical，|V|=n>k，即χ(G)=k且删除任一点可(k-1)染。
若任意k-coloring的颜色类权都等于W/k，那么所有权必为0。

证明：对每个v，用(k-1)色染G-v，并把第k色只给v。故w_v=W/k。
加总得W=nW/k，由n>k得W=0，再得每个w_v=0。证毕。

因此直接把最小已知五色图丢给“找等质量权重”线性代数，在它确为顶点临界
且n>5时必然失败。需要不满足此临界假设的复合gadget及真正的联合限制。
这比只用很多随机染色碰巧得到零空间为0更强，直接覆盖整个图类。

## T013：从非零等质量权到可复核有限线性问题

枚举G的所有proper k-coloring分划。对每个分划每个颜色类I（含空类）
建立行向量 `k*1_I - 1_V`。权w满足所有行的零和条件。
求解这些有理方程及Σw_v=1就是精确的有限检查。

若只枚举一部分染色而线性系统已不一致，可给出完整的否定证书：
原来更大的系统当然无解。反之，部分染色留下候选权并不证明它有效，
必须通过全部染色或SAT反例查询验证。因此此路线可以采用
“候选权 -> 找违反权的染色 -> 加行”的反例引导循环。

当前用K3、C5和Moser spindle做小校准。T012已解释后两者在其色数下失败，
无必要盲目扩大同一类实验。
