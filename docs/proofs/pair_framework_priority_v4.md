# Pair-interface推广的自主重审：什么仍可能触及原问题

2026-09-09；起始基线`c283141`。用户提供的1284行框架全文已读，
参考但不作为执行指令。文件与哈希见`references/SOURCES.md`。

## 1. 结论先行

当前没有根据给HN答案5、6、7分配可信概率，更没有终局证明。
按“能否改变原问题的量词”而非最近代码的方便程度，保留两个主攻方向：

1. **真实几何宿主与全部边界关系一起求解的五色下界。**
   搜索对象必须是完整图，或能证明等价于完整图的关系消元；
   不把提高Bad_5密度作为单独第一优先。
2. **超越首层有限剩余编码的普适上界。**
   具体第一关仍是E=K(√13)，但本轮T053/T054证明“换素数”与
   “有限多个各向异性奇剩余域的首层联合编码”均不能给≤6色。
   因此下一候选必须确实使用未被覆盖的信息，而非继续枚举小有限域。

六色(4,6)-core暂列储备，不与这两条争夺主优先级。它更换了目标参数，
却没有减轻全边界activation的量词要求；已有Parts足以给条件坏关系，
缺的不是再确认一次条件坏关系存在。

这与参考文档的“core optimization第一”有实质区别。接口语言值得保留，
但局部关系设计只有在一个真实宿主候选提出具体需求时才优先计算。

## 2. 参考文档中可直接重证的基础部分

### Clean pair-shell确实是精确名单编译器

设H为**非空有限**二维单位距离点图。逐点在v处附加等边三角形
v,a_v,b_v。旋转方向可避开有限个碰撞及非预期单位距离：对每个
旧点w≠v，新端点绕v的圆与以w为心的单位圆至多交两点，重合
同样只有有限坏角。与v及同三角形另一端点的预期边不列为坏条件。
后加三角形检查所有先前点，故最后边界图恰为一个matching。

若原坐标在实域F内，方向取有理单位圆参数即可使新坐标在F(√3)；
如果F含√3，不需要扩大域。这里使用的是无限候选方向避开有限坏集，
并不声称任意事先指定方向都会干净。

对k≥3，proper边界每对使用不同颜色，内部名单恰为其补集，
大小k−2。由于没有其他新边，边界可延伸当且仅当H可按该名单染色。
所有这样的名单都能由matching边界实现。因此全边界延伸等价于
H的(k−2,k)-choosability。

另一方面，先用q=max{3,χ(H)}染H，再在各三角形给两端选另外两色，
得到`χ(S(H))=max{3,χ(H)}`。这不是下界放大器。
H为空时应单独处理，不能机械套max{3,χ(H)}。

### 低度与局部邻域筛选正确，但不是完备约化

参考文档的最大度≤k−2筛选是list-Brooks的直接应用，k≥5且
二维UDG不含K4；顶点极小坏名单子图须δ≥k−2且Δ≥k−1。
这是坏**名单核**的条件。真正顶点极小的不可k染图须δ≥k，
两者不要混用，更不能把任意UDG假定为pair-shell。

单位圆邻域由旋转60度的六点轨道分解成C6的诱导子图，故二分。
它阻止仅用同一圆周内部单位边强迫三个颜色；不阻止外部宿主
通过其他点迫使圆周邻居使用更多颜色。

## 3. T055：六色及以上的pair坏核不能来自二分图

**定理。** 对k≥6，任意二分图H均为(k−2,k)-choosable，
无论点数、最大度或通常list chromatic number多大。
因此`Bad_k(H)=∅`。

**证明。** 把[k]分成两个不交色块A、B，使二者大小都≤k−3；
k≥6时取尽量均分即可。任一大小k−2的名单必同时与两块相交。
H的二分之一只用A中的允许色，另一半只用B中的允许色。
每边跨两块，所以染色合法。k=6时正是3+3分割。证毕。

这是成熟的“每个二分图均(r,2r−2)-choosable”的直接应用，
不是声称新发现列表染色定理。原文核验：
[Bonamy–Kang, Introduction及§2](https://arxiv.org/html/1507.03495v2)。
独立有限检查覆盖六色的20个三色块×15份四名单；无限图规模由上述
直接构造处理，不由这300个检查外推。

尤其，参考文档所提hypercube的高名单色数不能产生六色pair坏关系。
五色(3,5)则处于`ell=2r−1`而非`ell≤2r−2`，不能照搬此论证。
这说明从五色推广到六色并非只是把10种forbidden pair换成15种：
可承载坏关系的结构类别本身变了。最小六色坏核还须非二分。

## 4. Bad-set pressure可趋近1，而普通色数完全不增加

若H由n份无跨边的同一核心M组成，独立均匀选择各点forbidden pair，
则

`ρ_k(H)=1−(1−ρ_k(M))^n`。

这是因为联合可染当且仅当每份核心可染。取M为当前spindle、k=5，
T037给10^7份名单中恰10份坏名单，故`ρ_5(M)=10^(-6)`。
于是ρ_5(H)可任意接近1，但χ(H)=χ(S(H))=4。
任意多副本可用足够大的平移彼此分开，保持真实二维单位实现。

即使要求核心连通，也可把这些副本用单条桥依次连接，保留χ=4：
每步通过颜色重命名满足桥；几何上绕桥端的自由方向避开有限坏角。
原任一spindle子图的坏名单仍使整图无解，故上述式子仍给ρ的下界。
所以仅加“连通”条件也不能拯救把均匀坏比例作为进度度量的做法。

这不否认在**固定规模、固定真实宿主、固定几何代价**下比较坏关系
可能有用；它排除的是“ρ越来越大，所以更接近HN”的推断。

对真实宿主A、边界B，`μ(Bad)=1`等价于完整activation，还需μ
对`R_k(A,B)`中**每个可实现边界状态赋正质量**。若只取某份坏边界
上的点质量，就可人为得到1而遗漏其他逃逸。不存在宿主k染色时
R为空，已经是下界；不要用空分布包装这一情况。

## 5. 本轮实际推进：为算术路线找到了一个方法层面的终止条件

完整证明见[T053–T054](residue_method_obstruction.md)。

- 有限单位图的正确谱界迫使≤6色各向异性奇剩余目标满足q≤97。
- 全部14个素数幂中，K只允许F11；四种既有逃域扩张又都排除F11。
- 进一步证明所有有限多模首层编码都失败：CRT使源图覆盖目标
  张量积的每条边，而张量谱界仍严格超过6。

这一结论比T030的“固定11进积分窗口失效”不同且更强于换素数方向：
它覆盖任意素数选择和任意有限多模首层颜色函数。
但它**没有**证明E²不可五染或不可六染。

因此，以前“保留算术扩域上界”需要加上更明确的门槛：候选必须
使用高阶剩余信息、依赖深度的状态、各向同性/2进结构，或根本
不属于这种有限剩余编码。实代数转移给出了最终终点，不自动提供
一个能到达终点的方法。

## 6. 下一轮怎样才算继续朝原问题推进

### 主攻一：联合几何＋完整五染色，而非指定边界

最小可执行研究对象是不能被T051/T052逐步锁域的真实模块网络。
必须一起保留相对姿态、所有实际跨单位边，以及外部宿主的所有
合法染色；若用关系消元，变量识别必须对应同一物理点。

对于已知K模板，先过锁域与安全扩域筛选；若整个图仍在安全域，
不再投入下界搜索。若找到SAT，保存全图染色并找逃逸机制；
若得到UNSAT，只有精确几何和独立可重放证明才算不可五染证据。
超时仍为UNKNOWN，未取得证书不得写新界。

### 主攻二：E_13的非首层普适五/六色编码

下一份猜想必须先解释如何同时处理T030无界深度以及T054多模限制。
若只提出一个更大的有限域表或有限多个首层表，已不必运行。
即使解决E_13，也仍须给出覆盖任意实代数有限配置的扩张/分解，
才可借紧性与实闭域转移到原平面。

### 储备：只为真实activation需求设计新的core

保留六色非(4,6)-choosable小核问题；但先排除二分核和低度核。
没有真实宿主需求时不继续10^n或15^n全表扩张。

这些是研究优先级，不是结论概率。当前最具体的新成果是方法限制
及精确检查，距离最终HN答案仍有实质缺口。
