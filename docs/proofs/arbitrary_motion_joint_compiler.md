## 1. 输入与有限构造

设 X 为非空有限平面点集，Ωₖ(X) 为其全部实际单位边的 proper k 色词。
给定 s 个划分事件 e：源组 Aₑ⊂X、全局刚体运动
gₑ(x)=rₑx+aₑ、像组 gₑAₑ⊂X，以及该组一个完整划分 τₑ。
令 dₑ(c) 为源组与像组取得 τₑ 的两个指示值之差。

假定已严格证明

Σₑ yₑdₑ(c)≥δ>0，对每个 c∈Ωₖ(X)。

若 Ωₖ(X) 为空，直接返回 X。否则 W=Σ|yₑ|>0。
选定反射 S(x)=bar(x)。将每个 rₑ 写成 R(wₑ)S^{εₑ}，其中
R(v)=R₁^{v₁}⋯R_d^{v_d}、Rᵢ 为平面旋转、wₑ∈Zᵈ。
总能为每个事件各选一个旋转生成元，所以可取 d≤s、‖wₑ‖₁≤1；
rₑ=S 或 rₑ=1 时允许 wₑ=0。无需这些旋转独立或有有限阶。

先给一般盒大小：取 N,B≥0，L=2N+1、J=2B+1，满足

Σₑ |yₑ|(‖wₑ‖₁/L+1/J)<δ。                         (1)

令方向**索引集** I={−N,…,N}ᵈ×{0,1}，u_{v,ε}=R(v)S^ε。
定义 m=s|I| 个平移向量 t_{i,e}=uᵢaₑ，以及

T(n)=Σ_{i∈I,e} n_{i,e}t_{i,e}，n∈Zᵐ。

**T105。下列实际有限点集的诱导单位图不可 k 染：**

Y=⋃_{i∈I,n∈{−B,…,B}ᵐ}(T(n)+uᵢX)。             (2)

其点数不超过 |X|·2Lᵈ·J^{2sLᵈ}。使用各事件自己的旋转生成元时，
可以统一取 N=B=⌈W/δ⌉，因为 2W/(2N+1)<δ。
若坐标为实代数数且 y、δ 为有理数，(2) 仅需有限次精确加乘及等距变换。
巨大大小界不保证实际可承受的证书规模。

平移列表随方向盒 N 增长；没有假设无限阶旋转保持一个固定的有限
生成整数格。点数界中的指数 2sLᵈ 也随 N 增长，这只是一个粗构造
上界，不证明最小见证或最短反证必然爆炸。

## 2. 两种边界，严格索引配对

反设 Y 有 proper 染色 C。每个索引 (n,i) 给出 X 上 proper 词
c_{n,i}(x)=C(T(n)+uᵢx)。允许不同索引对应同一物理副本；全部保留重数。

右复合 gₑ 后，有

(T(n)+uᵢ·)∘gₑ=T(n)+uᵢaₑ+uᵢrₑ·。

若 i=(v,ε)，则平面旋转可交换且 S R(w) S=R(−w)，所以新方向索引为

i′=(v+(−1)^εwₑ, ε xor εₑ)。

新平移索引为 n′=n+e_{(i,e)}，即把来源方向对应的一个坐标加 1。
固定 T 使用整个 I 中的平移向量；它不随目的方向 i′ 改变。
于是当 i′∈I 且 n′∈{−B,…,B}ᵐ 时，两刚体副本完全相同。

此配对单射：i′ 唯一恢复 i，随后 n′ 唯一恢复 n。即使 R(v) 的
实际方向重合或 T 非单射，也不影响索引层的单射。

方向盒未配对比例至多 ‖wₑ‖₁/L；平移盒在一个指定坐标损失比例
1/J。并集界给出总损失至多两者之和。源端指示值之和与像端
指示值之和在配对部分抵消；两端各剩相同数量项，每项在 [0,1]。
因此平均差的绝对值至多损失比例，而不需额外乘 2。

所有未配对像事件也有定义，因为 gₑAₑ⊂X；我们从未对 Y 外的
整份 gₑX 假设颜色。对输入分离式作索引平均，即得

δ≤Σₑ |yₑ|(‖wₑ‖₁/L+1/J)<δ，矛盾。□

完整划分块也可像 T096 一样用系数振幅代替该块的绝对值和。
这里先保留简单的统一界，不另声称最优大小。

## 3. 一个完全精确的非 HN 校准

令 a=√3，b=√(a/2)，c=(a−1)/2，所以 c²+b²=1。
X 为以下两个相距足够远的路径的并集（坐标写为复数）：

A=(0, a/2+i/2, a)，
B=(10, 11, 10+(a+1)/2+ib, 10+a)。

独立核验全部 21 点对，实际图恰为 P₃⊔P₄，有四份 proper 二色词。
平移 g(x)=x+10 把 A 的两端映到 B 的两端。每份二色词中 A 两端
同色、B 两端异色，因此“端点同色”事件的差恒为 1：y=δ=1。

取 d=0、N=B=1，两个方向索引对应恒等与共轭，两个平移向量都是
10。(2) 实際去重后有 37 点、50 条单位边，其中包含单位五圈

0 → a/2+i/2 → a → (a+1)/2+ib → 1 → 0。

其每条边长度平方直接等于 1。此校准既有 proper 输入词，又有真正
全词分离和实际不可二染输出，不是从一个本来无词的输入作空泛验证。
它不是 NON5，也不提高 HN 下界。

[独立校准程序](../../research/verify_affine_joint_compiler.py)仅用有理数
及基 1,a,b,ab 的乘法；该基独立，因为 (2b)⁴=12 的多项式
x⁴−12 在素数 3 处 Eisenstein。另枚举 d=s=N=B=1 的非平凡方向索引例，
两个反射奇偶情形均核验 4374 个索引中 1944 个成功配对、单射性及
5/9≤1/3+1/3 的边界界。有限校准不替代第 2 节的一般证明。

## 4. 对下一路线的意义与非结论

T103/T104 已关闭当前 X 的整个 M⋊H₃₀ 事件族；只能换到该群之外，
或加入真正新点。例如 ν=(5+i√11)/6 是代数无限阶旋转。
其模平方为 1；若是单位根，ν+bar(ν)=5/3 应为有理代数整数，矛盾。
从含 ν 的有限运动族发现真正全词分离时，现在也有明确有限构造，
不必再猜一个有限方向闭包、统一平移格或二维 Gram 实现。

未闭合的核心依然是：找到并独立认证对 **全部 Ω₅(X)** 有效的
严格分离式。库内分离、固定仿射模型 UNSAT、有限周期失败及 UNKNOWN
均不满足输入。T105 不解决上界共尾问题，也不为 χ=6 提供新证据。
