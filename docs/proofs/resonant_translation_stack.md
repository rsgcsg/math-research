## 1. T072：完整无限图的有限位移描述

结论如下。每个X中的点唯一写为

`p_i+ℓ(a,b,c,d)+α(me₁+ne₂)`。

1. 同一α中心内，全部单位边恰由证书中的8008条有向记录
   `(i,j,Δa,Δb,Δc,Δd)`给出，对任意整数起点平移都适用。
2. 非零α中心差只有平方长N=3、4；所有跨层边只连接相同核心编号。
   每编号恰有24种有向位移记录。
3. 因而整个X的单位图是509个编号、20224条有向边轨道的Z⁶移位图。
   这是一份**无限图的完整描述**，不是某个有限周期上的SAT结论。

### 1.1 无重合及跨层同编号

P的坐标在分母96的八维平方自由基中，x的√3系数和y的有理系数
均为0。若`p_j−p_i∈L'`，比较这两个系数先得c=d=0。
其余坐标与ℓ(a,b,0,0)相等，且分母96与13互素，迫使13整除a,b。
所以非零差必属于7Λ，其迹长度至少7；P的迹直径恰4，矛盾。
因此`(P−P)∩L'={0}`，P+L'表达唯一。α不在K中，再得到α中心唯一。

T067的系数比较给任意跨层单位边

`u·δ=0, |u|²+(40/169)|δ|²=1`。

实高度只允许N=1、3、4，N=1需要√129/13，而129=3·43的平方类
不在K中。其余两壳位移分别是

`u=±(7/(13√3))Jδ`（N=3），
`u=±(3/26)Jδ`（N=4）。

它们全在L'中。所以跨边再一次迫使`p_j−p_i∈L'`，必有i=j。
N=3将(a,b)改变一个Λ单位步，中心差为
`±(a+2b,−2a−b)`；N=4将(c,d)改变一个Λ单位步，中心差为
`±(2c,2d)`。这里的±在固定平移步下各给一个实际单位边。
独立检查器逐一用16维整数平方核验全部24种跨层输运。

### 1.2 不依赖半径截断的同层穷尽

令P的原坐标整数分子之差乘13，记为`D_x,D_y`。统一分母1248。
给该差加ℓ(a,b,c,d)后，只有四个系数可变：

`X=D_x,0+336(2a+b), Y=−144d`，
`Z=144(2c+d), W=D_y,1+336b`。

X,Y分别是x的有理和√3系数，Z,W分别是y的有理和√3系数。
其它十二个系数固定。若向量为单位向量，对八个实嵌入取平均得

`X²+3Y²+Z²+3W² = 1248²−Σ_{axis,k≥2} r_k D_axis,k² = B`。 (1)

这里`r=(1,3,11,33,5,15,55,165)`，右端是已知整数。
B<0时没有候选；B≥0时正定式给每个变量明确的有限界。
再加上整数平移的必要且充分同余条件

`X≡D_x,0 (mod336), W≡D_y,1 (mod336)`，
`X−D_x,0−W+D_y,1≡0 (mod672)`，
`Y≡0 (mod144), Z+Y≡0 (mod288)`。 (2)

由(2)唯一恢复a,b,c,d。对每个候选再展开完整的八个根式系数，
只保留平方和恰等于1者；仅满足迹方程当然不够。
反过来任何真实边都满足(1)(2)，故这种枚举没有遗漏任意远平移。
这是T061的正定迹编译机制在本宿主上的新具体应用。

生产器按(X,W)/(Y,Z)配平方和，独立检查器按(X,Y)/(Z,W)配对，
并以gcd根式乘法复核单位等式，不导入搜索器。

全部259081个有序核心点对共有89247种差，其中15895种有非负
迹预算，共2062个不同差的迹候选。最后得到8008条有向接触实例，
49种平移差，其中3124条为非零平移接触。
1508条同时使用JΛ方向，且其编号对在原P中并不相邻；因此不能
把全部接触重新投影成原核心边来得到T070式图积分离。

### 1.3 这份有限描述没有假设染色周期

每条记录保留确切整数位移，源顶点仍有六个无界整数指标。
这是成熟的voltage/gain graph描述：有限编号图加整数边标签，
其派生图顶点为“编号×整数群”。本地直接证明了它与实际单位图
同构，不依赖抽象表示自动提供染色。

重读了[Jonoska–Krajčevski–McColm，§3](https://pmc.ncbi.nlm.nih.gov/articles/PMC5012322/)
的标签定义与派生图构造作概念核对。这里的Z⁶作用是抽象自由移位，
不是声称平面中存在六维离散晶格，也没有使用“最优染色必周期”。
将整数标签取模会另外增加颜色相等要求；商图负结果仍不能反推源图。

## 2. 旧颜色置换确实失败，但不是五色下界

位移`T=(3,0,4,0)`给`ℓ(T)=(21/13,12/13)`。
P与P+ℓ(T)之间有31条单位边，它们在指定旧五色词下给出16个
禁止颜色对。独立枚举120种相对颜色置换，全部至少冲突一条边。
这真正越过了上一轮“每份核心只换旧色名”的正构造。

但这个完整1018点、4915边的双核心图本身仍恰五色：其坐标全在K，
可直接把F11五色表拉回。新的两份颜色词已经逐条检查全部诱导边。
不把“指定旧分区无法相容”包装成新的六色核心；这是C008一类
机制在新几何上的再次出现，不另命名为新的普适障碍。

## 3. T073：两个共振方向同时无限延伸，仍恰五色

除了T再选实际接触位移`U=(-4,1,-1,-3)`。令S₀为T071的16个
平移指标，令M=ZT+ZU⊂Z⁴，并定义

`Y=P+ℓ(S₀+M)+αΛ`。

**Y的整个完整诱导单位图恰五色。** kT、lU和α中心的两个指标
全部无界，不是四个簇或七个中心的有限样本。

### 3.1 全部簇间接触

S₀在Z⁴/M中的16个陪集两两不同。这个有限条件由解下列整数方程
对全部S₀差直接验证；结合T072，Y内所有表达也唯一。

任意记录产生s→t的簇位移，当且仅当

`s+Δ−t = kT+lU = (3k−4l,l,4k−l,−3l)`。 (3)

同层Δ来自T072全部8008条记录；跨层Δ来自十二个Λ/JΛ单位步，
两种实际中心符号都保留在其几何证明中。式(3)可直接解出k,l，
没有簇半径截断。完整编译得到108906条有向关系，簇差只有
`(0,0),(±1,0),(0,±1)`。
所以这里没有漏掉未放入四簇试验的对角线或更远相邻簇。

### 3.2 四份自由核心词与显式公式

按T071证书的S₀次序，取16个颜色偏移

`φ=(0,4,3,3,4,4,3,4,3,3,4,4,3,4,3,0)`。

不冻结旧核心词，联合求出四份509字的五色词
`C_00,C_01,C_10,C_11`，完整内容在本轮证书中。
用公式

`c(p_i+ℓ(s+kT+lU)+αz) = C_(k mod2,l mod2)(i)+φ_s mod5`。 (4)

对108906条关系、四个起点奇偶状态，独立检查全部435624个
端点颜色不等式。端点的目标状态由真实的k,l改变计算；没有固定
核心端口名单或假定颜色激活。正表使(4)成为全域合法五染色。
Y含P，故χ(Y)=5。证毕。

求解端只有2036个核心颜色变量和70760条不同的边颜色禁配子句；
这是获得正证据的参数化。检查端不运行求解器，仅验证给定颜色词。
若这个参数化失败，同样不能认定Y不可五染。

## 4. 剩余方向真的存在，不能把Y写成X

证书还给出另外两条实际接触位移

`V=(-4,3,0,0), W=(-3,4,4,-1)`。

四个向量T,U,V,W组成行列式绝对值1的整数矩阵，所以确实生成
整个Z⁴。这不仅是数值秩观察，独立检查器展开24项整数行列式。
T073只处理前两个无界方向，不包含V、W的任意整数组合。

将T073的颜色强行投影到全部四指标模2会发生颜色不一致：其64个
“S₀标签×两簇奇偶”状态压成16类后，没有一类自动得到一致颜色词。
所以不能省略缺失方向，再宣称已有整个X五染色。

探索过若干3/5/9状态线性模型及四指标奇偶模型。有的预算内返回
UNSAT，有的UNKNOWN，均未生成独立负证书；不登记为负定理，
更不能当作实际源图不可五染。完整X和整个K²+αΛ仍未决定。
