# R2026-MOMENT-F：真正的五色三点共同律存在，但不存在全平面五染

2026-11-03。**完整书面证明；不是6/7终局。**本定理把[二点PSD到三点的桥](plane_coupled_moment_bridge_20261103.md)推进一层：第一个Bessel伪律虽在三点失败，但另有**同时保留所有二点边缘、任意三点局部合法**的五色模型。该结果利用经典的圆盘避距集合；不主张圆盘构造、分数色数或低阶矩技术的文献首创。

## 1. 精确命题（全部平面点集，不是固定Y）

对每个有限点集 F⊂R²，|F|≤3，记 Col_5(F) 为严格排除全部实际单位距离同色边的标号集合。

**定理F。** 存在一族概率 μ_F，索引为**所有**平面点集F（|F|≤3），满足：

1. 每个μ_F支持于Col_5(F)，且单点边缘均匀在5色上；
2. F⊂F' 且 |F'|≤3 时，μ_F是μ_F'的真实边缘；不是分别构造互不相容的三点law；
3. μ_F对平移、旋转、反射及五种颜色标签的全部置换不变；
4. 其二点核连续、径向、逐对非负，并满足所有有限点数的**全部颜色-位置分块PSD**条件。

然而这族 μ_F **不能**延伸为所有有限F的共同合法五色law：若能延伸，紧致性将产生全平面合法五染，与OpenAI Family158的已独立验证下界矛盾。

因此，**甚至真实的“全部三点一致性 + 全空间二点PSD”也不足以证明χ(R²)≥6**。这严格强化了R2026-MOMENT-D中某一Bessel伪核本身在三点失败的现象；不等于所有三点核都失败，也未判定四点层是否足够。

## 2. 一个完全显式、密度超过1/5的单位距离自由集合

取三角格
\[
L=\{m(2,0)+n(1,\sqrt3):m,n\in\mathbb Z\}.
\]
任意非零格位移的平方长为4(m²+mn+n²)≥4，故格点之间至少距离2。

令
\[
A=\bigcup_{\ell\in L}B(\ell,1/2)
\]
为每个格点周围的**开**圆盘的并。任意两个同一圆盘内的点距严格小于1；不同圆盘中的任意两点距离严格大于1。故A的任意两点都**不**相距1，边界不会制造等号。

基本平行四边形面积2√3，每个格点的圆盘面积π/4，开圆盘互不重叠。所以
\[
\delta=\mathrm{density}(A)=\frac{\pi}{8\sqrt3}>\frac15.
\]
最后一个严格不等号不依赖数值近似：π>3，√3<7/4，故δ>3/14>1/5。该避距圆盘阵列属于已有经典构造，而不是项目新发现。

## 3. 从单个独立集生成全域不变二点核

取随机角度R∈SO(2)为Haar均匀；独立取T为L一个基本域中的均匀平移。定义
\[
X(x)=\mathbf1_A(R^{-1}x-T)\in\{0,1\}.
\]
对任意x有E X(x)=δ；该二值随机场对**全部**平面平移、旋转及反射分布不变；对每对单位距离x,y有X(x)X(y)=0（甚至逐个随机样本成立）。

定义
\[
q(x-y)=\frac{\mathbb E[X(x)X(y)]}{\delta}.
\]
此q连续、径向、在[0,1]内，且q(0)=1、q(z)=0当|z|=1。q的连续性来自有界密度圆盘集在紧环面上的L¹平移连续性，再对R平均。

对所有颜色数k≥5，令
\[
f_k(z)=\frac{kq(z)-1}{k-1},\qquad
Q_{ij}(z)=\frac1{k^2}+\frac{\mathbf1_{i=j}-1/k}{k}\,f_k(z).
\]
于是Q_{ii}(z)=q(z)/k、Q_{ij}(z)=(1-q(z))/(k(k-1))（i≠j），是一致均匀边缘的非负二点表；同点异色零、单位边同色零。

证明整个分块PSD：设Y(x)=X(x)-δ，协方差核
\[
C(z)=\mathbb E[Y(x)Y(x+z)]
\]
是正定核，且q(z)=δ+C(z)/δ。因kδ>1，
\[
f_k(z)=\frac{kδ-1}{k-1}+\frac{k}{(k-1)δ}C(z)
\]
为正定核。颜色空间分解
\[
Q(z)=\frac1k P_\parallel+\frac{f_k(z)}k P_\perp
\]
给任意有限点数、任意复系数的PSD。这个步骤是**对完整全空间二次检验的证明**，不是小规模Gram实验。

## 4. 所有三点的联合分布同时存在

定义不同色概率D(x,y)=1-q(x-y)。由于X为真实二值随机场，
\[
2δ D(x,y)=\Pr(X(x)\ne X(y)).
\]
事件的三角并界表明，D是整个平面上的伪距离：
\[
D(x,z)\le D(x,y)+D(y,z).
\]

现在对任意三个**互异**点x₁,x₂,x₃，令p_{ij}=q(x_i-x_j)，s=p₁₂+p₁₃+p₂₃。设置如下五种等价关系划分的概率：
\[
\begin{aligned}
a&=\max\{0,(s-1)/2\} &&\text{三点同色};\\
b_{ij}&=p_{ij}-a &&\text{恰好i,j同色};\\
c&=1-s+2a &&\text{三点全异}.
\end{aligned}
\]
它们全非负，和为1。关键是a≤min p_{ij}：若a>0，此条件与三个三角不等式1-p_{ij}≤(1-p_{i\ell})+(1-p_{\ell j})完全等价；否则显然。c≥0来自a的定义。

以这些概率抽取五种划分，随后将划分的不同块**无放回地均匀分配到五种颜色**。对任意一对i,j，同色概率恰为a+b_{ij}=p_{ij}，由颜色置换对称得到完整二点表Q。三点法则只依赖三项距离、对点交换对称，因而对全部平面等距变换不变。

若某对点距离为1，其p_{ij}=0，因此所有该对点同色的划分概率均为0；故抽到的三点染色严格合法。

对于单点、双点，直接取上述三点概率的边缘（等价地，单点均匀、双点同色概率q）；任何三点法则在任意二点上的边缘都相同，**无论第三个点是谁**。所以由此定义的全部|F|≤3的μ_F精确射影相容。定理的四个存在性条件证毕。

## 5. 为什么这是严格的层次分离，而不是完整平面五染

若有一份覆盖**所有有限**点集的共同law，限制到每个F仍合法，特别每个有限Col_5(F)非空。由图染色紧致性得整个平面的五染，矛盾。这一步使用外部已验证的χ(R²)≥6；它不定位第一个失败的四点、五点或更大窗口，也没有提出一个有限NON5图的坐标。

结论的精确范围为：

- 二点PSD+真实二点非负：k=4已可行（见R2026-MOMENT-B/C）；
- 更强的**所有三点真概率＋彼此兼容＋二点PSD**：k=5已可行（本定理）；
- 所有有限点真概率且共同兼容：k=5不可能（外部Family158），k=6目前未知。

因此当前研究主线不能再假设三点一致性足以弥补全部谱伪律：必须继续寻找至少四点、并最终足以处理所有有限配置的颜色身份耦合。**“至少四点可能需要”不等于“四点一定足够”。**

## 6. 反向校准与来源

在单位等边三角形中p₁₂=p₁₃=p₂₃=0，上述law确实把全部概率放在“三点全异”；对任意三点，概率非负等价于D的三角不等式，可通过有理样本校准，但一般性由本证明承担。
