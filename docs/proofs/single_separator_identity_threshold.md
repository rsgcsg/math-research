# T173：单个 T165 separator 的身份稀疏化阈值恰为 71

2026-10-06（Australia/Brisbane）。接续 T172。本节不是新的 full15 分离式，而是精确决定一个受限方法族的能力上限：只允许使用 T165 的那一个 89 项 separator、三个 P/Q/R class-total 等式、概率盒，以及把若干具体事件边际固定到 C030 目标值。

## 1. 问题

T165 在七窗口边界面上给出

\[
\alpha\cdot x\le 2,
\]

而 C030 目标 \(t\) 满足

\[
\alpha\cdot t=169/27,\qquad
G:=\alpha\cdot t-2=115/27.
\]

若固定一组具体事件 \(S\) 使 \(x_e=t_e\)（\(e\in S\)），其余事件 \(F\) 仍只受

\[
0\le x_e\le1,\qquad
\sum_{e\in C}x_e=|C|t_C,\quad C=P,Q,R
\]

约束。问：至少要固定多少条具体事件，单靠上述 separator 才能推出矛盾？

## 2. 一类内部的精确最优逃逸

先固定一个类 \(C\)，目标同色率为 \(t\)，留下 \(m\) 条自由边，其 separator 系数排序为

\[
a_1\le a_2\le\cdots\le a_m.
\]

类总量约束要求

\[
\sum_i x_i=mt,\qquad0\le x_i\le1.
\]

为了尽量逃离 C030 的 separator 违例，需要最小化 \(\sum_i a_i x_i\)。这是盒与单个和等式上的标准交换论证：最优解先把最小系数坐标填到1，再至多一个分数坐标，剩余为0。写

\[
mt=q+f,\qquad q=\lfloor mt\rfloor,\quad0\le f<1,
\]

则

\[
\min\sum_i a_ix_i
=
\sum_{i=1}^q a_i+f a_{q+1}.
\]

因此这一自由系数集合可提供的最大 separator 逃逸为

\[
E_t(a_1,\ldots,a_m)
=
t\sum_i a_i-\sum_{i=1}^q a_i-fa_{q+1}. \tag{1}
\]

现在还可以选择哪 \(m\) 条边留自由。式 (1) 是所选系数按序位置的线性函数。检查器按原类全部系数从小到大扫描，以动态规划精确选择第 \(j\) 个自由系数；全程只用有理数，没有 LP 或浮点优化。

## 3. 三类合并后的精确阈值

对 P 的47条、Q 的11条、R 的31条分别计算所有自由条数 \(m_C\) 的最小可能逃逸，再遍历

\[
m_P+m_Q+m_R=89-k,
\]

其中 \(k\) 是固定到目标的具体事件数。

在临界附近得到：

| 固定事件数 \(k\) | 最小“最佳逃逸” | 一组最优自由条数 \((m_P,m_Q,m_R)\) |
|---:|---:|---:|
| 65 | \(2473/270\) | 由检查器给出 |
| 66 | \(2143/270\) | 由检查器给出 |
| 67 | \(69/10\) | 由检查器给出 |
| 68 | \(1603/270\) | 由检查器给出 |
| 69 | \(136/27\) | 由检查器给出 |
| 70 | \(\mathbf{115/27}\) | \((11,2,6)\) |
| 71 | \(\mathbf{32/9}\) | \((10,2,6)\) |
| 72 | \(77/27\) | 由检查器给出 |

关键是

\[
E_{70}=115/27=G,\qquad E_{71}=32/9<G.
\]

所以：

- 固定至多70条事件时，总能在这个放松中把 separator 至少降回2；因此**单个 T165 separator 不能严格推出矛盾**。
- 存在固定71条事件的选择，使剩余18条自由边即使最优调整，也只能提供 \(32/9\) 的逃逸，小于所需 \(115/27\)；因此**71条已经足以让这个受限放松矛盾**。

故阈值恰为

\[
\boxed{71}.
\]

## 5. 意义：旧 separator 不能被轻易压成“小边集定理”

T172 已说明具体边身份必不可少。本节进一步量化：如果只拿 T165 这一个 separator，再辅以三类总量和概率盒，那么要靠“固定若干具体边到目标”来得到矛盾，需要固定到 89 条中的 71 条。

这不是说真实边界多面体一定需要71条身份。相反，它说明**继续对同一个89项式做删边、gauge 或 class-total 消元不是有希望的小证书路线**。一个真正可运输、少量具体边的突破必须提供新的独立有效不等式、多个 separator 的联合，或更高阶颜色关系。
