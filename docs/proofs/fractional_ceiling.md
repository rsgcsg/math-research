# T023：单色独立集的全阶全等约束也不能提供六色下界

本命题是一个简单的路线排除引理，不宣称改进已有分数色数上界。
它明确覆盖项目中可能被误认为超越普通fractional限制的geometric版本。

## 精确命题

令G为任意有限欧氏单位距离图。在所有独立集J⊂V(G)上赋非负权w_J，
要求每个顶点的覆盖权至少1，并对任意两个全等顶点子集A,B要求

`Σ_(J⊇A) w_J = Σ_(J⊇B) w_J`。

这里允许所有阶数的子集与所有平面刚体运动，不只二点距离约束。
那么总有一个可行权重系统，使

`Σ_J w_J = 8/√3 < 5`。

这个线性系统就是[Dúcz原文第1节](https://arxiv.org/html/2606.12325v1#S1)
所回顾的geometric fractional coloring定义。故任何有限G的该放松值
都不可能超过5，不能用它的值>5证明原始平面至少需要六色。

## 显式周期独立集

取间距2的三角格L，其基本域面积为2√3。在每个L点放置一个外接圆
半径1/2的同向正十二边形的开内部，令S为这些开区域的并。

同一块中两点的距离严格小于1；不同块的中心距离至少2，两点到各自
中心的距离严格小于1/2，所以彼此距离严格大于1。因此S不包含单位对。

每个十二边形面积为`(12/2)(1/2)² sin(π/6)=3/4`，故面积密度为

`d=(3/4)/(2√3)=√3/8`。

## 随机刚体运动生成全部一致权重

先对S作基本域中的均匀随机平移，再作均匀随机旋转和公平随机反射，
得到随机独立集X。其分布在任意平面刚体运动下不变：平移对应于基本
环面上的均匀变量平移；旋转、反射对应于方向变量的保测变换。
每个固定点属于X的概率都为d。

对给定有限G定义

`w_J = Pr(X∩V(G)=J)/d`。

非独立J的概率为0。总权为1/d，每点覆盖权恰为1；若A、B全等，
刚体不变性给出`Pr(A⊂X)=Pr(B⊂X)`，因此全部全等约束同时成立。
最后`(8/√3)²=64/3<25`，所以总权严格小于5。证毕。

若将十二边形换成半径1/2的开圆盘，同样的证明给出更强的
`8√3/π≈4.4107`；这里使用较弱的代数常数，已足够排除>5路线。
没有用数值积分、采样或有限周期UNSAT证明无限结论。

## 这排除什么、不排除什么

- 普通fractional与所有阶数的单色全等矩约束，均不可能通过>5给出
  六色下界。继续加这类线性约束不会逃出该显式可行解。
- 不排除用这些方法获得>4从而证明至少五色；上界本来就大于4。
- 不排除完整多色joint relation：这里的随机对象只有一个独立集，
  并不是五个互不相交且覆盖整个平面的独立集所构成的随机划分。
- 不排除具有真实五色核心的非线性/整数组合矛盾、或六色全平面构造。

下一模型必须保留不同颜色类之间的互斥与共同覆盖，而不是只保存一个
颜色类的边缘分布。这是从单色矩到完整颜色模式分布的实质区别。
