## 1. 结论先行：方向有效，但必须改变成功标准

当前路线没有逻辑上跑偏：我们确实得到宿主上界、普适延伸、完整
边界关系和反例。但**并没有证据表明接近HN终局**。越来越熟悉一个
21点模板，可以产生真实定理，却仍可能只是在解释一个很特殊的
低色世界。不能用定理编号增长估计离终点的距离。

本轮不再把“八个坏gate能否失败”作为首要问题。先问两个更小的
机制问题：原NAE摘要到底丢掉了什么？跨内部边是否真的利用这份
被丢掉的信息？T046–T047已给肯定、可独立检查的答案：非空根点
支持可以是单点；两个各自可延伸的真实gate，由跨边变成联合不能
延伸某份边界。全图仍χ=4，因此activation与逃离安全域仍是两道硬门。

合理的阶段成功标准是：关闭一个具有明确量词的大类，或发现能
通过几何验证的新关系，再检验它是否逃过宿主上界与全边界逃逸。
没有基础给出“这条路有多少百分比解决HN”。近期再产生小结构
定理是现实目标；据此声称最终解答很可能出现，没有可校准依据。

## 2. 一个比“七轴凸包”更小的中心对象

对有限图G与边界B，保留完整关系

`R_k(G,B)={b:B→[k] | b延伸为G的proper k染色}`。

它不是色数、状态数量，也不是每个端口的可取色集合，而是一个
带物理端口标号的联合关系。颜色可整体重命名；几何端口不能任意
重命名。确定关系后，再根据下一次组合将接触哪些顶点选择摘要。

最实用的组织是三个问题，而非为每个类比增加一层体系：

| 层 | 真正要问什么 | 已有典型结果 |
|---|---|---|
| 宿主与几何 | 哪些有限关系系统真能出现？有没有统辖它的低色上界？ | T028、T029、T032、T035、T041–T045 |
| 精确接口 | 消去私有点后，哪些联合赋值仍可出现？ | T026/T027、T033/T036、T037、T046 |
| 全局量词 | 所有模块是否有一个共同选择？能否排除所有边界逃逸？ | T020/T021、T038–T043、T047 |

组合的基本运算是“合取全部真实约束，然后存在量化私有变量”。
若未来跨边触及一个已消去的内部点，就必须重新暴露它或重新计算
更大模块；不能沿用旧边界布尔谓词。T047就是这个原则的具体证据。

几何incidence capacity确实有独立价值，但不是固定的因果单行道：
颜色会选择修复超边，选中的姿态会制造新边，新边又改变精确关系。
适合做相互筛选，不宜宣称已得到一套对所有UDG有效的统一分解理论。

## 3. 参考文档中必须修正的逻辑跳跃

1. **边界延伸失败不自动编译成无条件高色图。** 七点spindle在三色
   名单下坏，或T047的40点三色边界坏，都不提供不可五染图。
   “找到了一个local-global gap，就可closure成下界”缺少真实activator。
   必须明确谁强制了那份边界，且排除宿主的其他五染色。
2. **修复动力学不是通向UNSAT的蕴涵链。** 一次重染失败、状态图不连通、
   存在冻结解都可与许多完整染色并存。不能把reconfiguration separation
   当作比UNSAT“只差一级”的证据；它们回答不同问题。
3. **局部度≤2不是全局度≤7。** Haxell型独立横截定理需要全局最大度Δ
   和分块大小≥2Δ等假设；14端口只在另证Δ≤7时有直接用处。端口可被
   任意多个其他模块邻接。重叠边界若改成出现拷贝，还须控制复制后的度数。
   更重要的是，独立击中只解决T043的正约束，不保证负全选约束成立。
4. **低宽度不自动等于任意预染色延伸。** 五片叶子分别固定五色的星图
   已使中心无法五染，尽管图是树；而无预染色的同一星图只需两色。
   宽度帮助计算完整关系，不能代替名单条件或非空证明。
5. **几何位于平面不等于planar graph。** 单位边可以交叉；若把所有
   候选误限为图论平面图，则四色定理已封死六色下界。

这些修正不是否定参考框架，而是为每个箭头补上缺失量词。

## 4. 旧结果实际只在反复揭示几个机制

### 宿主上界与信息擦除

T028一次解释Parts域内所有六色搜索失败，比逐个端口计数更强。
但它不证明任意预染色延伸：T047仍在安全域内，却有真坏边界。
因此“全图能染”和“某份旧染色能延伸”不能合并为一种柔性。

T026/T027说明Parts特定小接口关系为满；T007–T009的颜色稳定子
说明无参考的确定传输会被额外颜色和对称性破坏；T023/T024则说明
单色矩主动丢掉多色joint信息。三者都属于信息压缩，但各自丢失
的信息不同，不可用一个“秩很小”的口号代替具体核与纤维。

### 几何筛选与列表可约性

T032是成对轨道的正确正规形；T033是小规模任意名单全覆盖；T034
来自成熟list-Brooks而不是ordinary三染色；T035利用**实共轭**平方
和排除抽象可写但实几何不可能的关系；T036只关闭六轨道共同名单。
历史六轨道非均匀名单、原28点Galois几何仍未重放，不能被整理升级。

T041是有限距离标号图的部分等距映射分类，T045是两姿态相差单位
平移的短证书。成熟群作用与距离矩阵语言确实使它们自然，但二维
rigidity的“方程数多于自由度”不是不可实现证明：约束可能依赖。

### 修复与耦合

T037由两个三角形加桥的局部名单恒等式解释，没必要再用更大SAT
认证普适量词。T046保留根点支持，是同一恒等式自然的下一步。
T039是特定单颜色修复的Property-B问题；T042依赖真实端口稀疏性
及七点交换，不是所有超图的一般二染色定理。C005只展示可逃的级联。
T047进一步展示：模块自身“好”并不足够，跨内部边可冲突其强制根色。

### 路径与闭环

T031的递推可写成行列式1的2×2传递矩阵，有限周期关联单位根；
这是Chebyshev/代数整数语言的成熟重写。但不同中心有平移项与
几何可行域，不能把矩阵乘积不为恒等直接当颜色矛盾。
T020/T021的完整frame集合传播是正确范例；C004已证明Galois符号
不平衡可以与完整五染色并存。先计算真实多值关系，再考虑holonomy。

## 5. 哪些远领域连接值得使用，哪些暂不升级

| 连接 | 现在能具体做什么 | 当前缺失或停止条件 |
|---|---|---|
| CSP／关系数据库／消元 | 精确保留接触点支持，计算关系合取与投影；T046→T047已实用 | 抽象pp构造还须二维真实实现，不能任意复制线缆 |
| Boolean／计数／概率半环 | 同一几何与边界索引上，区分可行支持、染色数、概率分布 | 不同权重语义不能混用；局部概率相容不保证全局分布 |
| junction tree／动态规划 | 在running-intersection分解中匹配完整分离集状态 | 树状分解不保证消息非空；循环不能仅查单点边际 |
| list-Brooks／Gallai树 | 直接简化T034、T037与T046 | 已能短证时不继续扩大通用计算 |
| Property B／LLL／独立横截 | 给明确交叠度、全局度条件下的充分修复区间 | 不推断本模板所有稀疏超图都可修；不忽略T043负约束 |
| 实代数几何／平方和 | 先用正性证书排除抽象几何；T035已有实例 | 数值SDP不可代替精确恒等式，维数计数不可代替不可实现 |
| 赋值／模型论 | 扩大严格安全域；把终局准确归约到代数坐标 | 一个域或所有二次塔不等于所有代数数；密度论证无效 |
| SA／SoS／joint松弛 | 若有真实候选，找最先失败层并提取精确对偶 | 同一G27已饱和；不要为提高阶数而提高阶数 |
| circular／fractional／vector | 可作为有限图诊断，必须写明松弛方向 | 非整数“颜色”不是实数个标签；压力指标不能替代整数反证 |
| connection matrix／tensor | 有多个真实耦合样本后比较保留支持与计数的差异 | 满支持可以有复杂计数，高rank不自动意味着更强排除力 |
| sheaf／cohomology／Hom复形 | 仅在已找到明确状态与转移后研究非平凡不变量 | 当前没有颜色torsor或确定转移；不先造母范畴 |
| Potts／冻结相／纠错码 | 帮助命名“解很多／重染受限／无解”的区别 | 没有热力学极限或可比随机样本，不能据此预测5/6/7 |

一个很小的概率警示例：三个二元变量分别受`x=y,y=z,x≠z`约束。
每个约束取两个合法词各1/2，所有单点边际一致，但不存在联合解。
反过来，**全部有限变量集**上一致的完整联合分布与仅几个边际
不是一回事。Atserias–Kolaitis的关系/概率一致性框架正好区分这一点。

参考文档的polymorphism猜想也不能从“小实例皆可染”推断：关系
语言是否有特殊运算取决于全部关系，几何可实现的实例子类限制未必
来自模板代数。这里暂不新开“寻找神奇majority”的长期支线。

## 6. 上下界的真正连接，以及算术路线的准确终点

在通常使用选择公理的框架下，de Bruijn–Erdős紧致性给出：对固定k，
全平面可k染，当且仅当每个有限二维单位距离图可k染。因此上下界
是同一个全称命题的证明与反例搜索，不是动力学的两种状态。

更具体、值得重新强调的成熟结果是

`χ(R²)=χ(A²)=sup_{E⊂R为数域} χ(E²)`，

其中A为实代数数域。Madore §5.4已经明确给出第一等式，非本轮首创。
任意有限实点配置的单位边、点互异及非单位对都可用整系数多项式
等式/严格不等式表达；实闭域转移给出代数坐标的同一诱导图。
有限多个代数坐标生成一个数域E，再用图染色紧致性得到第二等式。
这不是“代数数稠密，所以近似不改变单位边”的错误连续性论证。

这一等式说明数域路线**原则上足够触及整个普通HN**，无需新增可测
或周期假设。但量词是所有实数域：T028覆盖一个域，兼容F11的安全
扩域仍非全部；仅研究多二次域或可尺规构造数也没有证明覆盖所有
有限实现。若只证明越来越多而不共尾的安全域，仍不能推出全平面上界。

对上界有用的具体目标不是“再找一个可五染有限表”，而是给出一类
扩域闭包定理，并清楚说明闭包最终覆盖哪些坐标。对下界则先问任何
候选是否被已知安全域包含，再花钱算染色。T047亦遵守这一筛选。

## 7. 5／6／7：严格证据与模型隐喻分开

本轮检索没有找到改变普通问题公认5到7区间的可信证明。de Grey
给有限不可四色图；经典七色铺砌给上界。新map-type七色结果依赖
区域边界假设，不能代替普通版本下界。三种可能的终局任务分别是：

| 答案 | 必须拿出的决定性证据 |
|---|---|
| 5 | 全平面五染色，或所有有限二维UDG五染色的普适定理 |
| 6 | 有限不可五染UDG，外加全平面六染色／普适有限六色定理 |
| 7 | 有限不可六染UDG；七色上界已知 |

“六色障碍需要高incidence或高interaction width”目前也只能是某些
模板的经验筛选，不是所有六色UDG的已证必要条件；不可把它当作
新的无条件结构假设。

旧三角格“7零defect、6一defect、5更强重复”的三相只是一类局部
校准。C001–C003已否定自动matching等关键桥梁，不能恢复成普遍
相分类。答案7也不逻辑要求先单独造恰六色图；可以直接找到不可
六染图，但当前项目尚没有越过第一道五色障碍。

有限图的circular参数满足`χ−1<χ_c≤χ`且`χ=ceil(χ_c)`；因此
`χ_c>5`确能给六色下界，但不是比证明不可五染天然更轻的捷径。
对无限图不在此使用未经证明的最优圆染色取得性。非整数Potts参数
可有解析意义，却没有“用了5.3种实际颜色”的直接语义。

连续得到修复定理不支持答案更可能是5：我们专挑这种模板研究，
样本具有强选择偏差；一个有限反例就足以改变下界。这不是统计投票。

## 8. 本轮实际选择与下一处最小障碍

### 已执行：接触点支持，而非继续坏gate计数

T046给根点支持的两失败刚性，任意调色板成立；五色三名单另有
1000→110个签名的独立完整覆盖。T047构造40点/81边的真实耦合，
零个单模块坏gate也可联合不能延伸选定边界；但整图恰四色。
完整证明与证书入口见[rooted_coupled_gate](rooted_coupled_gate.md)。

这不是HN突破，但确实回答了参考文档最小的机制问题：保留T045
原来禁止的边，能获得严格强于两个NAE谓词合取的关系。接下来不能
再只数“好／坏gate”，必须保留接触点支持；多接触时保留联合支持。

### 优先次序：只保留两条主线

1. **离域后的接触支持与activation。** 先找逃过T028的真实耦合，
   再问边界宿主的完整关系是否仍能避开根点强制冲突。最小证明目标
   是一个可实现的宿主逃逸定理，或一个完整边界关系确实被压入坏集
   的有限证书；失败也可证明一类root-forcing activator不可能。
   七匹配耦合的完整关系可按需查询，不先穷举26点全部边界。
2. **算术安全域的扩域闭包。** 对K(√13)先明确任意赋值深度的边
   应如何编码；寻找跨层兼容引理或一个精确编码反例。T030只排除
   固定积分窗口，不能从无界深度断言必须无限状态。成功若仅覆盖
   该域，诚实标作该域上界；若能统一闭包规则，才考虑更广数域。

保留但不立即展开：历史六轨道任意非均匀名单的认证恢复；它是
明确量词缺口，不应遗忘，但相比本轮短根支持引理，恢复包不应
吞掉核心推导时间。clean Property-B继续作为筛选库，不优先追8→9
等数字。R4、统计高阶、circle/rank与Kempe大状态图暂不新开搜索。

若两轮之后只是在安全域内获得更多边界坏例、却没有新的域外几何
或activation判断，应停止这一样本扩张。一个能实际改变终局量词
的no-go，比十个条件失败例更重要。

## 9. 本轮外部证据的实际使用范围

- [Madore, §1.3与§5.4](https://arxiv.org/html/1509.07023)：重读紧致性与
  实闭域论述；实代数平面等价是成熟结果，本文补写保留诱导非边的公式。
- [Loh–Sudakov, Theorem 1.1](https://arxiv.org/html/0706.2124)：局部稀疏
  独立横截仍需全局Δ、比例分块及渐近量词，未直接加强T042。
- [Atserias–Kolaitis, §§4.1–4.3](https://arxiv.org/html/2009.09488)：核对
  running intersection、join tree、Theorems 2/3及概率一致性表述，
  用于区分完整关系与局部边际；本文小反例独立可查。
- [de Grey](https://arxiv.org/abs/1804.02385)：普通问题五色下界原始来源。
- [Sokolov–Voronov](https://arxiv.org/abs/2502.01958)：只核对摘要中
  map-type七色结果的额外假设，不把其结果挪到任意普通染色。
