## 2026-09-19：六次宿主的精确答案与三色结构定理

[T125–126 / E095–096：完整证明与证据](docs/proofs/salem_sextic_four_coloring.md)
解决了上一checkpoint明确留下的六次 `3≤χ≤4`：

- 若 α 是 `X⁶−X⁴−X³−X²+1` 的非实单位圆根，则整个
  `U(Z[α])` 与 `U(Q(α))` 都恰四色，而且整个宿主无三角形。
  上界覆盖所有分母；这不是 `Q(α)²` 或整个平面的结论。
- 在同一加法群上，只列出前N个连续幂单位方向时，色数恰为：
  N=1–6时2色，N=7–12时3色，N≥13时4色。
  证明排除任意三染色，不假设它是线性、周期或有限精度染色。
- 另给114点267条全部实际边的顶点临界四色诱导图：821节点不可三染
  证书与114份删点三染色均独立核验。不主张最小点数或文献优先权。

机制是阿贝尔 Cayley 图的三色高度周期判据：真实关系格上的周期必须
同时满足模3、奇偶和1范数界，反过来这些条件也足够。
七条五步关系、十个整数分离式即可排除全部128种符号。
这是一项已证明的局部推进，**不是 HN 六色下界或六色上界**。
